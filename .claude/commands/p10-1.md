# P10-1. 무전 기록 패널과 전술상황판(평면도) 분리 (단계 5 보강)

> 사람용 메모(실행 전에 사람이 할 일):
> 기존 프로젝트에서 P10까지 끝난 뒤 넣습니다.

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md의 9-2, 9-2-1, 9-3을 읽고 HUD를 다음처럼 바꿔줘. 게임 로직은 건드리지 말고 UI만 바꿔.

1) 오른쪽 패널 = 무전 기록 전용(RadioLogPanel.tscn)
   - 기존 상황 요약·팀 카드·확인 필요는 여기서 빼.
   - RadioBus의 메시지를 최신이 맨 위로 쌓아(최대 200건, 오래된 것부터 삭제). 항목: 현장 시각, 발신자, 내용, 우선순위 색(대원안전 빨강/구조대상자 주황/일반 흰색).
   - 답한 질문 카드는 "N팀 질문 → 내 답" 한 줄로 등록.
   - 항목 클릭 → 그 대원/장소로 카메라 이동(없으면 무시).
   - 필터 탭: 전체 / 긴급 / 내 지시.
   - 긴급 고정줄(맨 위 최대 2줄): 긴급탈출, 무응답, 잔압 경보, 물탱크 고갈. 원인이 해결되면 사라짐. 패널을 접어도 고정줄은 남김.
   - 새 메시지가 오면 스크롤이 맨 위일 때만 자동으로 보여 주고, 아래를 보는 중이면 "새 무전 N건 ↑" 배지만 띄워.

2) 팀 초상 줄(TeamStrip.tscn) — 하단 콘솔 가운데 위
   - 팀마다 초상 + 공기잔량 링 + 질문 대기 시 "?". 클릭=선택, 더블클릭=카메라 이동. 숫자키 1~9와 연결.

3) 전술상황판(TacticalBoard.tscn)
   - 기존 M 키 평면도를 이것으로 바꿔. 상황 배지 옆 "전술상황판" 버튼, Tab, M 모두 토글. 반투명 전체 오버레이(화면의 약 80%), 게임은 계속 진행.
   - 가운데: 층 탭(외부/1층/…/옥상) + 평면도. KnowledgeBoard만 읽어 그릴 것(실제 상태 직접 읽기 금지).
     내부: 팀(마지막 보고 위치+보고 시각), 화점, 요구조자(보고/구조), 위험, 검색 완료 빗금, 연기 범위, 호스 라인, RIT.
     외부: 차량·스테이징 슬롯, 소화전·급수 연결, 진입구, 안전구역, 지휘소.
     도면 미확보면 대원이 밝힌 구조만. 보고가 60초 넘게 오래되면 아이콘을 흐리게.
   - 왼쪽 열(지휘): 전략·대응단계, 지휘 조직, 진입대원 통제표(팀·인원·진입 시각·잔압·위치).
   - 오른쪽 열(확인): 확인 필요 항목, 물 현황(잔량·급수원·예상 고갈), 후착대 도착 예정, 요구조자 집계.
   - 팀 아이콘을 방·세대로 드래그하면 기존 진입 지시 흐름(진입 4단계 중 목표·조건)을 그 자리에서 열고, 확정하면 무전으로 나가게 해. 내부 무전 지연 규칙은 그대로.
   - 상황판이 열려 있을 때 질문 카드는 상황판 위(더 높은 CanvasLayer)에 뜨게.
   - 저사양 PC: 상황판은 열려 있을 때만 2Hz로 갱신, 닫히면 갱신 중지.

4) 9-3 조작표와 도움말의 키 설명을 위 내용으로 고쳐.

테스트: GUT로 (a) 메시지 순서가 최신 우선인지, (b) 긴급 고정줄이 해결 시 사라지는지, (c) 상황판이 KnowledgeBoard에 없는 화점을 그리지 않는지 확인. 끝나면 바뀐 파일 목록과 스크린샷 위치를 알려줘.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
