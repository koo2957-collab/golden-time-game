# P10-2. 명령 카드 통일과 환자 집결지 (단계 5 보강)

> 사람용 메모(실행 전에 사람이 할 일):
> P10-1 다음에 넣습니다.

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-1의 '명령 카드 하나로 통일', '구조한 사람은 환자 집결지로 옮깁니다'와 9-3을 읽어라.
현재 문제: (1) 하단 콘솔 명령 버튼(이동·진입·탐색·방수·배연·철수)과 원형 메뉴(임무 단위) 항목이 다르다.
(2) 지휘관 자신의 명령을 내릴 곳이 없다. (3) 구조한 사람을 입구에 그냥 내려놓는다.
먼저 관련 코드를 찾아 보고하고 아래 계획을 승인받아라.

[1. 명령 카드(CommandCard)]
- 명령 항목의 원천은 data/commands.json 하나. 원형 메뉴와 하단 명령 카드가 같은 목록·같은 단축키(Q W E R A S)를 쓴다.
- 선택 대상에 따라 메뉴 세트를 바꾼다: team(진압·구조), ems(구급), vehicle(차종별), commander(선택 없음 또는 지휘관).
  team: 인명검색 / 화점진압 / 경계 / 배연 / 대기 / 철수
  commander: 전략 변경 / 대응단계 / 지원 요청 / 인원 점검 / 구역 지정 / 전원 철수·긴급탈출
  하위 메뉴가 있는 항목(전략, 구역 지정 등)은 같은 칸에서 한 단계 더 펼친다. Esc는 뒤로.
- 팀 좌클릭 = 원형 메뉴. 우클릭은 외부 대원 단순 이동만. 빈 곳 클릭·Esc로 선택 해제 하면 commander 세트.
- 지휘관 명령은 모두 RadioBus로 나가 무전 기록에 남고 DecisionLog 에 기록한다.
- 인원 점검: 각 팀이 인원·위치·잔압을 차례로 무전 보고(내부 교신 지연 적용) → KnowledgeBoard와 전술상황판 진입대원 통제표 갱신.
  일정 시간(params) 안에 응답 없는 팀은 무전 패널 긴급 고정줄에 올린다.
- 예전 동작 단위 버튼과 그 단축키 코드는 지운다. 9-3 조작표와 도움말도 맞춘다.

[2. 구역 지정(ZoneMarker)]
- 안전구역, 환자 집결지, 진입통제선을 외부 지도에 찍는다. 환자 집결지는 안전구역 안에만 놓인다.
- 구급대가 분류소를 설치하면 분류소가 환자 집결지를 대신한다.
- 전술상황판 외부 탭과 미니맵에 표시한다.

[3. 구조자 운반과 인계]
- 인명검색 임무의 '구조' 단계는 '운반 → 환자 집결지(또는 분류소) 인계 → 원래 임무 복귀'로 바꾼다.
  운반 중 이동 속도 배율·공기 소모 배율은 params.json(게임 설정값).
- 집결지가 없으면 첫 구조자가 입구에 도착할 때 질문 카드(data/cards/rescue_dropoff.json):
  1) 안전구역에 집결지 지정(정답, 고르면 구역 지정 모드로) 2) 구급차 옆(구급차 있을 때만) 3) 입구에 두고 복귀(오답).
  3을 고르면 구조자는 그 칸의 CO·연기를 계속 받고, 진입 동선을 막아 통과 속도를 낮춘다. DecisionLog 감점.
- Victim 상태: 구급대 없으면 집결지에서도 천천히 악화. 대원 1명을 '구조자 관찰'로 붙이면 악화 속도 감소(배율 params).
  구급대가 있으면 분류 → 처치 → 이송 순서로 처리하고 상황판 요구조자 집계에 반영.

테스트: 원형 메뉴와 명령 카드 항목·단축키 일치, 선택 해제 시 commander 세트, 인원 점검 무응답 팀 긴급 표시,
환자 집결지는 안전구역 밖에 못 놓음, 집결지 없을 때 카드 발동, 입구에 둔 구조자의 CO 누적 증가,
구조 후 대원이 원래 임무로 복귀.
계획 먼저 보여주고 승인 후 구현.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
