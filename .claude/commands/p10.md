# P10. 화면(투명 오버레이)·무전·전술상황판 (단계 6)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-2, 9-3, 9-4 를 읽어라. 고정 패널 없이 지도가 화면 전체를 쓰고, 나머지는 지도 위 반투명 요소로 띄운다.
업무 시스템이 아니라 게임처럼 보여야 한다.
- 항상 떠 있는 것 4가지:
  1) 왼쪽 위 상황 배지(경과시간·전략·풍향, 배지 클릭으로 전략 선언)
  2) 왼쪽 건물 층 막대(층별 연기·불 색, 대원 점, 클릭·휠로 층 이동, 맨 아래 외부)
  3) 오른쪽 상황판(반투명, 뒤 지도가 비침, 접기·펴기 = 가장자리 화살표 또는 Tab, 투명도 설정):
     상황 요약(화점·요구조자 보고 수·구조·미탐색 층·대원 부상) /
     팀 현황 카드(위치·임무·상태·공기 링·마지막 보고 경과, 오래되면 노랑·무응답 빨강, 대기 질문은 '?',
     클릭 선택·더블클릭 이동·끌어다 놓기 임무) / 확인 필요 항목(미해결 사항 고정, 해결되면 사라짐) /
     무전 기록(최근 순, 답한 질문 카드는 '질문 → 내 답' 한 줄, 누르면 전체 펼침).
     상황판은 무전 로그가 아니라 KnowledgeBoard(보고된 정보) 상태로 만든다. 접으면 팀 초상과 확인 필요 수만 남는 엇은 줄.
  4) 하단 콘솔(스타크래프트식 반투명 띠, 화면 높이 약 18%): 왼쪽 미니맵(도면 전 잠김) /
     가운데 선택 정보(팀 1개=대원별 초상·보직·공기 막대·피로·장비·임무, 여러 팀=아이콘 격자,
     차량=물탱크·펌프 압력·호스·승무원, 선택 없음=출동대 요약) / 오른쪽 명령 버튼(선택 대상에 따라 4~6개, 모서리에 단축키)
- 무전 자막은 하단 콘솔 바로 위 왼쪽.
- 카메라(마우스 우선): 화면 가장자리 20px 안에 마우스가 있으면 그 방향 스크롤(속도 설정), 휠 버튼 끌기로 지도 잡기,
  휠 줌(단계 3~4개), 팀 초상 더블클릭·카드 일러스트·무전 자막 클릭 시 그 위치로 이동, Home 은 지휘소. 방향키는 보조.
  창 모드에서도 가장자리 스크롤이 되도록 게임 중에는 Input.MOUSE_MODE_CONFINED, Esc 메뉴에서 해제. 맵 경계 밖으로는 못 나가게 제한.
- 무전 자막: 화면 아래 반투명 2~3줄, 발신자 작은 초상, 5초 뒤 흐려짐, 위험 보고는 빨간색
  (우선순위: 대원안전 > 구조대상자 > 주요요소 > 전술, SOP 107 1.3). 자막 클릭 시 지난 무전 펼침.
- 질문 카드는 P7 의 오버레이를 이 배치에 맞춘다(화면 가운데, 답하면 사라지고 오른쪽 무전 기록에 등록).
- 상황판 크게 보기(상황판 상단 확대 버튼): 전략, 팀별 임무·구역, 진입대원 목록(진입 시각·잔압·위치), RIT·안전담당, 상황 요약.
- 긴급탈출·무전 통제: 사건이 생기면 화면 위쪽에 큰 빨간 버튼이 나타나고, 누르면 일반 무전을 막고 구출 관련만 표시한다.
- 숫자는 기본 숨김, 마우스를 올리면 툴팁. 모든 버튼 툴팁에 단축키 표시.
- 위기 연출: 잔압 경보 시 초상 깜빡임, 긴급·특수현상 징후 때 화면 가장자리 붉은 비네트와 효과음 변화.
- 단계적 해금: data/stages.json 에 스테이지별로 보이는 명령 버튼 목록을 둔다(튜토리얼은 이동·진입·방수만).
- 테마: 반투명 진한 남색 바탕 + 소방 주황 강조, 둥근 모서리, 본문 16px 이상, 한글 글꼴 내장.
  UI 배율 1366x768 ~ 1920x1080.
테스트: 두 해상도 스크린샷에서 글자 잘림·격침 없음, 모든 명령을 마우스만으로 수행 가능, 모든 단축키 동작.
계획 먼저, 승인 후 구현.
