# P11. 평가·디브리핑·리플레이·저장 (단계 6)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 8장을 읽어라.
- 평가 5축과 배점, 등급 상한 규칙(대원 사망 → 최대 C, 치명 선택 → 최대 B).
- 디브리핑: 타임라인, 카드별 내 선택·최선 선택·SOP 조항 원문·연결된 결과, 운 좋게 넘어간 오답 표시.
- 리플레이: 시드 + 명령 로그로 재생(결정론 보장). 연기·온도 레이어 토글, 배속.
- '그때 다르게 했다면': 오답 카드 시점 상태로 돌아가 다른 선택으로 이어하기(점수 미기록).
- 프로필(이름·소속), 대원 성장 저장, 로컬 랭킹, 훈장.
- 결과 내보내기: CSV(한 판 한 줄) 와 PDF(등급, 5축, 틀린 SOP 목록). PDF 는 외부 라이브러리 없이 엔진 안에서 만들 방법을 먼저 제안해라
  (어렵다면 인쇄용 PNG + HTML 대안).
테스트: 같은 시드·명령 로그로 두 번 재생하면 결과가 같음, 점수 계산 경계값.
계획 먼저, 승인 후 구현.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
