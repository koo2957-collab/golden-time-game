# P13. SOP 원문으로 카드 대량 작성 (수시)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/sop/[파일명] 의 [SOP 번호 범위] 를 읽고 질문 카드 초안을 만들어라.
규칙:
- 조항 하나에 카드 하나. '상황 → 행동' 으로 쓰인 조항만 카드로 만든다(단순 설명 조항은 제외).
- 선택지 4개: 최선 1, 허용 0~1, 오답 1~2, 치명 0~1. 오답은 현장에서 실제로 하기 쉬운 실수로 만든다.
- 질문 문구는 대원이 무전으로 묻는 말투("팀장님, ~입니다. 어떻게 할까요?"), 2문장 이내.
- effect 는 기존 행동 키 목록(docs/data_schema.md)에서만 고른다. 없으면 'NEW:설명' 으로 표시만 하고 만들지 않는다.
- debrief 는 원문 문장을 근거로 쉽게 풀어 2문장 이내.
결과는 data/cards/draft_*.json 에 저장하고, 검수용 표(카드 id, 질문, 최선, SOP)를 docs/cards_review.md 로 만들어라.
내가 검수한 카드만 본 파일로 옮긴다.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
$ARGUMENTS
