# P14. 저사양 최적화와 배포 (단계 6·10)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-4 를 읽어라.
- 프레임·시뮬 시간·메모리를 화면 모서리에 표시하는 성능 오버레이(F11)와, 가장 무거운 장면을 자동 재생해 평균·최저 fps 를 기록하는 벤치마크 씬을 만들어라.
- 병목을 찾고 고쳐라: 보이지 않는 층 그리기 중지, 입자 상한, 연기 오버레이 갱신 주기, 텍스처 아틀라스, GDScript 핫루프 최적화.
- 설정 메뉴에 저사양 모드(30fps 제한, 효과 축소, 해상도 배율).
- Windows 내보내기 프리셋: 64비트, pck 내장 단일 exe 또는 exe+pck, 아이콘, 버전 정보. 콘솔 창 없음.
- 배포 폴더 구성과 README(실행 방법, 최저 사양, 결과 파일 위치, 문제 해결)를 만들어라.
- 내보내기 전에 내 PC에서 쓸 Godot 내보내기 템플릿 설치 절차를 알려줘라.
완료 기준: 벤치마크 결과를 docs/perf.md 에 기록, 내장그래픽 PC 에서 최저 30fps.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
