# P15-1. TRELLIS.2 모델 정리 (대원 그림 교체 1단계, 선택)

> 사람용 메모(실행 전에 사람이 할 일):
> 사람이 할 일
> 
> 1. AI 이미지 도구로 기준 그림 한 장을 만듭니다. 예시 문구: "한국 소방관 전신, 정면, 팔을 양옆으로 벌린 T자 자세, 황갈색 방화복과 반사띠, 헬멧, 등에 공기호흡기 용기, 얼굴에 면체, 장갑과 부츠, 흰 배경, 그림자 없음, 글자·로고 없음, 저폴리 게임 캐릭터 스타일". 팔·다리가 몸에 붙지 않고 손가락이 또렷한 그림을 고릅니다.
> 2. 허깅페이스의 마이크로소프트 공식 TRELLIS.2 체험 페이지(huggingface.co/spaces/microsoft/TRELLIS.2)에 그림을 올리고 생성 → GLB로 내려받기. 여러 번 돌려 가장 깔끔한 것을 고릅니다.
> 3. 파일을 art_source/firefighter/trellis.glb 로 넣습니다.

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

art_source/firefighter/trellis.glb 는 TRELLIS.2(MIT)로 만든 소방관 모델이다. Mixamo 자동 리깅에 올릴 수 있게 정리해라.
Blender 백그라운드 스크립트(tools/blender/clean_for_mixamo.py)로:
- 바닥·배경 조각처럼 떨어져 있는 작은 덩어리 삭제, 중복 정점 병합, 구멍 메우기.
- 면 수를 약 5,000~10,000 삼각형으로 줄이기(decimate), 텍스처는 유지.
- 키 약 1.75m로 크기 맞추기, 발밑을 바닥(0)에, 정면이 -Y 방향, 표준 T자 자세인지 확인.
- 텍스처를 포함해 FBX 로 art_source/firefighter/for_mixamo.fbx 내보내기(되지 않으면 OBJ+텍스처를 zip 으로).
- 정면·측면 미리보기 PNG 두 장을 렌더해 주고, 팔·다리가 몸에 붙어 있는 등 리깅에 문제가 될 곳을 보고해라.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
