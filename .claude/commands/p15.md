# P15. Kenney 3D 팩으로 그림 입히기 (그래픽 단계)

> 사람용 메모(실행 전에 사람이 할 일):
> 사람이 할 일: blender.org에서 Blender 설치, kenney.nl/assets에서 팩을 받아 art_source/kenney/ 에 풀기.

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

art_source/kenney/ 에 Kenney CC0 3D 팩(Animated Characters, Furniture Kit, Car Kit, City Kit)을 넣었다.
docs/design.md 9-4, 9-4-1, 4-2-1 을 읽고 게임용 2D 스프라이트로 구워라.
먼저 팩 안의 모델·애니메이션 목록과 계획을 보여 주고 승인받아라. Blender 실행 파일 위치도 찾아 보고해라.

1) tools/blender/bake.py (Blender 백그라운드 실행: blender -b -P bake.py -- <설정 json>)
   - 정사영 아이소메트릭 카메라를 타일 64x32(1타일=1m)에 맞춰 고정. 2배 렌더 후 축소, 배경 투명, 기준점은 발밑.
   - 설정은 tools/blender/bake_config.json(모델 경로, 동작 목록, 방향 수, 출력 폴더)에 두어 나중에 다른 모델도 같은 스크립트로 굽는다.
   - 대원: 옷을 방화복 색(황갈색+반사띠)으로 바꾸고 헬멧·공기호흡기 용기를 단순 도형으로 덧붙인다.
     헬멧 띠는 따로 한 장 더 렌더. 8방향 x 모든 동작 프레임. 주민·요구조자는 원래 옷 그대로.
   - 가구: 4방향 정지 그림(data/furnishings 의 가구 이름과 매칭). 차량: 8방향. 소방차가 없으면 트럭을 빨간색으로.
   - 파일 이름: <종류>/<이름>/<동작>_<방향0~7>_<프레임>.png
2) Godot 도구 스크립트(tools/import_sprites.gd)로 PNG 를 SpriteFrames·아틀라스로 변환하고 data/art.json 에 연결.
   그림이 없는 항목은 지금처럼 도형. 헬멧 띠 그림에 역할 색(modulate).
3) 팩에 없는 동작(웅크려 걷기, 들고 걷기, 방수, 무릎 꿇고 검색, 쓰러짐)은 목록으로 보고하고 가장 비슷한 동작으로 임시 연결.
4) 저사양 기준 텍스처 메모리·로드 시간 측정. credits 화면에 "Kenney (kenney.nl), CC0".
계획 먼저 보여주고 승인 후 구현.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
