# P2. 건물 정의와 아이소메트릭 층 맵 (단계 1)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 4-2, 9-1, 9-3 을 읽어라.
목표: 건물을 '층 → 구획실(방) → 개구부(문·창·계단·샤프트)' 그래프로 정의하고 아이소메트릭으로 그린다.
- TileMapLayer(아이소메트릭, 64x32, 1타일=1m)를 층마다 둔다. 레이어: 바닥, 벽, 문·창, 설비.
- TileSet custom data 로 room_id, opening_type(door/window/stair/shaft), facility(옥내소화전/연결송수구/수신반 등)를 칠한다.
- 로드 시 BuildingGraph(순수 클래스)를 자동 추출한다: 방 목록(면적, 천장고, 가연물 등급), 개구부 목록(연결된 두 방, 크기, 상태 닫힘/열림/파손).
- 현재 층만 표시, 벽은 컷어웨이(낮게), 위층 숨김. 층 이동은 왼쪽 층 막대 클릭·휠과 PageUp/PageDown, 층 막대 맨 아래가 외부.
- 안개 렌더 자리: 타일마다 미탐색(검정)·기억(어둡게, 마지막 모습 고정)·관찰 중(밝게) 3상태를 갖는 저해상도 안개 텍스처. 안 가본 내부는 벽도 그리지 않는다(시야 계산은 P4). '지휘관이 아는 정보'와 '실제 상태'를 따로 저장한다(디브리핑에서 비교).
- 외부 뷰: 단지 도로, 주차 자리, 화단, 소화전, 연결송수구, 가공전선, 건물 외벽(창문별 상태 표시 자리).
- 기존 아파트 맵을 이 방식으로 옮기되, 플레이 가능 층은 1층·발화층±2·옥상, 나머지는 계단실과 복도만 둔다.
- 세대 구성: 현관, 거실, 주방, 침실 2~3, 화장실, 발코니(대피공간 포함).
- 디버그 화면: F9 를 누르면 방 경계와 room_id, 개구부 연결선을 겨서 보여준다.
테스트: 추출된 그래프의 방 수·개구부 수가 맵과 일치, 고립된 방(연결 없는 방) 없음.
계획 먼저, 승인 후 구현.
