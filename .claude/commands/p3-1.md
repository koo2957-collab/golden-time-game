# P3-1. 화재·연기 진행 시스템 보강 (단계 1 보강, 기존 프로젝트 수정용)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 5-1~5-4, 5-2-1, 5-2-2, 5-3-1~5-3-4, 5-9 를 읽어라.
이 게임에서 화재·연기 진행은 핵심 기능이다. 방수량·방수 시간·확대 속도·가연물 양에 따라 진압 결과가 달라져야 한다.
먼저 현재 화재·연기 코드를 찾아, CLAUDE.md 의 비교 표(기획안 / 현재 구현 / 상용 게임 방식 / 추천 / 이유)로 보고하고 계획을 승인받아라.
시뮬레이션은 scripts/sim/ 의 순수 클래스, 수치는 data/fire_params.json·materials.json 에 source 필드와 함께 둔다.

[1. 발화와 진행 속도]
- 스테이지 데이터에 발화 세대·방·최초 가연물·발화원·발화 시각. 발화기에는 최초 가연물만 탄다.
- 구획실 데이터: 개구부(면적·높이), 바닥면적, 벽 종류, 천장고, 가연물 목록(재질·양·위치), 마감재 등급.
- 가연물 재질별 α 등급·연소열. 벽 옆·구석 가연물은 성장 보정. 성장기 연료지배, 최성기 개구부 면적으로 열방출률 상한.
- 남은 가연물량 = 열방출률 × 시간만큼 감소. 비율 기준값 아래면 쇠퇴기, 0이면 다 탐.

[2. 연소 확대 (전도·대류·복사·비화)]
- 대류: 연기층이 닿는 방·복도 가연물에 예열값 누적 → 발화온도 도달 시 발화.
- 복사: 상부층 온도로 바닥 가연물 착화(플래시오버 약 500℃). 창 분출화염이 위층 창·마주 보는 창 가열.
- 전도: 맞닿은 벽·슬래브 너머 가열(벽 종류별 계수). 문이 닫힌 옆방은 훨씬 느리게.
- 비화: 풍속 5m/s 이상일 때만 풍하측 불티 착화 확률. 천장 위 가연성 혼합기에 닿으면 FGI.
- 최성기 미연소 가스가 산소 많은 옆 공간에서 발화. 롤오버(복도 천장 선행 확대), 플레임오버(가연 마감 표면 급속 확산), 연기폭발(SOP 210 11) 조건 판정.
- 숨은 공간(천장 속·벽 속·셔터 감는 부분·슬래브 틈) 경로: 화면에 안 보이고 열화상·부분파괴로만 확인.
- 수직 연결부(Shaft 오브젝트): 창→위층 창, 발코니(가연물 유무), 계단실 방화문, 승강로, 파이프 샤프트(PVC면 HCl), EPS·케이블, 덕트·방화댐퍼, 커튼월 틈, 슬래브 관통부, 더스트 슈트. 각각 닫힘·가연 보온재·마감 불량 속성.
- 바람 방향·세기를 확대 방향 가중치로. DecisionLog 에 직상층·최상층 경계 시각과 관창 배치 기록.

[3. 연기]
- 연기 선두 이동 속도 상한: 수평 0.5~1, 수직 2~3, 계단 초기 1.5, 중기 3~4, 굴뚝효과 5 이상 (m/s, params).
- 이동력 6가지: 굴뚝효과(계절·높이), 부력(거리 감쇠), 팽창(개구부 수), 바람(풍상 급기/풍하 배기), 공조설비(가동 시 덕트 연결층 전달, 방재실에서 정지 가능), 엘리베이터 피스톤(일반 운행 시 승강로 유입, 소방운전 전환 시 감소).
- 중성대: 위쪽 개구부 개방 → 상승(시야 확보, 화세 증가), 아래쪽 → 하강. 아래로 공기 유입 지속 시 연소·연기 증가.
- 배기구 없는 방의 상부층 분무 → 상하층 온도 혼합.
- 연기 색(초기 흰색 → 중기 검은색), 창 분출 연기의 양·속도를 화재 단계로 결정해 화면 단서로 넘긴다(그리기는 화면 코드).
- 가연물 재질별 독성 계수(HCN, HCl, SO2, CO)와 산소 농도를 요구조자 모델에 전달. 시야에 따라 주민 보행속도 감소.

[4. 방수 = 빼앗는 열]
- 관창 냉각력 = 방수량(L/s) × 2.6 MJ/L × 효율(주수 형태·도달 여부별 params). 방의 열방출률과 비교해 불 에너지 증감.
- 분무는 연기층만, 가연물 소화는 가연물에 닿는 주수만. 필요 방수량(13.6 × 면적)은 안내값으로 유지.

[5. 진화와 재발화]
- 방 상태: 연소 중 / 초진 / 잔화정리 중 / 완진 / 재발화. 방마다 숨은 잔화량.
- 새 임무 '잔화정리'(data/commands.json): 바깥→중심, 위층→아래층, 높은→낮은 순. 감압 주수, 부분파괴(지휘관 승인 카드), 가연물 반출. 물 사용량은 수손에 누적.
- 잔화가 남은 채 시간이 지나면 재발화(산소 유입 시 가속). 완진 후 감시경계 대 지정 시 조기 발견·보고.
- 무전: 초진 보고, 완진 선언, 재발화 보고. DecisionLog: 초진·완진 시각, 총 수량, 수손, 재발화.

테스트(tests/):
1) 내화조 기본 거실 무진압 시 플래시오버가 20~30분 범위, 우레탄 많은 방은 더 빠름.
2) 문 닫힌 옆방은 열린 옆방보다 발화가 늦다.
3) 복도 연기 선두 0.5~1m/s, 중기 계단실 3~4m/s 범위. 15층 계단실이 아래층보다 위층부터 찬다.
4) 위쪽 개구부 개방 시 중성대 상승과 열방출률 증가, 아래쪽 개방 시 하강.
5) 풍속 5m/s 미만에서는 비화 없음.
6) PVC 파이프 샤프트 경로로 위층 확대 시 HCl 독성 증가.
7) 엘리베이터 일반 운행 시 승강로 연기 유입이 소방운전보다 많다.
8) 40mm 1선은 최성기 거실을 못 끄고, 3선이면 줄어든다. 도착이 늦을수록 진압에 필요한 총 물량이 늘어난다.
9) 잔화정리를 건너뛰면 일정 시간 뒤 재발화, 정리하면 재발화 없음, 감시경계가 있으면 조기 보고.
10) 성능: 15층 아파트 전 층 계산이 저사양 기준 한 틱 안에 끝나는지 측정해 보고.
