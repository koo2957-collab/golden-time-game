# P4-1. 차량 순차 도착·배치 지점·현장 작업 시간 (단계 2~3, 기존 프로젝트 수정용)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 6-1(출동대 편성, 배치 지점, 작업 시간 표), 4-4(도착 시간) 를 읽어라.
현재 문제: (1) 물탱크차가 펌프차보다 앞에 있고 차량이 한꺼번에 나타난다. (2) 차량을 직접 움직여야 한다.
(3) 소화전·물탱크차 급수와 수관 연장이 눈 깜짝할 사이 자동으로 연결된다. (4) 없는 장비를 가져오는 과정이 없다.
먼저 관련 코드를 찾아 원인을 보고하고, 아래대로 고칠 계획을 승인받아라.

[1. 순차 도착]
- 차량은 시나리오의 arrival_sec 순서대로 맵 진입점에서 한 대씩 등장한다(기본: 선착 펌프차 240 → 구조·구급·물탱크 300 → 후착분대 360 → 굴절차 480 → 지휘대 600).
  같은 시각이면 data 의 순서대로 5초 간격. 도착 무전("○○물탱크 현장 도착")을 낸다.
- 출동대 편성은 data/crews.json(6-1 기본 편성)에서 읽는다.

[2. 배치 지점]
- 맵 데이터에 StagingSlot 을 둔다: id, 위치·방향, 허용 차종, 속성(굴절차 전개 가능, 낙하물 위험구역 여부, 소화전까지 거리, 퇴각로 확보 여부).
- 차량을 직접 이동시키는 명령은 없앤다. 차량을 선택하면 빈 배치 지점들이 지도에 표시되고, 클릭하면 그곳으로 간다.
  도착했는데 지정이 없으면 운전원이 질문 카드("어디에 세울까요?", 선택지 = 빈 지점)를 띄운다. 출동 준비판에서 미리 지정할 수도 있다.
- 주행은 도로 차선 그래프를 따라간다. 다른 차량·주차차량을 통과하거나 뛰어넘을 수 없고, 앞이 막히면 서서 기다린다.
  회전은 회전 반경을 넣어 계산하고, 유턴은 넓은 곳(교차로·지정 회차 지점)에서만. 짧은 후진은 허용.
  차체 크기는 차종별 길이·폭(vehicles.json). 막혀서 갈 수 없으면 무전으로 보고하고 제자리.
- 배치 판정을 로그에 남긴다: 낙하물 구역 안 배치, 굴절차 지점을 다른 차가 차지, 퇴각로 막음(SOP 200 3.1, 201 3.1).

[3. 현장 작업 = 모습 + 시간]
- 모든 연결·준비는 대원이 따로 하는 '작업(Task)'이다. 작업별 시간은 data/params.json 의 task_times(6-1 표 값)에서 읽는다.
  시간은 2인 기준이고 1인이 하면 2배. 대원 머리 위에 작업명과 진행 막대를 표시한다.
- 호스 본 수 = 실제 경로 길이 ÷ 15m 올림 + 여유 1본. 연장 시간 = 본 수 × 1본 연장 시간 + 결합 개소 × 결합 시간.
- 소화전 급수: 운전원이 하차 → 차량에서 호스 꺼내기 → 소화전으로 걸어가 점령 → 호스 연장하며 차량으로 → 양쪽 결합 → 개방.
  물탱크차→펌프차 급수도 같은 방식(거리가 멀수록 본 수와 시간 증가). 다른 대원이 돕게 하면 2인 시간.
- 분대원 수관 연장: 팀이 자기 차량으로 가서 수관 준비(호스·관창 메기) → 방수구 결합 → 목표로 연장하며 이동.
  연장 중 이동 속도는 보통 이동의 0.8배. 호스는 대원 뒤로 선이 늘어나듯 그린다.
  1인 휴대 한도 호스 2본(params). 모자라면 연장이 멈추고 "호스가 모자랍니다" 보고 → 차량에 다시 가거나 다른 대원이 전달.
  호스가 연결되기 전에는 방수 불가, 방수 개시는 관창수 신호 후 운전원이 압력을 올리는 시간이 걸린다(SOP 206 1.3).
- 장비 인벤토리: 대원마다 휴대 장비 목록과 한도가 있다. 출동 준비판에서 챙긴 장비만 들고 내린다.
  없는 장비가 필요한 행동(예: 방화문 파괴)을 지시하면 "파괴기가 없습니다. 가지러 갈까요?" 질문 → 본인 탑승 차량까지 왕복 + 꺼내는 시간.
  짝이 없는 대원을 '장비 전달' 역할로 지정하면 대신 가져다 줄 수 있다.
- 작업 중 대원은 하단 콘솔·상황판에 '소화전 점령 중 0:35'처럼 보인다.

테스트: 도착 순서가 arrival_sec 대로(펌프차가 먼저), 차량이 다른 차를 뛰어넘지 않고 막히면 대기,
소화전 30m(3본) 2인 연결 시간이 1인의 절반, 45m 연장이 30m보다 오래 걸림, 수관 연장 중 속도 0.8배,
호스 부족 시 연장 멈춤, 없는 장비는 차량 왕복 후에만 사용 가능.
계획 먼저 보여주고 승인 후 구현.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
