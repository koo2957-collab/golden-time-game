# P4-2. 원형 명령 메뉴와 진입 지시 흐름 (단계 2, 기존 프로젝트 수정용)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-1 '내부 조작', '원형 명령 메뉴', '진입 지시' 와 9-3 을 읽어라.

[1. 원형 명령 메뉴(RadialMenu)]
- 대원·팀을 좌클릭하면 커서 둘레에 항목 4~8개가 둥글게 펼쳐진다(0.12초 확대 애니메이션, 항목마다 아이콘+글자+숫자키).
  항목은 data/commands.json 에서 보직·상황(외부/진입구/내부)에 따라 고른다. 바깥 클릭·Esc·우클릭으로 닫힌다.
- 내부 대원: 지도 우클릭 이동을 막고 원형 메뉴로만 지시. 메뉴 선택 = 무전 지시(교신 2~3초 + 복명복창 후 수행, radio_lines.json).
- 외부 대원: 같은 메뉴, 대면 지시라 즉시 수행. 우클릭 이동도 허용.
- 메뉴를 고른 뒤에는 대원이 임무를 스스로 수행한다(자동행동 P5).

[2. 진입 지시 4단계]
1) 원형 메뉴 '진입' 선택 → 진입 모드. 화면 상단에 '진입구를 고르세요 (Esc 취소)' 안내.
2) 맵 데이터의 EntryPoint(공동현관, 계단실 입구, 비상계단, 지하주차장 연결문, 사다리·굴절차 도달 창)만 밝은 아이콘으로 표시.
   사다리·굴절차 창은 해당 차량·장비가 전개됐을 때만 활성. 마우스를 올리면 툴팁: 연기 상태, 알려진 경우 급기측/배기측.
3) 진입구를 고르면 다층 단면 보기(P2-1)로 전환. 층 막대·단면에서 층을 고른 뒤 목표(세대·복도·계단참)를 클릭.
   미탐색·도면 없는 곳은 층·세대 단위까지만. 마우스를 올리면 진입구→목표 예상 경로를 그린다
   (아는 구간 실선, 모르는 구간 점선) + 예상 소요 시간(현장 시간) + 도착 시 예상 공기잔량.
4) 작은 패널에서 임무(인명검색/화점진압/배연/구조)와 조건(철수 잔압, 화점 발견 시, 요구조자 발견 시)을 고르고 '지시'.
   조건 기본값은 직전 사용값. 무전 문장 자동 생성("1팀, 계단실 B로 진입해 12층 1203호 인명검색하라").
- 선택한 진입구·경로는 DecisionLog 에 기록해 디브리핑에서 급기측 진입, 화점 직하층 거점 여부를 평가한다.
- 이미 진입한 팀은 원형 메뉴 '구역 변경'으로 3~4단계만 다시 밟는다.

[3. 문 앞 휠]
- 내부에서 팀이 문 앞(2타일 이내)에 있고 그 팀이 선택된 상태에서 문을 클릭하면 문 전용 원형 메뉴:
  가스 확인 후 개방 / 문 옆 벽에서 서서히 개방 / 파괴 후 개방(파괴기 필요) / 상부 배연 후 개방 / 문 닫고 대기.
- 이 메뉴를 질문 카드보다 먼저 쓰면 선제지시(skip_if_preordered)로 처리해 해당 카드가 뜨지 않는다.

테스트: 내부 대원 우클릭 이동 불가, 원형 메뉴 지시는 교신 후 수행, 외부는 즉시,
진입구는 EntryPoint 만 선택 가능, 미탐색 층은 세대 단위까지만 선택, 경로 미리보기의 실선/점선 구분,
문 앞 휠 사용 시 해당 질문 카드 미발동.
계획 먼저 보여주고 승인 후 구현.
