# P4-3. 대원 클릭 판정 개선 (기존 프로젝트 수정용)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-3 '대원 클릭은 그림 어디를 눌러도' 를 읽어라.
현재 문제: 대원 클릭 판정이 너무 작아 선택이 잘 안 된다. 현재 선택 코드와 판정 크기를 먼저 보고하고 아래대로 고쳐라.

- SelectionSystem 을 만들어 모든 클릭 선택을 한 곳에서 처리한다(각 노드의 input_event 에 맡기지 않는다).
- 대원 판정: 스프라이트를 덮는 타원, 화면 기준 최소 48x64px. 카메라 줌에 관계없이 화면 크기 기준으로 계산.
- 팀(2인 1조) 판정: 두 대원 판정 + 그 사이를 잇는 캡슐. 어느 곳을 눌러도 팀 선택.
- 자석 선택: 직접 맞은 것이 없으면 마우스에서 화면 30px(params) 안의 가장 가까운 팀 선택.
- 우선순위: 대원 > 차량 > 문·창 > 설비 > 바닥. 대원끼리 겹치면 선택 안 된 팀 우선, 같은 곳 다시 클릭 시 다음 후보로 순환.
- 같은 층·시야 안의 대원만 후보(다층 보기에서는 현재 층 우선, 안개 속 대원 제외).
- 호버 표시: 잡힐 후보에 윤곽 빛 + 팀 이름 라벨. 선택된 팀은 발밑 팀 색 고리.
- 가려진 대원: 벽·윗층 뒤의 대원은 팀 색 윤곽선 실루엣을 위에 그리고(셰이더 또는 복제 스프라이트), 그것도 클릭 판정.
- 드래그 박스 선택은 그대로 유지하되 팀 단위로 묶는다.

테스트: 대원 스프라이트 가장자리·헬멧·발 어디를 눌러도 선택, 두 대원 사이 클릭도 팀 선택,
줌아웃에서도 판정 48x64px 유지, 겹친 두 팀 반복 클릭 시 번갈아 선택, 가려진 대원 윤곽 클릭 시 선택.
계획 먼저 보여주고 승인 후 구현.
