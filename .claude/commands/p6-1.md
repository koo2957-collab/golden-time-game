# P6-1. 임무 단위 명령·필요 방수량·물 소모·탈출 부상 (단계 3, 기존 프로젝트 수정용)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 9-1 '명령은 임무 단위', 5-4(필요 방수량, 방수량 표, 물이 끊기면, 탈출 부상)를 읽어라.
현재 문제: 진압대·구조대 명령이 너무 많고, 수색 중 요구조자를 발견해도 구조하지 않는다.
물을 뿌리면 무조건 불이 꺼지고, 물이 거의 줄지 않는다. 먼저 관련 코드를 찾아 보고하고 아래 계획을 승인받아라.

[1. 임무 단위 명령]
- 원형 메뉴는 임무 6개 이하: 인명검색, 화점진압, 경계(연소확대 방지), 배연, 대기, 철수(+보고 요청·구역 변경은 하위). data/commands.json 으로 정의.
- 임무 = 세부 동작 순서(MissionPlan). 인명검색: 이동 → 문 개방 → 방별 탐색 → 발견 시 무전 보고 → 구조(피난장소로) → 남은 구역 계속.
  화점진압: 수관 준비 → 연장 → 진입 → 화점 탐색 → 방수 → 잔불 확인.
- 조건(요구조자 발견 시 즉시 구조 / 위치 보고 후 대기 등)으로 기본 동작을 바꾼다. 기본값은 '보고 후 즉시 구조'(SOP 203).
- 구조대·진압대 메뉴는 같고, 보직별로 작업 속도 보정만 다르다(roles.json).

[2. 필요 방수량]
- 구획실마다 required_flow = 13.6 L/min × 연소 중 면적(m²) × 화재하중 계수(params, 가연물 등급별).
- applied_flow = 그 방에 실제 닿는 관창 방수량 합(사거리·시야 안, 주수 형태별 효율 계수).
- ratio = applied/required. 1 이상이면 열방출·연소 면적 감소(비율에 비례), 0.5~1 이면 성장만 둔화,
  0.5 미만이면 계속 성장. 부족하면 관창수가 '수량이 부족합니다' 보고, 상황판 확인 필요에 등록.
- 디버그 패널(F10)에 방별 required/applied/ratio 표시.

[3. 물 소모]
- 관창 방수량: 65mm(외부) 611 L/min, 40mm(내부) 275 L/min. params.json 에 둔다.
- 펌프차 물탱크는 방수 중인 관창 합계만큼 현장 시간 기준으로 감소. 물은 방수 중일 때만 초 단위로 감소.
  급수: 물탱크차 연결 시 180 L/min(물탱크차 잔량이 있는 동안, 그만큼 물탱크차는 감소),
  소화전 연결 시 180 L/min 무제한. 탱크가 가득 차면 급수 중지(넘치지 않음).
  테스트 추가: 소화전 급수 + 40mm 1선이면 분당 95L 감소, 방수 중지 시 분당 180L 증가, 방수하지 않으면 소모 0.
  탱크 용량: 펌프차 2800 L, 물탱크차 4000 L(vehicles.json). 급수량: 물탱크차·소화전 모두 180 L/min(params.json).
  테스트 추가: 급수 없이 40mm 1선이면 현장 시간 약 10분 11초에 펌프차 탱크 고갈.
- 잔량 25% 운전원 경고 무전, 0이면 그 펌프차에 연결된 모든 관창 방수 중단.
- 물이 과하게 남는 현재 로직(누수·누락된 소모·배속 미적용)을 찾아 고쳐라.

[4. 물이 끊기면]
- 방수 중단 → 엄호주수 사라짐 → 화재 성장 재개. 관창수 '수압이 떨어졌습니다' 보고.
- 대원 주변 온도가 기준을 넘으면 철수 요청, 더 높거나 경로가 막히면 긴급탈출 선언(SOP 109).

[5. 탈출 부상]
- 대원마다 열 노출 누적치: 지나가는 칸의 상부층 온도·화염 여부 × 머문 시간. 낮은 자세는 감소, 화염 칸은 크게 증가, 엄호주수 받으면 크게 감소.
- 누적치에 따라 경상·중상 확률(params, 게임 설정값). 중상이면 이동 불가 → 구출 필요.
- 탈출 경로 계산은 열 노출을 비용으로 넣어 더 안전한 우회로를 고른다.
  우회로가 없으면 질문 카드: 엄호주수 받고 돌파 / 대기하며 RIT 요청 / 다른 출구 탐색. 막히면 고립(SOP 204).

테스트: 수색 중 발견 → 보고 → 자동 구조, 40mm 1선으로 50m² 최성기 거실은 안 꺼짐(비율 약 0.4),
40mm 3선이면 줄어듦, 40mm 2선 사용 시 탱크가 1선보다 2배 빨리 비움, 탱크 0이면 방수 중단·철수 요청,
화염 칸 통과 시 부상 확률 증가, 엄호주수 시 감소.
계획 먼저 보여주고 승인 후 구현.
