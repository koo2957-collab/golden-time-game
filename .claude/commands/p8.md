# P8. 요구조자·관계인·구급 (단계 5)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 5-5 와 7-3 구급 카드를 읽어라.
- Occupant: 유형(성인/노인/아이/거동불편자), 수면 여부, 위치, 상태.
- CO 노출은 params.json 의 농도별 사망시간으로 '노출시간/사망시간'을 누적(농도 사이는 보간). 0.7 이상 의식저하, 1.0 사망.
  산소 18% 미만 이동 둔화, 10% 이하 자력이동 불가. 연기층 아래에 있으면 노출 감소.
- 행동: 연기가 적으면 자력피난, 많으면 화장실·베란다·장롭·창가로 숨기, 발코니에서 구조 요청, 난간 매달림 이벤트.
  방송·대원 안내에 따라 '세대 내 대기' 또는 '계단 대피'.
- 단서 표시: 불 켜진 창, 현관 신발, 외부 뷰에서 보이는 사람.
- 관계인 NPC: 도착 시 다가와 정보를 준다. 시나리오마다 정보의 정확도가 다르다(틀린 정보 포함).
- 구급: 구출된 요구조자는 분류 구역으로 이동, 구급대가 START 카드를 띄운다(호흡·맥박·의식 값 제시).
  분류 결과에 따라 이송 순서가 정해지고, 오분류는 생존 확률에 반영.
테스트: 3,200ppm 에 30분 노출 시 사망, 구출 후 노출 중단, START 규칙(호흡 10 미만·30 초과 긴급).
계획 먼저, 승인 후 구현.
