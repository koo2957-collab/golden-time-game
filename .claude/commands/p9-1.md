# P9-1. 전체 지도·출동 단계·도착 연출 (단계 5)

> 사람용 메모: 참고 이미지(흰 덩어리 도시 속 색이 들어간 건물 1동)를 `docs/ref/citymap.jpg` 로 넣은 뒤 실행합니다.

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.

내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 4-4, 6-1(출동대 편성), 6-3(장비), 7장(카드), 9-1, 9-2 와 참고 이미지 docs/ref/citymap.jpg 를 보아라.

[1. 전체 지도 표현]
- 화재 건물, 도로(차선·횡단보도), 소화전, 주차차량, 가공전선, 수목만 색과 디테일을 넣는다.
- 나머지 건물은 참고 이미지처럼 흰색 매스 덩어리(아이소메트릭 박스, 윗면 밝게·옆면 조금 어둡게, 구운 그림자 스프라이트)로만 그린다.
  덩어리는 데이터(위치·폭·깊이·층수)로 자동 생성해 스테이지마다 손으로 그리지 않게 한다.
- 인접 건물에 연소확대 위험이 생기면(복사열·비화) 그 건물은 색이 들어간 상태로 바뀐다.
- 화재 건물은 외부 보기(P2-1)로 그리고, 연기 기둥을 멀리서도 보이게 한다.

[2. 시간축]
- 시나리오 JSON 에 ignition_to_call_sec(발화→신고 지연, 예: 120~360 중 시드 무작위)와 출동대별 arrival_sec 를 둔다.
  기본 arrival_sec: 선착대 240, 구조대·구급대·물탱크차 300, 후착분대 360, 굴절·고가사다리차 480, 지휘대 600.
- 스테이지 로드 시 FireSim 을 화면 없이 ignition_to_call_sec 만큼 빨리 돌려 초기 상태를 만든다(사무용 PC 2초 이내, 로딩 화면 표시).
- 게임 시계 = 신고 후 경과. 출동 단계(0~240초)는 시뮬을 약 2.7배속으로 돌려 실제 약 90초에 끝난다(배속은 params.json).
  선착대 도착 순간부터 현장 배속(params.time_scale, 난이도별 훈련 1.5 / 실전 2.0 / 악조건 2.5).
  화재·공기·노출·대원 작업·이동은 모두 현장 시간, 질문 카드 제한시간·자막·연출은 실제 시간. 디브리핑용으로 '발화 후 경과'도 기록한다.

[3. 출동 단계 화면]
- 카메라는 도시 전체를 멀리서 본다. 안전센터에서 출발한 차량 아이콘이 도로 경로를 따라 이동(경로는 도로 그래프 최단 경로).
- 상황실 무전이 시간에 맞춰 차례로 나온다(data/stages/*.json 의 dispatch_info 배열: 시각, 내용, 정확 여부).
  예: 00:20 "○○아파트 103동 12층 화재 신고, 연기 다량" / 01:10 "추가 신고: 13층 거동불편 노인 거주" /
  01:40 "건물 정보: 15층, 스프링클러 없음, 연결송수구 동쪽" / 02:30 "한전·도시가스 통보 완료".
- 무전은 상황판 무전 기록에 남고, 오른쪽 상황판에는 '출동 정보 요약'(대상, 발화층, 요구조자 정보, 건물 정보)이 쌓인다.
- 출동 준비판(하단 콘솔 가운데에 표시):
  a) 챙길 장비 체크: 방화문 파괴기, 동력절단기, 열화상카메라, 가스탐지기, 연결송수관용 장비팩, 라이트라인, 공기안전매트 등(equipment.json).
     인원별 휴대 한도가 있고, 체크 안 한 장비는 도착 후 차량에 다시 가서 가져와야 한다(시간 손실).
  b) 도착 후 임무 미리 배정: 분대원별 관창·검색·방재실 연락·안전담당 등. 배정한 대원은 도착 즉시 행동한다.
  c) 상황실 요청 버튼: 예비 소방용수 선정(지도에서 소화전 2개 이상 클릭), 관계자 조치 요청(발화세대 확인·가스 차단·주차차량 이동·피난 방송), 응원 요청.
  요청하지 않은 조치는 현장에 반영되지 않는다(예: 주차차량이 굴절차 자리를 막고 있음).
- 출동 단계 질문 카드(data/cards/dispatch_*.json)도 이 단계에서 뜬다. 모든 선택은 DecisionLog 에 남겨 디브리핑·평가에 쓴다.

[4. 도착 연출]
- 선착대 차량이 건물 앞에 이르면 카메라가 0.8초 동안 화재 건물로 확대(부드러운 ease), 흰 덩어리는 화면 밖으로 밀려난다.
- 선착대 차량 배치 단계(P4)로 이어진다. 이후 출동대는 arrival_sec 에 맞춰 도로 끝에서 들어오고,
  도착 무전("구조대 현장 도착")과 함께 배치 가능 상태가 된다. 지휘대 도착 시 지휘권 이양·도면 수신(9-1).
- 연출은 Space 로 건너뛸 수 있지만, 출동 준비판 결정을 끝내지 않으면 건너뛸 수 없다(끝내지 않은 항목은 '미결정'으로 기록).

[5. 성능]
- 흰 덩어리는 단순 폴리곤/스프라이트 배치(MultiMesh 또는 하나의 CanvasItem 에 일괄 그리기), 텍스처 없이 색만.
- 도시 전경에서도 60fps. 화재 건물 내부 층은 확대 전에는 그리지 않는다.

테스트: 시드 고정 시 도착 시점 화재 상태가 매번 같음, 게임 시계 04:00 에 선착대 도착, 출동 단계가 실제 약 90초,
체크 안 한 장비는 도착 후 차량에서 가져와야 함, 주차차량 이동 미요청 시 굴절차 자리 막힘, 도시 전경 프레임 측정.
