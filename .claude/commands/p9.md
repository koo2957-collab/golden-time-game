# P9. 아파트 스테이지 완성 (단계 5)

[먼저 읽을 것] 이 프롬프트는 이미 만들어진 프로그램을 고치기 위한 것이다. 프로그램은 기획안을 고치기 전 버전으로 만들어져 있다.
CLAUDE.md 의 '기획안과 현재 구현이 다를 때' 절차를 따라라: 관련 코드를 먼저 읽고, 기획안·현재 구현·상용 게임 방식을 비교한 표와 추천을 보여 준 뒤,
내가 고르면 구현해라. 이미 구현돼 있고 기획안과 같은 부분은 다시 만들지 말고 확인만 해라.

docs/design.md 4장(2-1 아파트), 7-3 을 읽어라.
스테이지 2-1 을 처음부터 끝까지 플레이 가능하게 만들어라.
- 진행 단계: 출동지령 → 출동 준비(적재 장비 선택) → 출동 중(상황실 정보, 예비 소방용수 카드) →
  도착·차량 배치 → 상황평가·전략 선언 → 대응 → 완진·잔불정리 → 복귀 보고. (SOP 200 단계)
- 시나리오 3개를 data/stages/apt_*.json 으로: (A) 주간 저층 거실 화재, (B) 야간 중층 침실 화재·백드래프트 조건·직상층 노인,
  (C) 겨울 고층 화재·강풍·발코니 요구조자·난간 매달림. 발화 세대 번호와 요구조자 배치는 시드로 무작위.
- 후착대(센터 1개, 구조대, 굴절차)는 설정된 시간에 도착. 응원요청 명령으로 추가 자원.
- 안전구역 그리기 도구(발화층 높이 1/2 기본 안내), 안전담당·RIT 지정 슬롯.
- 카드 7-3 표 전부가 이 스테이지에서 자연스럽게 뜨도록 트리거를 맞춰라.
- 종료 조건과 실패 없음(대원 사망 시에도 계속) 규칙.
테스트: 각 시나리오를 자동 봇(최선 선택만 하는 봇, 무응답 봇)으로 돌려 끝까지 진행되는지, 최선 봇이 무응답 봇보다 구조 인원이 많은지 확인.
계획 먼저, 승인 후 구현.

작업이 끝나면 docs/progress.md 에 이 프롬프트 번호, 바뀐 파일, 남은 문제를 한 줄씩 추가해라.
