# Fire Commander

소방 표준작전절차(SOP)를 학습하는 2D 탑다운 실시간 전략(RTS) 소방 지휘 게임.
현직 소방공무원 내부 교육용 (Windows PC, Godot 4.7).

## 실행

1. Godot 4.7 에디터에서 이 폴더의 `project.godot`를 연다.
2. F5로 실행한다. (메인 씬: `res://scenes/main/main.tscn`)

## 조작

| 입력 | 동작 |
|---|---|
| 시작 화면 | 시나리오 선택 (제목·SOP·난이도·학습 목표, 오류가 있으면 한글로 표시하고 시작을 막음), 평가/교육 모드, 자동화 수준 → Enter |
| 시작 화면 → 화면 설정 | 창 크기(HD 1280×720 · HD+ 1600×900 · 풀HD 1920×1080), 창/전체 화면, 화면 갱신(60 / 30프레임 — 저사양 PC는 30 권장). 저장하면 다음 실행 때도 유지 |
| 분대 명령칸 (조 선택 시 위 줄) | 진압대: 진압(W)·외부 방수(V)·잔불정리(G)·철수(X) / 구조대: 수색(W)·구조(V)·진입구 개척(E)·철수(X). 명령 하나에 문 개방·수관 연장·방수·검색·이송이 SOP 순서대로 이어진다. 잠긴 문·백드래프트 징후 문·발견한 구조대상자 등은 자동화 수준에 따라 멈추고 무전으로 지시를 기다린다 |
| W → 방 클릭 (여러 출동대 함께 선택) | 진압대는 진압, 구조대는 수색 |
| 교육 모드 | 판단이 필요한 순간 SOP 힌트 카드 (조항·원리·권장 행동). 같은 힌트는 한 판에 한 번, Enter로 닫기 |
| Enter | 출동 지령 확인 → 현장 도착 |
| C | 지휘권 선언·최초 상황보고 양식 (9개 항목, 무전 송신). 선언 후에는 전략 변경 (방어로 바꾸면 내부 대원 철수) |
| O | 조직·지원 창: 지원 요청(추가 출동대·대응 1단계), 단위대(방면·층·기능) 지정·해제, 안전 임무(RIT·현장안전담당) 지정 |
| P / 무전 패널 [인원점검] | 출동대·단위대별 인원·장비 이상 유무 보고 (SOP 109-1.3, 200-4.1) |
| 무전 패널 [긴급탈출 지시] | 전 대원 즉시 탈출, 진입 허가 취소 (SSG 9 2.1.7). 대원이 쓰러지면 그 조가 "긴급탈출"을 3회 송신하고 일반 무전은 멈춘다 (109) |
| 긴급탈출 상황에서 RIT 조 선택 → 쓰러진 대원 우클릭 | RIT 투입 (평소에는 RIT·현장안전담당에게 다른 임무를 줄 수 없다) |
| F | 현장 정보 창: 둘러보기·진술·물증 기록, 확인한 위험 요소 |
| 무전 패널 [360° 둘러보기] | 지휘관이 건물 둘레를 한 바퀴 돈다. 면 앞에 서야 그 면의 정보가 열린다 |
| 관계인 클릭 | 진술 창: 지휘관이 3m 안에 있으면 질문 (질문마다 8초, 그동안 지휘관은 멈춤). 진술은 틀릴 수 있다 |
| 선언 후 C → 상황 보완 보고 | 새로 알게 된 구조대상자·위험 요소를 다시 무전 보고 |
| 선언 후 C → 활동 종료 선언 | 활동을 끝내고 디브리핑으로 (제한 시간 40분이 지나도 자동 종료) |
| 디브리핑 | ① 계획 ② 실제(타임라인·숨은 정보 공개) ③ 왜(규칙별 판단·조항 원문) ④ 다음에는(잘한 점·고칠 점). 결과는 `user://reports/`에 JSON으로 저장 |
| 조 선택 → R | 그 조의 출동대에 내부 진입 명령 (무전). 명령을 받기 전에는 건물 입구 앞에서 멈춘다 |
| 대기 중인 후착대에 첫 명령 | 투입 무전("대기 해제, 현장 투입하라")이 먼저 나가고, 전달된 뒤 명령이 실행된다 |
| 현장지휘관(흰 몸체·빨간 안전모) 클릭 → 우클릭 | 지휘관 이동 (혼자서는 건물 안에 들어가지 않음) |
| 좌클릭 / Shift+좌클릭 | 조·차량 선택 / 추가·해제 |
| 드래그 | 범위 선택 |
| 더블클릭 | 같은 출동대 전체 선택 |
| 조 선택 → 우클릭 | 이동 (방수 중이면 방수를 멈추고 이동) |
| 조 선택 → 펌프차 우클릭 | 그 펌프차에서 수관 연장 |
| 조 선택 → H → 펌프차 클릭 | 수관 연장 (같은 기능) |
| 조 선택 → A / S → 목표 클릭 | 직사 / 분무 방수. 수관이 없으면 가까운 펌프차에서 자동 연장, 물줄기가 닿지 않으면 닿는 위치까지 이동 후 방수 |
| D | 방수 중지 |
| 조 선택 → 닫힌 문 우클릭 | 문 개방 (잠긴 문은 파괴: 문 앞 2명 이상, 60초) |
| 조 선택 → E → 문 클릭 | 문 개방·폐쇄 (파괴된 문은 닫을 수 없음) |
| 조 선택 → E → 창 클릭 | 창 파괴 (배연·상부 개방, 1명 5초) |
| 조 선택 → Q → 방 클릭 | 인명검색 (벽을 따라 훑고, 끝나면 [검색 완료] 표시) |
| 조 선택 → G → 방 클릭 | 잔불정리 (45초). 물로 끈 곳에 숨은 불씨는 열화상 조가 방에 들어가면 주황 점으로 보인다. 두면 재발화 |
| 디브리핑 아래 | 타임라인의 한 시점을 골라 "이 시점부터 다시 하기" · 다시 시작(F5, 같은 시나리오) · 시나리오 선택 |
| 조 선택 → 발견한 요구조자·쓰러진 대원 우클릭 | 구조: 2인이 업고 가장 가까운 바깥으로 이송 (수관 조는 불가) |
| 차량 선택 → 우클릭 | 전진·후진 (차도만) / 소화전 우클릭: 점령 / 물탱크차로 펌프차 우클릭: 급수 |
| Ctrl+숫자 / 숫자 | 부대 지정 / 호출 |
| 방향키, 휠 버튼 끌기, 휠 | 카메라 이동, 줌 |
| PgUp / PgDn, 층 탭 | 층 전환 |
| F1 / F2 / F3, Space | 1·2·4배속, 일시정지 |
| F5 | 처음부터 다시 시작 (데이터 파일 다시 읽음) |
| Esc | 대상 지정 취소 |
| Tab | 입체(기본) ↔ 상황판 화면 전환 |
| T | 열화상 화면 |
| F9 (개발용) | 화재 정보 패널: 방별 단계·온도·연기층·산소·가스·열방출률·시야, 최근 사건 |
| I + 클릭 (개발용) | 클릭한 위치에 발화 |
| F10 (개발용) | 정보 안개 끄기·켜기 (건물 안 전체 보기) |

현재 실행하면 개발용 시나리오(`data/scenarios/dev_house_fire.json`)로 1층 거실 소파에서 화재가 시작된다.
출동 지령 창이 먼저 뜨고, 창이 열려 있는 동안(지령·상황보고·전략 변경)에는 게임 시간이 멈춘다.
왼쪽 위에 무전 기록과 진입 현황(출동대별 진입 허가, 건물 안 조와 공기 잔량)이 나온다.

## 장비·수치 설정

코드를 고치지 않고 데이터 파일만 바꾸면 된다. 바꾼 뒤에는 단위 테스트를 돌려 교재 범위·진압 보정이 깨지지 않았는지 확인한다.

| 파일 | 내용 |
|---|---|
| `data/units/vehicles.json` | 차종별 제원: 탱크 용량(L), 관창 방수량(L/min), 급수량(L/min), 적재 호스(본 × m), 차체 길이·폭·높이(m), 속도(m/s) |
| `data/fire/fire_params.json` | 소화전 공급량, 직사·분무 사거리와 효율, 소화전·급수 연결 거리, 화재 성상 수치 |
| `data/units/firefighter.json` | 대원 보행 속도 |
| `data/units/test_roster.json` | 출동대 편성, 차량 배치 위치와 방향 |
| `data/units/dev_reinforcements.json` | 후착대·지원 출동대 편성 (차량을 타고 도착) |
| `data/fire/hazard_params.json` | 요구조자 노출, 특수현상, 불씨·재발화·잔불정리 시간 |
| `data/sop/hints.json` | 교육 모드 힌트 문구·트리거·조항 |
| `data/units/command_cards.json` | 출동대 종류별 명령칸 |
| `data/sop/rules.json` | SOP 판정 규칙 24개: 2025 SOP 조항·원문, 소방전술 근거·원리, 평가 축·기준값·등급 상한, 축 가중치, 등급 구간 |
| `data/command/safety_params.json` | 긴급탈출 반복 횟수, 현장안전담당 경고 공기 비율, 진입 판단 요소 유효 시간 |
| `data/command/survey_params.json` | 면 확인 거리·각도, 질문 시간, 현장지휘소 판정(층 높이, 위험반경 비율) |
| `data/command/radio_params.json` | 무전 송신 시간(호출·글자당), 같은 보고 반복 간격, 통솔범위(적정·한계·초과 시 명령 지연) |
| `data/scenarios/*.json` | 출동 지령(dispatch), 현장지휘관(commander), 최초 상황보고 정답(report_truth), 진입 명령 규칙, 후착대 도착표(arrivals), 지원 요청(support), 대기1단계 장소(staging), 현장 정보(site: 면 정보·실내등·현관 신발·관계인 진술), 평가(evaluation: 쓸 규칙, 기준값 덮어쓰기, 제한 시간, 학습 목표), 시작 화면 설명(meta), 차종 제원 덮어쓰기(vehicles), 판마다 다른 시드(variation.random_seed), 요구조자 후보 방(victims[].rooms) |
| `user://scenarios/*.json` | 직접 추가한 시나리오. 시작 화면이 함께 읽고 검증한다 |

예정: 시나리오별 장비 지정(M6).

렌더러는 호환성(OpenGL 3.3)이다. 2D 화면이라 화질 차이가 없고, 내장그래픽 PC에서도 돈다.
