# 소방 지휘관 RTS 훈련게임 개발 기획안

Nov 8, 2026 · @구성민

## 1. 개요

**가칭: 「선착대장 — 화재현장 지휘 시뮬레이터」.** 지휘관 1인이 실시간으로 출동대를 지휘하는 2D 아이소메트릭 RTS 게임입니다. 재난현장표준작전절차(SOP)를 게임 규칙 자체로 만들어, 플레이하는 동안 SOP가 몸에 익도록 하는 것이 목표입니다.

**핵심 컨셉 한 줄:** 대원은 SOP의 기본 행동은 스스로 하고, SOP상 판단이 필요한 순간에는 지휘관에게 "어떻게 할까요?"라고 묻습니다. 지휘관의 선택은 그대로 실행되고, 틀린 선택은 화재 시뮬레이션 안에서 실제와 같은 결과로 돌아옵니다.

### 기획 목표

1. **SOP 내재화:** SOP 100번대(지휘)·200번대(화재)·SSG(안전) 항목을 판단 카드와 시뮬레이션 규칙으로 옮겨, 외우는 대신 겪어서 익힙니다.
2. **현장 판단력:** 전략 선정(공격·방어·병행), 진입경로, 배연, 주수, 대피 우선순위 등 지휘관 판단을 시간 압박 속에서 반복 훈련합니다.
3. **대원 안전 의식:** 공기호흡기 잔량, 2인 1조, 진입 통제, RIT, 긴급탈출을 핵심 메커니즘으로 둡니다.
4. **교육 현장 적용:** 그래픽카드 없는 사무용 PC에서 설치 없이 실행되고, 1회 플레이 15\~25분으로 교육 1교시에 맞춥니다.
5. **재미:** 실시간 긴장감, 매번 달라지는 시나리오, 대원 성장, 등급과 기록 경쟁으로 반복 플레이를 유도합니다.

| --- | --- | --- |

## 2. 교재 분석 결과 — 게임 반영 매핑

1번 SOP는 게임의 **규칙**(무엇을 해야 하는가)이 되고, 2\~5번 소방전술은 게임의 **물리·데이터**(그렇게 하지 않으면 무슨 일이 생기는가)가 됩니다. 아래 표는 게임에 직접 쓰는 항목만 추린 것입니다.

## 3. 핵심 게임플레이

대원의 행동을 **자동행동 · 지휘명령 · 판단요청** 3층으로 나눕니다. 단순 이동과 기본 탐색은 자동, 부대 배치는 RTS식 명령, SOP상 선택이 필요한 순간은 대원이 지휘관에게 물어보는 판단요청입니다.

### 3-1. 제안하신 "대원이 묻고, 지휘관이 고르고, 틀리면 틀린 대로 결과가 나오는" 방식에 대한 판단

**채택을 권합니다.** SOP는 "상황 → 행동" 문장으로 쓰여 있어 선택지 문항으로 옮기기 쉽고, 틀린 선택의 결과를 직접 보면 기억에 오래 남습니다. 다만 그대로 만들면 생길 문제 여섯 가지가 있어, 아래처럼 보완합니다.

| 그대로 만들 때의 문제 | 보완책 |
| --- | --- |
| 오답마다 대형사고가 나면 현실과 다르고, "게임 논리"를 외우게 됨 | 결과를 화재 시뮬레이션이 만든다. 하부 문을 열면 산소가 유입되고, 그 실의 상태(500℃·산소 10%·가연성가스 축적)에 따라 백드래프트가 일어날 수도, 안 일어날 수도 있다 |
| 오답 후 결과가 나타나기까지 간격이 길면 원인을 모름 | 결과를 즉시형·지연형·누적형 3종으로 나누고, 디브리핑에서 "이 결과는 14:32의 이 선택 때문"으로 연결해 보여준다 |
| 게임 중 "오답입니다" 팝업은 몰입을 깨고 답을 찍게 만듦 | 게임 중에는 무전 보고와 현상(연기 색, 소리, 온도)으로만 알리고, 정답·SOP 근거는 디브리핑에서만 공개한다 |
| 같은 질문이 반복되면 번호를 외우게 됨 | 선택지 순서 무작위, 같은 카드도 문구·상황을 3가지 이상 변형, 상황에 따라 정답이 바뀌는 카드 포함(예: 같은 문 개방도 백드래프트 징후 유무에 따라 답이 다름) |
| 대원이 물어볼 때까지 기다리기만 하면 수동적인 지휘관을 훈련하게 됨 | **선제지시 보너스:** 대원이 묻기 전에 지휘관이 먼저 올바른 명령(예: 진입 전 가스탐지기 작동)을 내리면 질문 없이 수행하고 더 높은 점수를 준다 |
| 모르는 상황에서도 반드시 찍어야 함 | 일부 카드에 **"정보 확인"** 선택지(관계인 질문, 수신반 확인, 열화상카메라) 추가. 시간은 들지만 다음 선택의 근거를 준다 (SOP 102의 상황평가 훈련) |

추가로 **대원 숙련도**를 넣습니다. 신임 대원은 더 자주 물어보고, 고참 대원은 기본 SOP를 스스로 처리합니다. SOP 108의 "경험 부족 대원은 경험 많은 대원과 조편성"이 그대로 전략 요소가 되고, 게임을 반복할수록 내 대원이 성장하는 재미도 생깁니다.

### 3-3. "항상 실시간" 질문 처리 규칙

게임은 절대 멈추지 않으므로 질문이 쌓일 때의 규칙이 게임성의 핵심입니다.

1. **질문 대기열:** 화면 가운데에 한 장씩 뜨고 나머지는 뒤에서 기다리며(최대 3장), 만장이면 새 질문은 무전 로그에서 "대기 중"으로 밀립니다.
2. **긴급도 3단계:** 일반(흰색, 20초) · 중요(노란색, 12초) · 긴급(빨간색, 8초). 긴급 카드는 대기열 맨 앞으로 끼어듭니다. 초 수는 게임 설정값이며 시범운영에서 조정합니다.
3. **미응답 시:** 대원은 "지시 대기"로 멈춥니다. 멈춘 동안에도 공기는 줄고 불은 커집니다. 안전한 기본값을 주지 않는 이유는, 무시해도 손해가 없으면 질문을 안 읽게 되기 때문입니다.
4. **빠른 조작:** 숫자키 1\~4로 맨 앞 카드에 답하고, Space는 질문한 대원으로 화면을 이동합니다. 카드마다 질문한 대원의 위치·공기잔량·주변 온도를 작게 보여줍니다.
5. **질문 감소 수단:** 선제지시, 고참 대원 배치, 단위지휘관 지정(후반 스테이지에서 단위지휘관이 일부 카드를 대신 처리)으로 질문 수를 줄이는 것 자체가 지휘 실력입니다.
6. **초급자 배려:** 질문 시 멈추지는 않되, 튜토리얼과 챕터 1은 제한시간을 2배로 둡니다.

선제지시를 하면 질문 자체가 사라지고, 응답하지 않으면 대원은 멈춘 채 시간만 흐릅니다. 결과는 카드가 아니라 화재 시뮬레이션이 정합니다.

### 4-1. 개발 순서

기존 아파트(2-1)를 먼저 완성해 **버티컬 슬라이스**(한 스테이지를 출시 품질로 끝까지 만든 것)로 직원 시범교육을 하고, 그 피드백으로 나머지 스테이지를 만드는 것을 권합니다. 순서는 2-1 → 0(튜토리얼) → 1-1 → 1-2 → 2-2 → 3-1 → 3-2 → 3-3 → 4-1 입니다.

### 4-2. 맵 제작 규칙 (아파트 기준)

- **외부 맵:** 단지 도로, 주차 차량(이동 지시 대상), 화단·조경수(굴절차·에어매트 장애물), 지상·지하 소화전 2\~3개, 연결송수구, 가공전선, 관리사무소(수신반)를 배치합니다.
- **내부 맵:** 플레이 가능한 층은 1층, 발화층, 발화층 위아래 2개층, 옥상입니다. 나머지 층은 계단실과 복도만 단순 구조로 두어 PC 부담과 제작량을 줄입니다.
- **세대 내부:** 현관, 거실, 주방, 침실 2\~3, 화장실, 발코니(대피공간·경량칸막이 포함)로 구성합니다. 문·창문은 닫힘·열림·파손 3상태이며 환기 계산에 쓰입니다.
- **요구조자 단서:** 불 켜진 창, 현관 신발 수, 발코니의 사람을 보여주고, 관계인 NPC가 "위층 할머니가 혼자 살아요" 같은 정보를 줍니다(SOP 202 2.3).

#### 4-2-1. 층·세대마다 다른 구조와 집기

**판단: "같은 뼈대, 다른 속"으로 만듭니다.** 아파트는 같은 동이면 최상층·1층을 빼고 층마다 평면이 같은 경우가 많지만, 세대마다 확장·리모델링·가구 배치가 다릅니다. 교재도 이 점을 전술에 씁니다. 지상은 직하층으로 진입하고(SOP 202 각주), 미로형 시설은 발화층의 직하층 내부구조를 먼저 익힌 뒤 탐색합니다(SOP 202 4.4). 즉 "아래층과 비슷할 것"을 이용하되, "다를 수 있다"는 점을 염두에 두는 것이 실제 현장입니다.

| 상용 게임 | 방식 | 가져올 점 |
| --- | --- | --- |
| XCOM 2 | 건물 틀은 고정하고 구획(파셸)만 바꿔 끼움 | 동·층은 고정, 세대 안만 변형을 골라 끼움 |
| 히트맨 | 같은 맵이라도 임무마다 물건·사람 배치가 다름 | 같은 아파트를 여러 번 훈련해도 매번 다른 상황 |
| 스폰키 | 방 템플릿 + 시드(난수 번호) | 같은 시드면 같은 맵 → 리플레이·교관 출제에 쓸 수 있음 |

**데이터 4단계**

1. **동(건물 틀):** 층수, 계단실·승강로·샤프트 위치, 층별 세대 타입 배치. 수직 연결부는 모든 층이 같아야 하므로 여기서 고정합니다.
2. **세대 타입:** 평형별 표준 평면(A·B·C). 1층(필로티·상가)과 최상층(복층 등)은 별도 타입.
3. **세대 변형:** 발코니 확장 여부, 벽 철거·리모델링, 발코니 피난시설 상태(짐으로 막힘 등), 현관문 잠김·도어체크. 타입마다 2\~4개.
4. **집기 세트:** 일반 가정, 노인 1인 가구, 짐이 많이 쌓인 세대, 공실·이사 중, 리모델링 중(자재 적치) 등. 가구마다 재질·가연물량·크기·막힘 여부를 둡니다.

스테이지는 "동 + 세대별 (변형, 집기 세트)"를 난수 번호로 고릅니다. 교관이 만든 스테이지는 번호를 고정해 모두 같은 상황을 훈련하고, 자유 훈련은 매번 다르게 뽑습니다. 같은 번호면 항상 같은 맵이라 리플레이가 깨지지 않습니다.

**게임에 미치는 영향**

- **도면은 표준 타입만 보여 줍니다.** 변형과 가구는 도면에 없고, 대원이 본 것만 실제 구조로 덮어씁니다(9-1).
- **직하층 확인(새 임무):** 팀을 화점 세대 바로 아래 세대로 보내면, 그 세대 구조가 전술상황판에 화점 세대의 "추정 구조"(점선)로 격자 표시됩니다. 실제로 다르면 들어간 대원이 "구조가 다릅니다(발코니 확장)" 등으로 보고합니다.
- **같은 평면이라도 불은 다르게 탑니다.** 집기 세트가 가연물량·α·독성을 정하므로(5-2-1, 5-3-4) 짐이 많은 세대는 빨리 커지고 잔화도 많이 남습니다.
- **검색과 이동:** 가구는 지나갈 수 있지만 느려지는 칸 또는 막힌 칸입니다. 짐이 많으면 검색이 느려지고 퇴로가 좁아집니다.
- **요구조자 위치:** 교재의 중점 탐색 장소(화염 반대쪽 장롯·이불·막힌 통로·창가, 화장실·베란다)에 더 자주 있게 합니다(SOP 202 4.1\~4.2).
- **밖에서 보는 단서:** 세대별 실내등 점등, 출입구 신발 수(SOP 202 2.3.1), 도어체크가 걸린 문(화재1: 요구조자가 있다고 판단)을 집기·변형 데이터와 함께 둡니다.
- **판단거리:** "아래층과 같겠지"라고 바로 들어갈지, 직하층을 먼저 확인할지가 지휘관의 선택이 됩니다. 디브리핑에서 직하층 확인 여부와 그 때문에 줄거나 늘어난 시간을 보여 줍니다.
- **제작량:** 세대 타입 3\~5개 × 변형 2\~4개 × 집기 세트 5\~6개면 수백 가지 조합이 나오고, 그림은 가구 단위로만 만들면 됩니다.
- **가벼움:** 가구는 노드가 아니라 데이터로 두고, 보는 층만 그립니다.
- 변형 목록 중 발코니 피난시설(경량칸막이·대피공간·하향식 피난구)은 이번 교재 범위에 없는 내용이라 게임 설정값으로 두고 검수가 필요합니다.

### 4-3. 확장팩 후보 (본 기획 이후)

지하철(215), 지하가(216), 도로터널(219), 차량·친환경차(225·241), ESS(238), 리튬배터리 창고(242), 목조문화유산(228), 위험물·가스 저장시설(236·237), 산림(224). 이들은 터널 기류, 열폭주, BLEVE 등 별도 물리 규칙이 필요해 본 기획의 엔진이 완성된 뒤 추가합니다.

### 4-4. 전체 지도와 출동 단계

**지도 표현:** 화재 건물, 도로, 소화전·주차차량·가공전선·수목 같은 활동에 영향을 주는 것만 색과 디테일을 넣고, 나머지 건물은 흰색 덩어리(매스 모형)로만 그립니다. 눈이 자연스럽게 화재 건물로 가고, 그림량과 PC 부담도 크게 줄어듭니다. 단, 인접 건물에 불이 번질 위험이 생기면 그 건물도 색이 들어갑니다(주택 스테이지의 연소확대).

**시간축 판단:** 지적하신 대로 "도착했는데 이제 불이 나는" 구조는 현실과 맞지 않습니다. 더 정확히는 불은 신고보다도 먼저 시작됩니다. 따라서 선착대 도착 시점의 화재는 **"발화→신고 지연 + 출동 4분"만큼 진행된 상태**여야 합니다. 게임에서는 이렇게 처리합니다.

1. **사전 계산:** 스테이지를 열 때 화재 엔진을 화면 없이 빠르게 돌려 "발화→신고 지연"(시나리오별 2\~6분, 야간·숙면이면 길게) 동안의 연기·불·요구조자 상태를 만듭니다. 구획실 모델이라 사무용 PC에서 2초 안팎이면 됩니다.
2. **출동 단계(신고 접수 00:00 → 선착대 도착 04:00):** 게임 시계는 4분이 흐르지만 실제로는 약 1분 30초로 압축합니다. 이동만 보는 4분은 지루하고, 그렇다고 건너뛰면 출동 중 판단 훈련이 사라지기 때문입니다. 이 동안에도 화재는 뒤에서 계속 진행됩니다.
3. **도착 후:** 현장 시계의 기본 배속(실전 2배, 5-8)으로 흐릅니다.

시계는 "신고 후 경과"로 표시하고, 디브리핑에서는 "발화 후 경과"도 함께 보여 줍니다.

| 출동대 | 신고 후 도착(기본값) |
| --- | --- |
| 선착대(펌프차) | 4분 |
| 구조대·구급대·물탱크차 | 5분 |
| 후착분대 | 6분 |
| 굴절·고가사다리차 | 8분 |
| 지휘대 | 10분 |

선착대 4분은 요청하신 값이고, 나머지는 게임 설정값입니다. 시나리오 파일에서 센터 거리에 맞게 바꿉니다. 출동 중 판단이 그루하면 도착·전개가 늦어집니다. 예를 들어 관계자에게 주차차량 이동을 요청하지 않으면 굴절차 전개가 늦어집니다.

**출동 단계에서 지휘관이 하는 일 (SOP 200 1\~2단계, 201 1.1)**

- **상황실 무전 듣기:** 신고 내용, 추가 신고, 건물 정보(층수·구조·소방시설), 유관기관 조치가 차례로 들어옵니다. 시나리오마다 일부는 부정확합니다.
- **현장 상황 추정과 장비 지시:** 들은 정보로 필요한 장비를 골라 분대원에게 챙기게 합니다(방화문 파괴기, 열화상카메라, 가스탐지기, 연결송수관용 장비팩, 라이트라인 등). 가져가지 않은 장비는 도착 후 차량까지 가서 가져와야 해 시간이 듭니다.
- **도착 후 임무 미리 정하기:** 누가 관창을 들고, 누가 검색하고, 누가 방재실로 갈지 정해 두면 도착 즉시 움직입니다.
- **상황실에 요청:** 예비 소방용수 2개소 선정, 관계자 조치(발화세대 확인·가스 차단·주차차량 이동·피난 방송), 응원 요청.
- 이 선택들은 출동 단계 질문 카드와 "출동 준비판"으로 주고, 디브리핑에서 평가합니다.

**도착 연출:** 출동 단계에는 흰 덩어리 도시를 멀리서 보며, 화재 건물에서 오르는 연기 기둥과 도로를 따라 다가가는 소방차 아이콘을 봅니다. 선착대가 건물 앞에 이르면 카메라가 건물로 확대되고, 이후 출동대는 정해진 도착 시간에 맞춰 차례로 들어옵니다. 선착대가 도착하면 차량 배치부터 시작합니다. 반복 플레이를 위해 연출은 건너뛸 수 있지만, 출동 중 결정은 건너뛸 수 없습니다.

## 5. 시뮬레이션 모델

**화재·연기는 "구획실(방) 단위 2층 모델", 불꽃 모양과 대원 위치는 "1m 타일"로 계산합니다.** 방마다 천장 쪽 뜨거운 연기층과 바닥 쪽 차가운 공기층을 따로 두고, 문·창·계단실·샤프트로 연결합니다. 이 방식은 중성대, 플래시오버, 백드래프트를 교재의 조건 그대로 재현하면서도 계산량이 적어 사무용 PC에서 충분히 돌아갑니다.

### 5-1. 구획실 상태값

### 5-2. 화재 단계 전이 규칙

화재는 교재(소방전술 화재1 제2장 제3절)의 5단계를 따릅니다. 성장기 열방출률은 화재공학의 표준 모델인 t² 화재(Q = αt²)로 키우고, α는 가연물 종류로 정합니다(주택 가구류 보통·빠름, 샌드위치패널·우레탄 매우 빠름).

| 전이 | 조건 | 근거 |
| --- | --- | --- |
| 발화기 → 성장기 | 최초 가연물에서 주변 가연물로 열 전달 | 화재1 제2장 |
| 성장기 중 롤오버 | 상부층에 가연성가스 집적 + 발화온도 도달, 플래시오버 전조 | SOP 210 3 |
| 성장기 → 플래시오버 | 상부층 약 500℃ 전후 | 화재2 연소이론 |
| 플래시오버 → 최성기 | 실 전체 연소, 열방출률이 개구부 크기로 제한(환기지배) | 화재1 제2장 |
| 연소 완화(훈소) | 산소 15% 이하에서 연소 곤란, 가연성가스 쌓임 | 화재2 연소이론 |
| 백드래프트 | 평균 500℃ 전후 + 산소 약 10% + 가연성가스 다량 축적 상태에서 개구부로 공기 급유입 | 화재2, SOP 210 4 |
| 화재가스발화(FGI) | 인접 공간·천장 위에 가연성 혼합기 + 점화원(문 개방, 고압 직사주수, 장비 불꽃) | SOP 210 10 |
| 대피 기준 | 열화상카메라 350℃ 이상이면 대피, 패널마감 건물 500℃ 도달 시 진입 중단 | SOP 210 10.5.4, SOP 240 |
| 최성기 → 쇠퇴기 | 남은 가연물량 감소 | 화재1 제2장 |

#### 5-2-1. 발화와 화재 진행 속도

**발화(화재 발생)는 스테이지 데이터로 정합니다.** 발화 세대·방, 최초 가연물(종류·크기·위치), 발화원(전기·가스·담배·방화 등), 발화 시각을 적고, 발화부터 도착까지는 미리 계산합니다(4-4). 발화기에는 최초 가연물만 탑니다(화재1 제2장 제3절).

**화재 진행에 영향을 주는 요인 6가지를 모두 구획실 데이터로 둡니다**(화재1 제2장 제4절).

| 교재 요인 | 구획실 데이터 | 효과 |
| --- | --- | --- |
| 배연구(개구부) 크기·수·위치 | 문·창 목록과 면적·높이 | 최성기 열방출률 상한(환기지배), 중성대 위치 |
| 구획실 크기 | 바닥면적 | 연기층이 차는 속도 |
| 둘러싼 물질의 열 특성 | 벽 종류(내화조·경량칸막이·샌드위치패널·목조) | 실내 온도 상승 속도, 옆방으로 전도 |
| 천장 높이 | 천장고 | 연기층 하강 속도 |
| 최초 가연물의 크기·성분·위치 | 가연물 목록(재질·양·위치) | 성장 속도 α. 벽 옆·구석은 공기를 덜 빨아들여 화염 온도가 높음 |
| 추가 가연물 | 가연물 목록 | 플래시오버까지 시간, 남은 가연물량 |

- **가연물 재질:** 폴리우레탄·폼 가구·매트리스·팔레트 더미는 열방출률이 높아 급속히 탑니다. 같은 성분이면 저밀도가 고밀도보다 빨리 탑니다(화재1 제2장 제4절). → 가연물마다 α 등급과 연소열을 둡니다.
- **연료지배와 환기지배:** 성장기는 가연물이 결정하고(교재 "통제된 가연물"), 최성기는 개구부 크기가 결정합니다("통제된 배연").

**검수 기준값(교재):**

| 항목 | 교재 값 | 근거 |
| --- | --- | --- |
| 플래시오버 온도 | 약 483\~649℃ (게임 기본 500℃) | 화재1 제2장 제5절 |

#### 5-2-2. 연소 확대: 열이 옮겨 가는 네 가지 길

교재는 연소 확대 원인을 전도·대류·복사·비화로 나눕니다(화재2 제4편 제5절, 화재1 제2장 제1절). 게임은 넷을 따로 계산합니다.

| 방식 | 교재 내용 | 게임 규칙 | 플레이어가 막는 법 |
| --- | --- | --- | --- |
| 대류 | 초기 구획실 화재의 가장 중요한 열전달. 방출 에너지의 약 70%. 천장 제트·연기층이 위쪽 가연물을 예열 | 연기층이 닿는 방·복도의 가연물에 "예열값"을 누적(연기층 온도·두께 × 시간). 발화온도에 이르면 그 방이 발화 | 문 닫기, 배연, 상부층 분무 냉각 |
| 복사 | 가열된 연기층이 바닥 가연물을 가열해 플래시오버. 떨어진 건물에 불이 붙는 노출화재의 주원인 | 방 안: 상부층 온도로 바닥 가연물 착화. 바깥: 창 분출화염이 마주 보는 창·인접 동을 가열 | 상부층 냉각, 인접 동 쪽 경계관창·사전 살수 |
| 전도 | 벽·바닥·금속을 통해 이동 | 화재실과 맞닿은 벽·슬래브 너머 가연물을 천천히 가열. 내화조는 느리고 경량칸막이·샌드위치패널은 빠름. 금속 관통부·철판 내장 뒤는 숨은 발화점 | 인접실 열화상 확인, 벽 쪽 가연물 이동 |
| 비화 | 불티가 기류를 타고 옮겨 붙음. 화재가스발화의 점화원이 될 수 있음 | 풍속 5m/s 이상이면 풍하측에 불티 착화 확률(게임 설정값). 천장 위 가연성 혼합기에 불티가 닿으면 화재가스발화 | 풍하측 비화경계 관창 |

**바람과 관창 배치(화재1 제4장 제10절):** 풍속 3m/s 초과면 풍하측 연소 위험이 크고, 5m/s 이상이면 비화를 경계하며, 3m/s 이하면 복사열이 큰 쪽이 위험하고, 13m/s 이상 강풍이면 풍횡측에 대구경 관창으로 협공합니다. 바람은 확대 방향 가중치로 쓰고, 디브리핑에서 관창 배치가 이 기준에 맞았는지 평가합니다.

**방에서 방으로 번지는 조건**

1. **문·개구부가 열려 있으면** 연기층이 넘어가 옆 공간을 예열합니다. 최성기 화재실의 미연소 가스는 산소가 많은 옆 공간에서 발화합니다(화재1 제2장 제3절). 그래서 화재실 문이 열린 복도는 빠르게 위험해집니다.
2. **문이 닫혀 있으면** 전도로만 가열되어 훨씬 느립니다. 문은 내화 시간(게임 설정값)이 지나면 손상됩니다.
3. **숨은 공간:** 천장 속, 벽 속, 방화셔터 감는 부분, 슬래브와 벽 사이 틈을 따라 옆 구획으로 번집니다(화재1 제4장 제10절). 화면에 보이지 않고 열화상과 부분파괴로만 확인합니다.
4. **플레임오버:** 복도·계단의 벽·천장 가연성 마감 표면을 따라 불꽃이 급속히 퍼져, 대원 뒤쪽에서 확대해 고립시킬 수 있습니다(화재1 제2장 제5절). 맵 데이터에 마감재 등급(불연·준불연·난연·가연)을 둡니다.
5. **롤오버:** 뜨거운 가연성 가스가 천장을 따라 굴러가며 성큼성큼 건너뛰듯 번져, 복도에서 대기하던 대원을 고립시킬 수 있습니다. 화재실 문을 닫으면 예방되고, 플래시오버의 전조입니다(화재1 제2장 제5절).
6. **연기폭발:** 밀폐공간 가장자리로 새는 정도의 공기가 들어오고 열분해 산물·CO가 연소범위에 이르면, 점화원에 의해 압력 상승을 동반하며 폭발합니다. 우레탄폼 마감 건물에서 옆 구획 연기가 들어온 공간이 위험하고, 환기로 산소가 들어와도 일어날 수 있습니다(SOP 210 11).

**층에서 층으로 번지는 경로(수직 확대)**

맵 데이터에 수직 연결부(샤프트 오브젝트)를 두고, 각각 "닫힘 상태·가연성 보온재·마감 불량" 속성을 줍니다. 연결된 위층 칸을 예열합니다.

| 경로 | 번지는 조건 | 교재의 대응 | 근거 |
| --- | --- | --- | --- |
| 창 → 위층 창(자동노출) | 발코니·차양 없는 벽, 위층 창이 열림, 창가 커튼 | 위층 창 닫기, 커튼·가연물 제거, 창 부근 주수 | 화재1 제5장 제5절, SOP 223 1.8 |
| 발코니·스팬드럴 | 차열 효과가 크지만 발코니에 가연물이 있으면 확대 | 발코니 가연물 경계 | 화재1 제4장 제10절 |
| 계단실 | 화점층 계단실 방화문이 열리면 굴뚝 상태 | 화점층·직상층 계단실 문 폐쇄, 옥탑 문 개방 | 화재1 제4장 제10절 |
| 엘리베이터 | 승강로 전실에 화염 유입 | 직상층·최상층(정지층과 그 직하층) 경계 | 화재1 제4장 제10절 |
| 파이프 샤프트 | 관통부 매설 불량, 가연성 보온재, 염화비닐 배관(맹독성 가스) | 최상층·점검구에서 주수, 과잉주수 시 기계실 수손 | 화재1 제4장 제10절 |
| 전기 샤프트(EPS)·케이블 | 케이블 피복을 따라 빠르게 확산 | 집중방수·제거소화 | SOP 223 1.7, 화재1 제5장 제5절 |
| 덕트·방화댐퍼 | 관통부 매설 불량, 댐퍼 열림 | 화점층·직상층·최상층 관창, 댐퍼 폐쇄 | 화재1 제4장 제10절 |
| 커튼월 틈 | 바닥판과의 틈이 수직 통로 | 각 층 틈새 확인 | 화재1 제5장 제5절 |
| 슬래브 구멍·관통부 | 마감 불완전 | 직상층 경계 | SOP 223 1.7 |
| 더스트 슈트·기계 진입구 | 연기 분출 | 상황 확인 후 관창 | 화재1 제4장 제10절 |

**경계 범위:** 1차 경계는 화점 직상층이고, 직상층이 돌파될 우려가 있으면 그 위층으로 넓힙니다(SOP 223 2.9). 아파트는 초기 진화 기회를 놓치면 상층부로 확대됩니다(SOP 213 1.1). 디브리핑에서 직상층·최상층 경계를 언제 했는지 평가합니다.

### 5-3. 연기 이동

- 연기는 개구부를 통해 압력·온도 차이로 이동합니다. 화점실에서 계단실을 거쳐 **위층부터 차례로** 차고, 급기측과 배기측이 구분됩니다(SOP 223 1.3).
- 고층은 굴뚝효과를 넣습니다. 겨울에는 상승 기류가 강하고, 여름에는 아래로 흐를 수 있습니다(화재1 배연).
- 수직 연소 경로: 발코니 없는 창의 분출화염, EPS 샤프트, 슬래브 관통부, 열린 계단실 방화문(SOP 223 1.7\~1.9).
- 시계(m)는 연기 농도로 계산하고, 시계가 낮은 곳은 화면에 회색 안개로 가려 \*\*시야(fog of war)\*\*로 씁니다. 열화상카메라를 가진 대원 주변만 온도가 보입니다.
- 배연: 자연배연(창 개방), 송풍기 양압배연, 수직배연(상부 개방)을 명령으로 제공합니다. 배기구 없이 급기만 하면 연기가 요구조자 쪽으로 밀리고 화세가 커집니다.

#### 5-3-1. 연기 이동 속도

교재의 연기 유동 속도를 연기 선두가 움직이는 속도의 기준으로 씁니다(화재2 제4편 제7절).

| 방향 | 속도 | 비교 |
| --- | --- | --- |
| 수평 | 0.5\~1m/s | 사람 보행 1\~1.2m/s보다 느림 |
| 수직 | 2\~3m/s | 사람보다 빠름 |
| 계단(화재 초기) | 약 1.5m/s |  |
| 계단(화재 중기 이후) | 3\~4m/s |  |
| 굴뚝효과가 있는 건물 | 5m/s 이상 |  |

- 그래서 연기는 복도에서는 사람보다 느리지만 계단실에서는 사람보다 빠르고, "위층부터 차례로 찬다"(SOP 223 1.3)는 현상이 계산 결과로 나옵니다.
- **연기 속 보행:** 발밑과 벽이 보이지 않을 정도가 되면 보행속도가 현저히 느려지고 공황 위험이 커집니다(화재2 제4편 제7절). 요구조자·주민의 자력대피 속도를 시야에 따라 줄입니다.

#### 5-3-2. 연기를 움직이는 힘 여섯 가지

교재는 연기 이동력으로 굴뚝효과, 부력, 팽창, 바람, 공조설비(HVAC), 엘리베이터 피스톤 효과를 듭니다(화재2 제4편 제8절). 지금 기획안은 굴뚝효과와 부력만 다루므로 나머지를 더합니다.

| 힘 | 교재 내용 | 게임 규칙 | 플레이어 조작 |
| --- | --- | --- | --- |
| 굴뚝효과 | 실내외 온도차로 수직공간에 상승기류. 겨울 상향, 여름 하향(역굴뚝효과). 높고 밀폐될수록 강함 | 계절·건물 높이로 계단실·승강로 기류 방향과 세기 결정 | 계단 지정, 옥탑·1층 문 개폐 |
| 부력 | 고온 연기가 위로. 화염에서 멀어질수록 식어 약해짐 | 연기 온도를 거리에 따라 감쇠, 식은 연기는 층을 이루며 머묾 | 배연 |
| 팽창 | 개구부가 하나면 공기는 들어오고 연기는 나감. 큰 개구부가 여럿이면 압력차 무시 | 개구부 수에 따라 유입·유출 결정 | 개구부 개폐 |
| 바람 | 풍압이 건물 내 공기 누출·이동을 일으킴. 창·틈이 많을수록 영향 큼 | 풍상측 개구부는 급기, 풍하측은 배기로 작용(세기는 게임 설정값) | 진입은 풍상·급기측에서 |
| 공조설비 | 화재 구역에 공기를 계속 보내면 확산 가속. 화점층에서 10\~20층 위로 확대 가능 | 공조 가동 중이면 덕트로 연결된 층에 연기 전달 | 방재실·관리사무소에서 공조 정지 |
| 엘리베이터 피스톤 효과 | 승강기 이동 시 흡입압력으로 로비·승강로에 연기 유입 | 일반 운행 중이면 승강로로 연기 유입 증가 | 비상용 승강기 소방운전 전환(SOP 222 2.10) |

아파트 스테이지는 굴뚝효과·부력·팽창·바람·엘리베이터를 쓰고, 공조설비는 주상복합·상가 스테이지부터 씁니다. 공조 경로로 인한 고층 확대는 화재1 제4장 제8절에도 나옵니다.

#### 5-3-3. 중성대와 개구부 조작

중성대는 실내외 압력이 같은 높이로, 위로는 연기가 나가고 아래로는 신선한 공기가 들어옵니다(화재2 제4편 제8절). 연기층 높이(5-1)를 개구부 조작에 따라 다음처럼 움직입니다.

- **위쪽 개구부를 열면** 중성대가 올라가 아래쪽 시야와 활동공간이 넓어집니다. 대신 공기가 더 들어와 화세가 커질 수 있습니다.
- **아래쪽 개구부를 열면** 중성대가 내려갑니다. 고층 위층 창에 중성대가 생겨 연기가 분출할 때 아래층에 개구부를 만들면, 그 창 전체가 배기구가 될 수 있습니다(화재1 제4장 제7절).
- **아래쪽으로 공기가 계속 들어오면** 연소가 빨라지고 연기 발생량이 늘어 연기층이 빨리 내려와 요구조자 생존 가능성이 낮아집니다.
- **배연 효과 순서:** 지붕 중앙 파괴 > 지붕 가장자리 파괴 > 상층 개구부 파괴.
- **도착 시 판단 단서(질문 카드 근거):** 아래층 출입문으로 짙은 연기가 나오면 상층 개구부 개방을 고려합니다. 아래 개구부로 연기가 나오지 않으면 상층이 열려 있다고 보고 공기가 들어가는 출입문 쪽을 급기측으로 판단합니다.
- **연기 흐름 경로(Flow Path):** 압력이 높은 화점실의 열·연기는 열린 문·창 쪽으로 흐릅니다. 급기구 → 화점 → 배기구 경로 위에 있는 대원은 화염이 덮칠 수 있습니다. 방수 준비 전까지 경로를 막으면(문 닫기) 열방출률과 온도 상승이 억제됩니다(화재1 제2장 제5절).
- **가스층 열 균형:** 온도가 가장 높은 가스층에 바로 물을 뿌리면 수증기가 섞여 뜨거운 가스가 바닥까지 내려와 화상을 입습니다(화재1 제2장 제5절). 배기구 없이 상부층에 분무하면 상하층 온도를 섞습니다.

#### 5-3-4. 연기의 성질과 화면 단서

- **색:** 화재 초기는 흰 연기·수증기, 중기 이후는 검은 연기와 창 파손 화염 분출입니다(SOP 223 1.1, 1.4). 산소가 부족하면 탄소가 생겨 검어집니다(화재2 제4편 제7절). 창에서 나오는 연기의 색·양·속도를 화재 단계에 맞춰 그립니다.
- **외부에서 화점 추정 단서(화재1 제4장):** 연기가 나오는 층 이하를 화점층으로 판단합니다. 최상층 창에서 분출이 약한 흰 연기가 나오면 아래층이 화점인 경우가 많습니다. 야간에는 조명이 꺼진 층이 화점인 경우가 많습니다. 이 단서를 화면에 그리고 "화점층 판단" 카드로 묻습니다.
- **독성 가스(가연물 재질별, 화재2 표 4-12):** 우레탄·나일론·고무·모직은 시안화수소, 플라스틱·PVC는 염화수소, 중질유·고무·황화합물은 아황산가스, 불완전연소는 일산화탄소. 방 가연물 재질에 따라 연기 독성 계수를 정해 요구조자 모델(5-5)에 씁니다.
- **산소 농도와 인체(화재2 제4편 제7절):** 18%가 안전 최저, 16\~12%는 집중력·근력 저하, 14\~9%는 판단력 저하, 10\~6%는 의식 상실, 6% 이하는 6분 만에 사망. 요구조자 상태 계산에 넣습니다.
- **백드래프트 징후(화재1 표 1-9):** 공기가 빨려 드는 휘파람 소리·진동, 건물로 되돌아오거나 소용돌이치는 연기, 화염은 안 보이는데 뜨거운 창·문, 유리창 안쪽에 흘러내리는 검은 액체. 화면·소리 단서로 보여 줍니다.
- **플래시오버 징후(화재1 표 1-10):** 롤오버, 두텁고 뜨거운 연기가 아래로 쌓임, 대원이 낮은 자세를 유지할 수밖에 없는 열기.

### 5-4. 방수·소방용수

| 주수 모드 | 효과 | 부작용 |
| --- | --- | --- |
| 직사주수 | 멀리 닿고 화점 가연물 냉각이 큼 | 물 사용량·수손 큼, 구조물 충격(SOP 205 3.2), 혼합기 점화원 가능 |
| 분무주수(고·중·저속) | 연기층 열 흡수, 대원 보호 | 배기구 없는 방에서는 수증기로 열기가 내려와 대원·요구조자 화상 |
| 펜슬링·3D 주수 | 적은 물로 상부층 냉각, FGI 완충 | 숙련도 높은 대원만 가능 |
| 엄호주수 | 구조·진입 대원 보호 | 관창 1개 묶임 |
| 방수포 | 대량 주수 | 진입대원 있을 때 열기 역류로 피해(SOP 207 1.1), 장시간 사용 시 붕괴 위험(SOP 205 3.4) |

- 물은 차량 물탱크 → 펌프 → 호스 → 관창으로 흐릅니다. 탱크가 비면 방수가 멈추므로, 물탱크차 급수·소화전 점령·순환보수가 필수입니다(SOP 200 3.1).
- 호스는 본 단위 자원입니다. 모통이에 여유호스가 없거나 꺾이면 관창 압력이 떨어집니다(SOP 208).
- 아파트·고층은 옥내소화전과 연결송수관을 쓰면 호스 연장 시간이 크게 줍니다(SOP 235).
- 주수량은 하층 수손으로 누적되고, 평가의 재산피해에 들어갑니다(SOP 202 6.2 무작위 다량주수 지양).

**물을 뿌린다고 불이 꺼지는 것이 아닙니다.** 불의 규모에 비해 방수량이 모자라면 불은 계속 커집니다. 구획실마다 "필요 방수량"을 계산하고, 그 방에 닿는 관창들의 방수량 합계와 비교합니다.

```latex
\text{필요 방수량(L/min)} \approx 13.6 \times \text{연소 중인 면적(m^2)}
```

이 식은 미국 국립소방학교(NFA)의 화재 필요 유량 공식(면적 ft² ÷ 3 = gpm)을 미터법으로 바꾼 것이며, 실제 수치는 검수 후 확정합니다. 화재하중이 큰 곳(창고·샌드위치패널)은 계수를 키웁니다.

| 방수량 비율(실제 ÷ 필요) | 결과 |
| --- | --- |
| 1 이상 | 불이 줄어듦(비율이 클수록 빨리) |
| 0.5\~1 | 성장이 느려지지만 꺼지지 않음 → "수량이 부족합니다" 보고, 수관 추가 필요 |
| 0.5 미만 | 불이 계속 커짐, 관창수 주변 열기 증가 |

**방수 효과는 "빼앗는 열"로 계산합니다.** 그래야 방수량·방수 시간·불의 크기·가연물 양이 하나로 이어집니다.

- 교재 값으로 물 1L가 흡수하는 열을 구합니다. 20℃ 물을 100℃로 올리는 데 80cal/g, 증발 잠열 539.6cal/g이므로 다 증발하면 약 2.6MJ/L입니다(화재2 제2편 제2장).
- 관창의 냉각력 = 방수량(L/s) × 2.6MJ × 효율. 효율은 주수 형태·도달 여부별 게임 설정값(검수 필요)입니다.
- 냉각력이 그 방의 열방출률보다 크면 불의 에너지가 줄어 연소 면적이 줄고, 작으면 계속 커집니다. 남은 가연물이 많을수록 다시 커지려는 힘이 큽니다.
- 예: 40mm 1선(275L/min ≈ 4.6L/s)은 효율 100%여도 약 12MW, 효율 30%면 약 3.6MW입니다. 플래시오버 상태 거실(10MW 이상 가능)은 1선으로 꺼지지 않고, 위 비율표의 "0.5 미만"과 같은 결과가 됩니다.
- **직사와 분무의 역할:** 분무는 연기층 열을 빼앗아 플래시오버를 늦추고 대원을 보호하지만, 타고 있는 가연물을 끄는 것은 그 가연물에 닿는 주수입니다(교재: 연소실체를 목표로 주수). 연기층만 식히고 화점을 못 찾으면 불은 다시 커집니다.
- 필요 방수량(13.6 × 연소 면적) 식은 화면에 보여 주는 안내값으로 계속 씁니다.

**관창별 방수량과 물 소모:**

| 호스 | 사용 위치 | 방수량 |
| --- | --- | --- |
| 65mm | 외부 | 611 L/min |
| 40mm | 내부 | 275 L/min |

- 물탱크 용량은 펌프차 2,800L, 물탱크차 4,000L입니다. 펌프차 물탱크는 연결된 관창들의 방수량 합계만큼 줄어듭니다. 40mm 2선이면 분당 550L가 빠져 한 선일 때보다 2배 빨리 비웁니다.
- 급수는 분당 180L입니다. 물탱크차를 연결하면 물탱크차에 물이 남아 있는 동안 분당 180L로 채워지고, 소화전은 분당 180L가 끊임없이 들어옵니다. 물은 방수할 때만 초 단위로 줄어듭니다. 그래서 급수가 있어도 40mm 1선(275L)만 쏴도 분당 95L씩 줄고, 40mm 2선(550L)이면 분당 370L씩 줄어 급수 하나로는 버틸 수 없습니다. 방수를 멈추면 탱크가 다시 차오릅니다.
- 물탱크 잔량 25%에서 운전원이 무전으로 경고하고 상황판 "확인 필요"에 올라갑니다.

이 값으로 계산한 펌프차 방수 가능 시간(현장 시간, 가득 찬 상태에서 시작)입니다.

| 방수 | 급수 없음 | 물탱크차 연결 | 소화전 연결 |
| --- | --- | --- | --- |
| 40mm 1선 (275L/min) | 약 10분 | 약 25분 | 약 29분 |
| 40mm 2선 (550L/min) | 약 5분 | 약 8분 | 약 8분 |
| 65mm 1선 (611L/min) | 약 4분 30초 | 약 6분 30초 | 약 6분 30초 |

물탱크차 연결 시 40mm 1선은 물탱크차가 약 22분 뒤 비고, 그 뒤 펌프차 잔량으로 약 2분 30초를 더 씁니다. 2선 이상을 오래 쓰려면 급수를 두 곳 이상 잡거나 물탱크차 순환보수가 필요합니다(SOP 200 3.1.1.3).

**물이 끊기면 내부 대원이 위험해집니다.** 방수가 멈추면 엄호주수가 사라지고 불이 다시 커집니다. 관창수는 "수압이 떨어졌습니다"를 보고하고, 주변 온도가 기준을 넘으면 철수나 긴급탈출을 요청합니다.

**탈출 경로의 열기·화염은 부상으로 이어집니다.** 대원이 지나가는 칸마다 열 노출을 누적하고, 누적치에 따라 화상·부상 확률이 오릅니다.

- 낮은 자세로 연기층 아래를 지나면 노출이 줄어듭니다.
- 화염이 있는 칸을 지나면 크게 늘어납니다.
- 엄호주수를 받으면 크게 줄어듭니다.
- 경로가 막히면 고립(SOP 204)으로 넘어갑니다.

대원은 더 안전한 우회로가 있으면 스스로 고릅니다. 없으면 "탈출로에 화염이 있습니다"라고 물어봅니다(질문 카드: 엄호주수 받고 돌파 / 대기하며 RIT 요청 / 다른 출구 탐색). 열 노출 기준값은 게임 설정값(검수 필요)입니다.

### 5-5. 요구조자 생존 모델

CO 노출은 교재 표(화재2 표 4-11)를 기준으로 누적합니다. 현재 농도에서의 사망 시간으로 노출 시간을 나눌 값을 더해 가고, 합이 1에 가까워지면 의식을 잃고 1이 되면 사망합니다.

| CO 농도 | 교재상 증상 | 게임 사망시간 기준 |
| --- | --- | --- |
| 1,600 ppm | 두통·현기증·구토, 2시간이면 사망 | 120분 |
| 3,200 ppm | 30분이면 사망 | 30분 |
| 6,400 ppm | 15\~30분이면 사망 | 20분 |
| 12,800 ppm | 1\~3분 내 사망 | 2분 |

- 산소농도는 18% 미만에서 이동 속도가 줄고, 10% 이하에서 자력 이동이 불가능합니다(화재2 산소농도별 영향).
- 요구조자 유형: 자력피난 가능 성인, 노인, 아이, 거동불편자, 반려동물. 숙소 중(야간)이면 인지가 늦습니다.
- 숙기 행동: 화장실·베란다·장롭 안·막힌 통로·창가(SOP 202 4.1). 대원의 수색 대상 위치와 일치합니다.
- 구출 후에는 구급대가 START로 분류하고, 분류·이송 순서가 생존에 영향을 줍니다(구급 분류는 7장 카드).

### 5-6. 대원 상태 모델

공기호흡기는 6.8ℓ 용기에 300bar를 충전한 제품이 기준입니다. 분당 40ℓ로 쓰면 전체 약 51분이지만, 최소 탈출압력 55bar를 남겨야 하므로 실제 활동 가능 시간은 약 41분이고, 움직임이 클수록 더 줄어듭니다. 계산은 교재 공식(화재1 표 1-19)을 그대로 씁니다.

```latex
\text{사용가능시간(분)} = \frac{(\text{충전압력} - \text{탈출소요압력}) \times \text{용기용량}}{\text{분당 호흡량}} = \frac{(300-55)\times 6.8}{40} \approx 41
```

| 활동 | 분당 호흡량(ℓ/분) | 근거 |
| --- | --- | --- |
| 대기·보행 | 40 | 교재 가벼운 활동 기준 |
| 수색·호스 전개 | 55 | 게임 설정값(검수 필요) |
| 방수·파괴 | 65 | 게임 설정값(검수 필요) |
| 구조(요구조자 이동)·계단 오르기 | 80 | 게임 설정값(검수 필요) |
| 긴장·고립 상태 | ×1.3 | 교재 "긴장도에 따라 달라짐" 반영, 호흡조절 시 ×0.8(SOP 204 4.3) |

- 대원은 잔압 경보(최소 탈출압력 55bar)가 울리면 자동으로 "퇴각하겠습니다"를 보고합니다. 탈출경로가 길면 경보 전에 나와야 한다는 교재 내용을 반영해, 화면에 "출구까지 필요 공기"를 함께 표시합니다.
- 열 스트레스·피로: 고온 구역 체류와 고강도 활동으로 쌓이고, 휴식처에서 회복합니다(SOP 201 3.5). 피로가 높으면 속도가 줄고 부상 확률이 오릅니다.
- 부상·고립·실종은 사건(폭발·붕괴·낙하물)과 확률로 발생하며, 사망은 "사고 발생 후 구출하지 못했을 때"만 일어납니다. 대원 사망을 누구의 선택으로 만들지 않기 위한 교육적 배려입니다.

### 5-7. 계산 주기

화재·연기는 초당 5회, 대원 AI는 초당 10회, 화면은 60프레임으로 돌립니다. 발화층 ±2개층만 자세히 계산하고 나머지는 층 단위로 묶어 계산합니다. 시간 흐름은 아래 5-8을 따릅니다.

### 5-8. 시간 흐름: 하나의 현장 시계를 빠르게

**판단: 모든 것을 같은 비율로 빠르게 돌리는 "현장 시계"를 권합니다. 기본은 2배속입니다.** 실제 1초에 현장 시간이 2초 흐릅니다. 화재 성장, 공기호흡기 소모, CO 노출, 호스 연장·소화전 점령 같은 대원 작업이 모두 이 시계를 따릅니다.

| 방식 | 장점 | 문제 |
| --- | --- | --- |
| 전부 1:1(실제 시간) | 현실 그대로 | 아파트 한 판이 30분 이상, 호스 연장·이동을 기다리는 시간이 길어 지루함. 교육 1교시에 안 맞음 |
| 대원 작업만 빠르게 | 기다림이 줄어듦 | 불은 그대로인데 호스는 빨리 깔려, "연장에 시간이 든다"는 감각을 거꾸로 배움 |
| **전체를 같은 배속으로(권장)** | 한 판 10\~15분, 화재·공기·작업의 비율이 실제와 같음 | 지휘관의 판단 시간이 빠듯해짐 → 아래 질문 카드 규칙으로 보완 |

- **비율이 교육의 핵심입니다.** "호스 3본을 깔면 그동안 불이 얼마나 커지는가", "공기 41분 안에 얼마나 할 수 있는가"가 실제와 같아야 하므로, 일부만 빠르게 하지 않고 현장 전체를 함께 빠르게 합니다.
- **사람의 시간은 따로:** 질문 카드 제한시간(20·12·8초)과 연출·자막 표시 시간은 플레이어가 읽고 생각하는 시간이라 실제 초로 쟽니다. 배속을 올려도 읽을 시간은 줄지 않습니다.
- **난이도별 배속:** 훈련 1.5배, 실전 2배, 악조건 2.5배(게임 설정값). 교관이 설정에서 바꿀 수 있고, 플레이 도중에는 바꿀 수 없습니다(기록 비교를 위해).
- **출동 단계는 더 빠르게:** 이동만 하는 구간이라 약 2.7배로, 신고 후 4분이 실제 약 90초에 지나갑니다(4-4).
- **화면의 시계는 현장 시간:** 상황 배지·작업 막대·디브리핑의 시간은 모두 현장 시간으로 표시해, "소화전 점령 20초", "공기 41분" 같은 실제 감각을 그대로 익힙니다.

### 5-9. 진화와 재발화

불꽃이 보이지 않는다고 끝난 것이 아닙니다. 교재는 유염 현상이 끝나도 깊이 타 들어간 목재, 면·헝겊 속, 벽 사이에 남은 불씨가 시간이 지나 다시 연소할 수 있다고 하고, 주수 후 불꽃이 외관상 보이지 않는 상태를 "진압상태"라 부릅니다(화재1 제4장 제14절).

| 상태 | 판정 | 화면·무전 |
| --- | --- | --- |
| 연소 중 | 불꽃 있음 |  |
| 초진 | 그 방의 불꽃 소멸, "숨은 잔화량"은 남음 | 관창수 "초진입니다" 보고 |
| 잔화정리 중 | 잔화정리 임무 수행 |  |
| 완진 | 모든 방의 숨은 잔화량 0 | 지휘관이 완진 선언 |
| 재발화 | 숨은 잔화량이 남은 방이 다시 발화기로 | 화점 재발생 보고 |

- **숨은 잔화량:** 방마다 둡니다. 많이 남는 곳은 천장 속·바닥 아래·덕트·파이프 샤프트, 이중벽 속, 주방 철판 내장 뒤, 벽장·문틈, 이불·매트·섬유·종이·목재 더미입니다(화재1 제4장 제14절). 샌드위치패널은 천장·벽 심재 잔불과 가연물 중심부 심부화재를 따로 둡니다(SOP 240 2.4).
- **잔화정리 임무(새 명령):** 지휘자가 지정한 구역을 바깥에서 중심으로, 위층에서 아래층으로, 높은 곳에서 낮은 곳으로 진행합니다. 감압 주수, 부분파괴(지휘관 승인 필요), 물이 스며들지 않는 섬유·더미는 밖으로 반출합니다(화재1 제4장 제14절). 시간이 걸리고 대원 피로가 쌓입니다.
- **재발화 조건:** 숨은 잔화량이 남은 채 시간이 지나면 그 방이 발화기로 돌아갑니다. 배연·환기로 산소가 들어오면 빨라집니다(게임 설정값).
- **과잉주수:** 잔화정리에서 물을 많이 쓰면 수손 점수가 깎입니다. 교재는 과잉파괴·과잉주수를 피하라고 합니다.
- **재출화 방지 감시경계:** 완진 뒤 지휘자가 1개 대를 감시경계로 지정할 수 있습니다(화재1 제4장 제14절). 지정하면 재발화를 일찍 발견해 보고합니다.
- **판단거리:** "언제 초진을 보고하고, 언제 잔화정리를 끝내고, 감시경계를 남길지"가 지휘관의 판단입니다. 현장 상황평가 항목에도 "초진 또는 완진?"이 있습니다(현장안전관리 표준지침).
- **디브리핑 기록:** 초진 시각, 완진 시각, 총 사용 수량, 수손, 재발화 여부.

## 6. 유닛·차량·장비

**유닛은 "차량"과 "대원" 두 종류이고, 대원은 항상 2인 1조 팀 단위로 선택·명령합니다.** 한 명만 따로 보내려면 "단독행동 허가"를 해야 하고, 화재실 내부에서는 금지됩니다(SOP 201 3.7).

### 6-1. 차량

| 차량 | 역할 | 게임 내 특징 |
| --- | --- | --- |
| 펌프차 | 주 방수 거점, 연결송수구 송수 | 물탱크·방수구·호스 적재량, 운전원(기관원) 필수 |
| 물탱크차 | 펌프차 급수, 순환보수 | 도착 즉시 펌프차 급수·소화전 점령이 기본 행동(SOP 200 3.1.1.2) |
| 소형펌프차 | 협소 도로 진입 | 전통시장·주택가, 아파트 선진입(SOP 213 2.2) |
| 굴절차·고가사다리차 | 외부 구조, 고소 방수 | 전개 공간·지반·가공전선 검사, 전개 시간 김(SOP 209·326) |
| 구조공작차 | 구조대 수송, 파괴·구조장비 | 방화문 파괴기, 유압장비, 공기안전매트 |
| 구급차 | 분류·응급처치·이송 | 이송 중에는 현장 이탈(복귀 시간) |
| 지휘차 | 현장지휘소 | 배치 위치가 무전 품질·시야에 영향 |
| 배연차·조명차 | 대형 배연, 야간 조명 | 챕터 3부터 |

차량은 도착 배치 단계에서 자리를 고릅니다. 화염·폭발·낙하물 안전 위치, 후착대 공간, 굴절차 자리, 퇴각로를 보는 판정이 들어갑니다(SOP 200 3.1).

**출동대 기본 편성.** 별도로 바꾸지 않으면 아래 편성으로 출동합니다. 센터마다 다른 근무 환경은 설정 파일(`data/crews.json`)에서 인원과 구성을 고칠 수 있습니다.

| 출동대 | 인원 | 구성 | 비고 |
| --- | --- | --- | --- |
| 선착대(펌프차) | 5명 | 선착대장 1, 운전원 1, 분대원 3 | 선착대장이 플레이어 |
| 구조대 | 4명 | 운전원 포함 | 팀장은 선착대장이 있으므로 분대원 역할 |
| 구급대 | 3명 | 운전원 포함 |  |
| 후착분대(펌프차) | 5명 | 운전원 1, 분대원 4 | 팀장은 선착대장이 있으므로 분대원 역할 |
| 물탱크차 | 1명 | 운전원 |  |
| 굴절차·고가사다리차 | 1명 | 운전원 |  |
| 그 밖의 차량(배연·조명 등) | 1명 | 운전원 |  |

운전원을 뺀 분대원은 2인 1조로 묶입니다. 남는 1명(예: 선착대 분대원 3명 중 1명)은 지휘관이 관창보조, 방재실 연락, 현장안전담당 등으로 배정합니다. 단독으로 화재실에 들어갈 수는 없습니다.

**차량은 직접 운전하지 않고 "배치 지점"을 지정합니다.** 소방차를 마우스로 몰고 다니는 것은 훈련 가치가 적고, 실제 지휘관의 판단은 "어디에 세울것인가"입니다(SOP 200 3.1). 맵마다 배치 지점(예: 건물 전면·굴절차 전개 가능 / 소화전 옆 / 진입로 입구 / 후방 대기)을 4\~8곳 두고, 차량이 도착하면 운전원이 "어디에 세울까요?"라고 묻거나, 지휘관이 출동 준비판에서 미리 정합니다. 차량은 진입한 도로를 따라 실제 차처럼 스스로 갑니다. 다른 차량을 뛰어넘거나 좁은 길에서 회전할 수 없으므로, 먼저 온 차가 자리를 잘못 잡으면 뒤차가 막힙니다. 차량은 도착 시간 순서대로 한 대씩 들어옵니다(선착 펌프차가 항상 먼저).

**현장 작업에는 모습과 시간이 있습니다.** 호스·급수·장비가 눈 깜짝할 사이 연결되면 "누가 어디서 시간을 쓰는가"를 배울 수 없습니다. 대원이 직접 차량에서 호스를 꺼내 메고, 연장하고, 결합하는 모습이 보이고, 머리 위에 작업 진행 막대가 뜹니다. 아래 시간은 2인 기준 게임 설정값(검수 필요)이고, **1인이 하면 2배**가 걸립니다.

| 작업 | 시간(2인 기준) | 비고 |
| --- | --- | --- |
| 하차·장비 꺼내기 | 10초 |  |
| 소화전 점령(뚜껑·개폐 준비) | 20초 | 운전원 |
| 호스 1본(15m) 연장 | 15초 | 거리÷15m를 올림한 본 수 + 여유 1본 |
| 결합 1개소 | 5초 | 호스·송수구·관창 마다 |
| 분대원 수관 준비 | 20초 | 차량에서 호스·관창을 꺼내 메기 |
| 방수 개시 | 10초 | 관창수 신호 후 운전원이 압력 올림(SOP 206 1.3) |
| 없는 장비 가지러 가기 | 차량까지 왕복 + 10초 | 본인이 탑승한 차량에서만 |

- **수관 연장 중 이동 속도는 보통 이동의 0.8배**입니다. 호스는 대원 뒤로 선이 늘어나듯 그려집니다.
- 한 사람이 메고 갈 수 있는 호스는 2본입니다(게임 설정값). 모자라면 차량에 다시 가거나, 다른 대원이 가져다 주거나, 연결송수관을 쓰면 됩니다.
- 가지고 있지 않은 장비는 본인이 탑승한 차량까지 돌아가야 합니다. 짝이 없는 대원을 "장비 전달"로 쓰면 이 시간을 줄일 수 있어, 출동 단계의 장비 챙기기(4-4)가 의미를 갖습니다.

### 6-2. 대원 역할과 속성

| 역할 | 주요 행동 |
| --- | --- |
| 선착대장·단위지휘관 | 플레이어의 분신 또는 위임 대상. 후반에 카드 일부 대리 처리 |
| 관창수·관창보조 | 호스연장, 방수, 엄호주수 |
| 검색조 | 인명탐색, 검색완료 표시 |
| 운전원(기관원) | 펌프 조작, 급수, 방수압력 조절(SOP 206 1) |
| 구조대원 | 진입·구출, 파괴, 로프·사다리, 매트 |
| 구급대원 | START 분류, 응급처치, 이송 |
| 현장안전담당 | 진입 전 장비 점검, 위험요인 관측, 진입·퇴출 관리(SOP 108) |
| RIT | 다른 임무 없이 대기, 비상탈출로 확보, 고립 시 투입(SSG 9) |

**대원 속성:** 이름, 계급, 경력(수순에 따라 자동처리 범위·질문 빈도·펜슬링 가능 여부), 체력, 공기잔량, 피로·체온, 휴대장비, 현재 임무. 스테이지를 마치면 경험치가 쌓여 "신임 → 일반 → 숙련 → 고참"으로 성장합니다.

### 6-3. 휴대 장비

| 장비 | 게임 효과 |
| --- | --- |
| 공기호흡기(6.8ℓ, 300bar) | 5-6의 잔량 공식, 진입 필수 |
| 인명구조경보기(PASS) | 일정 시간 움직임이 없으면 자동 경보, 고립 대원 위치 표시 |
| 무전기 | 명령·보고 채널. 지하·철근 안에서는 감도 저하, 무선통신보조설비 연결 시 회복(SOP 235 11) |
| 열화상카메라 | 주변 온도·요구조자 표시, 350℃ 경고 |
| 가스탐지기 | 문 개방 전 폭발위험 판정(SOP 213 2.3.1) |
| 방화문 파괴기·동력절단기·갈고리 | 현관문·창 개방, 동력절단기는 불꽃 발생(가스 환경에서 점화원) |
| 라이트라인·케미컬라이트 | 지하·미로형 구획에서 퇴로 표시, 방향상실 방지(SOP 217·218) |
| 관창(40mm·65mm) | 40mm는 기동성, 65mm는 방수량·인원 많이 필요 |
| 송풍기 | 양압배연 |
| 연결송수관용 장비팩 | 예비호스·관창 묶음, 고층 진입 시간 단축(SOP 222 2.9) |

| 복식사다리 | 저층 창 진입·비상탈출로, 설치각 75°(SOP 207 2.2) |

출동 전 적재 장비를 고르는 "출동 준비" 화면에서 출동지령을 보고 필요한 장비를 골라야 합니다(SOP 200 1\~2, 201 1.1). 예를 들어 아파트 출동에서 방화문 파괴기를 안 실으면 현관문 개방이 늦어집니다.

## 7. 판단 이벤트(질문 카드) 설계

**카드 1장 = SOP 조항 1개**가 원칙입니다. 카드는 코드가 아닌 JSON 데이터 파일로 만들어, 교관이 프로그래밍 없이 문구·정답·해설을 고칠 수 있게 합니다. 아파트 스테이지에만 약 30장, 전체 약 150장을 목표로 합니다.

### 7-1. 카드 데이터 구조

```json
{
  "id": "APT-DOOR-01",
  "phase": "진입",
  "trigger": "팀이 발화세대 현관문 앞 도착",
  "asker": "관창수",
  "urgency": "중요",
  "time_limit_sec": 12,
  "text": "팀장님, 1203호 현관문 앞입니다. 문틈에서 연기가 새어 나옵니다. 어떻게 할까요?",
  "options": [
    {"text": "가스탐지기 확인 후 문 옆 벽에서 천천히 개방", "grade": "최선", "effect": "open_door_safe"},
    {"text": "방화문 파괴기로 즉시 강제개방", "grade": "오답", "effect": "open_door_fast"},
    {"text": "문 정면에 서서 개방하고 바로 진입", "grade": "치명", "effect": "open_door_front"},
    {"text": "관리사무소에 가스 차단 여부를 무전 확인", "grade": "허용", "effect": "ask_info", "time_cost_sec": 20}
  ],
  "sop_ref": ["SOP 213 2.3.1", "SSG 4 1.1.5"],
  "debrief": "가스누출이 의심되면 현관문 개방 전 가스탐지기를 작동하고, 문은 출입문 옆 벽에서 천천히 연다.",
  "skip_if_preordered": "order_gas_check"
}
```

- `effect`는 정답 여부가 아니라 **행동**을 가리킵니다. 결과는 시뮬레이션이 만듭니다. "즉시 강제개방"은 안에 가스가 없고 백드래프트 조건도 아니면 아무 일도 없을 수 있지만, 디브리핑에서는 여전히 오답으로 표시됩니다(운 좋게 넘어간 것도 가르칩니다).
- `skip_if_preordered`는 선제지시 규칙입니다. 지휘관이 먼저 "가스탐지 후 진입"을 명령했다면 이 카드는 뜨지 않고 최선 점수 + 선제지시 보너스를 받습니다.
- 같은 카드에 `variants`를 두어 문구·징후를 바꾸고, 백드래프트 징후(휘파람 소리, 틈으로 공기가 빨려 들어감)가 있을 때는 정답이 "하부 개방 금지, 상부 배연 후 개방"으로 바뀝니다(SOP 210 4.5).

### 7-2. 카드 분류 (현장 단계별)

출동 → 도착·배치 → 상황평가 → 전략 → 진입 → 인명탐색·구조 → 방수 → 배연 → 안전·긴급 → 구급 → 잔불정리·복귀. SOP 200의 단계 구성을 그대로 따릅니다.

### 7-4. 자동화 기준

아래 항목은 카드로 물어보지 않고 대원이 자동으로 합니다. 단, **신임 대원은 일부를 물어봅니다.**

- 이동 경로, 2인 1조 유지, 낮은 자세, 방 안 탐색 순서
- 검색완료 표시(방법은 스테이지 시작 시 한 번 정함)
- 호스 여유분 확보, 관창 반동 대비 자세
- 잔압 경보 시 퇴각 보고(승인은 지휘관이 함), 고립 시 PASS 작동
- 이상 발견 시 보고(SOP 200 3.3.3)

## 8. 평가·디브리핑·재미 요소

**평가는 SOP 106의 전술 우선순위(대원안전 → 인명구조 → 재산보호 → 화재진압)에 SOP 준수를 더한 5축입니다.** 가중치도 이 순서를 따라, 불을 빨리 꺼도 대원이 다치면 높은 등급을 받지 못합니다.

| 평가축 | 배점 | 측정 내용 |
| --- | --- | --- |
| 대원안전 | 30 | 부상·고립 수, 공기 고갈 직전 퇴출, 2인 1조 위반, RIT·안전담당 지정, 안전구역 설정 |
| 인명구조 | 30 | 구조·대피 인원, 사망자, 구조 우선순위 준수, 구출까지 걸린 시간 |
| 재산보호 | 10 | 연소 세대 수, 수손피해, 불필요한 파괴 |
| 화재진압 | 10 | 초기 방수 개시 시간, 완진 시간, 재발화 |
| SOP 준수 | 20 | 카드 정답률(최선 100%·허용 50%·오답 0·치명 감점), 선제지시 수, 무전 규율, 미응답 수 |

- **등급:** S(90 이상)·A·B·C·D. 대원 사망이 있으면 최대 C, 치명 선택이 있으면 최대 B입니다.
- **게임 종료 조건:** 시나리오에 제한시간은 두지 않고, 현장 상황으로 끝납니다(8-3). 대원이 사망해도 게임은 계속합니다. 현장은 멈추지 않고, 그 뒤의 지휘가 오히려 중요한 훈련이기 때문입니다.
- **난이도:** 훈련(제한시간 2배, 힌트 아이콘) · 실전(기본) · 악조건(야간·강풍·후착대 지연·소화전 고장).

### 8-1. 디브리핑 화면 (SOP 113)

1. **타임라인:** 신고접수부터 복귀까지 주요 사건과 지휘관 결정을 시간순으로 보여줍니다.
2. **판단 해설:** 카드마다 내 선택, 최선 선택, SOP 조항 원문, 그 선택이 만든 결과를 연결해 보여줍니다.
3. **리플레이:** 어느 시점이든 미니맵 재생으로 다시 볼 수 있고, 연기·온도 레이어를 켜서 "왜 그때 백드래프트가 났는지" 확인합니다.
4. **그때 다르게 했다면:** 오답 카드 시점으로 돌아가 다른 선택으로 이어서 플레이하는 연습 모드(점수는 기록하지 않음).
5. **출력:** 교육 결과를 PDF·CSV로 저장합니다. 이름, 스테이지, 등급, 5축 점수, 틀린 SOP 조항 목록이 들어가 교관이 취약 항목을 모아 볼 수 있습니다.

### 8-2. 재미 요소

| 요소 | 내용 |
| --- | --- |
| 실시간 긴장감 | 멈추지 않는 시간, 무전 교신음, 특수현상 징후 소리(휘파람·균열음), 잔압 경보음 |
| 매번 다른 상황 | 발화위치·시간대·계절·풍향·요구조자 배치·관계인 정보 정확도가 바뀜 |
| 내 대원 성장 | 대원 경력이 쌓이면 자동처리 범위가 넓어지고, 펜슬링 등 고급 기술이 열림 |
| 지휘관 승진 | 선착대장 → 지휘대장 → 통제단 지휘로 지휘 규모가 커짐 |
| 훈장·도전과제 | "무사고 완진", "선제지시 10회", "수손 최소", "전원 구조" 등 |
| 기록 경쟁 | PC별 로컬 랭킹, 결과 파일을 모아 센터·팀 대항전 가능(인터넷 불필요) |
| 실제 연결감 | 대원 이름·차량 호청을 우리 센터 편성으로 바꿀 수 있는 설정 파일 |

### 8-3. 게임이 끝나는 조건

**판단: 시간으로 끊지 않고 현장 상황으로 끝내는 것이 맞습니다.** "20분 안에 끝내라"는 게임 규칙을 배우게 되고, 현실의 화재는 진압되거나 탈 것이 없어야 끝나기 때문입니다. 다만 화재가 끝났는데도 아무도 현장을 닫지 않아 끝없이 이어지는 경우를 막는 장치는 필요합니다.

| 종료 | 조건 | 결과 |
| --- | --- | --- |
| 작전 완료 | 완진 → 잔불정리 → 남은 요구조자 검색 완료 → 지휘관이 "상황 종료" 선언 | 정상 평가 |
| 전소 | 화재 건물의 탈 수 있는 가연물이 다 타서 불이 스스로 꺼짐(또는 일정 비율 이상 붕괴) | "전소"로 종료, 재산보호·화재진압 점수 0, 디브리핑은 정상 진행 |
| 지휘관 선언 | 언제든 "상황 종료"를 선언할 수 있음. 단, 완진 전이거나 미검색 구역이 남아 있으면 경고 | 그 시점 상태로 평가. 조기 종료로 남은 요구조자는 미구조로 처리 |
| 임무 포기 | 메뉴에서 선택 | "미완료"로 기록, 디브리핑은 볼 수 있음 |

- 화재가 꺼진 뒤 현장 시간으로 10분 동안 상황 변화가 없으면 "상황을 종료할까요?" 알림을 띄웁니다(강제 종료는 아님).
- 대원이 사망해도 게임은 계속합니다. 현장은 멈추지 않고, 그 뒤의 지휘가 오히려 중요한 훈련이기 때문입니다.
- 전소까지 가는 판은 길어질 수 있으므로, 전소가 확실해지면(주요 구획이 모두 최성기·쇠퇴기이고 방수가 닿지 않음) "결과 보기"로 나머지를 빨리 돌릴 수 있게 합니다.

### 8-4. 메뉴와 나가기

**다른 게임처럼 Esc로 여는 게임 메뉴가 반드시 있어야 합니다.** 교육 중간에 멈추거나, 다시 하거나, 끝내고 나가는 일은 늘 생깁니다.

| 메뉴 항목 | 동작 |
| --- | --- |
| 계속하기 | 게임으로 돌아감 |
| 조작 도움말 | 단축키·마우스 조작 안내 |
| 설정 | 화면 모드, 소리, 상황판 투명도, 카메라 속도, 저사양 모드 |
| 처음부터 다시 | 같은 시나리오를 새로 시작(확인 창) |
| 임무 포기 | "미완료"로 기록하고 디브리핑으로(확인 창) |
| 메인 메뉴로 | 스테이지 선택 화면으로(확인 창) |
| 게임 종료 | 프로그램을 닫고 바탕화면으로(확인 창) |

- **메뉴를 열면 게임은 일시정지되고 지도와 질문 카드는 흐릿하게 가려집니다.** 메뉴를 열어 둔 채 질문을 오래 고민하는 식으로 "항상 실시간" 규칙을 피해 가지 못하게 하려는 것입니다. 일시정지 횟수는 기록만 하고 감점하지 않습니다.
- 창 닫기(X)나 Alt+F4를 눌러도 바로 꺼지지 않고 "게임 종료" 확인 창을 띄웁니다.
- 중간에 나간 판도 거기까지의 기록은 "미완료"로 저장되어, 교관이 누가 어디까지 했는지 볼 수 있습니다.
- 화면 흐름: 타이틀 → 프로필(이름·소속) → 스테이지 선택 → 출동 → 현장 → 디브리핑 → 다시하기 / 다음 스테이지 / 메인 메뉴. 타이틀과 스테이지 선택 화면에도 "게임 종료" 버튼을 둡니다.

## 9. 조작·화면·그래픽·기술 사양

**원칙은 두 가지입니다. 화면은 지도 하나이고 나머지는 그 위에 투명하게 뜹니다. 지휘관은 눈에 보이는 곳은 직접, 연기 속처럼 보이지 않는 곳은 임무와 무전으로 지휘합니다.** 패널로 화면을 나누면 업무 시스템처럼 보이고, 지도에서 모든 것을 클릭하게 하면 실제 지휘와 어긋나기 때문입니다.

### 9-1. 조작의 핵심: 보이는 곳은 직접, 안 보이는 곳은 임무로

**판단: 화면은 대원의 눈으로 보고, 지휘는 "임무형"으로 합니다.** 플레이어는 지휘관이 못 보는 곳에서 대원들이 SOP대로 움직이는 모습을 대원의 시야로 지켜봅니다. 하지만 연기 속 대원을 한 칸씩 클릭해 움직이지는 않습니다. SOP 107(3.1④)처럼 지휘관은 "목표·내용·위치에서 할 임무"를 지시하고, 내부에서 **"어디서 무엇을"은 지휘관이, "어떻게"는 대원이** 정합니다. "어떻게"에서 판단이 필요해지면 질문 카드가 뜹니다.

| 구역 | 지휘관이 보는 것 | 지휘 방식 | 대원이 알아서 하는 것 |
| --- | --- | --- | --- |
| 외부 (지휘관 시야 안) | 대원·차량·지휘관 시야 안만 실제 모습, 나머지는 어둡게 기억 | 스타크래프트식 직접 조작: 우클릭 이동, 대상 우클릭으로 상황 행동 | 도착하면 보직에 맞는 임무 자동 수행(운전원은 펌프·급수, 관창팀은 호스 전개, 구급대는 분류소 설치) |
| 진입구 (현관, 계단실, 창) | 진입 준비 중인 팀 | **임무 부여:** 팀 초상을 작전도의 구역에 끌어다 놓고 임무·철수 기준 선택 | 진입 전 장비 점검(안전담당이 있으면 빨라짐), 진입 보고 |
| 내부 (연기 속, 시야 밖) | 대원 눈에 보이는 범위만(벽·연기에 막힘). 작전도 기록은 무전 보고 기준 | **무전 지시:** 팀을 클릭해 원형 메뉴(경유지·구역 변경·대기·철수·보고 요청·지원 투입) | 경로 찾기, 탐색 순서, 문 개방 자세, 방수, 요구조자 이동. 판단이 필요하면 질문 |

[그림 생략: 구역별 지휘 방식 · 외부, 진입구, 내부]

지휘관의 손이 닿는 방식이 구역마다 다릅니다. 내부 정보는 무전 보고(점선)로만 돌아옵니다.

**시야 규칙 (스타크래프트식 안개)**

| 상태 | 화면 | 보이는 것 |
| --- | --- | --- |
| 안 가본 곳 | 검정 | 아무것도 모름. 내부 구조도 모름 |
| 지금 보는 곳 | 밝게 | 실제 모습 그대로: 불, 연기, 사람, 대원의 행동 |
| 본 적 있는 곳 | 어둡게 | 벽·문 구조는 남고, 불·연기·사람은 마지막으로 본 모습에서 멈춤. 지금 무슨 일이 있는지는 모름 |

- **누구의 눈인가:** 모든 대원·차량·지휘관의 시야를 합친 범위만 밝습니다. 시야는 카메라가 아니라 유닛 기준이라, 화면을 옮겨도 유닛이 없는 곳은 어둡습니다.
- **벽:** 시야는 벽과 닫힌 문을 통과하지 못합니다. 창문은 유리 상태에 따라 통과합니다.
- **연기:** 연기가 짙을수록 시야 거리가 줄어듭니다(맑음 약 10m, 짙은 연기 1m 미만, 게임 설정값). 연기층 아래로 자세를 낮추면 조금 늘어납니다(중성대).
- **랜턴:** 앞쪽 부채꼴로 시야를 늘리지만, 짙은 연기에서는 빛이 산란돼 효과가 작습니다.
- **열화상카메라:** 연기를 투과해 온도와 사람 윤곽만 단순한 색으로 보여 줍니다. 벽은 통과하지 못합니다.
- **다시 어두워짐:** 대원이 떠난 곳은 수 초에 걸쳐 어두워집니다. 마지막 모습만 남으니 다시 확인하러 가야 하고, 이것이 SOP 202의 교차탐색과 연결됩니다.
- **구조는 직접 밝힌다:** 처음에는 도면이 없습니다(아래 "도면과 미니맵"). 대원이 지나가며 본 벽·문만 지도에 남아, 탐색 자체가 지도를 만드는 과정이 됩니다.

**도면과 미니맵**

- **선착대장 시기:** 미니맵은 잠겨 있습니다("도면 수신 대기"). 단, 대원 1명을 관리사무소·방재실로 보내면 그 동의 평면도를 얻고, 수신반에서 발화층도 확인합니다(SOP 235). 그만큼 현장 인력이 빠지므로 언제 보낼지가 판단 요소입니다.
- **지휘대 도착:** 지휘권 이양과 함께 상황실에서 도면이 들어와 미니맵이 열립니다(SOP 112). 지휘대가 오기 전에 끝나는 스테이지는 끝까지 미니맵 없이 진행합니다.
- **표시:** 도면은 미니맵과 함께 본 화면의 검은 곳에도 흐린 선으로 깔립니다. 구조만 알려 주고, 불·연기·사람은 여전히 대원 시야와 보고로만 알 수 있습니다. 도면이 들어오면 방 단위 임무 부여가 가능해집니다.
- **도면과 실제의 차이:** 시나리오에 따라 발코니 확장, 불법 구획, 적치물로 막힌 통로처럼 도면과 다른 곳을 넣습니다. 대원이 실제로 본 구조가 도면을 덮어쓰고, 디브리핑에서 차이를 보여 줍니다.

**보이는 것과 기록되는 것은 다르다**

- 플레이어는 대원이 본 것을 화면으로 그대로 봅니다. 대원이 SOP대로 움직이는 모습을 관찰하는 것이 교육의 절반입니다.
- 그러나 작전도 아이콘(화점·요구조자·위험), 전술상황판, 평가는 대원이 **무전으로 보고한 것**만 기준으로 합니다. 화면에서 요구조자를 봤어도 보고가 없으면 기록에는 없는 것입니다. 신임 대원은 위치를 틀리게 보고할 수도 있습니다.
- 디브리핑에서는 "실제 상황"과 "지휘관이 보고받은 상황"을 나란히 보여 줍니다.

**내부 조작**

- **임무 부여:** 진입구에서 팀 초상을 구역에 끌어다 놓고 임무와 조건(철수 잔압, 화점 발견 시 "보고 후 대기 / 즉시 진압", 요구조자 발견 시 "즉시 구조 / 위치 보고")을 고릅니다. 안 가본 곳은 구조를 모르므로 처음 임무는 "12층", "1203호" 같은 층·세대 단위로 주고, 방이 드러나거나 도면이 들어오면 방 단위로 좁힙니다. 조건을 잘 정해 두면 질문 카드가 줄어듭니다(선제지시).
- **무전 경유지:** 필요하면 팀 표식의 원형 메뉴에서 "여기로" 경유지를 찍습니다. 본 적 있는 곳에만 찍을 수 있고, 교신 2\~3초와 복명복창을 거쳐 움직입니다(SOP 107 3.1⑤). 여러 팀에 동시에 지시하면 무전이 겹쳐 늦어집니다. 외부 대원은 대면 지시라 바로 움직입니다. 지휘관은 메뉴만 고르고, 글자를 입력하지 않습니다. 무전 문장("1팀, 철수하라" / "1팀, 철수하겠습니다")은 게임이 자동으로 만들어 무전 자막에 띄웁니다.
- **그 밖의 원형 메뉴:** 구역 변경, 대기, 철수, 보고 요청, 지원 투입.
- **지휘관의 일:** 진입 여부, 임무와 구역, 우선순위, 교대·철수 시점, RIT와 지원 투입, 그리고 질문 카드. 내부가 자율이어도 지휘관의 손은 쉬지 않습니다.

**원형 명령 메뉴로 통일합니다.** 대원(팀)을 클릭하면 커서 둘레에 명령이 둥글게 펼쳐지고, 고르면 그다음부터는 대원이 임무를 스스로 수행합니다.

- **내부:** 원형 메뉴로만 지시합니다. 지도 우클릭 이동은 막습니다. 메뉴를 고르는 것이 곧 무전 지시이므로 교신 2\~3초 뒤 움직입니다.
- **외부:** 같은 원형 메뉴를 쓰되 대면 지시라 바로 움직입니다. 외부에서는 지도 우클릭으로 단순 이동도 할 수 있습니다.
- 안팎을 같은 메뉴로 통일하면 배울 것이 하나로 줄고, "안에서는 늦게, 밖에서는 바로"라는 차이만으로 무전 지휘의 무게를 느끼게 됩니다.
- 메뉴 항목은 대상과 보직에 따라 바뀝니다(관창팀: 진입·탐색·방수·배연·대기·철수, 운전원: 급수·방수 압력, 구급대: 분류·이송 등). 항목마다 숫자키가 있습니다.

**명령은 "동작"이 아니라 "임무" 단위로 줍니다.** 수색과 구조를 따로 주면, 수색하다 사람을 발견해도 구조 명령을 기다리는 어색한 일이 생깁니다. SOP 203도 "발견하면 보고 후 즉시 구조"입니다. 그래서 원형 메뉴는 한 번에 6개 이하로 줄이고, 임무 안의 세부 동작은 SOP 순서대로 자동으로 이어집니다.

**명령 카드 하나로 통일(스타크래프트식).** 명령은 하단 콘솔 오른쪽 명령 카드(버튼 6개, Q W E R A S)와 원형 메뉴 두 곳에서 같은 항목·같은 단축키로 나옵니다. 원형 메뉴는 커서 근처에서 빨리 누르는 용도, 명령 카드는 같은 명령을 늘 보이게 두는 용도입니다. 예전 동작 단위 버튼(이동·탐색·방수)은 없앱니다.

| 선택한 것 | 명령 카드 |
| --- | --- |
| 팀(진압대·구조대) | Q 인명검색 · W 화점진압 · E 경계 · R 배연 · A 대기 · S 철수 |
| 구급대 | 분류소 설치 · 환자 인계 받기 · 이송 · 대기 |
| 차량 | 급수 연결 · 사다리 전개 · 자리 옮기기 등(차종별) |
| 없음 또는 지휘관 | Q 전략 변경 · W 대응단계 · E 지원 요청 · R 인원 점검 · A 구역 지정(안전구역·환자 집결지·진입통제선) · S 전원 철수·긴급탈출 |

- 팀은 **좌클릭**으로 원형 메뉴를 엽니다. 우클릭은 외부 대원의 단순 이동에만 씁니다.
- 빈 곳을 누르거나 Esc로 선택을 풀면 명령 카드가 지휘관 명령으로 바뀝니다. 지휘관 명령은 모두 무전으로 나가고 무전 기록에 남습니다.
- 인원 점검을 누르면 각 팀이 인원·위치·잔압을 차례로 보고하고, 전술상황판의 진입대원 통제표가 갱신됩니다. 응답이 없는 팀은 긴급 고정줄에 올라갑니다.

**구조한 사람은 환자 집결지로 옮깁니다.** 연기가 나오는 입구는 아직 위험한 곳이므로, 구조대상자는 먼저 위험에서 벗어난 곳으로 옮겨야 합니다(소방전술2 구출 및 운반). 상용 게임 EMERGENCY 시리즈와 림월드도 "지정한 처치 장소로 옮겨야 회복"하는 방식입니다.

- 지휘관이 지휘관 명령 → 구역 지정으로 **환자 집결지**를 찍습니다. 안전구역 안에만 찍힐니다. 구급대가 분류소를 차리면 분류소가 곳 집결지가 됩니다.
- 대원은 구조 후 집결지까지 운반하고, 인계한 뒤 원래 임무로 돌아갑니다. 운반 중에는 느려지고 공기를 더 씁니다(게임 설정값).
- 집결지가 없는 상태에서 첫 구조자가 나오면 질문 카드가 뜹니다.
  1. 안전구역에 집결지 지정(정답)
  2. 구급차 옆에 둠(구급차가 있을 때만)
  3. 입구에 두고 복귀 — 구조자가 계속 연기를 마시고 낙하물·진입 동선 방해가 생깁니다. 디브리핑에서 감점합니다.
- 구급대가 없으면 집결지의 구조자 상태가 천천히 나빠집니다. 대원 1명을 붙여 두면 악화가 느려지지만 그만큼 인력이 빠집니다. "구급대를 언제 부를지"가 판단거리가 됩니다.
- 구급대가 있으면 중증도 분류 → 응급처치 → 이송 순서로 처리되고, 전술상황판의 요구조자 집계(보고·구조·대피·미확인)에 반영됩니다.

| 임무 | 자동으로 이어지는 동작 | 질문 카드가 뜨는 때 |
| --- | --- | --- |
| 인명검색 | 이동 → 문 개방 → 방별 탐색 → 발견 시 무전 보고 → 구조(피난장소로 이동) → 남은 구역 계속 탐색 | 요구조자가 여럿일 때 우선순위, 구조 경로에 열기가 있을 때, 백드래프트 징후 등 |
| 화점진압 | 수관 준비 → 연장 → 진입 → 화점 탐색 → 방수 → 잔불 확인 | 주수 방법, 수량이 모자랄 때(아래 5-4) |
| 경계·연소확대 방지 | 지정 위치에 관창 배치 → 불이 다가오면 방수 | — |
| 배연 | 배기구 확보 → 급기(송풍기) | 배기구가 없을 때 |
| 대기·철수·보고 요청 | — | — |

임무를 줄 때 고르는 조건(예: 요구조자 발견 시 "즉시 구조 / 위치 보고 후 대기")이 기본 동작을 바꿉니다. 기본값은 SOP대로 "보고 후 즉시 구조"입니다. 구조대와 진압대가 따로 메뉴를 갖지 않고, 보직에 따라 잘하는 임무(더 빠름)가 다를 뿐입니다.

**진입 지시: 어느 문으로, 어느 층에**

상용 게임의 방식을 비교했습니다.

| 게임 | 방식 | 이 게임에 가져올 점 |
| --- | --- | --- |
| SWAT 4, Ready or Not | 대원을 고른 뒤 문을 가리키면 문 전용 명령 휠(점검, 개방 후 진입, 파괴 후 진입, 문 앞 대기) | 문을 누르면 문에 맞는 명령이 나오는 구조. "가스 확인 후 개방", "상부 배연 후 개방" 같은 SOP 행동을 그대로 넣기 좋음 |
| Door Kickers | 대원에서 목표까지 경로를 그리고, 문마다 행동을 지정 | 진입구에서 목표까지의 경로를 선으로 미리 보여 주는 점 |
| XCOM | 이동 가능한 곳을 밝게 표시하고 마우스를 올리면 경로 미리보기 | 고를 수 있는 진입구만 밝게 띄우는 점 |
| 스타크래프트 | 유닛 선택 → 명령 버튼 → 대상 클릭 | "팀 → 명령 → 대상" 순서가 익숙함 |

**추천: "팀 → 진입 → 진입구 → 목표 층·세대 → 조건" 4단계입니다.**

1. **팀을 클릭하고 원형 메뉴에서 "진입"을 고릅니다.**
2. **진입구를 고릅니다.** 건물 외부에 진입 가능한 곳만 아이콘으로 밝게 뜹니다(공동현관, 계단실 입구, 비상계단, 지하주차장 연결문, 사다리·굴절차로 닿는 창). 마우스를 올리면 연기 상태와 급기측·배기측 여부(알려진 경우)가 보입니다. 어느 문으로 들어갈지 자체가 판단 훈련입니다(급기측 진입 SSG 4, 화점 직하층 거점 SOP 202).
3. **목표 층·세대를 고릅니다.** 화면이 다층 단면으로 바뀌고, 층 막대나 단면에서 층을 누른 뒤 그 층의 세대·복도·계단참을 누릅니다. 구조를 모르는 곳은 "12층", "1203호" 단위까지만 고를 수 있습니다. 진입구에서 목표까지 예상 경로가 선으로 보이고(아는 구간은 실선, 모르는 구간은 점선), 예상 소요 시간과 도착 시 예상 공기잔량이 표시됩니다.
4. **임무와 조건을 고릅니다.** 임무(인명검색/화점진압/배연/구조), 철수 잔압, 화점·요구조자 발견 시 행동을 작은 버튼으로 고르고 "지시"를 누르면 무전이 나갑니다. 조건은 직전에 쓴 값이 기본으로 채워져 있어 보통 한 번에 넘어갑니다.

두 가지 더 있습니다. **문 앞 휠(SWAT 4식):** 내부에서 팀이 문 앞에 있을 때 그 문을 누르면 문 전용 메뉴(가스 확인 후 개방, 문 옆 벽에서 서서히 개방, 파괴 후 개방, 문 닫고 대기)가 나옵니다. 이 메뉴를 미리 쓰면 선제지시가 되어 질문 카드가 뜨지 않습니다. **수정:** 이미 진입한 팀의 목표는 원형 메뉴의 "구역 변경"으로 같은 3\~4단계를 다시 밟습니다.

### 9-2. 화면 구성: 지도 위에 투명하게

- **지도가 바탕:** 지도가 화면 전체를 쓰고, 모든 요소는 반투명하게 지도 위에 뜹니다.
- **왼쪽 위 상황 배지:** 경과시간, 전략(누르면 변경), 풍향, 대응단계.
- **왼쪽 건물 층 막대:** 건물 실루엣을 세로로 세운 막대. 층마다 연기·불 색과 대원 수가 보이고, 누르면 그 층으로 이동합니다. 맨 아래가 외부입니다.
- **오른쪽 무전 기록 패널:** 반투명 세로 패널로, 실시간 무전만 기록합니다. 최신이 맨 위입니다.
  1. **긴급 고정줄(맨 위, 최대 2줄):** 긴급탈출, 무전 무응답, 잔압 경보, 물탱크 고갈처럼 놓치면 안 되는 것만 빨간 줄로 고정되고, 해결되면 사라집니다.
  2. **무전 목록:** 시각·발신자·내용. 대원안전은 빨강, 구조대상자는 주황, 일반은 흰색(SOP 107 우선순위). 답한 질문 카드는 "3팀 질문 → 상부 배연 후 개방"처럼 등록됩니다. 항목을 누르면 그 대원·장소로 화면이 이동합니다.
  3. **필터:** 전체 / 긴급 / 내 지시.
  4. **접기:** 패널 가장자리 화살표로 접고 폅니다. 접으면 긴급 고정줄만 남습니다.
- **전술상황판(평면도):** 상황 배지 옆 "전술상황판" 버튼(또는 Tab, M)을 누르면 화면 가운데에 크게 반투명으로 펼쳐집니다. 게임은 멈추지 않고, 다시 누르면 닫힙니다. 무전 기록을 빼고 "지금 상황"을 모두 여기에 모읍니다(9-2-1).
- **팀 초상 줄:** 하단 콘솔 가운데 위쪽에 팀 초상과 공기잔량 링이 항상 한 줄로 보입니다. 질문을 기다리는 팀에는 "?"가 붙고, 누르면 선택됩니다. 전술상황판을 닫아 두어도 공기와 질문 상태는 늘 보여야 하기 때문입니다.
- **하단 콘솔(스타크래프트식):** 화면 아래 반투명 띠(화면 높이의 약 18%)입니다.
  1. **왼쪽 미니맵:** 도면을 얻기 전에는 "도면 수신 대기"로 잠깁니다(9-1).
  2. **가운데 선택 정보:** 무엇을 골랐는지에 따라 바뀝니다. 팀 하나면 대원별 초상·보직·공기 막대·피로·휴대 장비와 현재 임무·조건. 여러 팀이면 팀 아이콘 격자(누르면 그 팀만 선택). 차량이면 물탱크 잔량·펌프 압력·연결 호스·승무원. 아무것도 안 고르면 출동대 전체 요약.
  3. **오른쪽 명령 버튼:** 선택 대상에 따라 바뀌는 큰 아이콘 버튼(3×2), 모서리에 단축키.
- **무전 자막:** 하단 콘솔 바로 위 왼쪽에 반투명 2\~3줄로 뜨고 5초 뒤 흐려집니다. 지난 무전은 오른쪽 무전 기록 패널에 남습니다.
- **질문 카드:** 화면 가운데에 반투명하게 한 장씩 뜹니다. 무전기를 든 대원 일러스트, 말풍선 질문, 큰 선택 버튼 2\~4개, 일러스트 둘레의 남은 시간 링으로 구성합니다. 답하면 사라지고 오른쪽 무전 기록에 "질문 → 내 답"으로 등록됩니다. 기다리는 카드가 더 있으면 카드 모서리에 "+2"처럼 표시되고, 답하면 다음 카드가 뜹니다. 게임은 멈추지 않으므로 카드는 화면의 4분의 1 이하 크기로 두고 뒤의 지도가 비치게 합니다.
- **숫자는 숨김:** 기본은 게이지·색·아이콘, 숫자는 마우스를 올렸을 때 나옵니다.

#### 9-2-1. 전술상황판(평면도)

**판단: "무전 기록은 오른쪽 패널, 상황은 평면도 위에"로 나누는 것이 맞습니다.** 시간 순서로 쌓이는 정보(무전)와 장소에 묶인 정보(화점·팀 위치·요구조자)는 보는 방식이 다르기 때문입니다. 실제 현장지휘소의 전술상황판도 도면 위에 그리는 방식입니다(SOP 106 3.2).

| 게임 | 방식 | 가져올 점 |
| --- | --- | --- |
| 컴퍼니 오브 히어로즈 3 | 전술 지도(Tab)를 열면 전장 전체가 아이콘으로 보이고, 그 위에서 바로 명령 | 평면도에서 팀을 끌어다 놓아 임무 부여 |
| 레인보우 식스, Door Kickers | 평면도 위에 진입점·팀 경로를 그려 계획 | 평면도에 진입구·호스 라인·검색 완료 구역 표시 |
| 프로스트펑크 | 사건 알림이 한쪽에 쌓이고, 누르면 그 장소로 이동 | 무전 기록 클릭 시 화면 이동 |
| 스타크래프트 | 작은 미니맵은 화면 이동용으로 항상 표시 | 미니맵(이동용)과 전술상황판(판단용)을 따로 유지 |

**배치**

- **가운데 평면도:** 층 탭(외부 / 1층 / … / 옥상)을 골라 봅니다.
  - 내부 층: 팀 위치(마지막 보고 위치와 보고 시각), 화점, 요구조자(보고됨/구조됨), 위험 표시(붕괴·백드래프트 징후), 검색 완료 구역(빗금), 연기 범위, 호스 라인, RIT 위치.
  - 외부: 차량 배치, 소화전·급수 연결, 진입구, 안전구역, 지휘소, 분류소.
  - 도면을 얻기 전에는 대원이 밝힌 구조만 그려집니다(9-1).
- **왼쪽 열 — 지휘:** 전략·대응단계, 지휘 조직(단위지휘관·안전담당·RIT), 진입대원 통제표(팀·인원·진입 시각·잔압·위치). SOP 106 3.3.1과 201 3.7의 "진입대원 현황 관리"를 그대로 옮긴 것입니다.
- **오른쪽 열 — 확인:** 확인 필요 항목, 물 현황(펌프차 잔량·급수원·예상 고갈 시간), 후착대 도착 예정, 요구조자 집계(보고·구조·대피·미확인).

**원칙**

- **보고된 것만 그립니다.** 전술상황판은 지휘관이 아는 정보라, 실제 지도와 다를 수 있습니다. 오래된 보고는 흐리게 보이고 보고 시각이 붙습니다.
- **상황판에서도 지휘합니다.** 평면도의 팀 아이콘을 방·세대로 끌어다 놓으면 진입 지시 3\~4단계(목표·조건)가 뜨고, 무전으로 나갑니다.
- **놓치면 안 되는 것은 밖에도 둡니다.** 게임은 멈추지 않으므로, 상황판을 닫아 둬도 팀 공기잔량과 질문 대기는 팀 초상 줄에, 긴급 사항은 무전 패널 고정줄에 남습니다.
- 상황판을 열어 둔 채 질문 카드가 오면 카드는 상황판 위에 뜹니다.

[그림 생략: 기본 화면 배치 · 1920×1080 기준 개념도]

항상 떠 있는 것은 상황 배지, 층 막대, 오른쪽 상황판, 하단 콘솔 네 가지입니다. 무전 자막과 질문 카드는 필요할 때만 나타나고, 지난 무전과 질문·답은 모두 상황판 무전 기록에 남습니다.

### 9-3. 조작: 모든 명령은 마우스로, 단축키는 덤

모든 명령은 화면 버튼으로 할 수 있습니다. 단축키는 버튼에 적혀 있어 쓰다 보면 자연스럽게 외워지고, 몰라도 플레이에 지장이 없습니다.

| 하고 싶은 것 | 마우스 | 단축키 |
| --- | --- | --- |
| 팀 선택 | 팀 초상 줄·상황판의 팀 카드 클릭, 지도에서 클릭·드래그 | 1\~9 (팀 초상 줄 순서, 질문 카드가 떠 있으면 1\~4는 카드 답) |
| 외부 이동·배치 | 지도 우클릭 | — |
| 상황 행동(문 개방, 소화전 점령, 사다리 설치 등) | 대상에 마우스를 올리면 커서가 행동 아이콘으로 바뀌고, 우클릭하면 실행 | — |
| 명령 선택 | 아래 오른쪽 명령 버튼 | Q·W·E·R·A·S (버튼에 표시) |
| 진입 임무 부여 | 팀 초상을 작전도 구역에 끌어다 놓기 → 임무 휠에서 고르기 | — |
| 내부 무전 지시 | 지도의 대원(팀) 클릭 → 원형 메뉴(외부도 같은 메뉴, 외부는 우클릭 이동도 가능) | — |
| 질문 카드 답 | 선택 버튼 클릭 | 1\~4 |
| 질문한 대원 보기 | 카드의 일러스트 클릭 | Space |
| 층 이동 | 층 막대 클릭, 층 막대 위 마우스 휠 | PageUp·PageDown |
| 카메라 | 마우스를 화면 가장자리로(자동 스크롤), 휠 버튼 끌기, 휠 줌, 미니맵 클릭(도면 후) | 방향키 |
| 전략 선언 | 상황 배지 클릭 | — |
| 전술상황판 | 상황 배지 옆 전술상황판 버튼(또는 M) | Tab |
| 긴급탈출 선포·무전 통제 | 사건이 생기면 화면 위쪽에 크게 뜨는 빨간 버튼 | — |
|  |  |  |

**카메라는 스타크래프트처럼 마우스가 기본입니다.** 방향키는 보조일 뿐입니다.

- **가장자리 스크롤:** 마우스를 화면 끝에 대면 그쪽으로 화면이 흘러갑니다. 사무용 PC는 창 모드로 쓰는 경우가 많아, 게임 중에는 마우스가 창 밖으로 나가지 않게 가둡니다(Esc로 풀림). 속도는 설정에서 조절합니다.
- **휠 버튼 끌기:** 휠을 누른 채 끌면 지도가 손으로 잡은 것처럼 따라옵니다. 가장자리 스크롤이 어색한 사람에게 편합니다.
- **바로 가기:** 팀 초상 더블클릭, 질문 카드 일러스트 클릭, 무전 자막 클릭, 층 막대 클릭으로 그 자리에 즉시 이동합니다. 미니맵이 잠긴 선착대장 시기에는 이 방법들이 미니맵 역할을 대신합니다.
- **지휘소로 돌아오기:** 상황 배지를 누르면(또는 Home) 지휘소가 보이는 기본 위치로 돌아옵니다.

**대원 클릭은 "그림 어디를 눌러도" 잡혀야 합니다.** 아이소메트릭에서는 대원이 작고 벽·다른 대원과 겹치기 쉽기 때문입니다.

| 게임 | 선택 방식 | 가져올 점 |
| --- | --- | --- |
| 스타크래프트 2 | 클릭 판정이 그림보다 넓고, 마우스를 올리면 유닛 윤곽이 빛남. 건물에 가려진 유닛도 윤곽선으로 비침 | 넓은 판정, 올리면 강조, 가려진 대원 윤곽 표시 |
| 에이지 오브 엠파이어 시리즈 | 클릭 위치에 여러 개가 걸리면 유닛이 건물·지형보다 우선 | 우선순위 규칙 |
| 디아블로, 문명 | 마우스가 조금 빗나가도 가장 가까운 대상을 자석처럼 잡음 | 일정 반경 안 가장 가까운 대원 자동 선택 |

**이 게임에 맞춘 방식**

1. **판정을 그림보다 크게:** 대원마다 그림을 덮는 타원형 판정을 두고, 화면에서 최소 48×64px를 보장합니다. 줌아웃해도 판정은 작아지지 않습니다.
2. **2인 1조는 한 덩어리:** 두 사람 중 누구를 눌러도 팀 전체가 선택됩니다. 두 사람 사이 빈 곳도 팀 판정에 들어갑니다.
3. **자석 선택:** 정확히 누르지 못해도 마우스에서 화면 기준 30px 안에 있는 가장 가까운 팀이 잡힙니다.
4. **우선순위:** 같은 곳에 여러 개가 걸리면 대원 → 차량 → 문·창 → 소화전 등 설비 → 바닥 순입니다. 대원끼리 겹치면 현재 선택되지 않은 팀이 우선이고, 한 번 더 누르면 다음 팀으로 넘어갑니다.
5. **올리면 미리 보임:** 마우스를 올리면 잡힐 팀의 윤곽이 빛나고 팀 이름이 작게 뜨므로, 누르기 전에 무엇이 잡힐지 알 수 있습니다.
6. **가려진 대원:** 벽이나 윗층 뒤에 가려진 대원은 팀 색 윤곽선으로 비쳐 보이고, 그 윤곽선을 눌러도 선택됩니다. 단, 안개(시야 밖)에 있는 대원은 보이지 않으므로 상황판 팀 카드로 고릅니다.
7. **발밑 선택 고리:** 선택된 팀은 발밑에 팀 색 고리가 생겨, 연기 속에서도 어느 팀을 골랐는지 보입니다.

**게임다운 손맛을 주는 장치**

- **스마트 커서:** 대상 위에 커서를 올리면 할 수 있는 행동이 아이콘으로 미리 보입니다. 메뉴를 몰라도 "눌러 보면 되는" 조작입니다.
- **끌어다 놓기와 원형 메뉴:** 카드 게임처럼 팀을 구역에 던져 넣고, 메뉴는 커서 주변에 둥글게 펼쳐져 손을 덜 움직입니다.
- **대원의 짧은 응답:** 명령하면 "1팀, 진입합니다" 같은 말풍선과 효과음으로 반응해 지휘하는 느낌을 줍니다.
- **위기 연출:** 잔압 경보 때 초상이 깜빡이고, 긴급탈출이나 특수현상 징후 때는 화면 가장자리가 붉어지고 소리가 바뀝니다.
- **단계적 해금:** 튜토리얼은 이동·진입·방수 버튼만으로 시작하고, 스테이지마다 버튼이 늘어납니다. 처음부터 버튼이 많아 보이지 않게 합니다.

### 9-4. 그래픽 스타일

- 타일 64×32px(1타일 = 1m×1m) 아이소메트릭. 벽은 서 있는 벽과 잘린 벽 2단계
- 대원·차량은 8방향 스프라이트. 헬멧 띠 색으로 역할 구분(진압·구조·구급·안전담당·RIT)
- 안개는 3단계(검정·어둡게·밝게)를 저해상도 텍스처로 그리고, 랜턴 부채꼴은 가벼운 셰이더로 표현. 연기는 반투명 오버레이와 간단한 셰이더 1개, 불꽃은 프레임 애니메이션
- **질문 카드 일러스트:** 역할 5종(관창수, 구조대원, 구급대원, 운전원, 안전담당) × 상태 3종(평상, 연기 속, 긴급) = 15장. 개발 초기에는 실루엣으로 대신합니다
- UI 테마: 반투명 진한 남색 바탕에 소방 주황 강조, 둥근 모서리, 사무용 모니터에서도 읽히는 큰 글씨(본문 16px 이상)
- 초기에는 단색 도형으로 게임을 완성하고 그림은 나중에 바꿉니다. 실제 아파트 브랜드·실존 건물명은 쓰지 않습니다

**다층 단면 보기:** 층 사이를 넓게 띄운 분해도처럼 초점 층과 위·아래 각 2개 층을 함께 보여 줍니다. 층의 아무 곳이나 누르면 그 층만 또렷하고 나머지는 반투명으로 바뀌어, 선택한 층에 집중하면서도 위층으로 번지는 연기를 함께 볼 수 있습니다. 층 간격과 반투명 정도는 설정에서 조절합니다(프롬프트 P2-1).

#### 9-4-1. 그림 제작 방법(무료)

**방식: 3D 모델을 우리 카메라로 찍어 2D 그림으로 굽습니다**(스타크래프트 1·디아블로 2의 프리렌더 방식). 게임 안에는 그림만 들어가므로 그래픽카드 없는 PC에서도 가볍고, 그림은 data/art.json 으로 연결해 나중에 파일만 갈아 끼웁니다.

| 단계 | 무엇으로 | 라이선스 |
| --- | --- | --- |
| A. 먼저(임시 그림) | Kenney 3D 팩(Animated Characters, Furniture Kit, Car Kit, City Kit) | CC0, 출처 표시 선택 |
| B. 대원만 교체(선택) | 기준 그림 → TRELLIS.2(그림→3D) → Mixamo(뼈대·동작) | TRELLIS.2 MIT, Mixamo 무료·사용료 없음(원본 파일 재배포 금지) |
| 공통 | Blender(무료) + Claude Code 스크립트로 8방향 렌더, Godot 자동 가져오기 |  |

- **쓰지 않는 것:** Hunyuan3D는 라이선스 적용 지역에서 한국이 제외되어 쓸 수 없습니다. Meshy 무료는 CC BY(출처 표시)·월 100크레딧이라 보조로만 씁니다.
- **카메라 기준:** 정사영, 타일 64×32(1타일=1m), 대원 화면 높이 약 48\~64px, 2배로 렌더 후 축소, 배경 투명.
- **파일 이름:** <종류>/<이름>/<동작>*<방향0\~7>*<프레임>.png. 헬멧 띠는 별도 그림(게임에서 역할 색을 입힘).
- **필요한 대원 동작:** 서기, 걷기, 웅크려 걷기, 요구조자 들고 걷기, 방수, 무릎 꿇고 검색, 쓰러짐. 팩·Mixamo에 없는 방수·검색은 Blender 스크립트로 자세를 만듭니다.
- **순서:** P15(Kenney로 전체 굽기) → 게임에서 확인 → 필요하면 P15-1(TRELLIS 모델 정리) → Mixamo(사람이 웹에서) → P15-2(대원 그림 교체).
- 크레딧 화면에 쓴 자료의 출처를 넣습니다(예: Kenney (kenney.nl) CC0, TRELLIS.2 MIT).

## 10. 개발 로드맵

**1인 개발 + Claude Code 기준 약 30주로, 15주차에 아파트 버티컬 슬라이스로 직원 시범교육을 합니다.** 주당 투입 시간에 따라 달라지는 추정치입니다. 12장 프롬프트마다 해당 단계를 표시했습니다.

| 단계 | 기간 | 만드는 것 | 완료 기준 |
| --- | --- | --- | --- |
| 0. 점검·기반 | 1주 | 기존 프로젝트 분석, CLAUDE.md, 폴더 구조, 데이터 포맷 | 기존 아파트 장면이 새 구조에서 열림 |

| 2. 유닛·명령 | 3주 | 차량·대원·팀, 경로탐색, 명령, 자동행동, 공기잔량 | 2인 1조가 진입·탐색·방수·퇴각을 한 판 완수 |
| 3. 물·호스·소방시설 | 2주 | 물탱크·소화전·호스 본 수·연결송수관·옥내소화전·수손 | 탱크가 비면 방수가 멈추고 수손이 누적됨 |
| 4. 질문 카드 | 2주 | 카드 엔진, 대기열, 타이머, 선제지시, 결과 연결 | JSON 카드 30장이 아파트에서 뜨고 결과가 시뮬에 반영됨 |
| 5. 아파트 완성 | 2주 | 스테이지 2-1 시나리오 3개, 요구조자·관계인, 안전구역 | 처음부터 끝까지 플레이 가능 |

| 7. 튜토리얼·챕터 1 | 4주 | 훈련탑, 단독주택, 필로티 + 시범교육 피드백 반영 | 챕터 0\~2 연결 플레이 |

수치 검수는 단계 1·2·6 끝에 현장 경험 많은 직원 1\~2명에게 플레이시키고 받는 것을 권합니다. "이 상황에서 이렇게 빨리 번지지 않는다" 같은 피드백이 교육 효과를 좌우합니다.

## 11. 결정이 필요한 사항

아래는 기획자(사용자)가 정해야 하는 것입니다. 괄호 안은 정하기 전까지 기획안이 쓰는 가정입니다. 앞의 세 개는 단계 0 프롬프트를 돌리기 전에 정하는 것이 좋습니다.

- [ ] **기존 Godot 프로젝트의 버전·렌더러·구현 범위는?** 단계 0 프롬프트가 자동으로 조사하지만, Forward+ 렌더러나 3D 노드를 쓰고 있다면 전환 작업이 추가됩니다. (가정: 4.3 이상, 2D)
- [ ] **기존 구현이 탑다운인가요, 아이소메트릭인가요?** 탑다운이라면 로직은 살리고 화면 좌표만 아이소메트릭으로 바꾸는 작업을 단계 0에 넣습니다.
- [ ] **교육장 PC 실제 사양과 exe 실행 허용 여부** — CPU·그래픽·RAM 모델명과 전산 담당 확인. (가정: 9-4의 최저 사양, 실행 허용)
- [ ] **출동 편성 기준** — 안전센터 출동대 차량 수·탑승 인원, 후착대 도착 간격을 사하소방서 실제에 맞출지, 일반화할지. (결정: 6-1의 기본 편성 적용, data/crews.json 으로 근무 환경에 맞게 변경 가능)
- [ ] **게임 설정값 검수자** — 5장의 "게임 설정값(검수 필요)" 항목(활동별 호흡량, 연소 속도, 카드 제한시간 등)을 봐줄 현장 경력자.
- [ ] **실시간 속도 조절 허용 여부** — 질문 시 멈추지 않는 것은 유지하되, 초급자용으로 게임 전체를 0.75배속으로 돌리는 옵션을 둘지. (가정: 훈련 난이도에서만 제한시간 2배, 속도는 1배 고정)
- [ ] **교육 결과 보고 서식** — 교육 이수 증빙으로 쓸 서식이 있는지, PDF 하나면 되는지.
- [ ] **무전 음성** — 직원 목소리 녹음, TTS, 텍스트만 중 선택. (가정: 텍스트 + 효과음)
- [ ] **구급 비중** — 구출 후 분류·이송까지 직접 조작할지, 자동 처리할지. (가정: START 분류 카드만 직접, 처치·이송은 자동)
- [ ] **교관용 시나리오 편집기** — 발화위치·요구조자를 교관이 직접 배치하는 도구가 필요한지. (가정: 단계 10 이후 선택 기능)
