# 화재·연기·방수 모델 — 연구 자료 대조 (2026-11-13)

교재(소방전술) 대조는 [fire_textbook_check.md](fire_textbook_check.md)에 있다. 이 문서는 **교재 밖의 시뮬레이터·실험·표준**과 지금 게임을 견준 것이다.
게임 쪽 수치는 점검 도구로 잰 값이다: `tests/_probe_fire.gd`(화재하중·진행), `tests/_probe_victim.gd`(구조대상자 노출), 대상은 튜토리얼 주택.

## 1. 참고한 자료

| 자료 | 무엇 | 쓴 곳 |
| --- | --- | --- |
| NIST CFAST 7 Technical Reference Guide (TN 1889v1) | 미국 표준기술연구소의 구획 2층(zone) 화재 모델. 방마다 뜨거운 상부층·찬 하부층, 화염 기둥이 연기를 올리고 개구부로 넘친다 | 게임 모델 구조 비교 |
| Eurocode EN 1991-1-2 부속서 E (JRC 2012 워크숍 자료) | 용도별 화재하중·성장 속도·면적당 열방출률 | 화재하중 |
| Kerber 2012, Fire Technology — Analysis of Changing Residential Fire Dynamics | 실물 방 실험: 플래시오버 시간, 가구 열방출률 | 성장 속도 |
| UL 2010 (Kerber) 환기 실험 | 실물 주택 15회: 온도·산소·CO, 문 닫힌 방 | 연기·생존 |
| UL FSRI 2018 (Zevotek·Stakes·Willi) Fire Attack Part III | 실물 주택 26회: 구조대상자 위치별 노출량, 방수 효과 | 연기·생존·방수 |
| Grimwood (런던 소방, 실제 화재 100건), Barnett (뉴질랜드 TP 2004/1) | 필요 방수량 | 방수 |

## 2. 모델 구조 — 이미 표준 방식이다

| 요소 | CFAST | 게임 | 판정 |
| --- | --- | --- | --- |
| 방을 상부 연기층·하부 공기층 둘로 | 예 | 예 (`compartment_model.gd`) | 같음 |
| 화염 기둥이 공기를 끌어올려 연기층을 만듦 | Heskestad 식 | Zukoski 식 | 둘 다 표준 상관식 |
| 문·창으로 넘침, 공기 교환 | 압력차 유량식 | 연기층 높이·개구 인자(A√H) | 단순화, 방향 같음 |
| 환기 지배 최대 열방출률 | 산소 소비로 제한 | 1,500 × A√H kW | 표준식 |
| 상부층 온도 | 에너지 보존 | MQH 상관식 | 표준 상관식 |
| 가연물 | 사용자가 열방출률 곡선 입력 | 0.5m 칸마다 연료·최대 열방출률·성장 시간, 옆 칸으로 번짐 | 게임이 더 자세함 |
| 물 진압 | 스프링클러: 열방출률이 지수로 감소 | 칸마다 흡수 열량 누적 + 필요 방수량 비율 | 4장 |

**판단:** 연기·화염이 움직이는 뼈대는 CFAST와 같은 급이다. 뼈대를 바꿀 필요는 없고, **넣는 수치**가 문제다.

## 3. 수치 대조

### 3.1 화재하중 (가연물의 양)

| | 문헌 | 게임 (튜토리얼 주택) |
| --- | --- | --- |
| 주택 면적당 화재하중 | **948 MJ/㎡** (Eurocode 주택, 80% 분위) | 평균 **152 MJ/㎡** (방 160~240, 복도 100) |
| 의자 하나의 총 열량 | 419~425 MJ (Babrauskas) | 소파 칸당 100 MJ (3인 소파 약 700 MJ) — 품목은 맞음 |

→ 가구 하나하나는 맞지만 **방 전체로는 문헌의 약 1/6이다.** 옷·책·이불·바닥재 같은 생활용품이 빠져 있다. 결과: 방이 15분쯤이면 다 타서 스스로 꺼진다 (거실 열방출률이 13분부터 줄어듦). "놔두면 꺼진다"의 원인.

### 3.2 불이 커지는 속도

| | 문헌 | 게임 |
| --- | --- | --- |
| 1 MW 도달 | Eurocode 주택 '보통' 300초, '빠름' 150초 | 약 243초 |
| 플래시오버 | 현대 가구 방 3:20~4:45, 옛 가구 방 29분 이상 (Kerber) / 교재: 목조 5~6분 | 7:00 |
| 방 하나 최대 열방출률 | 7.5 MW (Kerber 실험 3) | 6.8 MW (환기 상한 7.2 MW) |
| 면적당 최대 열방출률 | 250 kW/㎡ (Eurocode 주택) | 약 400 kW/㎡ (환기 상한이 먼저 걸림) |

→ 성장 속도·최대 크기는 문헌 범위 안이다. 현대 가구 실험보다는 느리고 교재·Eurocode '보통'에 가깝다. **그대로 둔다.**

### 3.3 연기·일산화탄소

| | 문헌 | 게임 |
| --- | --- | --- |
| 연기층 CO (문 열린 방) | 1% 이상 ~ 4.2% | 예전 0.2~0.5% → **A안 적용 뒤 0.8~1.6%** |
| 바닥 30cm / 1m 높이 CO 비 | 0.33~0.45 | 예전 0.1 → **0.4** |
| 문 닫힌 방 | 끝까지 견딜 만함 (온도 63℃ 미만, CO 약 200ppm) | 불나기 전부터 닫혀 있으면 도착 8분까지 연기 0. **그 뒤 그 방에 불이 붙어** 211℃ |
| 연소 효율 (환기 부족) | 밀폐 주택은 환기 부족으로 CO가 급증 | 창이 깨져 효율 0.86 밑으로 안 내려감 |

→ CO는 A안으로 맞췄다(2026-11-13). 남은 점: **문 닫힌 옆방이 발화 11분 뒤 벽 너머 열로 불이 붙는다.** 벽돌조에서는 너무 이르다 (값 `wall_through_heat_kw_m2k`는 게임 설정값, 검수 필요 표시).

### 3.4 구조대상자 생존 기준

| | 문헌 (UL 2018) | 게임 |
| --- | --- | --- |
| 노출량 1 | 의식을 잃어 스스로 못 나옴 | 같음 |
| 노출량 3 | 사망 가능 (인구 절반 기준) | 같음 |
| 열로 의식 잃는 온도 | 150℃ (UL 2010, 바닥 30cm), 120℃ 넘으면 몇 분 안에 화상 | 무력화 시간식 (Purser) — 맞음 |

## 4. 방수 진압

### 4.1 문헌

| 출처 | 필요 방수량 |
| --- | --- |
| 물의 냉각 능력 | 1L가 약 2.6 MJ 흡수 (20℃ → 증기) |
| Grimwood (실제 화재 100건) | 전술 방수량 **4 L/min/㎡**, 2 L/min/㎡ 미만은 '위험' (그런 화재의 53%는 다 타 갈 때에야 진압), 화재하중이 크면 6 |
| Barnett (뉴질랜드 TP 2004/1) | **0.38 L/s per MW** (물이 실제로 쓰이는 효율 0.5), 구획 화재 5.7 L/min/㎡ (250 kW/㎡ 기준) |
| 미국 NFA | 면적(ft²) ÷ 3 gpm = **13.6 L/min/㎡** — 여유를 크게 둔 계획용 |
| 영국 평균 45mm 관창 | 290 L/min, 200 L/min 미만은 작은 방에서도 위험할 수 있음 |
| CFAST | 물이 충분하면 열방출률이 지수로 감소 |
| UL 2018 | 불난 구획에 물이 닿으면 건물 전체 온도가 빠르게 떨어짐. "물이 필요한 곳에 닿기만 하면 많이 필요하지 않다" |

### 4.2 게임

- 40mm 관창 275 L/min (문헌 평균 290과 비슷).
- 칸마다: 물 1L = 2.6 MJ × 효율(직사 0.6). 그 칸 열방출률 × 50초분을 빼앗으면 꺼짐.
- 방마다: 실제 방수량 ÷ 필요 방수량(13.6 L/min/㎡ × 타는 면적)이 1 미만이면 **꺼지지 않고 젖기만 함.**

### 4.3 차이

| 항목 | 문헌 | 게임 | 영향 |
| --- | --- | --- | --- |
| 필요 방수량 기준 | 4~6 L/min/㎡ (실제 화재), 0.38 L/s/MW | 13.6 L/min/㎡ (계획용) | 게임은 20㎡가 넘게 타면 관창 하나로는 **절대 못 끈다.** 문헌으로는 45~70㎡까지 가능 |
| 물 효율 | 0.33~0.5 | 직사 0.6 | 비슷 |
| 작은 불 진압 | 수 초~수십 초 | 2.5㎡(1 MW) 불을 1분 43초 | 게임이 오히려 느림 — 지나치게 쉬운 것이 아님 |

**G1에서 본 "문 앞에서 2분 만에 꺼진다"는 물리로는 맞다.** 도착 때 불이 1 MW(소파 하나)뿐이었기 때문이다. 싱거운 원인은 방수가 너무 세서가 아니라 **도착 때 불이 아직 작아서**다. 이것은 시나리오(G9)에서 고친다: 신고가 늦어 도착 때 이미 플래시오버가 지났거나, 불이 두 방에 걸쳐 있게.
