# 화재·연기·진압·잔화정리 — 교재 대조 (2026-11-10)

외부 검토 의견(5단계 화재 진행 보강)을 정하기 전에, 교재 원문과 지금 코드를 대조했다.
쪽수는 교재 인쇄 쪽수다. 「화재1」 = 소방전술1(화재1), 「화재2」 = 소방전술1(화재2).

## 1. 화재 진행 (화재1 제2장 제3~5절, 18~34쪽)

| 교재 | 코드 | 판정 |
|---|---|---|
| 구획실 5단계: 발화기 → 성장기 → 플래시오버 → 최성기 → 쇠퇴기 (18쪽) | 같은 5단계 + 훈소·다 탐·진화됨 | 맞음 |
| 쇠퇴기: 가연물을 소모하면서 열발산율이 줄고 온도가 내려간다. 타다 남은 잔화물은 일정 시간 온도를 유지할 수 있다 (22쪽) | 연료 20% 아래에서 열이 줄지만 **0이 되지 않아 영원히 '연소 중'** | **결함** — 교재대로면 결국 다 타서 끝나야 한다 |
| 화재 진행 영향 요인 6가지: 환기구 크기·수·위치, 구획실 크기, 둘러싼 물질의 열 특성, 천장 높이, 최초 가연물의 크기·위치, 추가 가연물 (22쪽) | 환기(개구 인자), 구획 크기, 벽 열손실, 천장고, 추가 가연물은 있음 | 최초 가연물 **위치**(벽·구석이면 공기를 덜 받아 더 뜨거움) 없음 — 작은 차이 |
| 열전달: 초기에는 거의 전도, 뜨거운 가스가 다른 가연물로 흐르며 대류·전도, 복사는 성장기→최성기 전환과 노출화재(인접 건물)의 주원인 (13·23쪽) | 옆 칸 화염열 + 천장 고온층 복사열로 착화, 인접 건물 노출 | 맞음 |
| 플래시오버: 483~649℃, 고온층 복사 20kW/㎡ 초과, 목조 5~6분·800~900℃, 내화조 20~30분 (29~31쪽) | 483~649℃ 범위(시드), 복사 계산 | 온도 맞음. **발생 시간(목조 5~6분, 내화조 20~30분)은 시험으로 확인한 적 없음** |
| 최성기: 미연소 가스가 인접 공간으로 흘러가 산소를 만나면 발화 (21쪽), 롤오버 → 출입문을 닫아 예방 (33쪽) | 미연소가스, 롤오버 징후, 문 닫기 효과 | 맞음 |
| 가스 열 균형: 고온층에 직접 방수하면 수증기로 열 균형이 깨져 뜨거운 가스가 아래로 섞이고 대원이 화상 (34쪽) | 없음 | 없음 (기획안 5-4 "배기구 없는 방 분무 → 수증기 피해"도 미구현) |

## 2. 연기 (화재2 제7~8절, 330~337쪽 / 화재1 108쪽, 150~151쪽)

| 교재 | 코드 | 판정 |
|---|---|---|
| 연기 속도: 수평 0.5~1m/s, 수직 2~3m/s, 계단 초기 약 1.5m/s·중기 3~4m/s, 굴뚝효과 건물 5m/s 이상 (화재2 330~331쪽) | 연기층 높이 차이로 넘침·계단 상승 계산 | **속도를 교재 수치와 맞춰 본 적 없음** — 시험 필요 |
| 연기 이동력: 굴뚝효과, 부력, 팽창, 바람, 공조(HVAC), 엘리베이터 피스톤 효과 (화재2 335쪽) | 부력(연기층)·팽창만 | **굴뚝효과·바람 없음** (기획안 5-3도 굴뚝효과 요구) |

| 고층: 굴뚝효과는 계단실·승강로에서 가장 두드러지고, 창을 열거나 깨면 이상기류 (화재1 150~151쪽) | 계단 상승만 | 굴뚝효과 없음 |
| 화점에 가까울수록 연기가 진하고 빠르다 (화재1 108쪽) | 연기 농도는 거리에 따라 옅어짐 | 맞음 |

## 3. 방수 진압 (화재1 제2장 제6절 38쪽, 화재2 제2편 제2장 192~196쪽)

| 교재 | 코드 | 판정 |
|---|---|---|
| 냉각소화: 물 1g이 증발하며 539cal 흡수, 비열도 가장 큼 (화재1 38쪽, 화재2 195쪽) | 물 1L = 2,600kJ (20→100℃ 80cal + 증발 539cal) | 맞음 |
| 가연물이 많을수록 열이 많고, 열이 많을수록 더 많은 소화약제가 필요 (화재1 14쪽, 질량보존) | 칸마다 '그 칸 열방출률 × 50초분'을 빼앗으면 꺼짐(누적) | 방향은 맞음. 다만 **누적이라 약한 물줄기도 오래 쏘면 꺼짐** — 열을 빼앗는 속도가 내는 속도보다 작으면 못 끄는 경쟁은 없음 |
| 질식효과: 수증기로 체적 약 1,700배 (화재2 195쪽) | 없음 | 없음 |
| 주수 형태: 봉상(직사) — 열용량 큰 고체 가연물의 대규모 화재에 유효, 타격·파괴 효과. 무상(분무) — 0.1~1mm, 질식·유화 효과, 전기화재에 유효 (화재2 192·196쪽) | 직사: 가연물 0.6·연기층 0.15 / 분무: 가연물 0.3·연기층 0.5 | 맞음. **교재는 분무가 고체 불을 못 끈다고 하지 않는다** → 외부 의견 ②("분무는 가연물을 못 끔, 0%")는 교재 근거가 약함. 지금처럼 낮은 효율로 두는 쪽이 교재에 가깝다 |
| 수손 방지: 주수량 최소, 화점 직하층 → 양옆 → 다른 층 순 방호 (화재1 257쪽) | 불 없는 곳 물 = 수손 | 맞음 (아래층 누수는 기획안 5-4) |

## 4. 잔화정리·재발화 (화재1 제4장 제14절 259~262쪽, 화재2 123~124쪽)

| 교재 | 코드 | 판정 |
|---|---|---|
| 불꽃이 사라져도 깊이 탄 목재 내부, 면·헝겊 속, 벽 사이 불씨가 시간이 지나 다시 연소 (259쪽) | 물로 끈 칸(연료 25% 이상)에 30% 확률로 숨은 불씨, 3~8분 뒤 재발화 | 맞음 (시간은 교재 수치 없음 — 추정) |
| 주수 사각이나 물이 스며들지 않은 곳에 불씨가 많다 (260쪽) | 확률이 칸마다 같음 | 일부 |
| 잔화를 빠뜨리기 쉬운 곳: 천장 뒤·바닥 아래·덕트 등 세로 구멍, 이중벽, 주방 화기 주위 철판 뒷면, 벽장·문틈, 기와 아래, **이불·매트·섬유·목재 더미** (260쪽) | 위치 구분 없음 | **없음** — 재질(소파·침구·목재)과 천장·벽에 불씨 가중을 두면 교재와 맞음 |
| 점검: 점검구로 확인, 천장·바닥 파괴해 확인, 손으로 벽 온도 확인 (261쪽) | 열화상카메라 든 조장이 방에 들어가면 찾음 | 일부 (파괴·손 확인 없음) |
| 잔화정리 순서: 지정 구역을 **바깥 → 중심, 위층 → 아래층, 높은 곳 → 낮은 곳** (261쪽) | 방마다 45초 작업 | **없음** |
| 방법: 감압 주수, 부분파괴·뒤집어 파기, 물이 안 스며드는 섬유·목재·종이 더미는 **옥외 반출**하거나 적셔 둠 (260~262쪽) | 한 가지 작업 | **없음** |
| **과잉 주수를 피하고 수손을 방지** (262쪽) | 잔화정리에 물 사용 개념 없음 | **없음** |
| 재출화 방지: 진화 후 감시경계 (262쪽) | 활동 종료 때 감시 지정 | 맞음 |
| 잔불탐색 때도 공기호흡기 착용 — 벽·천장 안의 유독가스가 나온다 (화재2 124쪽), 피로한 대원은 잔불정리에서 제외 (화재2 125쪽) | 없음 | 없음 (안전 판정 후보) |

## 6. 전도·대류·복사로 "일부 → 전체 → 전소"가 되는가 (2026-11-10 실험)

개발용 2층 주택(거실 소파 발화, 창 1개 열림)을 방수 없이 3시간 두고 방마다 상부층 온도를 쟀다.

| 시간 | 거실(발화실) | 복도 | 주방 | 방1·화장실 |
|---|---|---|---|---|
| 6분 | 487℃ 성장기 | 79℃ | 66℃ | 33~35℃ |
| 9분 | **831℃ 최성기** | 134℃ | 76℃ | 48~53℃ |
| 12분 | 753℃ | 117℃ | 69℃ | 46~55℃ |
| 20분 | 288℃ 쇠퇴기 | 56℃ | 27℃ | 28~29℃ |

- 거실은 교재(목조 5~6분 플래시오버, 800~900℃)와 비슷하게 탄다.
- 그러나 **옆방은 134℃를 넘지 못해 불이 옮겨 붙지 않고, 2층도 타지 않는다.** 불은 거실에서 다 타고 끝난다 → 집 전체가 타는 '전소'는 일어나지 않는다.

코드에 있는 전파 경로와 실제로 막히는 이유:

| 전파 | 코드 | 실험에서 막힌 이유 |
|---|---|---|
| 전도 (방 안) | 옆 칸 화염열로 착화 (0.5m 칸) | 방 안에서는 잘 번진다. 문 칸까지는 타지만 문 너머 칸으로는 약하다 |
| 전도 (벽·바닥 너머) | **없음** — 벽 칸은 열을 전하지 않는다 | 목조 주택의 벽·천장 너머, 아래층 → 위층 바닥 너머 확대가 없다 |
| 대류 (고온 가스) | 연기층이 문 상단보다 내려오면 옆방으로 넘치고 열·미연소가스를 옮김 | ① 받는 방의 연기층이 더 두꺼우면 흐름이 멈춘다 — 주방은 6분 뒤 76℃의 차가운 연기층 때문에 831℃ 가스를 더 받지 못함 ② 복도는 바깥 문이 열려 있어 들어온 열이 바로 빠짐 ③ 창이 열려 산소가 충분하면 미연소가스가 안 생겨 옆방으로 넘어가 타는 불꽃(교재 21쪽)이 없다 |
| 복사 | 같은 방 고온층 → 바닥 가연물, 화재 건물 창 → 인접 건물 창, 아래층 창 → 위층 창 | **열린 문을 통해 옆방 가연물로 가는 복사가 없다.** 옆방은 자기 방 고온층(134℃ → 약 0.5kW/㎡) 복사만 받아 착화 기준(약 10~20kW/㎡)에 못 미친다 |

교재 대조:
- 화재1 21쪽: 최성기에 미연소 가스가 인접 공간으로 흘러가 산소를 만나면 발화 → 일부만 구현(산소가 모자랄 때만)
- 화재1 13쪽: 뜨거운 가스가 다른 가연물로 흐르며 대류·전도로 열 전달, 복사는 노출화재의 주원인 → 문 너머 복사·전도가 없음
- 화재1 151쪽: 콘크리트 내력벽 고층아파트는 **문이 닫혀 있으면** 세대 밖으로 잘 번지지 않음 → 반대로 목조·문 열린 주택은 번져야 한다. 지금은 둘 다 번지지 않아 이 차이를 배울 수 없다

P3-1에 넣을 것 (추천):
1. 고온 가스 흐름을 연기층 두께가 아니라 온도·압력 차(중성대)로: 뜨거운 층은 차가운 층 위로 계속 넘어간다
2. 열린 문·창을 통한 복사와 화염 분출: 최성기 방의 문으로 옆방 가까운 칸이 가열되고, 문으로 불꽃이 나간다
3. 벽·바닥 너머 전도: 구조(목조 크게, 철근콘크리트 작게)에 따라 맞닿은 방·위층 가연물을 천천히 가열
4. 확인 시험: 목조 주택은 문이 열려 있으면 발화실 최성기 후 몇 분 안에 옆방이 착화(시간은 게임 설정값·검수), 콘크리트 아파트는 현관문이 닫혀 있으면 세대 밖으로 안 번짐(화재1 151쪽), 방치하면 목조 주택이 전소
