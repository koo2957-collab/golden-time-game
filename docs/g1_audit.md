## 점검 방법

- 점검 도구 `tests/_probe_tutorial.gd` (테스트 목록에는 넣지 않음). 화면 없이 튜토리얼을 실제 게임과 같은 설정(자동화 입문, 난이도 훈련, 출동 4분 선행 연소)으로 돌린다.
  - `best`: 안내판 문구대로만 행동하고 질문 카드에는 늘 '최선'을 고르는 플레이어
  - `idle`: 아무것도 하지 않는 플레이어 (30분)
- 실행: `godot --headless --path . -s res://tests/_probe_tutorial.gd -- best`
- 한계: 명령을 직접 넣었으므로 **마우스 조작 자체(클릭 판정·메뉴)는 재지 못했다.** 5장의 클릭 수는 안내판 문구와 코드로 센 것이다. 구급대·경계관창·배연·가스 차단 기능은 아래 막힘 때문에 실행되지 않아 확인하지 못했다.

## 2. 게임성: 긴장과 목표

| 사실 | 수치 |
| --- | --- |
| 절차대로 하면 불이 꺼지는 시각 | 도착 후 **2분 52초** (방수 시작 1분 43초 만에). 소실 2% |
| 불이 꺼진 곳 | **건물에 들어가기 전, 현관 문 앞에서 쏜 물로** 꺼짐. 진입 허가는 불이 거의 꺼진 뒤에 나옴 |
| 위기 | 가스·백드래프트·옆집 가열 모두 일어나지 않음 |
| 아무것도 안 하면 (idle) | 3분 플래시오버 → 9분 아이 의식 잃음 → 14분 옆집 가열 → 29분 소실 71%. **30분 동안 게임이 끝나지 않고, 아이는 불난 방 옆에서 20분 넘게 '의식 잃음'으로만 남음** (사망하지 않음) |
| 실패 처리 | 없음. 아이를 인계하지 않아도, 대원이 안에 있어도 '활동 종료'가 됨 |

판단: 지금 튜토리얼은 **정답대로 하면 3분 안에 싱겁게 끝나고, 틀리거나 방치해도 벌이 없다.** 지적하신 그대로다.

## 3. 대원이 '잘 안 움직이는' 원인으로 확인된 것

1. **임무가 끝나면 그 자리에 서 있는다.** 진압조는 불을 끈 뒤 거실 안에서 20분 동안 임무 없이 공기만 마셨고(100% → 경보), 스스로 나오지 않았다.
2. **구조한 사람을 둘 곳을 모르면 입구에서 멈춘다.** 이유는 무전 한 줄과 카드로만 알 수 있다.
3. **진입 허가 전후 순서가 어색하다.** 문 파괴·주수 방법 질문·방수가 진입 허가보다 먼저 일어난다. 플레이어에게는 "허가도 안 했는데 쏘고 있고, 다 꺼진 뒤에 들어가도 되냐고 묻는" 모습이다.
4. **카드에 답하지 않으면 멈춘 채로 있는다** (idle에서 카드 7장이 모두 '응답 없음 — 지시 대기').

## 4. 원인 → 본 사람 → 보고가 어긋난 곳

### 4.1 이번 실행에서 실제로 나온 것

| 보고·카드 | 문제 |
| --- | --- |
| 가스 시설 확인 카드 → '한 조를 보내 밸브 차단' 선택 | **아무 일도 일어나지 않음** (이 시나리오에는 잠글 밸브가 없다) |
| 구조대 "검색 중 화점 발견" 카드 (2분 50초) | 진압조가 그 불에 1분 40초째 물을 쏘고 있었다. **이미 아는 화점을 새로 발견했다고 묻는다** |
| 위 카드에서 '문을 닫는다' 선택 | "문을 닫을 수 없음" — 방금 파괴한 현관문이다. 할 수 없는 선택지가 최선으로 나온다 |
| "불씨 확인 (열화상) 4곳" (2분 51초) | 그 방은 아직 불타는 중이었다 (1초 뒤 진화). 불씨는 불이 꺼진 뒤에 찾는 것이다 |
| 검색 순서 카드 | 플레이어가 방을 직접 찍어 지시한 직후에 순서를 묻는다 |
| 예비 소방용수·관계자 조치 요청 카드 | 도착 1초 뒤에 뜬다 (SOP 200-2.2는 출동 중) |
| (idle) 롤오버 징후·붕괴 징후·현관 신발 물증·옆집 가열 | 건물 근처에 대원이 한 명도 없는데 보고된다. 신발은 현관문이 불에 타 없어진 순간 '발견'된다 |

### 4.2 코드에서 센 것

보고자가 실제 대원이 아니라 **"현장 대원"이라는 가짜 이름**으로 나오는 보고가 19종이다: 계단실 연기, 지휘소 위험, 붕괴 징후, 붕괴, 옆집 가열, 비화 착화, 연소 확대, 추락 위험, 뛰어내림(2), 간판 낙하(2), 낙하물 구역, 가스 폭발, 샤프트(4), 구조 추정 다름, 문 단서. 이 가운데 문 단서만 '대원 시야' 확인을 한다.

백드래프트 징후는 대원이 닫힌 문 앞에 갔을 때만 나오도록 되어 있어 코드상 맞다. 이번 실행에서는 그 상황이 생기지 않아 실제 동작은 확인하지 못했다.

## 5. 조작 단계 수 (안내판 문구·코드 기준, 화면에서 재지 않음)

| 하려는 일 | 지금 거치는 단계 |
| --- | --- |
| 지휘권 선언 | 선택 해제 → Q 전략 변경 → Q 선언·전략 → 10개 항목 양식 → 보내기 |
| RIT 지정 | 선택 해제 → E 지원 요청 → W 조직·안전 임무 → 조 고르기 → 지정 |
| 화점진압 | 층 막대 1층 → 조 클릭 → 방 클릭 → 화재진압 고르기 → (주수 카드) → (진입 허가 카드) |
| 구조한 사람 내려놓기 | 구역 지정 메뉴 → 환자 집결지 → 땅 클릭 (안내 없음) |
| 구급 처치 | 구급조 클릭 → W → 환자 클릭 |
| 완진·종료 | 명령 카드 옆 단추 → 확인 창 |

같은 '지휘관이 한 번 정하면 되는 일'이 2~3단 메뉴 안에 흩어져 있다.
