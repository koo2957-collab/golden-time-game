# 행동(동작) 목록과 만드는 절차

2026-11-15 사용자 결정: 동작은 **블렌더에서 사람·소품을 한 장면에 세워 만들고, 사용자가 보고 "됐다"고 한 것만** 스프라이트로 굽는다.
저사양 그림 메모리 기준(48MB)을 넘더라도 행동은 모두 만들고, 프레임 수는 나중에 줄인다.

- 검토용 블렌더 파일: `art_source/models/motion_review.blend` (대원 모델 사본, 게임 그림에 영향 없음)
- 굽기: `tools/blender/bake.py` · 모델: `tools/blender/firefighter_v2.py` · 가져오기: `tools/import_sprites.gd`
- 게임에서 동작을 고르는 곳: `scripts/ui/building/floor_layer.gd` `_unit_pose`

## 상태 표시

- **없음**: 그림이 없어 서 있거나 걷는 모습으로 나온다
- **임시**: 그림은 있지만 사용자가 장면으로 확인하지 않았다 (다시 만든다)
- **검토 중**: 블렌더에 장면이 있고 사용자 확인을 기다린다
- **완료**: 사용자 확인 → 굽기 → 게임 적용 → 게임에서 확인까지 끝

## 행동 하나를 끝내는 절차

1. **정의** — 누가, 몇 명이, 무엇을 들고, 어디에 서서, 무엇을 하는지 한 줄로 적고 근거(교재·SOP·참고 그림)를 붙인다. 근거가 없으면 사용자에게 묻는다.
2. **블렌더 장면** — `motion_review.blend`에 사람과 소품을 함께 세우고 동작을 넣는다 (8~12프레임, Space로 재생).
3. **사용자 확인** — 사용자가 블렌더에서 보고 고칠 점을 말한다. "됐다"고 할 때까지 2~3을 되풀이한다.
4. **굽기** — 확인한 동작을 사람마다 8방향으로 굽고 가져온다.
5. **게임 적용** — 언제 이 동작을 쓰는지(조건), 여러 사람이면 어디에 서는지, 소품을 어떻게 그리는지를 넣는다.
6. **확인** — 그림 테스트 + 화면 견본, 그다음 사용자가 게임에서 본다.
7. **기록** — 이 표의 상태를 바꾸고 docs/progress.md에 한 줄, 커밋.

## 한 번만 해 두는 준비 (A1을 끝내면서 같이 — 2026-11-15 끝남)

- **확인한 동작 그대로 굽기** ✓: `bake.py` scenes — 확인한 장면 파일을 열어 사람마다 8방향으로 굽고, 기준점(문틈 등)에서 그 사람까지의 자리를 meta.json `stand`에 적는다. 실행: `blender -b --factory-startup -P tools/blender/bake.py -- tools/blender/bake_config.json scenes <이름>`. 확인할 때마다 작업 파일을 `tools/blender/scenes/<이름>.blend`로 복사해 둔다(깃에 남김).
- **여러 사람 배치** ✓: 게임은 기준점(문틈)과 보는 방향을 정하고 `stand` 값으로 각자 자리에 세운다 (floor_layer.gd `force_frame`·`stand_spot`).
- **구조대상자·소품 모델**: 블렌더 장면에 세울 민간인, 들것, 문, 송풍기 등.
- **그림 메모리 기준** ✓: 테스트 상한을 128MB로 올려 둠 (저사양 목표 48MB는 다 만든 뒤 프레임 수로 맞춘다).
