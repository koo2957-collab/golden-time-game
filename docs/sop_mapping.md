# SOP ↔ 게임 기능 대응표

- 근거: **2025 재난현장표준작전절차 (소방청)** — 판정의 1차 근거. 조항 번호는 「소방전술 I」 제2편과 같다 (M6.5에서 대조 완료).
- 원리: 「소방전술 I (화재1·화재2)」 제1편 — 시뮬레이션과 디브리핑의 '왜' 설명. 판정 규칙(`data/sop/rules.json`)은 규칙마다 SOP 조항·원문과 소방전술 장절·원리를 함께 가진다.
- 2025판에서 교재와 달라진 점: 101-2.1 최초 상황보고는 8개 항목(차량 진입·회차 삭제 → 게임은 참고로만 표시), 109 긴급탈출 절차 보강, SSG 9 신속동료구조팀(RIT) 운영 표준지침 신설, 113-3.1.5~3.1.8 기록 기밀·처벌 근거 사용 금지.
- 범위: 첫 시나리오(SOP 214 주택화재)에 필요한 조항. 다른 유형은 확장할 때 추가한다.
- **규칙 ID**: `data/sop/`에서 쓸 판정 규칙의 ID 후보. 형식은 `SOP{번호}-{조항}`.
- **판정 유형**: 시간(T초 이내) / 순서(A 후 B) / 금지(조건에서 X 금지) / 상태(유지) / 평가(정확도·적합성) / 시스템(판정 없이 게임 규칙으로 구현)
