# M6.5 2025 재난현장표준작전절차 정합화 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_safety
GODOT --headless --path . -s res://tests/run_tests.gd -- test_evaluation
```

확인하는 것: 긴급탈출 선언(3회)·무선 침묵·해제, 조 전원 쓰러짐 = 무응답, RIT 대기·다른 임무 금지·긴급탈출 때 투입, 긴급탈출 지시·인원점검, 현장안전담당 공기 경고, 진입 금지 판단 요소, 최초보고 ⑨ 미채점, 새 판정 규칙(24개), 소방전술 근거 표기.

## 직접 해 보기

### RIT·현장안전담당
1. 시나리오 ① → 지휘권 선언(C).
2. O → 아래 "안전 임무"에서 구조1 2조 → **RIT 지정**, 진압1 2조 → **현장안전담당 지정**.
3. 무전으로 "신속동료구조팀(RIT) 수신", "현장안전담당 수신"이 오고, 진입 현황에 "2조 RIT", "2조 안전담당"이 붙는다.
4. RIT 조에 검색(Q)을 시키면 "RIT은 다른 임무를 받지 않음" 알림이 뜬다.

### 긴급탈출
1. 진압1 1조를 진입시켜 거실 깊이 보낸 채 오래 두거나(공기 소진), 플래시오버 때까지 둔다.
2. 대원이 쓰러지면 "진압1 1조. 긴급탈출, 긴급탈출, 긴급탈출. … 구출 지원 필요" 무전과 함께 무전 패널 위에 "⚠ 긴급탈출 상황 — 무선 침묵"이 뜬다. 이후 일반 보고(문 개방 등)는 무전에 나오지 않는다.
3. RIT 조를 선택해 쓰러진 대원을 우클릭 → "RIT 투입" 알림, RIT가 들어가 업고 나온다. 밖으로 나오면 "긴급탈출 상황 해제".
4. 무전 패널의 **긴급탈출 지시** → 내부 대원 전원이 문 밖으로 나온다 → **인원점검 (P)** → 출동대마다 "인원 4명 이상 없음, 장비 이상 없음".

### 진입 금지 판단
- 롤오버·백드래프트 징후 무전이 온 직후 진입 명령(R)을 내리면 "진입 금지 판단 요소 (SOP 102-4.1) — ⑧ 특수현상 징후…" 알림이 뜨고 디브리핑에서 감점된다.

### 종료와 디브리핑
1. C → 활동 종료 선언 → 종료 창에 인원점검 상태와 "재발화 감시" 선택이 보인다. "관계자에게 감시 당부"를 고르고 종료.
2. 디브리핑 ③ 탭 맨 위에 "주요 의사결정과 그때 알던 정보", 규칙마다 "SOP …「원문」"과 "왜? 소방전술 …" 두 줄이 보인다.
