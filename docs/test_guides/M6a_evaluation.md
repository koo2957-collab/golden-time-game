# M6a 평가·디브리핑 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_evaluation
```

확인하는 것: 규칙 라이브러리와 시나리오 규칙 일치, 활동 종료(선언·제한 시간), 일찍 끝냈을 때 낮은 등급과 잘한 점 1개 이상, 검색 순서 판정, 등급 상한(대원 행동 불능·구조 50% 미만 → 최고 C), 결과 파일 저장.

## 직접 해 보기

1. 게임 실행 → 시작 화면에서 "주택화재 ① 낮 · 1층 거실" → Enter → 출동 지령 창 Enter.
2. C → 최초 상황보고 양식을 채우고 무전 송신.
3. 아무것도 하지 않고 다시 C → 전략 창의 **활동 종료 선언** → 종료 창의 **종료하고 디브리핑**.
4. 확인
   - 디브리핑 화면이 뜨고 위쪽에 등급(대부분 D), 점수, 축별 점수, 결과 저장 경로가 보인다.
   - 탭 ①~④가 있고, ② 탭에 "숨은 정보 공개"(구조대상자 실제 위치, 진술의 진위)가 있다.
   - ④ 탭에 잘한 점이 최소 1개, 고칠 점이 최대 3개 보인다.
5. 저장 경로의 JSON 파일을 열어 grade·rules가 들어 있는지 본다.

## 제한 시간 자동 종료

시나리오의 `evaluation.time_limit_s`(개발용 2400초)가 지나면 자동으로 디브리핑으로 넘어간다. F3(4배속)으로 확인할 수 있다.
