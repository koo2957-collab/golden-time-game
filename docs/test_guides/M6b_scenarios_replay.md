# M6b 시나리오·다시 하기·잔불정리 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_scenario_loader
GODOT --headless --path . -s res://tests/run_tests.gd -- test_replay
GODOT --headless --path . -s res://tests/run_tests.gd -- test_overhaul
```

확인하는 것: 시나리오 목록·검증(한글 오류), 시나리오별 차량 제원 덮어쓰기, 판마다 다른 시드, 다시 하기 결정론(원래 판과 상태가 같음), 불씨 발생·열화상 발견·잔불정리·재발화.

## 직접 해 보기

### 시작 화면과 검증
1. 게임 실행 → 시나리오 4개(①②③ + 개발용)가 보인다.
2. `%APPDATA%\Godot\app_userdata\Fire Commander\scenarios\` 폴더에 개발용 시나리오를 복사하고 `"id"` 줄을 지운 뒤 게임을 다시 켠다 → 목록에 "⚠ 오류"로 표시되고 시작 버튼이 꺼진다.

### 다시 하기
1. 시나리오 ①을 2~3분 플레이(진입 명령, 수관 등) → C → 활동 종료.
2. 디브리핑 아래 목록에서 타임라인 시점(예: "지휘권 선언 직전")을 고르고 **이 시점부터 다시 하기**.
3. 진행률이 표시된 뒤 그 시점에서 일시정지 상태로 열리고, 대원·차량 위치가 그때와 같다. Space로 다시 진행.

### 잔불정리·재발화
1. 시나리오 ①에서 진입 명령(R) 후 진압1 1조로 거실을 진압한다.
2. 불이 꺼진 뒤 열화상카메라를 가진 조(진압1 1조·구조1 1조)를 거실에 보내면 주황 점(불씨)이 보인다.
3. 그 조를 선택하고 G → 방 클릭 → 45초 뒤 "잔불정리 완료" 무전.
4. 불씨를 그대로 두면 3~8분 뒤 "재발화" 알림이 뜬다.

### 정식 시나리오
- ② 새벽 2층: 판마다 딸의 위치가 방4 또는 복도로 바뀐다.
- ③ 주방 LPG: 펌프차 물이 2,400L로 적고, C면을 돌아봐야 LPG가 보인다.
