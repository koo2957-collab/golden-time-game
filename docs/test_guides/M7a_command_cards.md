# M7a 분대 명령칸·RECEO·교육 모드 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_tactical
GODOT --headless --path . -s res://tests/run_tests.gd -- test_hints
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것: 진압(잠긴 문 파괴 → 수관·분무 방수, 불이 잡히면 중지), 난이도별 문 처리(중급은 잠긴 문에서, 상급은 닫힌 문에서 멈춤), 백드래프트 징후 문은 열지 않음(SOP 210-4.5), 수색 → 자동 이송(입문)/보고 후 대기(중급), 철수, 다른 명령을 받으면 취소, 다시 하기 결정론, 힌트 트리거·한 번만·대기열·평가 모드에서 꺼짐, W 키로 출동대 종류별 명령.

## 직접 해 보기

### 명령칸
1. 시작 화면에서 시나리오 ①, **평가 모드**, 자동화 "시나리오 난이도(입문)" → 시작.
2. 지휘권 선언(C) 후 진압1을 선택하고 R(진입 명령).
3. 진압1 1조를 클릭 → 화면 오른쪽 아래 위 줄에 "진압대 명령칸: 진압(W)·외부 방수(V)·잔불정리(G)·철수(X)"가 보인다.
4. W → 거실 클릭 → 잠긴 현관을 파괴하고 수관을 펼쳐 분무 방수, 불이 꺼지면 "1층 거실 화염 진압, 방수 중지" 무전.
5. 구조1 1조를 클릭 → "구조대 명령칸: 수색(W)·구조(V)·진입구 개척(E)·철수(X)". W → 방1 클릭 → 문을 열고 검색, 아이를 찾으면 업고 나온다.
6. X → 선택한 조만 밖으로 나온다.

### 자동화 수준
- 시작 화면에서 "자동화: 중급"으로 시작해 진압(W) → 현관에서 "잠김 — 진입구 개척(문 파괴) 지시 바람" 무전 후 멈춘다. E로 문을 직접 열어 이어 간다.
- "자동화: 상급"이면 닫힌 문마다 멈춘다.

### RECEO 상태판
- 무전 패널 가운데에 "우선순위 (대원 안전 → RECEO)"와 여섯 줄(안전, R 구조, E 외부, C 확산, E 진압, O 잔불)이 보이고, 처리되지 않은 첫 줄 앞에 ▶가 붙는다.

### 교육 모드
1. 시작 화면에서 **교육 모드**로 시작.
2. 1분 동안 지휘권을 선언하지 않으면 "교육 — 지휘권을 아직 선언하지 않았습니다" 카드(SOP 101-1.2, 왜?, →할 일)가 뜨고 게임이 멈춘다. Enter로 닫는다.
3. RIT 없이 진입 명령을 내리면 SSG 9 카드, 공기 경보·구조대상자 발견·화염 진압 후에도 카드가 한 번씩 뜬다.
4. 인원점검 없이 활동 종료 창을 열면 "인원점검 없이 활동을 끝내려 합니다" 카드.
5. 디브리핑 위쪽에 "교육 모드 · 난이도 입문"이 표시된다.
