# M7b-1 인접 건물 연소·가스 차단·붕괴 징후·후착대 명령칸 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_exposure
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

이 테스트가 확인하는 것:
- 건물 묶음: 화재 건물과 옆집이 따로 있고, 둘러보기 외곽은 바뀌지 않는다.
- 연소 확대: 경계관창이 없으면 옆집 창이 깨지고 실내에 불이 붙는다. 경계관창이 그 창을 겨냥하면 가열이 쌓이지 않는다.
- 바람: 풍하이면 가열이 강해지고 풍상이면 약해진다.
- 가스: 시나리오 ③의 LPG 밸브를 조가 가서 차단한다. 밸브가 열린 채 주방이 플래시오버에 이르면 가스 폭발이 난다.
- 붕괴: 벽돌조 구획에서 붕괴 징후가 먼저 오고, 그 뒤 붕괴로 안의 대원이 행동 불능이 된다.
- 후착대: 후착 진압대 명령칸이 있고, 나중에 도착한 출동대는 "후착"으로 표시된다. 새 판정 규칙 3개가 들어 있다.

기존 테스트도 그대로 통과해야 한다 (전체 115개). 옆집의 무작위 값은 따로 뽑으므로, 같은 시드에서 요구조자 위치와 화재 경과가 예전과 같다.

## 직접 해 보기

### 1. 옆집 연소 확대와 경계관창 (시나리오 ②, 북풍 3m/s)
1. 시작 화면에서 **주택화재 ② 새벽 · 2층**을 고르고 교육 모드로 시작한다.
2. 상황판(Tab)에서 화재 건물 동쪽 약 2m에 **옆집**(방·거실 두 칸)이 보인다.
3. 진압하지 말고 3배속으로 기다린다. 약 9분에 다음이 차례로 나온다.
   - 무전 "옆집 외벽 가열 (2층 방4 화염) — 경계관창 필요"
   - 교육 카드 "인접 건물이 가열되고 있습니다" (SOP 214-2.4)
4. 무전 패널 RECEO의 **E 외부** 줄에 "옆집 가열 NN%"가 표시되고, 퍼센트가 계속 오른다.
5. 진압대 한 조를 고르고 **외부 방수(V)**로 옆집 서쪽 창이나 두 건물 사이를 클릭한다. 그러면 가열 %가 내려간다.
6. 기본 설정에서 방치하면 30분 안에 가열이 70%대까지 오른다. 경계관창 없이 끝내면 디브리핑의 "인접 건물 연소 확대 방지" 항목이 낮게 나온다 (0.3점, "경계관창 없이 불이 옮겨 붙지 않았을 뿐").
   - 실제로 옆집에 불이 옮겨 붙는 것까지 보려면 `exposure_ignite_kj`를 1500으로 낮춘다. 그러면 약 6분 30초에 "옆집 방으로 연소 확대" 무전이 나오고, 그 항목은 0점이 된다.

### 2. 가스 차단 (시나리오 ③, LPG)
1. **주택화재 ③ 저녁 · 1층 주방 (LPG)**를 시작한다.
2. 지휘관을 건물 뒤(C면, 북쪽)로 둘러보게 하거나, 3분 20초 뒤 도착하는 "할머니 아들"에게 위험 요소를 묻는다. 그러면 위험물(가스 등)이 확인된다.
3. 확인한 뒤에는 주방 뒤 바깥에 **노란 "주방 뒤 LPG 밸브" 표시**가 나타나고, 교육 모드에서는 "가스 시설을 확인했습니다" 카드가 뜬다.
4. 조를 하나 고르고 밸브를 **우클릭**한다. "가스 밸브 차단하러 감" 무전이 나오고, 약 10초 작업한 뒤 "주방 뒤 LPG 밸브 차단" 무전이 나온다. 표시는 어두운 "(차단)"으로 바뀐다.
5. 밸브를 열어 둔 채 주방이 플래시오버에 이르면 **가스 폭발**이 나고, 주방 안 대원은 행동 불능이 된다.
6. 디브리핑의 "가스(난방연료) 차단" 항목은 5분 안에 차단하면 만점이다.

### 3. 붕괴 징후 (벽돌조, 모든 주택 시나리오)
1. 시나리오 ①을 시작하고 진압하지 않고 기다린다. 약 12분 뒤 무전 "붕괴 징후 (폭음·균열음) — 1층 거실"이 나오고 교육 카드가 뜬다.
2. 진입 명령(R) 때의 진입 판단 요소에 "⑨ 붕괴 징후 (1층 거실)"가 붙는다.
3. 징후 뒤 철수(X)나 방어 전략으로 내부 대원을 1분 안에 빼면, 디브리핑의 "붕괴 징후 시 즉시 철수" 항목이 만점이다.
4. 최성기가 더 오래 이어져 그 구획이 붕괴하면, 안에 있던 대원은 "붕괴"로 행동 불능이 된다.

### 4. 후착 진압대 명령칸
1. 시나리오 ①에서 약 3분 뒤 진압2가 도착하면 대기1단계에 선다. 투입한 뒤 진압2의 조를 클릭한다.
2. 위 줄에 "후착 진압대 명령칸: 포위 진압(W) · 경계관창(V) · 교차 탐색 · 철수(X)"가 보인다.
   - 포위 진압: 선착대와 다른 방면의 방을 진압한다.
   - 경계관창: 옆집 창을 겨냥해 외부 방수를 한다.
   - 교차 탐색: 이미 검색한 방을 다시 검색한다.
3. 선착 출동대(진압1)를 고르면 예전처럼 "진압대 명령칸"이 보인다.

## 조정 가능한 값 (`data/fire/hazard_params.json`, 모두 추정값)

| 값 | 기본 | 뜻 |
|---|---|---|
| exposure_ignite_kj | 3000 | 옆집 창이 깨지고 불이 붙는 누적 가열량 (kJ/㎡) |
| exposure_crit_kw | 5 | 이보다 약한 복사열은 쌓이지 않음 (kW/㎡) |
| exposure_sign_ratio | 0.4 | 가열 알림이 나오는 비율 |
| wind_k | 0.15 | 풍속 1m/s당 풍하 쪽 가열 증가 비율 |
| gas_reignite_s / gas_off_s | 20 / 10 | 가스레인지 재착화 간격 / 밸브 차단 작업 시간 (초) |
| collapse_s / collapse_sign_ratio | 600 / 0.6 | 최성기가 이만큼 이어지면 붕괴 / 징후가 나오는 비율 |
