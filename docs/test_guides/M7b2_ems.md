# M7b-2 구급대(처치·이송·인계)·운전원 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_ems
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_ems`가 확인하는 것:
- 중증도 분류: 의식을 잃었으면 긴급, 의식이 있고 노출이 적으면 비응급.
- 입문 흐름: 처치 지시 → 환자에게 가서 180초 처치 → 자동 이송.
  - 들것으로 구급차까지 옮긴 뒤 출발한다. 구급차와 대원은 현장을 떠난다.
  - 출발 10분 뒤 병원 인계, 그 10분 뒤 현장 복귀.
- 처치 지연: 긴급 환자는 구조 후 7분 동안 처치를 못 받으면 사망한다. 비응급 환자는 기다려도 사망하지 않는다.
- 중급: 처치가 끝나면 "이송 지시 바람" 보고 후 기다리고, 이송 지시를 받으면 출발한다.
- 제한: 구급대가 아닌 조는 처치할 수 없다. 이동 명령을 받으면 처치가 취소되고 환자는 다시 처치 대기가 된다.
- 운전원·데이터: 펌프차 운전원 표시, 구급대 명령칸, 시나리오의 이송 병원·판정 규칙·구급1 출동이 들어 있다.

이번 기준 전체 결과는 `결과: 121 통과, 0 실패`이다.

## 직접 해 보기

### 1. 구급대 도착과 처치 (시나리오 ②, 교육 모드, 자동화 입문)
1. **주택화재 ② 새벽 · 2층**을 교육 모드로 시작한다. 출동 지령에 "구급1(약 5분 뒤)"가 보인다.
2. 지휘권을 선언하고 구조대로 요구조자를 구조해 밖으로 데리고 나온다.
3. 밖으로 나온 사람이 화면에 중증도 색 표시와 함께 보인다.
   - 표시 예: "아내(41) · 긴급 · 처치 대기". 빨강은 긴급, 노랑은 응급, 초록은 비응급이다.
   - 무전 기록에 "환자 분류 긴급 — …(SOP 402)"가 남는다.
4. 약 5분 뒤 구급1이 대기1단계에 선다. 구급1 조를 선택하면 "구급대 명령칸: 처치(W) · 이송(V)"이 보인다.
5. W를 누르고 환자를 클릭한다(또는 환자 우클릭). 구급대가 가서 "응급처치 시작" → 약 3분 뒤 "응급처치 완료"가 나온다.
6. 입문에서는 자동으로 들것 이송이 이어진다.
   - "환자 이송 출발 — … → ○○병원 응급실 (가상), 소방교 민서준 운전" 무전이 나온다.
   - 구급차와 구급대원 2명이 화면에서 사라진다.
7. 약 10분 뒤 "병원 인계", 다시 10분 뒤 "구급대 복귀"가 나온다. 구급차가 제자리에 다시 나타난다.
8. 구조된 환자가 처치 없이 1분 넘게 기다리면 교육 카드 "구조된 환자가 처치를 기다립니다"가 뜬다.
9. 무전 패널 RECEO의 R 줄에 "처치 대기 N"이 붙는다.

### 2. 처치 지연 (실패 경험)
- 구급대를 투입하지 않고 의식 잃은 사람을 구조해 두면, 약 7분 뒤 "사망 (구조 후 응급처치 지연)"이 된다.
- 디브리핑의 "구조 후 응급처치" 항목은 0점이 되고, 생존 구조 항목도 함께 떨어진다.

### 3. 이송 직접 지시 (자동화 중급)
- 시작 화면에서 자동화를 "중급"으로 두면, 처치가 끝난 뒤 "응급처치 완료 — 이송 지시 바람"에서 멈춘다.
- 구급대 조를 선택하고 V(이송)를 누른 뒤 환자를 클릭하면 이송이 시작된다.

### 4. 운전원
- 차량을 클릭하면 선택 정보에 "[진압1] 펌프차 (운전원 소방장 김기현) — 물 …"처럼 운전원이 나온다.
- 소화전 점령, 급수 연결, 이동 불가 기록에 "(운전원 …)"이 붙는다.
- 구급차가 이송 중이면 차량 줄에 "환자 이송 중 (현장 없음)"이 표시된다.

### 5. 디브리핑
- ② 숨은 정보의 구조대상자 결과에 중증도와 단계가 붙는다.
  - 예: "12:30 구조 (의식 잃음) · 긴급 · 이송 중".
- 판정 항목 "구조 후 응급처치"(SOP 400-3.2, 402)와 "처치 후 병원 이송"(400-3.3·3.4)이 나온다.
