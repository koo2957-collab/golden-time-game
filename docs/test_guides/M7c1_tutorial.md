# M7c-1 튜토리얼 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- tutorial
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것: 튜토리얼 시나리오 검증 통과·시작 화면 맨 위·구조대상자 1명, 단계가 순서대로 넘어감(뒤 단계를 먼저 해도 앞 단계가 끝나야 넘어감). 전체 결과는 `결과: 124 통과, 0 실패`.

## 직접 해 보기

1. 게임을 켜면 시작 화면 맨 위에 **튜토리얼 · 기본 지휘 흐름 [튜토리얼]**이 있다. 고르면 오른쪽 설명에 안내 순서가 나온다.
2. 시작(Enter) → 출동 지령 창을 닫으면 화면 **오른쪽 위 초록 안내판**에 "튜토리얼 2 / 13 — 지휘권 선언 · 최초 상황보고"와 조작 키, SOP 근거가 보인다.
3. 안내대로 해 본다. 단계가 이루어지면 자동으로 다음 단계로 넘어가고, 아래에 끝낸 단계가 ✓로 쌓인다.
   - 선언(C) → 지휘관을 건물 옆·뒤로 우클릭 이동(면 2개 확인) → 대원 선택 → RIT 지정(O) → 진입 명령(R) → 진압(W, 방 클릭) → 구조대 수색(W) → 구조 → 구급1 처치(W, 환자 클릭) → 완진 → 인원점검(P) → 활동 종료(C 메뉴)
4. 아이는 1층 방1 침대 옆에 있어 창 밖에서는 보이지 않는다. 검색해야 찾는다.
5. 마지막에 "튜토리얼 완료"가 표시되고 디브리핑이 열린다.
6. 튜토리얼에서는 게임을 멈추는 교육 힌트 카드가 나오지 않는다 (안내판과 겹치지 않게).
