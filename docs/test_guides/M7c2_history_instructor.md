# M7c-2 내 기록·익명 집계·교관 설정 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_history
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것: 결과 파일 읽기(오래된 순, 해당 없는 축 제외), 축별 성장(처음 → 최근), 시나리오별 익명 집계(판 수·등급 분포·평균·자주 나온 고칠 점, 날짜·개인 기록 없음), JSON·CSV 내보내기, 교관 수치 덮어쓰기는 게임 화면에서만 적용되고 원본 표는 바뀌지 않음, 바뀐 수치 기록. 전체 결과 `결과: 127 통과, 0 실패`.

## 직접 해 보기

### 내 기록
1. 아무 시나리오나 한 판 끝까지 한다(활동 종료 → 디브리핑).
2. 시작 화면으로 돌아가 왼쪽 아래 **내 기록**을 누른다.
3. "축별 성장 (처음 3판 평균 → 최근 3판 평균)"과 지난 판 목록(날짜·시나리오·모드·자동화·등급·점수·고칠 점 2개)이 보인다. 오른 축은 초록, 떨어진 축은 빨강.
4. **익명 집계 내보내기** → 아래에 저장 경로가 나온다(`…/Fire Commander/export/aggregate_날짜.json`, 같은 이름 `.csv`). 파일을 열어 이름·날짜별 기록 없이 시나리오별 통계만 있는지 확인한다.
5. Esc 또는 닫기.

### 교관 설정
1. 시작 화면 **교관 설정**.
2. "이번 주 훈련"에서 주택화재 ③을 고르고 안내 문구(예: "가스 차단과 경계관창")를 쓴다.
3. "시작 화면 기본값"을 교육 모드 / 중급으로 바꾼다.
4. 수치 표에서 예를 들어 `구급 · transport_s`를 300으로, `화재 · exposure_ignite_kj`를 1500으로 바꾼다(이름에 마우스를 올리면 설명과 기본값).
5. **저장** → 닫기. 시작 화면 목록에 "★ 이번 주 훈련 — 주택화재 ③ …"이 붙고, 고르면 설명 위쪽에 안내 문구가 나온다.
6. 게임을 껐다 켜면 시작 화면 기본값이 교육 모드·중급으로 잡혀 있다.
7. 시나리오 ②를 하면 옆집이 더 빨리 탄다(1500). 끝난 뒤 결과 파일(`reports/*.json`)의 `instructor_params`에 바꾼 값이 남는다.
8. **기본값으로** → 저장하면 원래 수치로 돌아간다.

## 참고
- 교관 설정 파일: `%APPDATA%\Godot\app_userdata\Fire Commander\instructor.json` (지우면 모두 기본값).
- 결과 폴더: `…\Fire Commander\reports`. 조작 점검(ui_smoke)도 결과를 남기므로 개발 PC의 내 기록에는 개발용 판이 섞일 수 있다.
