# M7c-3 대원 개성·캠페인 뼈대 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_campaign
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것: 개성 배율 적용(베테랑은 공기를 덜, 신참은 더 쓰고 열에 약함 — 같은 곳에 10분 있으면 신참 공기가 더 적음), 후착대 편성의 개성이 모두 정의됨, 캠페인 진행(처음엔 1장만, 튜토리얼 끝내면 2장, C 미만이면 도전 중, B면 완료·다음 장 열림, 시나리오 없는 장은 준비 중), 캠페인 시나리오가 모두 있음. 전체 결과 `결과: 130 통과, 0 실패`.

## 직접 해 보기

### 대원 개성
1. 주택화재 ①을 시작하고 약 3분 뒤 도착하는 진압2를 투입한다.
2. 진압2 1조를 클릭하면 선택 정보의 조 상태에 "개성: 오세훈 베테랑"이, 2조에는 "문태양 신참"이 보인다.
3. 두 조를 같은 방에 오래 두면 신참이 있는 조의 공기 %가 더 빨리 줄어든다(배율 1.15). 열 민감 대원은 열 스트레스 경고가 빨리 온다.
4. 개성과 배율은 `data/units/traits.json`, 누구에게 줄지는 편성 파일 `members[].traits`에서 바꾼다.

### 캠페인
1. 시작 화면 왼쪽 아래 **캠페인**.
2. 1장(튜토리얼)만 "도전 가능", 나머지는 "잠김", 5장은 "준비 중"(M8 공동주택).
3. 1장 버튼을 누르면 화면이 닫히고 시작 화면에서 튜토리얼이 골라져 있다.
4. 튜토리얼을 끝내면(등급 무관) 1장 "완료", 2장 "도전 가능". 주택화재 ①을 C 이상으로 끝내면 3장이 열린다.
5. 각 시나리오 버튼에 "최고 B"처럼 내 최고 등급이 나온다. 잠긴 장의 시나리오도 시작 화면 목록에서는 자유 연습으로 할 수 있다.
