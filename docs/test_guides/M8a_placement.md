# M8a 선착 차량 배치 선택 (SOP 200-3.1.1) — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- placement
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것: 네 시나리오(주택 ①②③·튜토리얼)의 모든 배치 보기가 도로 안에서 겹치지 않고 섬, 배치 명령 → 펌프차 위치 변경·기록·한 번만, 정면 배치는 판정 0.4점과 이유, 도착 5초 뒤에는 고를 수 없음, 개발용 시나리오는 배치·규칙 없음. 전체 결과 `결과: 133 통과, 0 실패`.

## 직접 해 보기

1. 주택화재 ①을 시작하면 출동 지령 창 아래에 **"선착 차량 배치 (SOP 200-3.1.1)"** 보기가 있다 (기본: 건물 모서리(B면 쪽) 앞).
2. 보기를 바꾸면 아래 설명이 바뀐다.
   - 건물 정면 바로 앞: 수관은 짧지만 창 화염·유리 낙하 범위, 사다리차·후착대 자리 없음
   - 건물 모서리(B면 쪽) 앞, 물탱크차는 옆 차로: 피해 범위 밖, 정면·동쪽을 비움
   - 건물을 지나 소화전 가까이: 소화전은 빠르지만 후착대 대기 장소 입구를 막음
3. "건물 정면 바로 앞"을 고르고 Enter → 펌프차가 건물 한가운데 앞(입체 화면 빨간 차)에, 물탱크차는 옆 차로 서쪽에 선다. 무전 기록에 "선착 차량 배치 — 건물 정면 바로 앞에 펌프차".
4. 활동을 끝내면 디브리핑 화재 안정화 축에 "선착 차량 배치 (SOP 200-3.1.1)" — 40점, "화염·낙하물 피해 범위에 차량을 두고 특수차 공간을 막았다"가 나온다. 모서리 배치는 100점, 소화전 쪽은 60점.
5. 다시 하기(디브리핑 ③ 시점 선택)를 하면 같은 배치로 재현된다.

## 고칠 수 있는 곳
- 보기와 점수·설명: 각 시나리오 `approach` (차량 순서는 펌프차, 물탱크차).
