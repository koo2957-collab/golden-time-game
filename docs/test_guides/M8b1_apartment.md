# M8b-1 아파트화재 ① — 연결송수관·방화문 (SOP 213, 200-3.3.1) — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- apartment
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

확인하는 것:
- 시나리오: 검증 통과, 5층 건물, 송수구와 층별 방수구 5개, 현관 방화문, 세대·계단실 구획, 상황보고 층수 정답("4층 이상").
- 방화문: 파괴 시간이 단독주택 현관의 2배.
- 송수구: 서쪽 기본 위치에서는 멀어서 연결되지 않고, 건너편 차로 배치에서는 연결된다.
- 방수구 수관: 3층 방수가 3층 방수구 수관으로 시작되고, 물은 펌프차 탱크에서 줄어든다. 판정 fire.standpipe가 1.0이다.
- 송수구 미연결: 방수구를 쓸 수 없다는 보고가 나오고 펌프차 수관으로 대신한다.

전체 결과는 `결과: 137 통과, 0 실패`.

## 직접 해 보기

1. 시작 화면에서 **아파트화재 ① 낮 · 3층 세대 [중급]**을 고른다(캠페인 5장도 같은 시나리오).
2. 출동 지령 창에서 배치 보기를 고른다.
   - 공동현관 바로 앞: 송수구는 가깝지만 특수차 자리를 막는다.
   - 건너편 차로: 기본값.
   - 건물 서쪽 끝 앞: 송수구가 멀다.
3. 화면 오른쪽 위에 1층~5층 탭이 있다. PgUp/PgDn이나 탭으로 3층을 보면 301호 거실에 불이 있다. 301호 현관이 열려 있어 1~3분 사이에 "연기 유입 — 5층/3층/4층 계단실" 무전이 나온다.
4. 1층에서 공동현관 동쪽에 주황색 **송수구**가 있다. 펌프차를 선택하고 송수구를 우클릭하면 "송수구 연결 — 진압1 펌프차 (운전원 …)"이 나온다.
   - 서쪽 끝 배치였다면 "송수구가 멀어 연결 못함"이 나온다. 펌프차를 송수구 가까이(앞 차로 가운데)로 옮긴 뒤 다시 우클릭한다.
5. 진입 명령(R) 뒤 진압1 조로 W를 누르고 3층 301호 거실을 클릭한다. 조가 계단으로 올라가면 3층 계단실 **방수구**에서 수관이 시작된다("방수구에서 수관 연장 — … (3층)"). 펌프차에서 계단으로 끌어올리지 않는다.
   - 조를 선택하고 방수구를 직접 우클릭해도 된다.
6. 4층 401호 할머니에게 가려면 잠긴 현관 방화문을 파괴해야 한다. 두 명 이상 필요하고, 단독주택 현관(60초)의 두 배인 약 120초가 걸린다.
7. 관리사무소 직원은 2분 30초 뒤 도착한다. 302호 학생 정보를 알려 준다(301호 주민은 "302호는 비어요"라고 틀리게 말한다).
8. 디브리핑 화재 안정화 축의 "연결송수관 활용 (SOP 200-3.3.1, 213-1.3)" 점수:

   | 상황 | 점수 |
   |---|---|
   | 방수구 사용 | 100 |
   | 송수구만 연결 | 50 |
   | 계단으로 끌어올림 | 20 |
