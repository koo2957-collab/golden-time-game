# M8b-2 아파트화재 ② — 상층 연소 확대·공기안전매트·낙하물 (SOP 213) — 테스트 방법

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_falls
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 142 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_falls`가 확인하는 것:
- 아파트에는 아래층 창 → 위층 창 짝이 있고, 단독주택에는 없다. 2층 주택에서는 추락·낙하물을 따지지 않는다.
- 창가 주민의 방에 불이 붙으면 "뛰어내리려 함" 무전이 나온다. 4분 뒤 매트 없이 뛰어내리면 사망한다.
- 창 아래에 매트가 있으면 구조된다. 응급 환자로 분류되고, 판정 rescue.air_mat이 만점이다.
- 진압대는 매트를 설치하지 못한다. 구조대는 창 아래로 가서 60초 동안 설치한다.
- 4층 창이 깨지면 반경 6m 낙하물 구역이 생긴다. 구역 안에 있으면 체류 시간이 쌓이고, 진입 경고는 한 번만 나온다.

## 직접 해 보기 — 아파트화재 ② 새벽 · 3층 → 상층 확대 [상급]

아무 조치 없이 두었을 때의 흐름:

| 시각 | 일어나는 일 |
|---|---|
| 약 4분 | 302호 거실 창 파손 → "낙하물 위험 — 3층 302호 거실 A면 창 파손, 아래 반경 4.5m" (상황판에 빨간 원) |
| 약 12분 | 302호 거실 플래시오버 |
| 약 13분 40초 | "4층 402호 거실 (위층 창) 외벽 가열 — 경계관창 필요"<br>동시에 "창가 요구조자가 뛰어내리려 함 — 402호 주민(35) (공기안전매트 필요)" (교육 모드면 카드) |
| 약 16분 30초 | "4층 402호 거실으로 연소 확대" |
| 약 20분 30초 | 402호 주민 추락 — 매트가 없으면 사망 |
| 이후 | 같은 방식으로 5층까지 번진다 |

막는 방법:
1. **공기안전매트:** 구조대 조를 선택하고 명령칸에서 '공기안전매트'를 누른 뒤, 402호 거실 창 아래 바닥(A면, 공동현관 동쪽 화단)을 클릭한다. 60초 뒤 노란 매트가 생긴다. 구조2(약 6분 뒤 도착)도 쓸 수 있다.
   - 주민이 뛰어내리면 "창에서 추락 — 공기안전매트에 착지" 무전이 나오고 구조된다. 구급대가 처치해야 한다.
2. **경계관창:** 외부 방수(V)로 402호 거실 창을 겨냥하면 위층 창 가열이 식는다. RECEO E줄의 "상층 세대 가열 %"가 내려간다.
3. **빠른 진압:** 송수구를 연결하고 3층 방수구 수관으로 302호를 빨리 끄면 위층 확대 자체를 막는다.
4. **내부 구조:** 402호 현관 방화문을 파괴하고(약 2분) 들어가 구조해도 된다.
5. **낙하물 구역:** 빨간 원 안에 대원을 두면 "낙하물 위험구역에 대원 진입" 무전이 나오고, 디브리핑 "낙하물 안전구역" 항목이 깎인다.

디브리핑 확인:
- 인명구조 축: "추락 예상지점 공기안전매트 (SOP 213-2.4.3)"
- 대원 안전 축: "낙하물 안전구역 (SOP 213-2.7.1)"
- 재산 보호 축: "인접 건물 연소 확대 방지 — 상층 세대"
