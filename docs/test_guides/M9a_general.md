# M9a 일반건축물화재 ① — 자력 대피·배관 샤프트·간판 낙하 (SOP 212) — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_general
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 147 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_general`이 확인하는 것:
- 시나리오·건물: 시나리오 검증 통과, 3층 건물, 층마다 샤프트, 2층 간판, 자력 대피 가능 5명.
- 자력 대피: 연기가 차기 전에 알아차린 사람은 스스로 나오고, 나온 사람은 구급 분류 대상이 된다.
- 갇힘: 1층 복도에 연기가 차 있으면 아무도 나가지 못하고 제자리에서 기다린다(갇힘 무전).
- 샤프트: 주방이 최성기가 되면 1층 샤프트 → 3분 뒤 2층 샤프트 → 4분 뒤 2층 옆 방 착화 순서로 번진다. 대원이 2층 샤프트에 들어가면 그 층에서 멈추고 판정 fire.shaft가 높게 나온다.
- 간판: 간판 뒤 창이 깨지면 경고가 나오고, 90초 뒤 떨어져 아래 대원이 행동 불능이 된다.

## 직접 해 보기 — 일반건축물 ① 저녁 · 1층 식당 주방 [중급]

아무 조치 없이 두었을 때의 흐름:

| 시각 | 일어나는 일 |
|---|---|
| 1분 10초 | "자력 대피 — 강사(31) 밖으로 나옴" |
| 2분 40초 | 학생1·2 자력 대피 (건물 앞에 환자 표시, 구급 분류 대상) |
| 4분 | "대피하던 사람이 연기에 갇힘 — 학생3·학생4, 2층 강의실3" (1층 복도에 연기가 차서 출발하지 못함) |
| 16분 | 주방 플래시오버. 가스 밸브가 열려 있으면 가스 폭발 |
| 16분 | "1층 샤프트(PS)로 화염·연기 유입 — 위층 확인 필요" |
| 19분 | "2층 샤프트(PS)에서 연기" |
| 23분 | "샤프트 통해 연소 확대 — 2층 강의실2" |
| 26분 | 같은 방식으로 3층 사무실2까지 번진다 |
| 27분 | 3층 사무실2의 야근자(이어폰, 화재 모름)가 의식을 잃고 사망한다 |

해 볼 것:
1. **배치:** 출동 지령 창에서 "건물 서쪽 끝(비상구 쪽) 앞"을 고른다(정면은 간판·창 아래).
2. **관계인 진술:**
   - 식당 사장(C로 질문)에게서 2층 학원, 건물 뒤 가스 밸브, 서쪽 비상구 정보를 얻는다.
   - 3분 20초 뒤 오는 학원 원장에게서 인원(학생 4·강사 1)과 3층 야근자 가능성을 얻는다.
3. **갇힌 사람:** 구조1로 서쪽 비상구 → 계단 → 2층 강의실3을 수색해 학생3·4를 구조한다.
4. **가스:** 한 조를 건물 뒤(C면) "주방 가스 중간밸브"로 보내 우클릭으로 차단한다.
5. **샤프트:** "샤프트로 화염·연기 유입" 무전이 오면, 한 조를 2층 복도 가운데 PS(배관 샤프트) 문 안으로 보내거나 방수한다. "2층 샤프트(PS) 확인·차단" 무전이 나오면 위층 확대가 멈춘다.
6. **3층 검색:** 3층 사무실2 야근자를 찾는다(불빛이 켜져 있음).
7. **간판:** 1층 식당이나 2층 강의실3 남쪽 창에서 화염이 나오면 "간판 뒤 화염 분출 — 2층 학원 간판 낙하 위험" 무전이 나온다. 90초 안에 정면 보도에서 대원을 뺀다.

디브리핑 확인:
- 화재 안정화 축: "샤프트·배관 관통부 확인 (SOP 212-2.3)"
- 인명구조 축: 생존·시간, 구급 처치(스스로 나온 사람 포함)
- 대원 안전 축: 낙하물 안전구역

## 조정 가능한 값 (`data/fire/hazard_params.json`, 모두 추정값)

| 값 | 기본 | 뜻 |
|---|---|---|
| evac_alert_s | 60 | 알아차리는 기본 시간 (사람마다 시나리오 alert_s로 덮어씀) |

| sign_fall_s / sign_radius_m | 90 / 3 | 간판 낙하까지 시간 / 덮치는 반경 |
