# M9b 물탱크차 순환보수 (SOP 200-3.1.1.3) — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_shuttle
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 150 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_shuttle`이 확인하는 것:
- 고장 소화전: 주택화재 ③의 소화전은 점령되지 않고 "소화전 사용 불가(고장)" 무전이 나온다.
- 지정: 펌프차는 순환보수 대상이 아니고, 물탱크차만 지정할 수 있다.
- 왕복: 지정하면 펌프차에 급수를 연결한다. 탱크가 10% 아래로 떨어지면 원거리 수원으로 떠난다(급수 끊김, 화면에서 사라짐). 왕복 300초와 급수 시간이 지나면 가득 채워 돌아와 다시 급수한다(왕복 1회).
- 판정: 지시하지 않으면 낮은 점수, 지시하고 물이 끊기지 않으면 만점. 다른 시나리오에는 순환보수가 없다.

## 직접 해 보기 — 주택화재 ③ 저녁 · 1층 주방 (LPG) [상급]

1. 출동 지령에 "소화전: … (점검 중 — 사용 불가 신고 있음), 원거리 소화전 약 600m"가 보인다.
2. 물탱크차를 선택하고 동쪽 소화전을 우클릭하면 "소화전 사용 불가(고장) — 진압1 물탱크차 (운전원 …)" 무전이 나온다. 교육 모드면 "소화전을 쓸 수 없습니다" 카드가 뜬다.
3. 물탱크차를 선택한 채로 **B**를 누르면 "순환보수 지정 — 진압1 물탱크차 (운전원 …), 수원: 원거리 소화전 (약 600m)" 무전이 나온다. 펌프차에 급수가 연결된다.
   - 선택 정보에 "순환보수 0회", 아래 줄에 "B: 순환보수 해제"가 보인다.
4. 진압을 계속하면 물탱크차 물이 줄어든다. 10% 아래가 되면 "급수하러 출발 — … (약 N분 뒤 복귀)" 무전이 나오고 물탱크차가 화면에서 사라진다.
5. 그 사이에는 펌프차 탱크만으로 방수한다. 소형 펌프차 2,400L, 관창 1개(350L/분)면 약 7분이다.
6. 시간이 되면 "급수 마치고 복귀" 무전과 함께 제자리로 돌아와 다시 급수한다.
7. 디브리핑 화재 안정화 축의 "수원 확보 곤란 시 순환보수 (SOP 200-3.1.1.3)" 점수:

   | 상황 | 점수 |
   |---|---|
   | 지시했고 물이 끊기지 않음 | 100 |
   | 지시했지만 물이 끊김 | 50 |
   | 지시 안 함 | 0~40 |

   "급수 연결" 판정에서는 소화전이 고장이므로 점령 항목이 빠진다.

## 고칠 수 있는 곳
