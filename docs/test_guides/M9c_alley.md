# M9c 골목 안 주택 — 진입·회차 판단 (SOP 101-2.1 ⑨, 200-3.1.1) — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_alley
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 153 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_alley`가 확인하는 것:
- 시나리오·지도: 시나리오 검증 통과, 상황보고 ⑨ 정답 "진입 가능, 회차 불가", 골목은 차도이고 앞마당은 담장으로 막힘(큰길에서 앞마당은 골목으로 돌아서 감).
- 배치 보기: 세 가지 모두 차량 2대가 도로 위에 겹치지 않고 선다.
- 골목 안 펌프차: 큰길 쪽으로 이동 명령을 주면 돌리지 못하고 후진으로만 나온다.
- 판정: 골목 진입 배치는 0.5점이고, 설명에 "회차"가 들어간다.

## 직접 해 보기 — 주택화재 ④ 낮 · 골목 안 주택 [중급]

1. 시작 화면에서 주택화재 ③ 다음의 **주택화재 ④**를 고른다(캠페인 4장에도 있음).
2. 출동 지령에 "폭 3m 막다른 골목 안", "골목 끝은 막혀 있음 (회차 공간 없음)"이 보인다.
3. 배치 보기를 고른다.

   | 배치 | 결과 |
   |---|---|
   | 큰길 골목 입구 옆에 정차 | 수관을 골목 따라 길게 연장한다. 골목이 비어 있다 |
   | 펌프차만 골목 안 집 옆까지 진입 | 펌프차가 골목 안에서 집 D면 옆에 선다. 수관은 짧지만 골목이 막힌다 |
   | 두 차 모두 골목 안으로 | 골목이 완전히 막힌다 |

4. 골목에 넣었다면 펌프차를 선택하고 큰길 쪽을 우클릭해 본다. 차를 돌리지 못하고 **후진**("후진" 표시)으로 천천히 나온다. 수관이 연결돼 있으면 움직이지 못한다.
5. 큰길에 세웠다면 대원 이동이 담장 때문에 골목으로 돌아간다. 수관도 골목을 따라 길게 깔린다.
6. 최초 상황보고(C)의 ⑨에서 "진입 가능, 회차 불가"를 고르면 정답이다.
7. 디브리핑 화재 안정화 축의 "선착 차량 배치 (SOP 200-3.1.1)" 점수:

   | 배치 | 점수 |
   |---|---|
   | 큰길 골목 입구 | 100 |
   | 펌프차만 골목 진입 | 50 |
   | 두 차 모두 골목 | 20 |

   지휘 절차 축의 상황보고 정확도에도 ⑨가 들어간다.

## 참고
- 차량 회전반경 경로 계산(교차로에서 꺾어 들어가기)은 하지 않는다. 진입·회차 판단은 배치 보기와 "골목 안 차량은 후진으로만 나옴"으로 훈련한다.
