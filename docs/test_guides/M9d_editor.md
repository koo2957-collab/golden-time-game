# M9d 시나리오 편집기 — 테스트 방법

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_editor
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 156 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_editor`가 확인하는 것:
- 사본: 사본 id와 제목이 새로 붙는다.
- 글: 출동 지령의 빈 줄은 빼고 저장한다.
- 발화점·구조대상자: 바깥 칸·벽 칸에는 놓을 수 없다.
- 관계인: 위치를 옮길 수 있다.
- 저장: 저장 후 검증을 통과하고, 시작 화면 목록에 "(추가)"로 나오며, 그대로 실행된다.
- 다시 고치기: 가까운 항목을 지울 수 있고, 다시 열면 같은 파일에 저장된다.
- 오류: 잘못된 사본은 한글 오류를 돌려준다.

## 직접 해 보기

1. 시작 화면 아래 **시나리오 편집기**를 누른다.
2. 위쪽에서 원본(예: 주택화재 ① 낮 · 1층 거실)을 고르고 **이 시나리오로 사본 만들기**를 누른다. 제목 칸에 "(사본) …"이 들어온다. 원하는 제목으로 바꾼다.
3. 오른쪽에서 요약, 출동 지령(한 줄에 한 항목), 난이도, 제한 시간, "판마다 다른 시드"를 고친다.
4. 왼쪽 도면:
   - **발화점 놓기**: 층을 고르고 방 바닥을 클릭하면 빨간 점이 생긴다. 바깥이나 벽을 누르면 아래 상태 줄에 이유가 나온다.
   - **구조대상자 놓기**: 오른쪽 "구조대상자 속성"을 적고 바닥을 클릭하면 노란 마름모와 이름이 생긴다.
     - 이름·나이·거동 가능/불편을 정한다.
     - 창가에 체크하면 3층 이상에서 추락 위험이 생긴다.
     - 자력 대피에 체크하면 스스로 대피를 시도한다.
   - **관계인 옮기기**: 관계인을 고르고 1층 바깥을 클릭하면 파란 점이 옮겨진다.
   - **지우기**: 빨간 점이나 노란 마름모 근처를 클릭한다.
5. **저장·검증**을 누른다.
   - 문제가 없으면 "저장했습니다: …/scenarios/custom_….json"이 나온다.
   - 문제가 있으면 고칠 곳이 한글 목록으로 나온다. 예: 발화점이 하나도 없음.
6. 닫으면 시작 화면 목록 아래쪽에 새 시나리오가 "(추가)"로 보이고, 바로 시작할 수 있다.
7. 만든 파일은 `%APPDATA%\Godot\app_userdata\Fire Commander\scenarios\`에 있다. 다른 PC에 복사해 같은 폴더에 넣으면 그대로 쓸 수 있다.

## 아직 안 되는 것
- 도면(건물) 자체 편집, 후착대·지원 출동대 편성, 관계인 진술 문구, 평가 규칙 선택은 아직 편집기에서 못 한다.
  - 사본은 원본 설정을 그대로 물려받는다.
  - 필요하면 JSON 파일에서 직접 고친다.
