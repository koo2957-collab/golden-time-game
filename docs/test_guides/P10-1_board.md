## 1. 오른쪽 무전 기록

- 무전만 쌓이고 최신이 맨 위입니다. 대원 안전은 빨강, 구조대상자는 주황, 내 지시는 파랑, 나머지는 흰색입니다.
- 답한 질문 카드는 "진압1 1조 질문 → 진입 허가 — 진입하라"처럼 한 줄로 남습니다.
- 대원이 보낸 무전 항목을 누르면 그 대원이 있는 곳(층 포함)으로 화면이 옮겨 갑니다.
- 필터는 전체 / 긴급 / 내 지시입니다.
- 아래를 보는 중에 새 무전이 오면 목록은 그대로 두고 "새 무전 N건 ↑" 배지만 뜹니다. 배지를 누르면 맨 위로 갑니다.
- **긴급 고정줄**(맨 위 빨간 줄, 최대 2줄)에는 긴급탈출, 인원 점검 무응답, 잔압 경보, 물탱크 고갈이 올라옵니다. 해결되면 사라지고, 패널을 "▶ 접기"로 접어도 고정줄은 남습니다.
- 패널의 빈 곳을 누르면 그대로 지도가 눌립니다.

## 2. 팀 초상 줄 (하단 콘솔 위 가운데)

- 현장의 조마다 색 원이 하나씩 있고, 둘레 링이 공기 잔량입니다(초록 → 주황 → 빨강). 질문을 기다리는 조에는 노란 "?"가 붙습니다.
- 누르면 선택, 두 번 누르면 그 조로 화면 이동합니다.
- 숫자 1~9로 이 순서의 조를 고릅니다. 질문 카드가 떠 있을 때 1~4는 카드 답입니다.

## 3. 전술상황판 (Tab · M · 아래 바 '상황판' 단추) — 2026-11-14 화이트보드

- 화면의 85%쯤 되는 가로형(16:9) 화이트보드 한 장이 열립니다. 알루미늄 틀과 모서리 캡, 아래에 마커 받침이 있습니다. 게임은 계속 진행되고, 질문 장면과 지휘 창은 상황판 위에 뜹니다.
- 판 위의 글은 모두 보드마커 손글씨입니다. 검정 = 내용, 파랑 = 제목, 빨강 = 급한 것·확인 필요, 회색 = 해당 없음.
- **맨 위 줄:** "전술상황판", 층 탭(외부 / 1층 / 2층 … — 고른 탭은 파란 네모), 닫기.
- **왼쪽 60% — 도면:** 아래 두 줄이 범례입니다(보는 판에 따라 바뀜).
  - 무전으로 보고된 것만 그립니다. 불이 화면에 보여도 대원이 "화점 발견"을 무전으로 보내기 전에는 상황판에 없습니다.
  - 구조: 벽은 먹 선, 창은 파란 선, 문은 갈색 선입니다. 대원이 아직 안 본 곳은 회색 빈칸에 건물 외곽선만 보입니다(도면을 얻으면 도면).
  - 조는 자석 명패("진압1-1", 왼쪽 칩이 헬멧 색)입니다. 건물 안이면 마지막으로 무전을 보낸 자리와 "○초 전"이 붙고, 60초가 넘으면 흐려집니다. RIT는 빨간 겹테두리와 이름 뒤 "RIT"입니다.
  - 화점 = 빨간 불꽃 + 빨간 빗금, 연기 = 회색 물결선, 구조대상자 = 노란 사람 + 인원수(구조 완료는 초록 체크), 위험 징후 = 노란 삼각형 + 글자.
  - 검색: 검색 임무를 주면 방에 사선(/)이 그어지고, "검색 완료" 보고가 오면 ✕가 됩니다.
  - 수관: 방수 중이면 파란 실선, 연장만 했으면 파란 점선입니다.
  - 외부 탭: 차량 네모 자석("진압1 펌프"), 소화전(파란 원 안 H)과 급수 연결선, 진입구(초록 화살표 + 이름), 안전구역(초록 점선)·진입통제선(주황 점선)·집결지·분류소(십자), 지휘소(파란 깃발), 지휘관 자석, 건물 면(A·B·C·D).
- **오른쪽 40% — 정보 칸** (선으로 나눈 다섯 칸, 글이 넘치면 휠로 넘깁니다):
  - 전략 · 출동대: 전략, 출동대별 진입 허가·대기·접근 중.
  - 우선순위 (안전 → RECEO): 지금 가장 급한 항목이 빨간 ▶.
  - 임무 부여 · 진입대원 통제: 조마다 한 줄(위치 · 임무 · 잔압 · 보고 시각), 아래에 통솔범위. 줄을 누르면 선택, 두 번 누르면 화면 이동, **끌어다 도면의 방에 놓으면 임무 창**.
  - 확인 필요 · 구조대상자 · 물: 확인 필요(빨강), 구조대상자 집계(보고 기준), 펌프차 물 잔량·급수원.
  - 출동 정보: 상황실 지령 내용, 둘러보기.
- 도면의 조 자석을 방에 끌어다 놓아도 임무 창이 뜹니다. 확정하면 건물 안 조에게는 무전으로 나갑니다.

## 확인할 점

- 상황판이 지휘관이 모르는 것(보고 전 화점·요구조자)을 보여 주지 않는지 확인합니다.
- 연기 범위는 지금 보고된 화점·계단실·샤프트 연기만입니다. 대원이 "연기 짙음"을 따로 보고하는 기능은 아직 없습니다.
