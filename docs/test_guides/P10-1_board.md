```
godot --path . -s res://tests/ui_smoke.gd

```

## 1. 오른쪽 무전 기록

- 무전만 쌓이고 최신이 맨 위입니다. 대원 안전은 빨강, 구조대상자는 주황, 내 지시는 파랑, 나머지는 흰색입니다.
- 답한 질문 카드는 "진압1 1조 질문 → 진입 허가 — 진입하라"처럼 한 줄로 남습니다.
- 대원이 보낸 무전 항목을 누르면 그 대원이 있는 곳(층 포함)으로 화면이 옮겨 갑니다.
- 필터는 전체 / 긴급 / 내 지시입니다.
- 아래를 보는 중에 새 무전이 오면 목록은 그대로 두고 "새 무전 N건 ↑" 배지만 뜹니다. 배지를 누르면 맨 위로 갑니다.
- **긴급 고정줄**(맨 위 빨간 줄, 최대 2줄)에는 긴급탈출, 인원 점검 무응답, 잔압 경보, 물탱크 고갈이 올라옵니다. 해결되면 사라지고, 패널을 "▶ 접기"로 접어도 고정줄은 남습니다.
- 패널의 빈 곳을 누르면 그대로 지도가 눌립니다.

## 2. 팀 초상 줄 (하단 콘솔 위 가운데)

- 현장의 조마다 색 원이 하나씩 있고, 둘레 링이 공기 잔량입니다(초록 → 주황 → 빨강). 질문을 기다리는 조에는 노란 "?"가 붙습니다.
- 누르면 선택, 두 번 누르면 그 조로 화면 이동합니다.
- 숫자 1~9로 이 순서의 조를 고릅니다. 질문 카드가 떠 있을 때 1~4는 카드 답입니다.

## 3. 전술상황판 (Tab · M · 상황 배지 옆 버튼)

- 화면 가운데 80%에 반투명으로 열리고, 게임은 계속 진행됩니다. 질문 카드와 지휘 창은 상황판 위에 뜹니다.
- **가운데:** 층 탭(외부 / 1층 / 2층 …)과 평면도입니다.
  - 무전으로 보고된 것만 그립니다. 불이 화면에 보여도 대원이 "화점 발견"을 무전으로 보내기 전에는 상황판에 없습니다.
  - 팀은 마지막으로 무전을 보낸 자리와 "○초 전"으로 표시되고, 60초가 넘으면 흐려집니다.
  - 그 밖에 화점, 연기, 요구조자(노랑 = 보고, 초록 = 구조), 위험 징후(▲), 검색 완료(빗금), 호스 라인, RIT(흰 고리)가 나옵니다.
  - 도면이 없으면 대원이 지나가며 본 구조만 보입니다.
  - 외부 탭에는 차량·소화전·급수 연결선·진입구·안전구역·집결지·분류소·지휘소가 나옵니다.
- **왼쪽 열(지휘):** 전략·출동대 진입 현황, 통솔범위, 둘러보기, 진입대원 통제표(팀 카드)가 있습니다.
- **오른쪽 열(확인):** 상황 요약, 확인 필요, 물 현황(펌프차 잔량·급수원·예상 고갈), 요구조자 집계가 있습니다.
- 평면도의 팀 아이콘이나 왼쪽 팀 카드를 방에 끌어다 놓으면 임무 창이 뜹니다. 확정하면 건물 안 조에게는 무전으로 나갑니다.

## 확인할 점

- 상황판이 지휘관이 모르는 것(보고 전 화점·요구조자)을 보여 주지 않는지 확인합니다.
- 연기 범위는 지금 보고된 화점·계단실·샤프트 연기만입니다. 대원이 "연기 짙음"을 따로 보고하는 기능은 아직 없습니다.
