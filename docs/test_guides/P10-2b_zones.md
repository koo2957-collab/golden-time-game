# P10-2 ⓑ 구역 지정 · 분류소 — 직접 해 보기

지휘관이 외부 지도에 안전구역·환자 집결지·진입통제선을 찍고, 구급대가 분류소를 차립니다.
다음 단계(ⓒ)에서는 구조한 사람을 이 집결지·분류소로 옮깁니다.

## 자동 점검

```
godot --headless --path . -s res://tests/run_tests.gd -- test_zones.gd
godot --path . -s res://tests/ui_command_card.gd
```

## 해 보기

1. 아무것도 고르지 않고 **A 구역 지정**을 누릅니다. 하위 칸은 Q 안전구역 · W 환자 집결지 · E 진입통제선입니다.
2. **Q 안전구역**을 누르고 건물 밖 도로·마당을 끌어 사각형을 만듭니다.
   - 끌지 않고 한 번만 클릭하면 그 자리를 가운데로 10m 정사각형이 생깁니다.
   - 건물과 겹치면 "안전구역 지정 안 됨 — 건물과 겹침" 알림이 뜨고 지정되지 않습니다.
   - 낙하물 위험구역과 겹치면 경고만 하고 지정은 됩니다.
3. 무전 "각 출동대, 현장지휘관. 안전구역 지정, 건물 남쪽 ○m."이 끝나면 지도에 초록 테두리와 "안전구역" 이름이 생깁니다. 미니맵에도 나옵니다.
4. **W 환자 집결지**를 누르고 안전구역 안을 클릭합니다.
   - 빨간 십자와 "환자 집결지"가 생깁니다.
   - 안전구역 밖을 클릭하면 "안전구역 안에만 놓을 수 있음" 알림이 뜹니다.
   - 안전구역이 아직 없으면 "안전구역을 먼저 지정하세요" 알림이 뜹니다.
5. **E 진입통제선**을 누르고 두 점을 차례로 클릭합니다. 주황 점선이 생깁니다.
6. 오른쪽 전술상황판 맨 아래 줄에 "구역: 안전구역 ✓ · 환자 집결지 ✓ · 진입통제선 ✓"가 나오는지 봅니다.
7. 구급대가 도착하면 조를 고르고 **Q 분류소 설치** → 안전구역 안을 클릭합니다.
   - 구급대가 그 자리로 가고, 둥근 진행 표시와 "분류소 설치 중"이 보입니다.
   - 60초가 지나면 파란 십자 "분류소"가 생기고, 환자 집결지 표시는 분류소로 바뀝니다. 상황판 줄도 "분류소 ✓ (집결지 대신)"으로 바뀝니다.
8. 구역 지정은 모두 무전으로 나가고, 디브리핑의 판단 기록에 "안전구역 지정 — 건물 남쪽 ○m"처럼 남습니다.
