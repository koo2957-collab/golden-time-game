godot --headless --path . -s res://tests/run_tests.gd -- test_dropoff.gd,test_ems.gd

## 1. 집결지로 옮기기

1. A 구역 지정으로 안전구역과 환자 집결지를 먼저 찍습니다(ⓑ).
2. 구조대에 Q 인명검색을 줍니다. 요구조자를 찾아 업고 나오면 입구에서 멈추지 않고 **환자 집결지까지 옮겨** 인계합니다.
   - 알림: "구조자 인계 — 아이(7) → 환자 집결지"
3. 층 단위 인명검색 중이었다면, 인계 뒤 **원래 층 검색으로 돌아갑니다**.
4. 구급대가 분류소를 차렸으면 집결지 대신 분류소로 옮깁니다.
5. 업고 가는 동안은 느리고(속도 0.5배), 공기를 가장 많이 씁니다(호흡 4단계 중 가장 센 단계 — R9에서 이미 있던 규칙).

## 2. 집결지가 없을 때

1. 구역을 찍지 않은 채 구조를 시킵니다.
2. 구조한 조가 입구 밖에서 멈추고 **"구조자 둘 곳"** 카드가 뜹니다.
   1. 안전구역에 환자 집결지를 지정한다 (정답): 바로 구역 지정 모드가 열립니다. 집결지를 찍으면 그리로 옮깁니다.
   2. 구급차 옆에 둔다: 구급차가 현장에 있을 때만 나옵니다.
   3. 입구에 두고 복귀한다 (오답)
3. 3을 고르면 다음과 같습니다.
   - 구조자가 열린 현관문으로 나오는 연기를 계속 마십니다(안쪽 방 연기의 0.3배, 게임 설정값). 많이 마시면 의식을 잃거나 사망합니다.
   - 그 칸은 지나가기 어려워 대원이 돌아갑니다.
   - 디브리핑의 "구조자 인계 장소"가 0점이고, 카드 기록은 오답입니다.
4. 카드에 답하지 않으면 30초 뒤 다시 묻습니다.

## 3. 구급대를 부르기 전 악화

- 처치를 받지 못한 응급 환자는 15분(게임 설정값) 뒤 긴급으로 나빠집니다.
- 긴급 환자는 7분 뒤 사망합니다(기존 값).
- 구조자 곁에 대원이 서 있으면 악화가 절반 속도로 느려집니다. A 대기 → A 구조자 관찰 → 환자 클릭으로 보낼 수 있습니다. 그만큼 그 조는 다른 일을 못 합니다.

## 4. START 중증도 분류

1. 걸을 수 있는 사람은 자동으로 **비응급(녹색)**이 됩니다.
2. 걷지 못하는 사람은 집결지에 오면 **"중증도 분류 (START)"** 카드가 뜹니다.
   - 묻는 사람: 구급대가 있으면 구급대, 없으면 구조한 조입니다.
   - 단서 예: "의식 없음, 호흡 34회/분, 요골맥박 약함, 지시를 따르지 못함"
   - 선택: 긴급(적색) / 응급(황색) / 비응급(녹색) / 지연(흑색)
3. 고른 분류가 지도와 요구조자 현황에 나옵니다. 고르기 전에는 "미분류"(회색)입니다. 실제 중증도는 화면에 나오지 않습니다.
4. 분류소·집결지 옆에서 쉬는 구급대는 **분류표 순서**(긴급 → 응급 → 미분류 → 비응급, 지연은 처치하지 않음)대로 알아서 처치합니다.
   - 그래서 긴급을 비응급으로 잘못 분류하면 처치가 뒤로 밀려 사망할 수 있습니다.
5. 디브리핑 **"중증도 분류 (START)"**에 사람마다 이런 줄이 나옵니다.
   "환자(40) 실제 긴급 · 분류 비응급 (틀림) · 처치 못함 · 사망"
   - 과분류(실제보다 높게)는 절반 점수, 살릴 수 있는 사람을 지연으로 분류하면 치명입니다.
