# 즉시 지시 — 명령을 누르면 바로 움직인다

2026-11-11. 사용자 결정 ③.

| 난이도 | 지휘관 지시 | 통솔범위 초과 지연 | 대원 보고 |
|---|---|---|---|
| 훈련 | **바로 실행** (무전 문장·복명복창은 무전 기록에 바로 남음) | 없음 | 줄을 서서 늦게 (글자당 시간 절반) |
| 실전 | **바로 실행** | 있음 — 화면에 "통솔범위 초과 — 명령 N초 지연, 단위대를 편성하면 없어진다" | 줄을 서서 늦게 (절반) |
| 악조건 | 예전처럼 **무전이 끝나야** 실행 (채널 혼잡이 그대로 훈련) | 있음 | 줄을 서서 늦게 |

- 진입 허가: 대원이 문 앞에 닿으면 **카드가 바로** 뜬다 (요청 무전을 기다리지 않음).
- 상황판에는 여전히 **보고된 정보만** 오른다 (보고는 무전 지연 그대로).

## 직접 해 보기
1. 시작 메뉴에서 **훈련** 또는 **실전** → 아파트화재 ①.
2. 조를 골라 진입구 클릭 → 바로 움직인다. 문 앞에 닿자마자 진입 허가 카드.
3. 건물 안 조에게 방 클릭 → 인명검색: 바로 움직이고, 오른쪽 무전 기록에 지시·복명복창 문장이 바로 뜬다.
4. 같은 것을 **악조건**으로 해 보면 무전이 끝날 때까지 기다린다.
