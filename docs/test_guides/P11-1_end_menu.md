# P11-1 종료 조건·게임 메뉴·나가기 + 화재 확산 보강

2026-11-10. 기획안 8-3·8-4(종료·메뉴)와 5-2-2(연소 확대)·교재 대조([fire_textbook_check.md](../fire_textbook_check.md)).

## 정한 것 (추천안대로, docs/decisions.md)

| 항목 | 정한 것 |
|---|---|
| 제한 시간 | 없앰 (시나리오·편집기·화면 남은 시간·5분/1분 알림·훈련 2배 모두) |
| 종료 제안 | 지금 조건(불 없음 + 건물 안 생존자 없음 60초) 유지 + 5분마다 다시 알림 (강제 종료 아님) |
| 전소 | 대원이 초진하지 못한 채 불이 스스로 꺼지고 건물이 70% 이상 탐(교재 소실 정도 '전소'), 또는 구획 절반 이상 붕괴 → 자동 종료. 재산보호·화재진압 0점 |
| 결과 보기 | 전소가 확실하면(불붙은 곳 모두 최성기·쇠퇴기 + 60초 방수 없음) 버튼 → 계산 없이 그 자리에서 전소 확정 |
| 활동 종료 선언 | 완진 선언 + 타는 칸 없음 + 미검색 구역 없음 = 작전 완료, 아니면 조기 종료. 경고에 연소 중으로 본 곳·검색 안 한 곳 목록 |
| Esc | 선택 모드·창이 있으면 먼저 닫고, 없으면 게임 메뉴 (모든 난이도에서 게임 멈춤, 지도·카드 어둡게 가림, 멈춘 횟수 기록) |
| 화면 흐름 | 시작 화면 하나 유지 + 프로필(이름·소속) 줄·처음 실행 때 입력 창, 게임 종료 버튼, 디브리핑 '다음 스테이지' |
| 미완료 | 처음부터 다시·임무 포기·메인 메뉴·게임 종료(X 포함)로 나가면 '미완료'로 저장. 내 기록에 표시, 성장·집계·캠페인·대원 성장에는 넣지 않음 |

## 화재 확산 보강 (P3-1 [2] 일부를 먼저)

- 쇠퇴기 끝 소진: 칸 연료가 처음의 2% 아래면 다 탐 (이전에는 연료가 0에 닿지 않아 영원히 '연소 중')
- 대류: 뜨거운 연기층은 옆 구획 연기층이 더 두꺼워도 30℃ 이상 차가우면 그 위로 계속 넘어감
- 문 너머 복사: 열린·깨진 문으로 옆 구획 고온층이 보이면 문 가까운 칸(3m 안)이 복사열을 받음
- 최성기 화염 분출: 최성기 구획의 열린 문 앞 칸은 화염열 30kW/㎡(거리에 따라 감소)
- 벽·바닥 너머 전도: 구획 벽체가 상부층 온도를 구조별 시간 상수로 따라가고, 벽 뒤·바로 위층 맞닿은 칸이 가열 (목조·패널 > 벽돌 > 철근콘크리트)
- 나무 문 소손: 닫힌 문의 칸이 모두 타면 뚫림. 방화문(건물 JSON fire_doors)은 타지 않음
- 소실 정도: 전소 70% 이상 · 반소 30~70% · 부분소 (화재1 5쪽, 화재조사 및 보고규정 제16조) — 결과·CSV에 기록

실험 (개발용 주택, 방치): 9분 거실 최성기 → 주방·복도 → 계단으로 2층 복도 → 2층 방2·3·4 최성기 → 약 50분에 꺼짐, 건물 78% 소실 = 전소. 틱 비용 5.1ms(변화 없음).

## 직접 확인

1. 시작 화면 위쪽 '교육생' 줄 — 처음 실행이면 이름·소속 입력 창이 뜬다. 오른쪽 아래 '게임 종료' → 확인 창.
2. 시나리오를 시작하고 Esc → 게임 메뉴(게임이 멈추고 지도가 어둡게 가려짐). 처음부터 다시·임무 포기·메인 메뉴·게임 종료는 확인 창.
3. 창 닫기(X) → 게임 종료 확인 창, 취소하면 게임 계속.
4. 임무 포기 → 디브리핑 맨 위 '미완료'. 내 기록에서 '미완료'로 보인다.
5. 화면 위 시계에 '남은 시간'이 없다. 방수하지 않고 두면 불이 옆방·위층으로 번지고, 전소가 확실해지면 '결과 보기' 버튼이 뜬다.

## 남은 것

- 메뉴의 '설정'은 지금 화면 설정(해상도·창·프레임)만. 소리·상황판 투명도·카메라 속도·저사양 모드는 P10-1·P14.
- 확산 수치(문 화염 30kW/㎡, 벽 전도 계수 등)는 게임 설정값 — 현장 검수 필요.
