## 그림 다시 굽기 (그림을 바꾸고 싶을 때)

```
# 1) Blender로 굽기 (모두 약 15분, 한 종류만: … characters firefighter)
blender -b --factory-startup -P tools/blender/bake.py -- tools/blender/bake_config.json [characters|vehicles|furniture] [이름] [quick]
# 2) Godot 아틀라스로 묶기 (한 묶음만: -- characters/firefighter)
godot --headless --path . -s res://tools/import_sprites.gd
godot --headless --path . --import
```

- 이 PC의 Blender: `C:\Users\koo29\Downloads\blender-5.4.0-alpha…\blender.exe` (알파판 — 문제가 생기면 4.x LTS 안정판으로)
- 원본 팩: `art_source/kenney/` (저장소에 넣지 않음, `F:\golden time game\kenney_*`에서 복사)
- 색·크기·동작 프레임 수: `tools/blender/bake_config.json`. 어떤 대상에 어떤 그림: `data/art.json` (`"enabled": false`면 모두 도형)

## 자동 점검

```
godot --headless --path . -s res://tests/run_tests.gd -- test_art.gd
godot --path . -s res://tests/_shot_sprites.gd -- (저장 폴더) [시나리오]   # 바깥(그림·도형 비교)·단면 캡처
```

## 직접 해 보기

1. 아무 시나리오 → 출동 지령 창 닫기. 차량이 한 대씩 들어오며 소방차 그림으로 보인다(경광등 깜빡임).
2. 대원이 내리면 방화복 대원이 2명씩. 헬멧 띠가 진압대는 빨강, 구조대는 주황.
3. 대원을 움직이면 걷는 방향으로 돌아서 걷는다. 낮은 자세(웅크림)를 켜면 웅크려 걷는다.
4. 방수 중인 조는 관창을 든 낮은 자세, 검색 중 멈춘 조는 무릎 꿇고 바닥을 더듬는다. 구조자를 옮기는 조는 팔을 앞으로.
5. 단면(층)으로 들어가면 가구가 그림으로 보이고, 불이 지나간 가구는 어둡게 변한다.
6. **열화상(T)**: 예전 도형 그대로(그림은 열화상 색이 아님).
7. 시작 메뉴 아래 **자료 출처** → "Kenney (kenney.nl), CC0".

## 남은 것

- 대원 얼굴은 Kenney 얼굴 그대로(면체 없음). 질문 카드 일러스트 15장은 아직 실루엣.
- 웅크린 채 멈춰 있으면 웅크려 걷기 첫 프레임을 쓴다. 들것·2인 운반 자세는 1인 들기 자세로 대신.
- 열화상 전용 그림 없음, 건물 외벽·도시(흰 매스)는 그대로.
- P15-1·P15-2(TRELLIS·Mixamo 대원 교체)는 사람이 먼저 할 일이 있어 아직.
