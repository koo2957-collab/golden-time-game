## 2. 대원 걷기 (Blender 5.2.3 LTS로 다시 굽기)

- **원인 1:** 애니메이션 파일에 함께 들어 있는 2프레임짜리 'Targeting Pose'를 실제 동작 대신 골랐다(이름 끝 .001 때문에 걸러지지 않음) → 모든 걷기 프레임이 같은 그림이었다.
- **원인 2:** 동작을 붙였다 떼며 frame_set으로 읽어 Blender가 다시 평가하지 않았다.
- **고침:** 동작 이름으로 정확히 고르고, 애니메이션 곡선에서 프레임마다 자세를 직접 읽는다. 팩에 걷기가 없어 뛰기를 쉬는 자세 쪽으로 섞어(보폭·상하 흔들림 줄임) 팔을 내린 채 다리와 반대로 흔드는 **걷기**를 만들었고, 웅크려 걷기·들고 걷기도 이 걷기를 바탕으로 한다. 서기도 숨쉬듯 조금씩 움직인다.
- Blender: `C:\Program Files\Blender Foundation\Blender 5.2\blender.exe` (5.2.3 LTS)
- 동작 하나만 빠르게 확인: `blender -b --factory-startup -P tools/blender/bake.py -- tools/blender/bake_config.json characters firefighter only=walk 3` (방향 3 옆모습)

## 직접 해 보기

1. 아파트화재 ① → 출동 지령 창 닫고 **아무것도 하지 않기**: 요구조자 "발견"이 저절로 뜨지 않는다. 대신 시간이 지나 상황실이 "119 신고: ○○호에 사람이 갇혀 있다"를 전할 수 있다(위치는 세대까지만).
2. 대원을 움직여 걷는 모습 확인: 다리가 번갈아 나가고 팔을 흔든다. 웅크림을 켜면 숙여 걷는다.
3. 발화층 단면으로 가서 불꽃·불빛·연기층이 일렁이는지 확인. T(열화상)를 누르면 예전 도형.
