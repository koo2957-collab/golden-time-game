# P4-2 원형 메뉴 · 진입 지시 4단계 · 문 앞 휠 — 직접 해 보기

## 자동 점검

```
godot --headless --path . -s res://tests/run_tests.gd -- test_entry_flow.gd
godot --path . -s res://tests/ui_command_card.gd
```

## 1. 원형 메뉴

- 대원을 클릭하면 커서 둘레에 메뉴가 0.12초 동안 커지며 펼쳐집니다.
- 바깥 클릭, Esc, 우클릭으로 닫힙니다.

## 2. 진입 지시 4단계 (밖에 있는 조)

1. 진압대 조를 고르고 **W 화점진압**(또는 Q 인명검색)을 누릅니다. 화면 위에 "진입구를 고르세요 (Esc 취소)"가 뜹니다.
2. 바깥 출입문만 노란 동그라미로 밝게 보입니다.
   - 마우스를 올리면 연기 상태와 급기측·배기측(바람이 불어오는 쪽 문이 급기측)이 나옵니다.
   - 진입구가 아닌 곳을 누르면 "진입구를 고르세요" 알림만 뜹니다.
3. 진입구를 누르면 그 층 단면 보기로 바뀝니다. 층 막대나 PgUp/PgDn으로 층을 고르고 목표에 마우스를 올립니다.
   - 진입구에서 목표까지 예상 경로가 그려집니다. 아는 구간은 실선, 모르는 구간은 점선입니다.
   - "예상 ○초 · 도착 공기 ○%"가 함께 나옵니다.
   - 못 본 방은 층 단위 임무가 됩니다.
4. 목표를 누르면 임무 창이 뜹니다.
   - 누른 키의 임무에 ▶ 표시가 붙습니다. 조건은 직전에 쓴 값입니다.
   - **Enter** 또는 임무 버튼으로 지시합니다.
   - 알림 예: "진압1 1조, 현관 출입문으로 진입해 1층 거실 진압하라."
5. 조는 고른 진입구 앞으로 간 뒤, 입구에서 진입 허가를 요청합니다(P10-2 카드).
6. 이미 건물 안에 있는 조는 1·2단계 없이 목표 → 임무 창만 거칩니다(구역 변경).
7. 디브리핑의 **"진입구 선택 (급기측·직하층 거점)"**에서 조마다 진입구와 급기측·배기측을 봅니다. 고층은 화재층 한 층 아래 방수구를 썼는지도 봅니다.

## 3. 건물 안 조

- 지도를 우클릭해도 움직이지 않고 "건물 안 조는 원형 메뉴로 지시합니다" 알림이 뜹니다.
- 이동은 A 대기 → E 여기로 (본 적 있는 곳만, 무전 2~3초 뒤 복명복창하고 움직임).

## 4. 문 앞 휠

1. 건물 안 조 하나를 고른 채, 그 조에서 2칸 안의 문을 클릭합니다.
2. 문 전용 원형 메뉴가 뜹니다: Q 가스 확인 후 개방 · W 문 옆 벽에서 서서히 · E 파괴 후 개방 · R 상부 배연 후 개방 · A 문 닫고 대기.
3. 상급(직접 지휘) 난이도에서는 닫힌 문 앞에서 질문 카드가 뜹니다.
   - 휠을 먼저 고르면 카드가 뜨지 않고 휠대로 합니다.
   - 디브리핑 카드 기록에는 "선제지시"로 남고, 등급은 카드의 같은 행동 선택지를 따릅니다.
4. 이미 카드가 떠 있을 때 휠을 고르면 카드가 사라지고 휠대로 합니다.
