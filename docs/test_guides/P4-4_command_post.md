# P4-4 지휘소·후착대 임무 받기 — 직접 해 보기

2026-11-11. 기획안 9-1-1, SOP 101-2.1⑤·101-3·103-2.1·104-1.3.

## 무엇이 바뀌었나

| 항목 | 내용 |
|---|---|
| 지휘 위치 | 지휘권 선언 창에 **⑤ 지휘 위치(지휘소)**: "지금 선 자리" 또는 "지도에서 고르기(송신 뒤 클릭)". 선언이 전달되면 그 자리가 현장지휘소 |
| 지휘 방식 | 지휘관이 지휘소 반경(4m) 안 = **고정지휘**, 밖 = **이동지휘**. 지도에 깃발 "지휘소 · 고정지휘/이동지휘" |
| 이동지휘 불이익 | 전술상황판에 대원 보고가 15초 늦게 오르고, **일상 보고(전략·전술 무전) 약 25%를 놓친다** (무전 기록에 "놓침 — 이동지휘 중"). 대원 안전·구조대상자·주요요소 무전은 놓치지 않는다 |
| 지휘소 평가 | 정할 때 관찰·안전(발화층 높이 1/2 낙하물 반경)·동선을 평가. 위험반경 안이면 **"지휘소 위치 — 낙하물" 카드** (최선: 위험반경 밖 현장이 보이는 곳으로 자동 이동) |
| 지휘소 옮기기 | A 구역 지정 ▸ **R 지휘소** → 건물 밖 클릭 (무전 후 지휘관이 걸어간다) |
| 직전대기 장소 | A 구역 지정 ▸ **A 직전대기 장소** → 후착대가 지휘소 대신 그곳에 모인다 (SOP 103-2.1.3) |
| 후착대 | 지휘소가 없으면 차 옆에서 기다리며 **60초마다 "○○ ○명, 차량 옆 대기 중. 임무 주십시오."** (무전이 붐빈다). 지휘소·직전대기 장소가 있으면 그리로 걸어와 줄을 서고 한 번 "지휘소 도착. 임무 주십시오." |
| 따라 모이기 | 지휘관이 지휘소를 떠나면 줄 선(임무 없는) 출동대가 지휘관 곁으로 따라온다 |
| 대기 시간 | 도착부터 첫 임무까지 기다린 시간을 판단 기록에 남기고, 디브리핑 '지휘소' 항목에 "후착대 임무 대기 총 ○초" |
| 구역 설치 | 안전구역·환자 집결지·진입통제선은 무전 뒤 **가까운 임무 없는 조가 가서 30초 동안 설치**해야 생긴다. 지도에 "○○ 설치 대기/중". 임무 없는 조가 없으면 "설치할 조가 없음" 알림 후 조가 비면 설치 |
| 지휘권 이양 | 이양받으면 그 자리를 지휘소로 고정지휘 |

수치: data/command/radio_params.json (post_radius_m, mobile_board_delay_s, mobile_miss_ratio, post_ask_s, follow_dist_m, zone_install_s) — 모두 게임 설정값.

## 직접 해 보기 (후착대가 오는 시나리오, 예: 아파트화재 ①·고층 아파트 ①)

1. 출동 지령 창을 닫고 지휘권 선언을 미룬 채 3분쯤 기다린다 → 후착대가 대기 장소에 서서 1분마다 "임무 주십시오" 무전.
2. C(선언) → ⑤ 지휘 위치 "지도에서 고르기" → 송신 → 건물에서 떨어진 바깥 클릭.
   - 깃발 "지휘소", 지휘관이 걸어가 도착하면 "고정지휘". 후착대가 지휘소 옆으로 와서 줄을 서고 한 번만 "지휘소 도착. 임무 주십시오."
3. 일부러 건물 바로 앞을 지휘소로 고르면 "지휘소 위치 — 낙하물" 카드 → 최선을 고르면 위험반경 밖으로 깃발이 옮겨진다.
4. 지휘관을 지휘소에서 멀리 걷게 하면 "지휘 방식: 이동지휘" 알림, 무전 기록에 가끔 "(놓침 — 이동지휘 중)". 줄 선 후착대가 지휘관을 따라온다.
5. A 구역 지정 ▸ Q 안전구역 → 무전 뒤 조 하나가 그 자리로 가서 30초 뒤 안전구역이 생긴다.
6. 활동 종료 → 디브리핑 '지휘소' 항목에 지휘소 평가와 후착대 임무 대기 총시간.
