# 대원 이동 방식 바꾸기 — 진입구 → 진입 허가 → 층 → 계단 → 방 (P4-5)

2026-11-11. 사용자 결정 조작 방식.

## 바뀐 것

| 전 | 후 |
|---|---|
| 대원을 클릭할 때마다 원형 메뉴, 문을 누르면 또 원형 메뉴 | **대원 클릭 = 고르기만.** 명령은 노랗게 빛나는 곳을 누르거나 명령 카드(Q·W·E·R·A·S) |
| 땅 우클릭 = 대원 이동 | **땅 우클릭 = 늘 현장지휘관 이동.** 대원은 땅으로 직접 움직이지 않는다 |
| — | 대원을 고른 채 펌프차·방수구·밸브·창·요구조자·환자 **우클릭 = 그 임무** (그대로) |

## 순서 (처음 하는 사람용 안내 한 줄이 화면 위에 뜬다)

1. **밖의 분대(조)를 고른다** → 들어갈 수 있는 출입문이 **노랗게 깜빡인다**. 마우스를 올리면 문 이름·연기 상태·급기측/배기측·이미 기다리는 조가 보인다.
2. **출입문을 누른다** → 대원이 **건물 밖으로 둘러서** 그 문 앞까지 가서 멈추고 **진입 허가를 무전으로 묻는다** (질문 카드: 허가·대기·금지).
   - 두 분대 이상이 각자 다른 문에서 기다리면 진입 카드 아래에 **"5. 모두 동시 진입 허가"** — 포위·양방향 진입을 동시에.
3. **허가하면** 화면이 외부 보기로 바뀌고 그 조가 골라진다 → **외벽의 층에 마우스를 올리면 그 층 테두리가 노랗게** → 누르면 그 층으로.
4. **계단이 둘 이상인 건물**(지하 노래방 스테이지)에서는 대원이 "계단 2곳 확인 — A계단(급기측)·B계단(배기측). 어느 계단을 쓸까요?" 하고 묻고, **두 계단이 노랗게** → 누른 계단으로 간다. 계단이 하나거나 아직 못 봤으면 묻지 않고 간다.
5. **그 층 단면에서 방에 마우스를 올리면 노랗게** → 누르면 작은 목록: **1 화재진압 · 2 인명검색 · 3 직하층 확인 · 4 조건 바꾸기…** (숫자키도 됨). 본 적 없는 방은 층 단위.
6. 건물 안 조를 고른 채 **곁의 문을 누르면** 문 행동 목록 (가스 확인 후 개방·문 옆 벽에서·파괴·상부 배연 후·문 닫고 대기).

**미리 지시(선제지시):** 대원이 문으로 걸어가는 동안 층·방을 먼저 눌러 두면 허가 뒤 층을 묻지 않고 바로 간다.

## 직접 해 보기

1. 아파트화재 ① → 출동 지령 닫기 → 차가 서면 **진압1 조를 클릭**: 1층 계단실 출입문이 노랗게.
2. 출입문 클릭 → 문 앞에서 멈추고 무전·카드로 진입 허가 요청 → 1번(허가).
3. 외부 보기에서 **3층 외벽에 마우스** → 노란 테두리 → 클릭 → 3층 단면으로 바뀐다.
4. 3층 방(세대)에 마우스 → 노란 테두리 → 클릭 → 2 인명검색.
5. **땅을 우클릭** → 대원은 그대로, 지휘관(파란 헬멧)이 걸어간다.
6. 계단 고르기: 시작 메뉴의 **지하 노래방** 스테이지에서 조를 들여보낸 뒤 지하1층 → 두 계단이 노랗게.

## 알려진 한계

- 지금 시나리오 건물은 대부분 계단이 하나라 계단 질문은 지하 노래방에서만 나온다. 아파트 계단실형 2개 동 같은 건물은 스테이지 데이터가 필요하다.
- 사다리·굴절차로 닿는 창은 아직 진입구 목록에 없다 (진입구 = 바깥 출입문).
- 출동대 분대 단위가 아니라 조(2인) 단위로 고른다. 출동대 전체는 조 더블클릭.
