## P9-1

| 항목 | 한 것 |
|---|---|
| 현장 시계 | 난이도별 고정 배속: 훈련 1.5 · 실전 2 · 악조건 2.5 (phase_params field_time_scale). 플레이 중 배속 키는 안내만 (리플레이 보기는 바꿀 수 있음) |
| 질문 카드 제한시간 | 실제 초 (현장 틱으로는 × 배속). 훈련은 2배 |
| 출동 단계 | 신고 후 4분(dispatch_s 240) 동안 불이 뒤에서 진행 — 결과가 늘 같도록(다시 하기·리플레이) 난이도를 정할 때 한 번에 계산. 출동 지령 창이 이 4분을 실제 약 90초로 보여 주고(진행 막대), 상황실 지령 줄이 시간에 맞춰 차례로 나온다 |
| 시계 | 화면은 "신고 후 mm:ss" (도착 순간 04:00), 디브리핑용 발화 후 경과 = 늦은 신고(preburn_s) + 신고 후 |
| 흰 매스 도시 | 현장 지도 둘레 3겹 블록을 시드로 자동 생성, 흰 아이소 박스(윗면 밝게·옆면 어둡게)와 회색 도로. 텍스처·그림자 없음, 한 번 그리면 다시 그리지 않음 (scripts/ui/city_mass_view.gd) |
| 도착 연출 | 출동 단계에는 멀리서 보고, 출동 지령 창을 닫으면 0.8초 동안 화재 건물로 확대 |

남은 것: 출동 준비판의 상황실 요청 버튼(예비 소방용수 2개소 지도에서 고르기, 관계자 조치·주차차량 이동), 도착 후 임무 미리 배정, 도로를 따라 다가가는 소방차 아이콘, 신고 기준 도착표(240·300·360·480·600) — 지금 후착대 도착은 선착 도착 기준 시각.
