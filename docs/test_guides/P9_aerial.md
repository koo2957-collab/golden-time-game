## 외부 안전구역 안내선 (SOP 213-2.7.1)

안전구역을 정하기 전에는 건물 둘레에 점선 안내선이 보인다: "안전구역은 이 선 밖 (발화층 높이의 1/2 ○m)". 풍속이 6m/s 이상이면(겨울 고층 7m/s) 건물 높이 기준. 선 안쪽에 안전구역을 그리면 "건물에서 ○m — … 이상 떨어뜨릴 것" 경고(지정은 됨). 수치: data/fire/hazard_params.json `floor_height_m`·`safe_zone_strong_wind_mps`.

## 직접 해 보기

1. 15층 아파트 저층(sop213_3, 발화 2~4층) → 출동 지령 창 닫기 → 약 4분 뒤 "굴절1" 도착 무전, 동쪽 대기 장소에 굴절차.
2. 굴절차 클릭 → R 자리 옮기기 → 발화 세대 창 쪽 건물 가까운 도로 (깨진 창 아래 낙하물 구역은 피함).
3. **바스켓 구조**: 발화층·직상층 단면으로 내려가 창가에 보이는(발견된) 요구조자가 있으면, 굴절차를 고르고 **A 바스켓 구조** → 그 사람 클릭.
   - 확인: "전개 시작 — 약 180초" → "바스켓 구조 시작 — ○층 ○○, 약 ○○초" → 시간이 지나면 "구조"되고 구급대 분류로.
   - 10층 이상 창을 고르면 "닿지 않음 (높이 ○m — 작업 높이 27m 넘음)".
4. **방수포 확인 카드**: 진압대가 화점실에 들어가 있을 때 굴절차(또는 펌프차) **W 방수포** → 그 방 창 클릭 → "방수포 — 내부 진입대" 긴급 카드. "즉시 방수"를 고르면 전개 뒤 물이 나오고 진입대 열 스트레스가 오른다(팀 초상 줄·디브리핑 위반).
5. **추락 위험**: 겨울 고층(sop213_5)처럼 창가 요구조자가 있는 판에서 굴절차가 온 뒤 추락 위험 카드가 뜨면 바스켓 선택지가 보인다.

## 남은 것 / 한계

- 가공전선·지반 검사는 없다 (맵에 전선 데이터 없음). 전개 공간은 낙하물 구역만 본다.
- 바스켓으로 대원을 창으로 들여보내는 진입구(기획안 9-1 "사다리·굴절차로 닿는 창")는 아직 없다.
- 고가사다리차는 따로 만들지 않았다 (같은 제원 표에 차종만 추가하면 됨).
