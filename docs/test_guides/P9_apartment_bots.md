# P9 아파트 스테이지 — 봇 점검으로 찾은 막힘 3가지 고침 — 직접 해 보기

2026-11-10. 다른 PC에서 남긴 문제 "최선 봇도 10분 동안 구조 0명"의 원인을 찾아 고쳤다.

## 무엇이 막혀 있었나

| 증상 | 원인 | 고친 것 |
|---|---|---|
| 진입 허가를 받아도 대원이 1층 입구 앞에 계속 서 있음 | 문 열기·방수 자리로 가던 대원의 길이 입구에서 잘렸는데(허가 대기), 허가가 나도 임무 중인 조는 다시 길을 찾지 않았다 | 허가가 나면 입구에서 기다리던 조는 임무가 있어도 원래 가려던 곳으로 다시 간다 (`command_system._on_entry_received`) |
| 대원이 1층에 서 있는데 3층 방 검색이 몇 초 만에 "완료" | 검색 지점으로 가다 멈추기만 하면 다음 지점으로 넘어갔다 (입구에서 멈춘 것도 도착으로 셈) | 검색 지점에 실제로 닿아야(같은 층 2칸 안) 다음으로. 못 닿았으면 1초마다 다시 길을 찾고, 길이 아예 없을 때만 건너뜀 (`rescue_system._step_search`) |
| 화점진압 조가 1층 밖에서 "수관 길이 한계"로 묶임 | 연결송수관 방수구(3층)에서 **건물 밖에 서 있는 대원 위치까지** 호스를 깔아서, 계단을 오르기도 전에 길이를 다 썼다 | 방수구에서 멀면 **호스 가방을 들고 방수구까지 올라가서** 거기서 결합·연장한다 (`water_system` `hose_to_outlet` → `hose_outlet_laid`). 진입 허가 판단에서도 방수구 수관은 "충수 전 대기" 대상이 아니다 (입구에서는 마른 호스 가방이 맞음) |

봇 테스트도 실제 지휘관처럼 바꿨다: 시작할 때 안전구역 → (무전으로 정해지면) 그 가운데 환자 집결지, 출동대가 3개가 되면 남는 조 하나를 RIT로 지정. 두 봇(최선·무응답)이 같은 지휘를 하고 질문 카드 답만 다르다.

결과 (현장 10분): A 주간 저층·B 야간 중층·C 겨울 고층 모두 최선 봇 2명 생존 구조, 무응답 봇 0명 (진입 허가 카드에 답하지 않으면 들어가지 못함).

```
godot --headless --path . -s res://tests/run_tests.gd -- test_apt_bots.gd     # 약 5~6분
```

## 직접 해 보기 (스테이지 2-1 아파트, 아무 시나리오)

1. 시작 메뉴 → 15층 아파트 시나리오(sop213_3·4·5) → 출동 지령 창 닫기.
2. 선착 진압대 1조에 **W 화점진압** → 진입구·발화층 지정 → 지시. "상층 수관 연장" 카드에 **송수구 연결·방수구 연장**.
   - 확인: 무전 기록에 "방수구로 호스 가방 휴대"가 뜨고, 대원이 입구에서 진입 허가를 요청한다.
3. 진입 허가 카드에 **진입 허가**.
   - 확인: 대원이 계단으로 발화층까지 올라가 방수구 앞에서 "방수구 수관 연장"(결합·충수 진행 막대) 뒤 화점실로 간다. 1층에 묶여 있지 않다.
4. 구조대 조에 **Q 인명검색**(발화층·직상층) → 진입 허가.
   - 확인: 대원이 실제로 그 층 방을 돌며 검색한다. 1층에 서 있는 동안 "검색 완료"가 뜨지 않는다.
5. 바깥 안전구역 → 환자 집결지 지정 → 구조자를 업고 나오면 집결지에 인계·분류된다.
