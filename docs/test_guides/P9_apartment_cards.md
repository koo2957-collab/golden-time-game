# P9 아파트 카드 5장 추가 (기획안 7-3) — 직접 해 보기

2026-11-10. 기획안 7-3 표에서 아직 없던 카드 5장을 넣었다. 이제 7-3 표에서 빠진 것은 **굴절차 방수포** 하나뿐이다 (굴절차 유닛이 아직 없음 → 다음 작업).

| 카드 | 언제 뜨나 | 최선 | 오답이면 |
|---|---|---|---|
| 물탱크차 첫 조치 (TANKER-FIRST-01) | 물탱크차가 현장에 서면 (실제 플레이의 순차 도착, 후착대 대기 장소 도착) | 펌프차 급수 연결 (+ 허용: 소화전 점령) | 연결 없이 대기 → 펌프차 2,800L만 쓰다 물 소진 카드 |
| 대피 세대 순서 (EVAC-ORDER-01) | 5층 이상 공동주택에 자력 대피 주민이 있고, 전략이 정해졌을 때 | 발화세대 → 발화층·직상층 → 노약자 | 1층부터: 대원이 층마다 45초씩 돌며 안내 → 위층 주민은 스스로 알아챘어도 안내가 닿을 때까지 기다림 |
| 화점 못 찾음·시계 0 (FIRE-LOST-01) | 화점진압 조가 건물 안에서 15분 동안 화점에 물을 대지 못하고 가시거리 1m 미만 | 철수(진입 금지)·교대조 | 계속 탐색 → 공기 고갈 위험 그대로 |
| RIT 다른 임무 (RIT-HELP-01) | 수관 연장이 한계·보충일 때 대기 중인 RIT가 있으면 | 돕지 않음 | 돕게 함 → RIT 지정이 풀리고 그 조가 호스 조 쪽으로 감 (긴급탈출 때 RIT 없음) |
| 송풍기 배기구 (PPV-EXHAUST-01) | 송풍기를 놓았는데 바람길에 열린 창이 없을 때 | 바람길의 창(타는 방 먼저)을 다른 조가 열어 배기구 확보 | 그대로 가동 → 연기는 안 빠지고 타는 방에 산소만 들어가 불이 커짐 |

## 직접 해 보기

1. **물탱크차**: 15층 아파트(sop213_3) → 출동 지령 창 닫기 → 차량이 한 대씩 들어오다 물탱크차가 서면 "물탱크차 첫 조치" 카드. 최선을 고르면 물탱크차 위에 급수 작업 막대 → 펌프차와 급수선 연결.
2. **대피 순서**: 같은 판에서 Q 전략 → 공격. 무전 전달 뒤 "대피 세대 순서" 카드. 무전 기록에 "대피 안내 순서 — 발화층·직상층 먼저".
   - 3층 아파트(sop213_1)에서는 뜨지 않는다.
3. **RIT**: 지원 요청 아래 조직에서 한 조를 RIT로 지정 → 다른 조로 방수구가 먼 화점진압(수관이 길어 보충이 필요한 곳) → "RIT 다른 임무" 카드. "돕게 한다"를 고르면 RIT 표시가 사라진다.
4. **송풍기**: 3층 아파트에서 한 조를 1층 현관문 앞 우클릭 → 송풍기. 창이 모두 닫혀 있으면 "송풍기 배기구" 카드. 최선이면 다른 조가 창을 깨러 간다.
5. **화점 못 찾음**: 야간 중층(sop213_4)처럼 연기가 짙은 판에서 화점진압 조를 화점과 먼 세대로 보내 15분 두면 긴급 카드. (자동 점검에서는 시간을 줄여 확인)
