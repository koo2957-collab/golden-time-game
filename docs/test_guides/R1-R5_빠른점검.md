# R1~R5 빠른 점검 (약 15분)

R1 종료 체계, R2 난이도, R3·R4 질문 카드, R5 평가 배점을 한 판으로 확인하는 순서다. 자세한 내용은 단계별 문서에 있다. 확인하다 이상한 점은 아래 "메모"에 적어 주면 다음 작업에서 고친다.

> R6a 이후 바뀐 키: 입체/평면 전환은 **M**, Tab은 오른쪽 전술상황판 접기. 무전 패널은 오른쪽으로 옮겨졌다.

## 준비
- 게임을 켜면 시작 화면이 나온다. 아래쪽 줄에서 다음을 고른다.
  - 난이도: **훈련 (제한시간 2배·일시정지)** — 처음에는 멈춰 가며 보기 좋다
  - 자동화: **중급 (보고 후 대기)** — 질문 카드가 많이 뜬다
  - 모드: 평가 모드 또는 교육 모드
- 시나리오: **주택화재 ① 낮 · 1층 거실** → 시작(Enter)

## 1. 출동·도착 (R1 단계 표시, R2 시간, R4 카드)
1. 출동 지령 창 아래 "선착 차량 배치"에서 하나를 고르고 Enter.
2. 화면 맨 위 가운데의 단계 표시줄을 본다: ① 출동·도착 → **② 지휘권 확립** (노란색).
3. 왼쪽 위 시계: "경과 00:05 / 남은 49:55 ×1 훈련".
4. 화면 위쪽 가운데에 질문 카드가 뜬다: "예비 소방용수", "관계자 조치 요청" (일반, 흰 테두리).
   - 숫자 키 1~3이나 클릭으로 답한다. 정답·오답은 게임 중에 나오지 않는다.

## 2. 지휘·진입 (R3 카드)
1. C → 최초 상황보고·지휘권 선언. 단계가 ③ 진압·인명구조로 바뀐다.
2. 진압1 조 선택 → R(진입 명령) → W(진압) → 거실 클릭.
3. 중급이라 잠긴 현관 앞에서 멈추고 **"잠긴 문" 카드**(중요, 노란 테두리)가 뜬다.
   - "문 옆 벽에 붙어 파괴기로 강제 개방하고 진입"을 고르면 조가 문을 부수고 들어가 진압한다.
   - 12초 동안 답하지 않으면 카드가 사라지고 조는 그대로 서 있다(지시 대기).
4. 구조1 조 → W(수색) → 방1. 아이를 찾으면 **"구조대상자 발견" 카드**가 뜬다 → "즉시 업고…" 선택.
5. 무전 패널 아래 줄의 **선제지시**를 열어 "잠긴 문은 … 바로 파괴 개방" 등을 켜 보면, 그 뒤로 그 카드는 뜨지 않는다.

## 3. 초진·잔불·완진 (R1)
1. 불이 잡히고 1분이 지나면 무전 "초진 — 1층 거실 (진압1 1조)". 단계가 ⑤ 잔불정리·2차 검색으로 바뀐다.
   - "초진 후 잔불정리"와 "완진 판단" 카드가 뜬다.
2. 구조대로 방들을 다시 수색하면 "2차 검색 완료 — …" 무전이 나온다.
3. 무전 패널 **완진 선언** → 확인 목록(초진 보고, 발화층·직상층 2차 검색, 보이는 불, 불씨)을 보고 선언한다. 단계가 ⑦ 마무리로 바뀐다.
4. **인원점검(P)** → **활동 종료**(재발화 감시 고르기) → 디브리핑.

## 4. 디브리핑 (R5)
1. 축 이름: 대원 안전 · 인명구조 · 재산 보호 · 화재 안정화 · **SOP 준수**.
2. ③ 위쪽 **"판단 요청 해설"**: 카드마다 [등급] 제목 → 내 선택 (SOP) — 해설.
3. 새 판정 항목:
   - "완진 선언의 정확성"
   - "2차 검색"
   - "마무리 순서"
   - "대원 판단 요청에 대한 지시"
4. 한 번은 일부러 백드래프트 징후 문 카드에서 "즉시 문을 열고 진입"(치명)을 골라 보면, 등급이 B를 넘지 않고 이유가 표시된다.
   - 주택화재 ②에서 잘 나온다.

## 5. 실전 난이도 (R2)
1. 시작 화면에서 **실전**으로 다시 시작한다.
2. 출동 지령을 닫은 뒤 C 창을 열어도 시간이 흐른다. Space를 누르면 "일시정지할 수 없습니다", F2는 "1배속 고정입니다" 알림이 나온다.
3. **악조건**: 소화전이 고장이라 물탱크차 B(순환보수)가 필요하다. 후착대가 늦게 오고 바람이 세다.
