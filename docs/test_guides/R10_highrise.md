근거:
- 기획안 4장 표(2-1 계단식 아파트 15층: 발화층·직상층 주민 우선 대피, 연기 이동경로, 옥내소화전·연결송수관, 낙하물 안전구역)

## 새로 생긴 것

| 무엇 | 어떻게 |
|---|---|
| **15층 계단식 아파트** (`data/buildings/apartment_15f.json`) | 층마다 두 세대(○01호·○02호)와 가운데 계단실이 있다. 왼쪽 층 막대에 15개 층이 나온다. 연결송수관 방수구가 층마다 있고, 마당 동쪽에 관리사무소(방재실)가 있다. 도면과 다른 곳은 801호·1301호 발코니 확장이다. 계산 시간은 1틱(0.1초)에 약 19ms다(이 PC 기준) |
| **옥내소화전** (SOP 235) | 계단실 방수구 수관을 송수구 연결 **없이도** 바로 쓸 수 있다. 물은 건물 수조(5,200ℓ, 130ℓ/분)에서 나오고, 무전에 "옥내소화전에서 수관 연장"이 나온다. 수조가 바닥나면 "옥내소화전 수조 소진 — 송수구에 펌프차를 연결해야 방수 계속"을 보고한다. 송수구에 펌프차를 연결하면 그 수관은 자동으로 펌프차 물로 바뀐다 |
| **출동 준비 (적재 장비)** | 출동 지령 창에서 기본 장비 외에 **3개**를 더 고른다(4번째는 막힘). 무엇을 실었는지 기록(다시 하기·디브리핑)에 남는다. 효과는 아래 표와 같다 |
| **늦은 신고** | 시나리오 `fire.preburn_s`만큼 불을 먼저 진행시킨 뒤 시작한다(시계는 0부터) |
| **시나리오 3개** | 아래 표와 같다. 모두 제한 시간 30분이다 |

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_highrise.gd`에서 확인하는 것:
- 시나리오 3개를 불러오고 검증을 통과한다
- 15층 속도가 1틱 100ms 미만이다
- 송수구 없이 옥내소화전으로 방수하고, 송수구를 연결하면 펌프차 물로 바뀐다
- 수조가 소진되면 보고한다
- 늦은 신고(닫힌 방, 산소 감소)
- 적재 장비는 3개까지, 한 번만 정한다

조작 점검은 시작 화면의 모든 시나리오 검증을 포함한다.

## 직접 해 보기
1. 시작 화면에서 "고층 아파트 ① 낮 · 3층 거실 (15층)"을 고른다.
2. 출동 지령 창 아래 "출동 준비"에서 3개를 고르고(예: 방화문 파괴기, 고층 호스팩, 예비 공기용기) Enter.
3. 진입 명령(R) 뒤 진압1 조를 3층 계단실로 보내 방수구를 우클릭하면 "옥내소화전에서 수관 연장"이 나온다. W로 301호를 진압한다.
4. 펌프차를 고르고 공동현관 옆 송수구를 우클릭해 연결한다. 수조가 바닥나기 전에 이어 대는 것이 요점이다.
5. ②에서는 8층 북쪽 창이 검게 그을려 있다. 닫힌 안방 문을 바로 열면 백드래프트가 날 수 있다. 질문 카드와 상부 배연(창 깨기)으로 대응한다.
6. ③에서는 1401호 발코니 아래에 매트를 펴고(구조대, 공기안전매트), 13층으로 물을 올린다.
