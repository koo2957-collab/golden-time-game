# R11 주수 확장·송풍기 양압배연 — 테스트 방법

근거:
- 기획안 P3(송풍기 양압배연)·P6(주수 5종: 직사·분무·펜슬링·3D·엄호·방수포)
- SOP 210-10.4(인근 구획 문 개방 전 3D 주수), 203-2.1(긴박 시 엄호주수·배연 동시), 207-1.1(진입대원이 있는 화재실 방수포 금지)
- 소방전술 화재1 배연전술(양압배연)

## 새로 생긴 것

| 무엇 | 조작 | 효과 |
|---|---|---|
| **펜슬링·3D 주수** | 조 선택 → **Z** 또는 "펜슬링·3D" → 천장 가스층(방) 클릭 | 짧게 끊어 쏘아 고온 가스층을 잘 식힌다(가스 냉각 효율 0.85, 분무 0.5). 물은 연속 방수의 35%만 쓰므로 수손이 적다. 가연물 표면은 거의 식히지 못한다 |
| **엄호 주수** | **N** 또는 "엄호" → 앞쪽 클릭 | 넓은 분무 막을 친다. 관창 둘레 2.5m 안 대원은 복사열이 절반으로 준다(옆 조의 구조·문 개방 엄호) |
| **방수포** | 진압대 명령칸 "방수포" → 바깥 창·문 클릭 (다시 누르면 중지) | 그 출동대 펌프차의 방수포로 1,500ℓ/분을 쏜다(사거리 30m, 높이 포함). 유리는 물줄기에 깨지고, 펌프차 물이 빠르게 준다. 그 방에 진입대원이 있으면 **"진입대원이 있는 방에 방수포 사용 — 즉시 중지 (SOP 207-1.1)"** 무전이 나오고, 판정 "방수포와 진입대원"에서 0점이 된다 |
| **송풍기 양압배연** | 진압대 명령칸 "송풍기 배연" → 바깥 출입문 클릭 (다시 누르면 끔) | 조가 문 밖에 송풍기를 놓고 켠다. 같은 층에서 열린 문으로 이어진 구획의 연기를 배출구(깨지거나 열린 창, 다른 열린 바깥 문)로 밀어낸다. 아래 경우에는 무전이 나온다 |

송풍기 무전:
- 배출구가 없으면 "배출구가 없어 연기가 빠지지 않음"을 알린다.
- 타는 구획이 바람길에 있으면 "화점이 바람길에 있음 — 불이 배출구 쪽으로 커질 수 있다"를 경고한다. 실제로 그 방에 산소가 들어간다.
- 그 조에 다른 명령을 주면 송풍기가 꺼진다.

화면:
- 아래 세부 명령 줄은 직사(A)·분무(S)·펜슬링·3D(Z)·엄호(N)·방수 중지(D)다.
- 입체 화면에 방수포 물줄기(펌프차에서 창으로 휘는 선)와 송풍기(문 밖 회색 상자, "가동/설치 중")가 보인다.

수치는 모두 추정값이다(`data/fire/fire_params.json`의 pencil_·cover_·monitor_·ppv_, `firefighter.json`의 cover_heat_factor).

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_streams.gd`에서 확인하는 것:
- 펜슬링은 분무보다 물을 절반 넘게 덜 쓴다
- 엄호 막 안에서 복사열이 준다
- 방수포: 창만 겨눌 수 있다, 유리 파손, 물 소모, 진입대원 위반, 사거리
- 송풍기: 배출구 없음 알림, 배출구가 있으면 연기가 빠짐, 다른 명령을 주면 꺼짐

## 직접 해 보기
1. 주택화재 ①에서 진입 뒤 진압1 1조로 거실 앞에서 **Z**(펜슬링)를 써 본다. 펌프차 물이 분무보다 천천히 줄고, RECEO의 롤오버 징후가 늦게 나온다.
2. 구조1 조가 불 가까운 방 문을 열 때, 진압1 2조에 **N**(엄호)를 걸고 같은 곳을 클릭한다. 구조 조의 복사열 표시가 반으로 준다.
3. 진입대원이 모두 나온 뒤 진압대 명령칸 "방수포"로 거실 남쪽 창을 친다. 대원이 남아 있을 때 쏘면 위반 무전과 판정이 나온다.
4. 연기가 찬 2층 주택에서 뒤쪽 창을 먼저 깨고(E 문·창) 옆문 앞에 "송풍기 배연"을 놓는다. 연기가 빠지는 것을 본다. 창을 깨지 않으면 "배출구 없음"이 나온다.
