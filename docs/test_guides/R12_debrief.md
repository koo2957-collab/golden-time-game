# R12 디브리핑 확장 — 리플레이 보기·인쇄용 보고서·대원 성장 — 테스트 방법

근거:
- 기획안 8-1(디브리핑):
  - ③ 리플레이는 어느 시점이든 다시 보고, 연기·온도 레이어를 켜서 확인한다
  - ⑤ 출력은 PDF·CSV(이름, 스테이지, 등급, 5축 점수, 틀린 SOP 조항)
- 기획안 6-2(대원 성장: 신임 → 일반 → 숙련 → 고참)

## 새로 생긴 것

| 무엇 | 어떻게 |
|---|---|
| **리플레이 보기** | 디브리핑 아래 시점 목록에서 고르고 **"이 시점부터 리플레이 보기"**를 누른다. 그 시점까지 빠르게 재생한 뒤 멈춘다. Space로 재생·정지하고 배속을 바꾼다(난이도와 상관없이). 기록된 명령만 그 시각에 다시 들어가며, 플레이어 명령은 받지 않는다. **연기**는 화면에 그대로, **온도**는 T(열화상)로 본다. 위쪽에 "▶ 리플레이 보기" 표시줄이 나온다. Esc를 누르면 시작 화면으로 간다. 끝까지 보면 디브리핑이 다시 나온다(성장 경험치는 주지 않음) |
| **이 시점부터 다시 하기** | 전과 같다(그 시점부터 내가 다시 지휘). 대원 성장 단계도 그대로 넘긴다 |
| **보고서 저장 (인쇄·CSV)** | 디브리핑 아래 버튼. `user://export/`에 HTML(브라우저가 열림, "인쇄 / PDF로 저장" 버튼)을 저장하고, `results.csv`에 한 줄을 더한다 |
| ↳ HTML 내용 | 등급·점수, 5축 점수, 판정 항목(SOP·점수·내용), 판단 요청 해설, 도면과 구조 정보, 대원 성장, 틀린 SOP 조항 |
| ↳ CSV 내용 | 저장 시각·시나리오·모드·난이도·등급·점수·5축·틀린 SOP. 엑셀에서 한글이 깨지지 않게 BOM을 넣었다 |
| **대원 성장** | 판을 끝까지 하면 대원마다 경험치를 받는다: 참가 +1, 그 조가 구조대상자를 옮겨 냈으면 +1, 등급 B 이상이면 +1. 쓰러진 대원은 받지 않는다 |
| ↳ 단계 | 0 신임 / 3 일반 / 8 숙련 / 15 고참. 처음은 일반(3)에서 시작한다. 공기 소모·열 스트레스 배율은 1.1 / 1.0 / 0.95 / 0.9 (`data/units/growth.json`) |
| ↳ 화면 | 디브리핑 ④ "다음에는" 아래에 "대원 성장"(★ 승급 표시)이 나오고, 조를 고르면 선택 정보의 "개성"에 단계가 나온다 |
| ↳ 저장 | 기록은 `user://crew_growth.json`(이름 기준)에 남는다. 다음 판을 시작할 때 적용하고, 다시 하기에도 같은 값을 쓴다 |

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_debrief_ext.gd`에서 확인하는 것:
- HTML·CSV 내용과 저장(두 판이면 CSV가 머리줄 + 2줄)
- 성장 단계와 경험치 지급, 고참이면 공기를 덜 씀
- 리플레이 보기는 플레이어 명령을 무시하고 기록만 넣음
- 다시 하기에서도 성장이 유지됨

## 직접 해 보기
1. 주택화재 ①을 끝까지 하고 디브리핑을 연다. ④ 탭 아래 "대원 성장"을 본다.
2. **보고서 저장**을 누르면 브라우저에 보고서가 열린다. 인쇄 버튼으로 PDF 저장을 해 본다. 같은 폴더의 results.csv를 엑셀로 연다.
3. 시점 목록에서 "백드래프트 징후 직전" 같은 시점을 고르고 **리플레이 보기**를 누른다.
   - Space로 재생하고 T로 열화상(온도)을 켜서, 왜 그 일이 일어났는지 본다.
   - 클릭이나 키로 명령을 내려도 반영되지 않는다.
4. 같은 시나리오를 다시 시작하면 경험치가 쌓인 대원의 단계가 선택 정보에 보인다. 몇 판 하면 "숙련"으로 오른다.
