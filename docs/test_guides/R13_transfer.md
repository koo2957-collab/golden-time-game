# R13 지휘권 이양·지휘대장·비상용승강기 (스테이지 2-2) — 테스트 방법

근거:
- 기획안 4장 표(2-2 고층 아파트: 지휘권 이양 후 지휘대장, 비상용승강기는 화재층 2개층 아래까지, 화점 직하층 활동거점, 상하층 부분 대피)
- 기획안 3-3(단위지휘관 지정으로 질문 수 줄이기)
- SOP 112(지휘권 이양), 222(고층건축물화재)
- 2026-11-08 결정: 이양 = 역할 전환(종료 아님)

## 새로 생긴 것

| 무엇 | 어떻게 |
|---|---|
| **지휘대 도착** | 시나리오 `command_unit`의 시각에 "○○소방서 지휘대 도착 — 지휘권 이양 브리핑 바람" 무전이 나온다. 확인 필요 목록에 이양 항목이 생기고, 지휘관 버튼 줄에 노란 **"지휘권 이양"** 버튼이 나타난다. 처음 한 번은 브리핑 창이 저절로 열린다 |
| **이양 브리핑 창** | 6개 항목(화재 상황·인명 상황·전략·투입 자원·안전 위험요인·필요 자원)마다 3개 보기 중 **지금까지 확인한 사실**을 고른다. 보기는 시뮬레이션의 현재 상태에서 만들고, 판 시드로 섞는다. "나중에"로 미룰 수 있지만 늦을수록 점수가 깎인다 |
| **이양 뒤** | 플레이어는 시나리오의 지휘대장(소방령)이 되어 **계속 지휘**한다. 상황실에서 도면이 들어와 미니맵이 열리고 방 단위 임무가 가능해진다(R8) |
| **단위지휘관 대리 처리** | 이양 뒤에는 단위대(O)로 묶은 출동대의 질문 카드를 그 단위지휘관이 최선으로 대신 처리한다(무전 기록 "A면(진압1) 대리 처리: 잠긴 문"). 지휘대장에게는 묻지 않는다. 디브리핑 해설에는 "[단위지휘관 대리]"로 나온다 |
| **비상용승강기** | 25층 건물 계단실 옆 승강장(입체 화면에 "비상용승강기" 기둥)에 조를 데려간다. 명령칸 **"승강기"**를 누르고 PgUp/PgDn·층 막대로 **내릴 층을 화면에 띄운 뒤 지도를 클릭**한다. 문 10초 + 층당 2초 뒤 그 층 승강장에 내린다 |
| ↳ 운행 규칙 | 화재층 2개층 아래보다 높이 타면 "…까지 승강기 운행 — 화재층(18층) 2개층 아래까지만 (SOP 222)" 대원 안전 무전이 나오고 위반으로 기록된다 |
| **판정** | "지휘권 이양 브리핑"(SOP 112): 정확도 60% + 도착 뒤 걸린 시간 40%(2분 안 만점, 10분 0점). 틀린 항목을 표시한다. "비상용승강기 운행 범위"(SOP 222)도 판정한다 |
| **시나리오** | "고층 아파트 ④ 지휘권 이양 · 18층 (25층)": 1801호 화재(현관 열림), 2001호 할머니(거동 불편), 1901호·1802호 주민(늦게 스스로 대피). 지휘대는 약 8분 뒤 도착하고 후착대가 많다. 캠페인 8장 |

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_transfer.gd`에서 확인하는 것:
- 25층 시나리오 검증
- 도착 → 이양: 정확도 5/6, 지휘대장, 도면 수신, 판정의 틀린 항목
- 단위대 소속 출동대 카드를 대리 처리(최선)
- 승강기: 16층 정상 운행, 17층은 위반

조작 점검에서 확인하는 것:
- 지휘대 도착 → 브리핑 창 → 사실 고르기 → 이양 → 지휘대장(정확도 100%)

## 직접 해 보기
1. 시작 화면에서 "고층 아파트 ④ 지휘권 이양 · 18층 (25층)"을 고른다.
2. 선착대장으로 지휘권을 선언하고 진입·검색을 시작한다. 조직(O)에서 진압1·진압2를 "A면" 단위대로 묶어 둔다.
3. 진압2 조를 1층 계단실 옆 승강장으로 데려가 **승강기**를 누른다. PgUp으로 16층을 띄우고 클릭하면 16층에 내린다(17층에 내리면 위반 무전).
4. 약 8분 뒤 지휘대가 도착하면 브리핑 창이 열린다. 사실대로 고르고 **브리핑하고 이양**을 누른다.
   - 지휘관 이름이 "지휘대장 한도윤"으로 바뀐다.
   - 미니맵이 열린다.
   - 이후 A면 소속 조의 질문은 대리 처리된다(무전 기록 확인).
5. 디브리핑에서 "지휘권 이양 브리핑" 점수와 틀린 항목을 본다.
