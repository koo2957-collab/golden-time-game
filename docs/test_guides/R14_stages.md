# R14 나머지 스테이지 — 0 훈련탑 · 1-2 필로티 · 3-1 전통시장 · 3-2 지하층 · 3-3 물류창고 · 4-1 초고층 — 테스트 방법

근거: 기획안 4장 스테이지 표, P12(스테이지 추가 템플릿), SOP 200·201·208(0), 232(1-2), 233(3-1), 217·202(3-2), 240·210·205(3-3), 223·222·107(4-1).

기획안은 스테이지마다 시나리오 3개를 두지만, 이번에는 스테이지마다 **1개**와 전용 메커니즘·카드를 만들었다. 나머지 시나리오는 같은 지도에서 발화 위치·시간대·요구조자를 바꿔 늘리면 된다(보고서 개선점). 스테이지 1-1(단독주택)과 2-1·2-2(아파트·고층)는 앞 단계에서 만들었다.

## 스테이지별 내용

| 스테이지 | 지도 | 새 메커니즘 | 전용 질문 카드 |
|---|---|---|---|
| **0 훈련탑** (`stage0_training_tower`) | 4층 훈련탑(계단실·복도·훈련실 2) | 입문 난이도. 3층 팔레트 연기, 4층 훈련 인형 | 진입 전 공기호흡기 점검 (SOP 201-3.7) |
| **1-2 필로티 다세대** (`stage1_2_piloti`) | 1층 필로티 주차장(남쪽이 트임·기둥)·공동현관, 2~4층 세대 | 주차 차량 재료 "차량". **가연성 외장재**: 아래층 화염이 위층 창을 데우는 속도 ×2.5 (`facade_factor`) | 필로티 차량 화재와 출입구 (SOP 232) |
| **3-1 전통시장** (`stage3_1_market`) | 1층 점포 10곳과 가운데 아케이드 통로, 2층 주택 | 점포 적재물(재료 "적재물"). 아케이드 지붕 아래 연기 체류. 플레이어는 지휘대장 | 진입로와 포위 배치 (SOP 233) |
| **3-2 지하층** (`stage3_2_basement`) | 1층(서쪽 급기측·동쪽 배기측 계단, 편의점), **지하1층** 미로형 노래방(층 막대에서 1층 위에 "지하1층"으로 보임) | **라이트라인·방향감각 상실**: 가시거리 1m 미만에서 라이트라인 없이 90초 있으면 조가 방향을 잃고 멈춘다(대원 안전 무전). 라이트라인 1칸 안에 있거나 다른 조가 2칸 안으로 오면 되찾는다. 명령칸 **"라이트라인"** → 끝 지점 클릭(노란 점선으로 깔림). 방음재(재료) | 지하층 진입 방향 (SOP 217) |
| **3-3 물류창고** (`stage3_3_warehouse`) | 단층 샌드위치패널 창고(사무실·적재 구역, 하역장 셔터) | **샌드위치패널 붕괴**(최성기 300초면 천장 붕괴, 징후 무전 — 붕괴 시스템 확장). 적재물·샌드위치패널 재료. 3분 늦은 신고. 안에 사람 없음(진입하지 않는 것이 정답) | 샌드위치패널 창고 진입 판단 (SOP 240, 205-3.5) |
| **4-1 초고층** (`stage4_1_supertall`) | 52층 중 1층(로비·방재실)과 28~34층만 상세(층 index 1~8, `floor_numbers`) | **피난안전구역**(30층): 위층 자력 대피자는 30층 피난안전구역으로 내려간다("…피난안전구역 도착"). 승강기 시간·규칙은 실제 층 번호(1→30층 약 54초). 1층 방재실 30초 → 도면 | 초고층 재실자 대피 (SOP 223) |

공통:
- 스테이지 카드는 `stages` 값이 있어 **그 스테이지 시나리오에서만** 나온다.
- 모든 스테이지에 판정 "비상용승강기 운행 범위"가 들어간다(승강기가 없는 건물은 해당 없음).
- 캠페인에 0장·9~13장을 더했다(총 14장).
- 시작 화면 순서: 튜토리얼 → 훈련탑 → 주택 → 아파트 → 근린 → 고층 → 필로티 → 시장 → 지하 → 창고 → 초고층.

## 직접 해 보기
1. **훈련탑**: 도착하면 "진입 전 공기호흡기 점검" 카드가 뜬다. 진압1 조로 3층 연기를 진압하고, 구조1 조로 4층 인형을 구조한다.
2. **필로티**: 주차 차량 불이 공동현관 옆에서 커지고, 2층 창 외장재로 번진다.
   - 외부 방수(V)로 출입구 쪽을 먼저 막는다.
   - 402호 창가 주민 아래에 매트를 편다.
3. **전통시장**: 아케이드 통로에 연기가 찬다. 후착대를 반대편 입구로 보내 포위한다.
4. **지하층**: "지하1층"을 띄운다(PgUp).
   - 구조1 조로 서쪽 계단에서 **라이트라인**을 노래방 복도 끝까지 깔며 들어간다.
   - 라이트라인 없이 깊은 연기 속에 오래 두면 "방향감각 상실" 무전이 나오고 조가 멈춘다. 라이트라인을 그 옆으로 이어 주면 다시 움직인다.
5. **물류창고**: 검은 연기·패널 변형을 보고 진입 판단 카드에 답한다. 방어 전략을 선언하고 방수포·외부 방수를 쓴다. 오래 타면 붕괴 징후 무전이 나온다.
6. **초고층**:
   - 1층 방재실에 조를 30초 두면 도면과 수신반 발화층(32층)을 얻는다.
   - 33·34층 근무자는 30층 피난안전구역으로 내려간다.
   - 진압 조는 승강기로 30층까지 올라간 뒤 계단으로 31·32층으로 간다.
