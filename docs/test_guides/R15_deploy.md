# R15 배포 — 성능 표시·벤치마크·내보내기 설정·배포 안내 — 테스트 방법

근거: 기획안 P14(저사양·배포: 성능 오버레이, 벤치마크, 저사양 모드, exe 내보내기), 기획안 10장(사무용 PC 30fps 이상).

## 새로 생긴 것

| 무엇 | 어떻게 |
|---|---|
| **성능 표시** | 게임 중 **F12**를 누르면 왼쪽 위에 fps · 프레임 ms · 시뮬레이션 ms(이동 평균) · 그리기 호출 수 · 메모리가 나온다. 다시 누르면 끈다 |
| **벤치마크** | `성능_측정.bat` 또는 `GODOT --path . -s res://tests/benchmark.gd`로 잰다. 정식 시나리오 18개를 30초씩 돌려 1틱 평균·최대 ms를 재고, 창이 있으면 15층 아파트 입체 화면을 20초 돌려 평균 fps를 잰다. 결과는 user://benchmark.txt에 저장된다 |
| **저사양 모드** | 시작 화면 "화면 설정"의 30fps 상한·HD 해상도(이전부터 있음). 벤치마크가 30fps 미만이면 이것을 권한다 |
| **내보내기 설정** | `export_presets.cfg`(Windows Desktop, tests·docs 제외, 데이터 JSON 포함, pck를 exe에 넣음) + `실행파일_만들기.bat`. 내보내기 템플릿이 이 PC에 없어 exe는 아직 만들지 않았다. 템플릿은 약 1GB이고 편집기에서 한 번 설치한다 |
| **실행 파일 없이 배포** | `게임_실행.bat`: 프로젝트 폴더 + `godot/` 안 Godot 실행 파일로 바로 실행한다 |
| **배포 안내** | `docs/배포_안내.md`: 필요한 PC, 두 가지 배포 방법, 설치 후 확인, 기록 위치, 교관이 고칠 수 있는 데이터 |

이 PC(노트북 i5-1335U, Intel Iris Xe)의 측정 결과:
- 시뮬레이션 1틱 평균은 주택 2~3ms, 아파트 6ms, 15층 18ms, 25층 30ms, 초고층(상세 8개 층) 9ms다. 모두 실시간 기준(100ms 미만)을 여유 있게 통과했다.
- 15층 아파트 입체 화면은 평균 **55.5fps**(가장 긴 프레임 48ms)로 30fps 기준을 통과했다.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
GODOT --path . -s res://tests/benchmark.gd
```

조작 점검에 "F12 → 성능 표시"를 더했다.

## 직접 해 보기
1. `게임_실행.bat`(또는 편집기)로 게임을 켜고 15층 아파트를 시작해 **F12**를 누른다. fps가 30 이상인지 본다.
2. `성능_측정.bat`를 실행해 결과 창을 본다.
3. 편집기에서 내보내기 템플릿을 설치한 뒤 `실행파일_만들기.bat`를 실행한다. `build/FireCommander.exe`가 생기면, 다른 PC에 이 파일 하나만 복사해 실행해 본다.
