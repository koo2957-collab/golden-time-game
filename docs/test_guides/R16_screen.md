# R16 화면 개선 — 지휘관 드래그 선택·미니맵·입면 층 막대·외부 보기

2026-11-09 사용자 요청 4가지 (기획안 9-1·9-2·9-3과 비교해 정함).

## 자동 점검

화면 코드만 바뀌었으므로 조작 점검으로 본다.

```
GODOT --path . -s res://tests/ui_smoke.gd
```

새로 들어간 항목:
- 빈 곳 클릭 → 지휘관 선택 해제, 현장지휘관 드래그 선택
- 시작은 외부 보기, PgUp: 외부 보기 → 1층 단면 → 2층
- 층 막대: 2개 층 + 외부 띠, 층 칸 클릭 → 그 층 단면, 휠 → 한 칸, 외부 띠 → 외부 보기
- 외부 보기(입체)에서 카메라가 외관 높이까지 올라감
- 미니맵: 도면 전에도 클릭·끌기로 화면 이동, 화면 범위(모서리 4개)
- 지하층 건물: `test_stages.gd` — index 2 = 지하1층(층 번호 -1)

## 직접 확인

1. **지휘관 드래그 선택**: 주택화재 ①에서 지휘관(노란 표시) 주변을 끌어서 고른다 → 우클릭으로 이동한다. 조가 같이 들어간 범위면 조가 골라진다.
2. **미니맵**(왼쪽 아래)
   - 처음부터 도로·차량(주황)·소화전(파랑)·건물 덩어리가 보인다. 아래에 "도면: …에 조를 보내면" 안내가 나온다.
   - 흰 테두리가 지금 화면 범위다. 미니맵을 누르거나 누른 채 끌면 화면이 따라간다.
   - 방재실·관리사무소에 조를 보내 도면을 얻으면 지금 보는 층의 평면도가 나온다.
3. **층 막대**(왼쪽 위)
   - 반투명 건물 모양으로 보인다. 불을 본 층은 빨강·불꽃, 짙은 연기는 회색이고, 파란 점은 대원 수다.
   - 고층 아파트(25층)는 층이 촘촘하게 다 보인다. 초고층(4-1)은 "2~27층"이 한 덩어리로 줄어 있다. 지하층(3-2)은 지하1층이 땅(외부) 띠 아래에 있다.
   - 층 칸에 마우스를 올리면 층 이름·불·연기·대원 수가 나온다. 클릭하면 그 층 단면, 휠을 굴리면 한 칸씩 움직인다.
4. **외부 보기**
   - 시작하면 화면 위에 [입체 · 외부 보기]가 나온다. 건물이 외관으로 보이고 실내는 보이지 않는다.
   - 창에 확인한 불은 주황(깜빡임), 짙은 연기는 회색, 실내등은 노랑이다. 모르는 창은 어두운 유리다.
   - 열린 창에서 연기가 나온다. 건물 안 조는 그 층 높이에 동그란 표식(번호)으로, 발견한 구조대상자는 초록 점으로 보인다.
   - 층 막대 1층 칸(또는 PgUp)을 누르면 1층 단면, 맨 아래 "외부" 띠(또는 1층에서 PgDn)를 누르면 다시 외부 보기다.
   - 고층 건물은 위층 높이를 줄여 그린다 (전체 약 30m 안). 실제 비율이 아니라 교육용 표시다.
   - Home(지휘소로)은 지휘관이 밖에 있으면 외부 보기로 간다. 팀 카드 더블클릭은 그 조가 건물 안이면 그 층 단면으로 간다.

## 알려진 한계

- 외관은 보는 쪽(남·동) 두 면만 그린다. 뒤쪽 면(북·서)은 화면에서 보이지 않는 방향이다.
- 외부 보기에서 건물 뒤(북·서쪽)에 있는 대원·차량은 외관에 가려진다. 층 막대 1층 칸으로 단면을 보면 보인다.
- 창가에 선 구조대상자 그림은 아직 없다. 발견한 구조대상자를 초록 점 표식으로만 보여 준다.
- 대원이 건물에 들어갈 때 자동으로 단면으로 바뀌는 기능은 넣지 않았다. 여러 조가 다른 층에 있으면 화면이 저절로 바뀌어 지휘관이 바깥을 놓치기 쉬워서다. 팀 카드 더블클릭으로 이동한다.
