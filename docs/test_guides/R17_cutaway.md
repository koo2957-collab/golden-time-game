# R17 건물 두 모습 — 외부 보기 · 인형집 단면

2026-11-09 사용자 요청서(기획안 4-2·9-1·9-4, 참고 그림 `docs/ref/cutaway.jpg`)대로 건물을 두 모습으로 보여 준다.
- **외부 보기**: 외벽이 닫힌 건물 전체 외관 (외벽·창·발코니·옥상)
- **내부 단면 보기**: 카메라 쪽 벽 두 면을 걷어 내고 지금 층과 아래 2개 층을 쌓아 보여 주는 인형집 단면

## 구조

| 파일 | 하는 일 |
|---|---|
| `scripts/ui/iso_view.gd` (IsoView) | 층 노드 묶음. `show_view(층, 외부)`로 보일 층을 정하고 배치·밝기·전환 연출 |
| `scripts/ui/building/floor_layer.gd` (FloorLayer) | 층 하나 그리기 (R16까지의 iso_view.gd를 옮김). 바닥·벽·문창·가구·설비·대원·불·연기, 외부 보기면 외관 |
| `scripts/ui/building/floor_stack.gd` (FloorStack) | 순수 계산: 보일 층 목록, 밝기, 화면 위치, 벽 모양(온전/잘림/숨김), 앞 모서리, 계단 연결, 아래층 클릭 판정 |
| `scripts/ui/building/view_params.gd` + `data/ui/view_params.json` | 층 높이·아래 층 수·밝기·잘린 벽 높이·슬래브 두께·전환 시간·줌 배율 |
| `scripts/ui/building/tile_skin.gd` + `data/ui/tile_skin.json` | 타일 종류표 (바닥 베이지·뒷벽 회색·벽 단면 흰 띠·슬래브 진회색·계단·승강로) |

- 지금 층은 화면 높이 0, 아래 층은 143px씩 아래로 내려 그리고 0.75, 0.55로 어둡게 한다. 위층·지붕은 그리지 않는다(노드 `visible = false`, 시뮬레이션은 계속).
- 벽: 바깥이 북·서쪽에 붙은 외벽(뒷벽)은 천장까지, 앞벽(남·동)과 실내 벽은 0.2m 잘린 벽 + 흰 단면 띠. 남서·북동 모서리 기둥은 남아 건물 모양을 잡는다.
- 슬래브: 공중에 뜬 층의 남·동 모서리에 0.3m 진회색 띠.
- 계단: 위층과 이어지는 계단 칸은 위층 바닥을 뚫고, 아래층에서 위층 바닥까지 디딤판(칸마다 2단)이 올라간다. 비상용승강기 승강로는 보이는 층을 관통한다.
- 연기: 연기층 아래 경계 평면 + 방의 남·동 단면에 천장부터 중성대까지 반투명 띠 (연기층 두께가 단면에서 보인다).
- 안개(9-1): 층마다 칸별 3단계 그대로. 안 가 본 층은 슬래브 윤곽만 보이고 속은 검다(도면이 있으면 흐린 도면 선).
- 클릭: 지금 층만 선택·명령. 아래층이 보이는 곳을 누르면 그 층이 지금 층이 된다 (선택은 유지).
- 외부 보기: 층 띠, 창틀·문살, 아파트 발코니 난간(건물 JSON `facade_style.balcony`), 옥상 바닥판·난간·계단실 옥탑. 창 상태 표시 5가지:
  - 실내 불빛(노랑) · 짙은 연기(회색 유리) · 연기 분출(연기 기둥) · **화염 분출**(불난 방의 깨진·열린 창 위로 불꽃) · **깨진 유리**(금 간 선) · **창가·발코니의 사람**(손 흔드는 사람 + 초록 테두리)
  - 모두 바깥 시야(대원·차량·지휘관)에 들어왔거나 본 적 있는 것만.
- 전환 연출 0.3초: 안으로·아래로 갈 때는 이전 모습(외관·위층)이 30px 올라가며 흐려지고, 밖으로·위로 갈 때는 새 맨 위 층이 위에서 내려앉는다. 게임은 멈추지 않는다.
- 줌: 외부 보기에서 건물 위로 1.3배 이상 확대하면 단면(선택한 조가 건물 안이면 그 층, 아니면 1층), 단면에서 0.6배 이하로 축소하면 외부 보기.

## 자동 점검

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_cutaway.gd   # 층 쌓기 계산 (1초)
GODOT --path . -s res://tests/ui_cutaway.gd                               # 15층 아파트 화면 점검 + 스크린샷 + 프레임 측정 (약 1분 30초, 창이 열림)
GODOT --path . -s res://tests/ui_smoke.gd                                 # 기존 조작 점검 (약 3분)
```

`test_cutaway.gd` (요청서 테스트 항목):
- 15층 아파트에서 12층을 고르면 12·11·10층만, 13층 이상은 없음 · 밝기 1/0.75/0.55 · 143px씩 아래
- 12층 앞벽(남·동)은 잘린 벽, 뒷벽(북·서)은 온전, 실내 벽은 잘림, 외부 보기에서는 외벽 모두 온전 · 숨김 설정
- 계단이 11→12층, 10→11층으로 이어짐 (계단실 4×5칸)
- 아래층(11층·10층)이 보이는 곳을 누르면 그 층, 빈 곳은 지금 층, 1층 도로는 1층
- 초고층(28층 아래 생략 층)·지하층 건물(1층 밑 지하)은 쌓지 않음

`ui_cutaway.gd` (실제 화면):
- 시작은 외부 보기(외관 노드 하나), 12층 → 단면 12·11·10층 노드, 13층 이상 없음, 잘린 벽 0.2m·뒷벽 2.4m, 계단 디딤판 20칸, 바닥 구멍
- 전환 연출이 돌고 0.3초 뒤 끝남 · 11층이 보이는 곳 클릭 → 11층, 위층 잔상이 사라짐
- 외부 보기로 돌아오면 외벽 닫힘, 깨진 창·화염 분출 창이 있음, 구조대상자를 창가로 옮기면 창가 사람 표시
- 줌: 건물 위로 확대 → 선택한 조가 있는 7층 단면, 크게 축소 → 외부 보기
- 스크린샷 저장: `docs/ref/cutaway_exterior.png`, `docs/ref/cutaway_interior.png` (내부는 구조가 보이게 정보 안개를 잠깐 끈 화면)
- 프레임 측정 결과는 화면과 `user://cutaway_fps.txt`

## 프레임 측정 (사무용 PC: i5-9500 · UHD Graphics 630, 1600×900 창, 수직동기 60Hz)

기획안 최저 사양(8세대 i5 · UHD 620)과 비슷한 급이다.

| 장면 (15층 아파트) | 그리기만 (일시정지) | 게임 1배속 |
|---|---|---|
| 외부 보기, 시작 직후 | 56.5fps | 30.5fps |
| 외부 보기, 불이 번진 뒤(약 6분) | 44.9fps | 24.8fps |
| 단면 12·11·10층 | 58.3fps | 30.4fps |
| 단면 3·2·1층 (발화층, 도로·차량 포함) | 51.9fps | 26.1fps |
| (참고) 1층 단면, 아래층 없음 — R16과 같은 그림 | 55.0fps | — |

- GPU는 프레임당 2.5~4ms로 여유가 크다. 느린 곳은 CPU다.
- **그리기**: 처음에는 단면 37fps·외부 49fps였다. 가려지는 칸 빼기(아래층은 위층 바닥 밖으로 보이는 띠만, 외부 보기는 바깥 칸과 남·동 외벽만), 아래층은 틱이 바뀔 때만 번갈아 다시 그리기, 외관 창 묶어 그리기로 위 표까지 올렸다.
- **1배속에서 더 떨어지는 까닭은 시뮬레이션 계산**이다. 15층 아파트는 1틱 평균 29.5ms·최대 59ms(`tests/benchmark.gd`), 25층은 평균 50ms다. 화면과 같은 스레드에서 1초에 10틱을 돌려 틱마다 프레임이 끊긴다. R17 이전부터 있던 비용이며 화면 작업으로는 줄지 않는다.
- **60fps 목표는 아직 못 맞췄다.** 다음 단계 추천 (R18 성능):
  1. 시뮬레이션 틱을 작업 스레드로 옮기기(결정론은 그대로, 화면은 틱 사이 사본을 읽음) 또는 화재 격자 계산 줄이기 — 1배속 끊김의 대부분
  2. 층 노드의 고정 도형(벽·가구)을 층마다 한 번 만들어 둔 삼각형 묶음으로 그리기 — 그리기 시간 절반 이하
  3. 설정의 "저사양 모드(30fps 상한·효과 축소)" (기획안 9-5)

## 직접 확인

1. 고층 아파트 ①(15층)을 시작한다. 처음은 [입체 · 외부 보기] — 층 띠·창틀·발코니 난간·옥탑이 있는 외관.
2. 층 막대에서 12층을 누른다 → 0.3초 동안 외관이 위로 흐려지며 12층 단면. 아래로 11·10층이 어둡게 쌓이고 앞벽은 흰 단면 띠, 계단실 구멍으로 11층에서 올라오는 계단이 보인다.
3. 12층 바닥 아래로 보이는 11층 띠를 누르면 11층이 된다. 대원 선택은 그대로다.
4. 휠로 크게 축소하면 외부 보기, 건물 위에서 확대하면 다시 단면(선택한 조가 건물 안이면 그 층).
5. 몇 분 지나 3층 창이 깨지면 외관에서 그 창 위로 불꽃이 넘실대고 유리에 금이 보인다. 위층 창에서 연기가 나온다.
6. F12로 성능 표시를 켜 fps를 본다.

## 알려진 한계

- 아래층은 위층 바닥판에 가려 앞쪽 띠만 보인다 (위에서 내려다보는 시점). 가려진 곳의 아래층 대원·불은 보이지 않는다 — 층 막대·아래층 띠 클릭으로 내려가 본다.
- 외관은 보는 쪽(남·동) 두 면만 그린다 (R16과 같음).
- 아래층은 1초에 5번만 다시 그려 대원 움직임이 덜 부드럽다 (보이기만 하는 층이라 그렇게 정함).
- 15층 이상 외관은 R16처럼 층 높이를 줄여 그린다 (전체 약 30m 안).
- 60fps는 위 측정처럼 아직 아니다.
