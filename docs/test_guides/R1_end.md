# R1 종료 체계 — 활동 단계·초진·완진 선언·마무리 — 테스트 방법

근거: SOP 111~113, 202-6, 102-4.1 ⑥, 소방전술 I(화재1) 제4장 제5절 현장지휘권 확립 8단계. 순서는 초진 → 잔불정리·2차 검색 → 완진 선언 → 마무리 → 활동 종료.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_phases
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_phases`가 확인하는 것:
- 단계 시작: 처음에는 ① 출동·도착이고, 도착하면 ② 지휘권 확립이다.
- 초진: 거실을 방수해 진압하면 초진이 판정되고 ⑤ 잔불정리·2차 검색 단계로 넘어간다. 수관을 든 조가 자기가 보는 방(거실)을 "초진"으로 보고한다.
- 물을 쓰지 않으면 15분이 지나도 초진이 아니다.
- 2차 검색: 초진 뒤 검색은 2차 검색으로 기록된다.
- 완진 선언: 불이 남아 있어도 선언은 막지 않고 ⑦ 마무리로 넘어간다. 대신 판정 "완진 선언의 정확성"이 0점이다.
- 마무리 순서: 완진 선언·인원점검·감시 없이 끝내면 0점, 완진 → 인원점검 → 감시 → 종료면 만점이다.
- 시간 알림: 5분 전·1분 전 알림이 나오고, 불도 생존자도 없으면 종료를 제안한다.

`ui_smoke`(조작 점검)에 단계 표시줄, "남은" 시간, 완진 선언 창 → 선언 → 마무리 단계 항목을 추가했다. 전체 결과는 `결과: 162 통과, 0 실패`, 조작 점검은 `모두 통과`.

## 직접 해 보기 — 주택화재 ① (또는 튜토리얼)

1. 화면 맨 위 가운데에 **① 출동·도착 → ② 지휘권 확립 → … → ⑧ 활동 종료** 표시줄이 있다. 지금 단계는 노란색 굵은 글씨, 지난 단계는 흐리게 보인다.
2. 왼쪽 위 시계가 "경과 03:10 / 남은 36:50"처럼 남은 시간을 함께 보인다.
3. 지휘권을 선언하면 ③ 진압·인명구조로 바뀐다.
4. 거실을 진압해 불이 잡히고 1분이 지나면 무전 "초진 — 1층 거실 (진압1 1조)"가 나온다. 표시줄은 ⑤ 잔불정리·2차 검색으로 바뀐다.
   - 교육 모드면 "초진 보고를 받았습니다" 카드가 뜬다.
   - 보고는 그 조가 본 방만이다. 2층에 불이 남아 있으면 그 불은 보고에 빠진다.
5. 구조대로 방들을 다시 검색(W)하면 "2차 검색 완료 — 1층 방1" 같은 무전이 나온다. 열화상(T)과 잔불정리(G)로 불씨를 정리한다.
6. 무전 패널 아래 줄의 **완진 선언**을 누르면 확인 목록이 나온다.
   - 초진 보고
   - 발화층·직상층 2차 검색 몇/몇
   - 보이는 불
   - 찾은 불씨와 잔불정리 횟수

   **완진 선언 (무전)**을 누르면 ⑦ 마무리로 넘어간다. 불이 남아 있어도 선언은 된다(평가에서 감점).
7. **인원점검(P)**을 하고, **활동 종료**에서 재발화 감시를 고른 뒤 종료하면 디브리핑으로 넘어간다.
   - 완진 선언 전에 활동 종료 창을 열면 "⚠ 아직 완진 선언 전입니다…" 경고가 보인다.
8. 제한 시간 5분 전·1분 전에 무전 알림이 나온다.
9. 구조대상자가 모두 나오고 불이 모두 꺼진 채 1분이 지나면 "더 할 일이 없습니다 — …" 무전으로 종료를 제안한다(강제 아님).
10. 디브리핑 판정에 새 항목 3개가 나온다.

    | 축 | 항목 |
    |---|---|
    | 화재 안정화 | "완진 선언의 정확성" |
    | 인명구조 | "2차 검색" |
    | 지휘 절차 | "마무리 순서" |

11. 대원이 쓰러지거나 사망해도 게임은 끝나지 않는다(기획안 8장).

## 튜토리얼 바뀐 점
- 기존 "완진 확인" 단계는 세 단계로 바뀌었다: "초진 보고", "잔불정리·2차 검색", "완진 선언".
- 마지막 단계는 "복귀 보고 · 활동 종료"다.
- 전체 15단계다.

## 조정 가능한 값 (`data/command/phase_params.json`, 추정값)

| 값 | 기본 | 뜻 |
|---|---|---|
| knockdown_hold_s | 60 | 초진 조건이 이만큼 이어지면 초진 |
| end_suggest_quiet_s | 60 | 불·생존자 없는 상태가 이만큼 이어지면 종료 제안 |
