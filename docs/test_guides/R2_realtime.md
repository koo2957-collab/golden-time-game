# R2 실시간 규칙 — 난이도 훈련·실전·악조건 — 테스트 방법

근거: 기획안 3-3 ("항상 실시간" 질문 처리 규칙), 8장 (난이도), docs/plan_gap.md 결정 사항.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_realism
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_realism`이 확인하는 것:
- 제한 시간: 주택 ①의 실전 기준은 25분이다. 훈련은 2배이고 실전은 그대로다.
- 악조건: 풍속이 2배(최소 5m/s)로 강해진다. 소화전은 모두 고장이고 원거리 수원 순환보수만 쓸 수 있다. 후착대는 1.5배 늦게 오고, 난이도 기록이 남는다.
- 시나리오: 기본 시나리오의 제한 시간이 모두 25~30분이다.
- 다시 하기: 같은 난이도(악조건)로 재현되고, 결과 파일에 난이도가 기록된다.

`ui_smoke`(조작 점검)는 배속·일시정지 조작을 확인하므로 **훈련** 난이도로 시작하도록 바꿨다. 전체 결과는 `결과: 166 통과, 0 실패`, 조작 점검은 `모두 통과`.

## 직접 해 보기

1. 시작 화면 아래에 **난이도** 선택이 새로 생겼다: 훈련 / 실전 / 악조건. 기본은 실전이다. 기존 '자동화(입문·중급·상급)'와는 별개다.
2. **실전**으로 주택화재 ①을 시작한다.
   - 출동 지령 창이 떠 있는 동안만 시간이 멈춘다.
   - 지령을 닫으면 시계가 "경과 00:10 / 남은 24:50 ×1 실전 · 1배속 고정"처럼 보인다.
   - 지휘(C)·조직(O) 창을 열어도 시간이 흐른다.
   - Space를 누르면 "실전 난이도는 일시정지할 수 없습니다" 알림만 나온다.
   - F2·F3(배속)을 누르면 "1배속 고정입니다" 알림만 나온다.
   - 교육 모드 힌트 카드가 떠도 시간이 흐른다.
3. **훈련**으로 시작하면 제한 시간이 2배(50분)다. 일시정지·배속이 되고, 창·힌트 카드가 뜨면 멈춘다(전과 같음).
4. **악조건**으로 시작하면 다음이 달라진다.
   - 출동 지령 뒤 무전 기록에 "난이도 — 악조건"이 남는다.
   - 소화전을 점령하려 하면 "소화전 사용 불가(고장)"가 나온다. 물탱크차 B(순환보수)로 원거리 소화전을 오가야 한다.
   - 후착대 도착 예정 시간이 실전보다 1.5배 늦다(무전 패널 진입 현황에서 확인).
   - 바람이 강해 옆집 가열이 빨라진다.
5. 디브리핑 결과 파일(`reports/*.json`)에 `"realism": "악조건"`처럼 기록된다. "이 시점부터 다시 하기"를 해도 같은 난이도로 재현된다.
6. 교관 설정의 "시작 화면 기본값"에서 난이도 기본값을 정할 수 있다.

## 시나리오 제한 시간 (실전 1배속 기준)

| 시나리오 | 제한 시간 |
|---|---|
| 주택 ①, 주택 ④ 골목 | 25분 |
| 튜토리얼, 주택 ②·③, 아파트 ①·②, 일반건축물 ① | 30분 |

## 조정 가능한 값 (`data/command/phase_params.json`, 추정값)

| 값 | 기본 | 뜻 |
|---|---|---|
| training_time_factor | 2.0 | 훈련 제한 시간 배율 |
| harsh_wind_factor / harsh_wind_min_mps | 2.0 / 5 | 악조건 풍속 배율 / 최소 풍속 |
| harsh_arrival_factor | 1.5 | 악조건 후착대 도착 시간 배율 |
| harsh_shuttle_round_trip_s | 420 | 악조건에서 순환보수 원거리 수원 왕복 시간 (시나리오에 수원이 없을 때) |

## 하지 않은 것
- 기획안 8장의 "야간" 악조건은 화면 밝기 변경이 필요하다. 그래서 시나리오 시간대(주택 ②·아파트 ②가 새벽)로 대신했다.
- 질문 카드 제한 시간 2배는 R3(질문 카드 엔진)에서 넣는다.
