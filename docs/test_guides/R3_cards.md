# R3 질문 카드 엔진 — 테스트 방법

근거: 기획안 3-3("항상 실시간" 질문 처리 규칙), 3-4(오답 결과), 7장(카드 데이터·분류), P7.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_cards
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 173 통과, 0 실패`, 조작 점검은 `모두 통과`.

`test_cards`가 확인하는 것:
- 카드 데이터: 카드 6장 이상이 불러와지고, 카드마다 최선 선택지와 SOP 근거가 있다.
- 잠긴 문 카드: 중급 자동화에서 진압 명령을 내리면 잠긴 현관 앞에서 조가 멈추고 "잠긴 문" 카드가 뜬다(문구 채움).
- 답하기: 최선 선택(강제 개방)을 고르면 카드가 사라지고 결정이 기록된다. 문 파괴 작업이 시작되고, 그 결과는 시뮬레이션이 만든다.
- 미응답: 12초(중요) 동안 답하지 않으면 카드가 사라지고 "미응답"으로 기록된다. 문은 그대로이고 조는 지시 대기다(안전한 기본값 없음).
- 선제지시: "잠긴 문은 바로 파괴"를 켜 두면 카드가 뜨지 않고 '선제지시'(최선)로 기록되며, 바로 파괴 개방한다.
- 대기열: 카드는 최대 3장이고 긴급 카드가 맨 앞이다. 넘치는 카드는 "대기 중"으로 밀린다.
- 훈련 난이도: 카드 제한시간이 2배다. 같은 시드면 선택지 섞는 순서가 같다(다시 하기 결정론).
- 판정: "대원 판단 요청에 대한 지시"(최선·미응답·선제지시 → 2/3).

## 직접 해 보기

1. 시작 화면에서 **자동화: 중급** 또는 **상급**으로 주택화재 ①을 시작한다. 입문은 문을 알아서 열어 카드가 적다.
2. 선언 → 진입 명령(R) → 진압1 조에 W(진압) → 거실을 클릭한다. 조가 잠긴 현관 앞에서 멈추고, 화면 위쪽 가운데에 카드가 뜬다.
   - 맨 위 줄: [중요] 잠긴 문 · 1층 · 공기 98%
   - 질문: "진압1 1조: 현관 잠겨 있습니다. 어떻게 할까요?"
   - 아래: 남은 시간 막대, 번호 붙은 선택지 3개
3. 숫자 키(1~3)나 클릭으로 답한다. 게임은 카드가 떠 있어도 멈추지 않는다(실전). 무전 기록에 "지시 — 잠긴 문: …"이 남고, 고른 행동대로 조가 움직인다. 정답·오답은 게임 중에 표시하지 않는다.
4. 답하지 않으면 12초 뒤 카드가 사라지고 조는 멈춘 채로 있다(지시 대기). 무전으로는 보내지 않고, 디브리핑 "판단 요청 해설"에 "미응답"으로 남는다.
5. 이 밖에 카드가 뜨는 상황:

   | 상황 | 긴급도 |
   |---|---|
   | 백드래프트 징후 문 | 긴급 |
   | 구조대상자 발견 (의식이 없으면 긴급) | 중요 |
   | 공기 잔량 경보 | 긴급 |
   | 상급 자동화에서 닫힌 문 | 일반 |
   | 초진 보고 뒤 잔불정리 방법 | 일반 |

6. 카드가 여러 장이면 긴급 카드가 먼저 뜨고 카드 아래에 "+N 대기"가 보인다. 3장이 넘으면 "판단 요청 대기 중" 무전으로 밀린다.
7. 무전 패널 아래 줄의 **선제지시**에서 6가지를 미리 켤 수 있다. 켜 둔 상황은 카드 없이 그대로 처리되고, "선제지시대로 처리" 무전이 나온다. 예: "백드래프트 징후 문은 상부 창 배연 뒤 개방".
8. 디브리핑 ③ 위쪽 "판단 요청 해설"에 카드마다 다음이 나온다.
   - 묻은 시각
   - [등급]
   - 제목 → 내 선택
   - SOP 조항
   - 해설

   지휘 절차 축에는 "대원 판단 요청에 대한 지시"가 들어간다.
9. 훈련 난이도면 카드 제한시간이 2배(긴급 16초)다.

## 교관이 고칠 수 있는 곳
- `data/cards/cards.json`: 카드 문구, 선택지, 등급, 해설, SOP 조항, 선제지시 항목.
- `data/cards/card_params.json`: 긴급도별 초, 대기열 크기, 훈련 배율.
