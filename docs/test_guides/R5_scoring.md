# R5 평가 배점·SOP 준수 축 — 테스트 방법

근거: 기획안 8장 (평가축·배점·등급 상한), SOP 106 (전술 우선순위).

## 바뀐 것

| 축 | 전 | 후 |
|---|---|---|
| 대원 안전 | 25 | **30** |
| 인명구조 | 25 | **30** |
| 재산 보호 | 15 | **10** |
| 화재 안정화 | 15 | **10** |
| 지휘 절차 → **SOP 준수** | 20 | 20 |

- SOP 준수 축: 기존 지휘 절차 규칙에 질문 카드 판정 "대원 판단 요청에 대한 지시"가 더해진다. 판정 방식은 다음과 같다.
  - 최선은 100점, 허용은 50점이다.
  - 오답·치명·미응답·대기 밀림은 0점이다.
  - 선제지시로 처리한 카드는 최선으로 본다.
  - 판정 설명에 "선제지시로 질문 N건 줄임"이 붙는다.
- 등급 상한: 질문 카드에서 **치명** 선택을 하나라도 하면 최대 B다. 대원 행동 불능·생존 구조 50% 미만이면 최대 C인 기존 규칙도 그대로다.
  - 디브리핑 머리에 "치명 판단 1건 (백드래프트 징후 문, SOP 210-4.4, SOP 210-4.5) → 최고 B"처럼 이유가 나온다.
- 결과 파일의 `rules_version`이 3으로 올라간다(배점이 다르므로 이전 결과와 점수를 바로 비교하지 않는다).

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd -- test_scoring
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

전체 결과는 `결과: 178 통과, 0 실패`(test_scoring 3개는 따로 통과), 조작 점검은 `모두 통과`.

`test_scoring`이 확인하는 것:
- 배점: 30/30/10/10/20이고, 마지막 축 이름이 "SOP 준수"이며, 치명 상한이 B다.
- 치명 상한: 95점이라도 치명 판단이 있으면 B이고, 치명 카드 하나로 끝낸 판은 B보다 좋을 수 없다. 카드 판정은 SOP 준수 축에 있다.
- 선제지시: 2건 + 허용 1건이면 83점이고, 설명에 "선제지시로 질문 2건 줄임"이 나온다.

## 직접 해 보기

1. 아무 시나리오나 자동화 **중급**으로 시작해 백드래프트 징후 문 카드가 뜨게 한다.
   - 주택화재 ②에서 2층 방4 쪽 문이 닫힌 채 오래 타면 잘 나온다.
2. 그 카드에서 "즉시 문을 열고 진입"(치명)을 고른 뒤, 나머지는 잘 진행해 종료한다.
3. 디브리핑 ①의 점수는 높아도 등급은 B 이하이고, 상한 이유에 "치명 판단 … → 최고 B"가 나온다.
4. 디브리핑 ③에서 축 이름이 "SOP 준수"로 바뀌었고, 그 아래에 "대원 판단 요청에 대한 지시" 항목이 보인다.
5. 같은 판을 선제지시를 많이 켜 두고 해 보면, 그 항목 설명에 "선제지시로 질문 N건 줄임"이 나온다.

## 기획안과 다른 점
- 기획안 SOP 준수 축의 "무전 규율"은 별도 점수를 두지 않았다. 무전 보고·지휘 절차는 기존 규칙(선언·상황보고·통솔범위 등)이 이미 본다.
