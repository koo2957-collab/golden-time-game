# R6a 화면 배치 ① — 상황 배지·층 막대·전술상황판·무전 자막·긴급 버튼 — 테스트 방법

근거: 기획안 9-2(화면 구성), 9-3(조작). 사용자 결정(2026-11-08):
- Tab = 전술상황판 접기·펴기, **M = 입체/평면 전환**(전에는 Tab)
- 게임 중 마우스를 창 안에 가둠(Esc로 풂)
- 왼쪽 무전 패널을 오른쪽 전술상황판으로 합침

## 바뀐 화면

| 위치 | 무엇 |
|---|---|
| 왼쪽 위 **상황 배지** | 1줄: 경과/남은 시간·배속·난이도. 2줄: **전략 · 풍향 · 대응 단계**. 누르면 지휘(C) 창(전략 변경) |
| 왼쪽 **층 막대** | 위에서부터 꼭대기 층 → 1층·외부. 층마다 "불"(빨강)/"연기"(회색)와 그 층 대원 수. 누르면 그 층으로 |
| 오른쪽 **전술상황판** | 반투명. 위에서부터 상황 요약(RECEO) · 팀 현황 · **확인 필요**(해결 안 된 일) · 무전 기록(최근 순, 답한 질문 카드 "질문: … → 내 답") · 지휘 버튼. 제목에 "확인 필요 N". **Tab**이나 "▶ 접기"로 접으면 제목과 버튼만 남는다 |
| 아래 왼쪽 **무전 자막** | 최근 무전 2~3줄, 5초 뒤 사라짐. 대원 안전 무전은 빨강 |
| 위쪽 가운데 **긴급 버튼** | 긴급탈출 상황이면 큰 빨간 버튼 → 누르면 전원 긴급탈출 지시 |
| 화면 가장자리 **붉은 비네트** | 긴급탈출이거나 최근 30초 안에 롤오버·백드래프트·350℃·붕괴·추락 징후가 있으면 깜빡임 |
| 카메라 | 마우스를 화면 가장자리(20px)에 대면 그쪽으로 흐른다. 게임 중에는 마우스가 창 밖으로 나가지 않는다(Esc로 풀고, 화면을 클릭하면 다시 가둠) |

알림 문구와 질문 카드는 상황판이 가리지 않도록 지도 영역 가운데에 뜬다.

확인 필요 항목:
- 긴급탈출 상황
- 대기 중인 판단 요청
- 제보받았지만 검색하지 않은 방
- 처치를 기다리는 환자
- 열린 가스 밸브
- 순환보수가 없는 소화전 고장
- 확인하지 않은 위층 샤프트
- 매트가 없는 창가 주민
- 정리하지 않은 불씨

모두 지휘관이 아는 정보로만 만든다.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

조작 점검(`ui_smoke`)은 입체/평면 전환 키가 M으로 바뀐 것을 반영했다. 실제 마우스 위치에 따라 카메라가 흐르지 않도록 점검 중에는 가장자리 스크롤과 마우스 가둠을 끈다. 전체 결과는 `결과: 181 통과, 0 실패`, 조작 점검은 `모두 통과`.

## 직접 해 보기
1. 아파트화재 ①을 시작한다.
2. 왼쪽 위 배지 둘째 줄에 "전략 미선언 · 서풍 2m/s · 선착대"가 보인다. 배지를 클릭하면 지휘 창이 열린다.
3. 왼쪽 층 막대 "5층 … 1층·외부"를 누르면 그 층으로 바뀐다. 불이 커지면 3층이 빨갛게 "불", 연기가 오른 층은 "연기"로 바뀐다.
4. 오른쪽 상황판:
   - Tab을 누르면 접히고 지휘 버튼만 남는다. 다시 Tab을 누르면 펴진다.
   - 질문 카드에 답하면 무전 기록에 "질문: 잠긴 문 → 문 옆 벽에 …"가 생긴다.
   - 확인 필요에 "대원 판단 요청 1건 대기" 등이 생겼다가, 해결하면 사라진다.
5. M으로 입체/평면을 바꾼다.
6. 마우스를 화면 가장자리에 대면 지도가 흐른다. Esc를 누르면 "마우스 가둠을 풀었습니다" 알림이 나오고 마우스가 창 밖으로 나갈 수 있다. 화면을 클릭하면 다시 가둔다.
7. 대원이 쓰러지면(긴급탈출) 위쪽에 빨간 버튼이 나오고 화면 가장자리가 붉게 깜빡인다.
