# R6b 화면 배치 ② — 하단 콘솔·지휘소 복귀 — 테스트 방법

근거: 기획안 9-2(화면 구성: 하단 콘솔 = 미니맵·선택 정보·명령 버튼), 9-3(조작: Home = 지휘소).

## 바뀐 화면

| 위치 | 무엇 |
|---|---|
| 화면 아래 **콘솔** (반투명 띠, 화면 높이의 18%, 최소 150px) | 왼쪽: **미니맵 자리**. 지금은 "도면 수신 대기"로 잠겨 있다(R8에서 도면을 얻으면 열린다). 가운데: **선택 정보**. 오른쪽: **명령 버튼** |
| 콘솔 가운데 — 아무것도 안 골랐을 때 | **출동대 요약**: 대마다 현장 접근 중/대기1단계/현장, 안에 들어간 조 수와 그중 가장 낮은 공기량 |
| 콘솔 오른쪽 — 아무것도 안 골랐을 때 | **지휘관 명령**: 지휘(C), 조직·지원(O), 현장 정보(F), 360° 둘러보기, 긴급탈출 지시, 인원점검(P), 선제지시, 완진 선언, 활동 종료. 전에는 오른쪽 상황판 아래에 있었다 |
| 콘솔 오른쪽 — 조를 골랐을 때 | **출동대 명령칸**(진압 W, 외부 방수 V, 잔불정리 G, 철수 X)과 **세부 명령**(진입 R, 검색 Q, 문·창 E, 수관 연장 H, 직사 A, 분무 S, 방수 중지 D). 전에는 오른쪽 아래에 따로 떠 있었다 |
| 콘솔 오른쪽 아래 **? 조작** | 마우스를 올리면 조작키 목록. 전에는 화면에 늘 떠 있던 도움말 |
| 왼쪽 열 | 층 막대 아래에 구조대상자 패널과 열화상 범례가 차례로 쌓인다(서로 겹치지 않는다) |
| 무전 자막 | 콘솔 바로 위에 뜬다 |
| **Home** 키 | 현장지휘관(지휘소)이 있는 층과 위치로 카메라를 돌린다 |

오른쪽 전술상황판에는 이제 상황 요약·팀 현황·확인 필요·무전 기록만 남는다. Tab으로 접으면 제목만 남아 지도가 넓어진다.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

화면 배치만 바뀌었고 시뮬레이션·명령·평가는 그대로다. 전체 결과는 `결과: 181 통과, 0 실패`, 조작 점검은 `모두 통과`. 콘솔은 그 아래 지도 클릭을 막으므로, 조작 점검에서 소화전을 누르기 전에 카메라를 소화전으로 옮긴다.

## 직접 해 보기
1. 아파트화재 ①을 시작한다.
2. 화면 아래 띠를 본다.
   - 왼쪽은 "미니맵 / 도면 수신 대기"이다.
   - 가운데는 "선택 없음 — 출동대 요약"과 대별 상태이다.
   - 오른쪽에는 지휘 버튼 두 줄이 있다.
3. 진압대 조를 클릭한다. 오른쪽이 진압대 명령칸과 세부 명령으로 바뀌고, 가운데에 그 조의 정보가 나온다.
4. 빈 곳을 클릭해 선택을 푼다. 다시 지휘 버튼이 나온다.
5. 조를 안에 들여보낸 뒤 선택을 풀면 요약에 "내부 1조, 최저 공기 …%"가 보인다.
6. 다른 층으로 가서 카메라를 멀리 옮긴 뒤 **Home**을 누르면 지휘소로 돌아온다.
7. "? 조작"에 마우스를 올려 조작키 목록을 본다.
8. 창 크기를 바꿔도 콘솔이 아래에 붙어 있고 왼쪽 패널과 겹치지 않는지 본다.
