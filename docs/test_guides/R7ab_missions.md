# R7a·R7b 임무형 내부 지휘 ① — 내부 무전 지시·층 단위 임무·임무 조건 — 테스트 방법

근거: 기획안 9-1 ("보이는 곳은 직접, 안 보이는 곳은 임무와 무전으로"), SOP 107 3.1⑤(지시 → 수신 확인), 214-2.1(인명검색 최우선), 210-3.5(화재실 문 닫기), 201-3.7(공기 경보 시 철수).

사용자 결정(2026-11-08):
- 모든 난이도에 기획안대로 적용한다.
- 도면(R8)을 얻기 전에는 본 적 없는 곳에 층 단위 임무만 줄 수 있다.

## 바뀐 규칙

| 무엇 | 어떻게 |
|---|---|
| **건물 안 조에게 내리는 명령** | 무전으로 간다. 지휘망에 "진압1 1조, 현장지휘관. 1층 거실로 이동하라." 송신이 끝나면(약 2~3초) 실행하고, 조가 "…이동하겠음."으로 복명복창한다. 다른 무전이 송신 중이면 기다리므로, 여러 조에 한꺼번에 지시하면 늦어진다. 철수 지시는 대원 안전 우선순위로 먼저 나간다 |
| 밖에 있는 조 | 대면 지시라 바로 실행된다(전과 같음) |
| **경유지(우클릭 이동)** | 건물 안 칸은 대원이 **본 적 있는 칸**에만 찍을 수 있다. 본 적 없는 칸을 우클릭하면 "본 적 없는 곳에는 경유지를 찍을 수 없습니다 — 진압·검색 임무로 맡기세요" 알림이 뜨고 움직이지 않는다 |
| **층 단위 임무** | 본 적 없는 방에 진압(W)·검색(Q) 등을 지시하면 자동으로 **층 진압·층 검색**으로 바뀐다("본 적 없는 방 → 2층 단위 임무로 지시" 알림) |
| 층 검색 | 그 층에서 아직 검색하지 않은 방을 가까운 곳부터 차례로 검색하고, 다 하면 "2층 검색 완료"를 보고한다. 구조대상자를 찾아 옮기기 시작하거나 지시를 기다리며 멈추면 이어 가지 않는다 |
| 층 진압 | 그 층에서 타는 방을 찾아 진압하고, 다음 타는 방으로 간다. 불이 없으면 "2층 화점을 찾지 못함 — 지시 바람"으로 멈춘다 |
| **화점 발견** | 검색 중인 조가 5m 안에서 불을 보면 "화점 발견 — 1층 거실"을 보고하고 **질문 카드 "검색 중 화점 발견"**이 뜬다 |
| **임무 조건** | 조마다 철수 잔압·화점 발견 시·요구조자 발견 시 행동을 정해 두면, 그 상황에서 카드 없이 그대로 한다. 디브리핑에는 "[최선·임무 조건]"처럼 표시되고, 등급은 같은 행동의 카드 선택지를 따른다. 예를 들어 "요구조자 발견 시: 위치 보고 후 대기"는 214-2.1과 달라 오답이다. 임무 조건을 정하는 화면은 R7c(끌어다 놓기·임무 휠)에서 붙는다 |

"화점 발견" 카드의 선택지:

| 선택 | 등급 |
|---|---|
| 화재실 문을 닫아 연소를 늦추고 위치를 보고한 뒤 검색 계속 | 최선 |
| 수관으로 즉시 진압 (수관이 있는 조만) | 허용 |
| 검색을 멈추고 진압대를 기다림 | 오답 |
| 문을 열어 둔 채 검색 계속 | 오답 |

철수 잔압 선택지(data/command/mission_params.json):
- 경보 울리면 철수(기본, SOP 201-3.7)
- 절반 남으면 철수
- 3분의 1 쓰면 철수

뒤의 두 기준은 추정값이라 현장 검수가 필요하다.

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

새로 넣은 테스트는 다음 두 파일이다.
- `test_interior.gd`: 본 적 없는 곳 거절, 무전 지시와 복명복창, 밖은 바로 실행, 철수 우선순위, 다시 하기 일치
- `test_missions.gd`: 층 단위 임무 강제, 층 검색이 방을 차례로 도는지, 층 진압, 임무 조건과 카드, 화점 발견, 철수 잔압

조작 점검에 추가한 항목:
- 건물 안 조가 본 적 없는 곳을 우클릭하면 거절된다
- 본 곳을 우클릭하면 무전 지시가 나간다
- 본 적 없는 방에 W를 쓰면 층 진압으로 바뀐다

엔진 테스트(시나리오만 불러오는 테스트)에서는 이 규칙이 꺼져 있다. 실제 게임은 시작할 때 난이도를 적용하면서 켠다.

## 직접 해 보기
1. 주택화재 ①을 시작한다.
2. 진입 명령(R) 뒤 진압1 1조에게 W → 거실을 클릭한다.
   - 거실이 아직 안 보였다면 "본 적 없는 방 → 1층 단위 임무로 지시" 알림이 뜨고, 조는 1층에서 타는 방을 찾아 진압한다.
3. 조가 건물 안에 들어가면 우클릭으로 옮겨 본다.
   - 아래 무전 자막에 "…이동하라." → "…이동하겠음."이 차례로 나오고, 그 사이 조는 기다린다.
   - 아직 아무도 안 가 본 어두운 곳을 우클릭하면 거절 알림이 뜬다.
4. 구조1 조에게 Q → 2층 방을 클릭한다.
   - 2층 단위로 바뀌어 방을 차례로 검색한다.
   - 검색 중 불을 보면 "검색 중 화점 발견" 카드가 뜬다.
5. 여러 조에게 연달아 지시해서 무전이 밀리는지(늦게 움직이는지) 본다.
