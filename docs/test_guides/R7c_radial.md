# R7c 임무형 내부 지휘 ② — 원형 메뉴·팀 카드 끌어다 놓기·임무 창 — 테스트 방법

근거: 기획안 9-1(임무 부여·무전 경유지·원형 메뉴), 9-2 ②(팀 현황 카드), 9-3(조작 표). SOP 107-1.6(대원 보고).

사용자 결정(2026-11-08): 팀 카드를 끌어다 놓아도 진입 명령(R)은 함께 내리지 않는다. 진입 명령 판단(SOP 102-5.2)을 따로 평가하기 위해서다.

## 바뀐 화면·조작

| 무엇 | 어떻게 |
|---|---|
| **원형 메뉴** | 건물 안에 있는 조를 **우클릭**하면 커서 둘레에 6칸 메뉴가 뜬다. 가운데 위에 "진압1 1조 · 층 검색 (2층 방1)"처럼 조와 임무가 나온다. 바깥을 누르거나 우클릭·Esc로 닫는다 |
| ↳ 여기로 | 경유지 모드. 본 적 있는 곳을 클릭하면 무전으로 이동 지시(R7a 규칙) |
| ↳ 구역 변경 | 주 임무(W) 모드. 방이나 층을 클릭해 임무 구역을 바꾼다 |
| ↳ 대기 | 하던 일을 멈추고 그 자리에서 대기("현 위치 대기하라.") |
| ↳ 철수 | 이 조만 가장 가까운 출구로 철수(대원 안전 우선 무전) |
| ↳ 보고 요청 | "현재 위치와 상황 보고하라." → 조가 "현재 1층 거실, 임무 층 진압 (1층 거실), 공기 72%, 짙은 연기."로 답한다 |
| ↳ 지원 투입 | 밖에서 쉬는 조(같은 출동대 먼저, 가까운 순, RIT·안전담당·구급대 제외)를 같은 임무에 투입. 없으면 회색 |
| **팀 카드** | 오른쪽 상황판 "팀 현황" 아래에 조마다 한 줄: 이름 · 위치 · 임무 · 공기 · 마지막 보고 경과. 판단 요청이 기다리고 있으면 앞에 "?"가 붙고, 임무 조건이 있으면 다음 줄에 나온다 |
| ↳ 색 | 쓰러짐·공기 30% 미만은 빨강, 보고가 90초 넘게 없으면 노랑, 밖에 있는 조는 흐리게 |
| ↳ 마우스 | 클릭 = 선택, 더블클릭 = 그 조로 화면 이동, **끌어서 지도에 놓기 = 임무 창** |
| **임무 창** | 놓은 곳이 본 방이면 "구조1 1조 → 1층 방1", 본 적 없는 곳이면 "→ 2층 (층 단위 — 아직 본 적 없는 곳)". 임무 조건 세 줄(철수 잔압·화점 발견 시·요구조자 발견 시)을 고르고 **화점 진압** 또는 **인명 검색**을 누른다. 조건은 다음 창의 기본값으로 남는다. 배연은 R11에서 붙는다 |
| 진입 명령 | 진입 명령(R)이 없는 출동대면 임무 창에 빨간 안내가 나온다. 임무를 받아도 입구에서 기다린다 |
| 상황판 | 내용이 길어지면 하단 콘솔 위에서 스크롤된다. Tab으로 접으면 제목만 남는다 |

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_missions.gd`에 대기·보고 요청을 더했다.

조작 점검에 추가한 항목:
- 건물 안 조를 우클릭하면 원형 메뉴가 열린다(6항목)
- 항목을 클릭하면 메뉴가 닫히고 보고 요청 무전이 나간다
- 대기를 고르면 대기 지시가 나간다
- 팀 카드가 있다
- 팀 카드를 지도에 끌어다 놓으면(실제 마우스 입력) 임무 창이 열린다
- 임무 창에서 임무 조건과 인명 검색이 함께 나간다
- 조건이 기록된다

## 직접 해 보기
1. 주택화재 ①을 시작한다. 지휘권을 선언(C)하고 진입 명령(R)을 내린다.
2. 오른쪽 상황판의 팀 카드 "구조1 1조"를 끌어 2층 방 위에 놓는다.
   - 임무 창에서 "요구조자 발견 시: 즉시 구조"를 고르고 **인명 검색**을 누른다.
   - 2층을 본 적이 없으면 "2층 검색"으로 바뀐다.
   - 구조대상자를 찾으면 질문 카드 없이 바로 업고 나온다. 디브리핑에는 "[최선·임무 조건]"으로 나온다.
3. 조가 건물 안에 들어가면 그 조를 우클릭한다. 원형 메뉴에서 **보고 요청**을 고르면 무전 자막에 요청과 답이 차례로 나오고, 팀 카드의 "보고 N초 전"이 0으로 돌아간다.
4. 원형 메뉴의 **지원 투입**을 고르면, 밖에서 쉬는 조가 같은 임무로 들어간다(알림 표시).
5. 팀 카드를 더블클릭하면 그 조가 있는 층·위치로 화면이 옮겨진다.
