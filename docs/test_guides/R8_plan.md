# R8 도면·미니맵 — 구조는 직접 밝힌다 — 테스트 방법

근거: 기획안 9-1 "도면과 미니맵"·"구조는 직접 밝힌다", 9-2 ①(미니맵), SOP 235(방재실 수신반), SOP 112(지휘대 도착 시 도면 수신).

## 바뀐 규칙·화면

| 무엇 | 어떻게 |
|---|---|
| **구조는 직접 밝힌다** | 처음에는 건물 안 벽·문·가구·방 이름이 보이지 않는다. 바깥에서 보이는 외벽·창·문과, 대원이 직접 보거나 창 너머로 들여다본 곳만 지도에 남는다. 모르는 실내는 거의 검게 덮인다 |
| **창 관찰은 보이는 면만** | 전에는 모든 외부 창을 밖에서 들여다본 것으로 쳤다. 이제는 그 창이 향한 쪽(40칸 안)에 지휘관이나 바깥 대원이 있어야 들여다볼 수 있다. 뒤쪽(C면) 창 안은 둘러보거나 들어가야 안다 |
| **관리사무소(방재실)** | 아파트·근린생활시설 마당에 보라색 건물로 표시된다. 조를 보내(우클릭 이동) 60초 머물게 하면 **도면 확보**를 하고 **수신반 발화층**("수신반 확인: 화재 신호 3층")을 무전으로 보고한다. 머무는 동안 표시가 "도면 확인 중 N%"로 바뀐다. 그 조는 그동안 현장에서 빠진다 |
| 지휘대 도착 | 상황실에서 도면이 들어오는 경로를 만들어 두었다. 실제 연결은 R13 지휘권 이양에서 한다 |
| **도면을 얻으면** | 모르는 곳에 흐린 파란 선(벽)과 노란 선(문)이 깔리고 방 이름이 보인다. 불·연기·사람은 여전히 대원이 본 것만 보인다. 본 적 없는 방에도 **방 단위 임무**를 줄 수 있다(R7의 층 단위 제한이 풀림) |
| **미니맵** | 하단 콘솔 왼쪽. 도면 전에는 "도면 수신 대기"와 함께 "관리사무소(방재실)에 조를 보내면 도면"을 안내한다. 도면을 얻으면 지금 보는 층의 평면, 대원(하늘색)·지휘관(노랑)·쓰러진 대원(빨강), 확인한 불(빨강 칸), 발견한 구조대상자(초록)를 그린다. **클릭하면 그곳으로 화면이 이동**한다 |
| **도면과 실제가 다른 곳** | 아파트 3층 301호는 발코니가 확장되어 있다(도면에는 벽, 실제는 터짐). 근린 1층 식당·편의점 사이는 불법 칸막이로 막혀 있다(도면에는 통로). 대원이 실제로 보면 "도면과 다름 — …" 무전이 나오고, 지도는 실제 구조로 바뀐다 |
| **디브리핑** | "도면과 구조 정보" 항목이 생긴다. 언제 어디서 도면을 얻었는지와 수신반 발화층이 나오고, 도면 없이 끝났으면 방재실로 얻을 수 있었다고 알려 준다. 도면과 다른 곳을 확인했는지도 나온다 |
| 단독주택 | 방재실이 없어 끝까지 도면 없이 한다(기획안 9-1 "지휘대가 오기 전에 끝나는 스테이지는 끝까지 미니맵 없이") |

## 자동 테스트

```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```

`test_plan.gd`에서 확인하는 것:
- 처음에는 외벽만 안다
- 방재실에 60초 머물면 도면과 수신반 발화층을 얻는다
- 도면과 실제가 다른 곳을 발견하면 디브리핑에 기록된다
- 단독주택에는 방재실이 없다

조작 점검에서 확인하는 것:
- 도면 전에는 미니맵이 잠겨 있다
- 도면을 얻으면 미니맵이 열리고 방 단위 임무를 줄 수 있다
- 미니맵을 클릭하면 화면이 이동한다

창 관찰 방식이 바뀐 뒤에도 기존 테스트는 모두 통과했다(전체 201 통과).

## 직접 해 보기
1. 아파트화재 ①을 시작한다. 3층을 보면 건물 안이 거의 검고, 남쪽 창 가까이만 보인다.
2. 진압2 조처럼 쉬는 조를 골라 오른쪽 마당의 보라색 **관리사무소(방재실)**을 우클릭한다. 60초 동안 "도면 확인 중 %"가 오른다.
3. 도면을 얻으면 무전 "도면 확보 — 관리사무소(방재실)"과 "수신반 확인: 화재 신호 3층"이 나온다.
   - 지도에 흐린 선이 깔리고, 미니맵이 열린다.
   - 미니맵을 클릭해 이동해 본다.
4. 3층 301호 거실에 들어가면 "도면과 다름 — 3층 301호 발코니 확장…"이 나온다.
5. 끝낸 뒤 디브리핑 ③의 "도면과 구조 정보"를 본다.
