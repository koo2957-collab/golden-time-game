# R9 수치 정비 — CO 교재 표·호흡량 4단계·산소·출구까지 필요 공기·출동 편성 — 테스트 방법

근거: 기획안 5-5(요구조자 생존 모델), 5-6(대원 상태 모델), 6-1(출동 편성). 교재: 소방전술 화재2 표 4-11(CO 농도별 사망시간)·산소농도별 영향, 화재1 표 1-19(공기호흡기 사용가능시간).

## 바뀐 수치

| 무엇 | 전 | 지금 |
|---|---|---|
| **CO 노출** | 공학식(ISO 13571) — 분당 ppm^1.036/35,000 | **교재 표**: 1,600ppm 120분 · 3,200ppm 30분 · 6,400ppm 20분 · 12,800ppm 2분(사이는 로그 보간). "노출시간 ÷ 그 농도의 사망시간"을 더해 1이면 사망, 1/3이면 의식 잃음(추정). 공학식은 비교용 함수로 남김 |
| **호흡량** | 40 / 60(이동·작업) / 80(고열) | **4단계** 대기·보행 40 / 수색·호스 전개 55 / 방수·파괴 65 / 구조(업고 이동)·계단 80 ℓ/분 |
| 긴장 배율 | 없음 | 고열 구역(위험 복사열의 절반 이상)이나 긴급탈출 상황 ×1.3 |
| 호흡조절 | 없음 | 잔압 경보가 울린 뒤 ×0.8 (SOP 204 4.3) |
| 공기호흡기 | 2040ℓ, 경보 18% | 6.8ℓ×300bar = 2040ℓ, 경보 55bar(18.3%) → 40ℓ/분이면 약 41분 (교재 공식) |
| **출구까지 필요 공기** | 없음 | 건물 안에서 가장 가까운 열린 출구까지 거리(직선 × 1.4, 층마다 계단 6칸)를 지금 호흡량으로 걸어 나가는 데 드는 공기. 그만큼 쓰면 경보 아래로 내려가는 순간 **"출구까지 공기 약 N bar 필요, 잔압 M bar — 퇴각 건의"**를 대원 안전 무전으로 보고한다 |
| **산소** | 연소 판정에만 | 요구조자가 스스로 대피할 때 18% 미만이면 절반 속도, 10% 이하면 움직이지 못함 |
| **출동 편성** | 파일 없음 | `data/units/crews.json`에 기획안 6-1 표(선착대 5·구조 4·구급 3·후착 5·운전원 1)와 게임 편성을 함께 둔다. 시나리오 편성이 이를 넘지 않는지 테스트로 확인한다 |

화면에서 바뀐 것:
- 팀 카드에 "잔압 210bar (출구 12bar)"가 나온다.
- 선택 정보에 "잔압 210bar (70%) · 출구까지 필요 12bar · 호흡 55ℓ/분"이 나온다.

기획안과 다른 점:
- 선착대 분대원은 기획안에서 3명(1조 + 남는 1명)이지만, 단독 대원 배정이 아직 없어 2조 4명으로 둔다.
- 의식 잃음 시점은 교재 표에 없어 치사량의 1/3로 추정했다.
- 두 가지 모두 보고서의 개선점에 적었다.

## 직접 해 보기
1. 주택화재 ①에서 진압1 조를 들여보내고 조를 클릭한다. 선택 정보에 잔압(bar)과 출구까지 필요한 공기, 지금 호흡량이 나온다. 방수를 시작하면 호흡이 65로, 구조대상자를 업으면 80으로 오른다.
2. 아파트에서 3층 깊은 곳까지 들어간 조가 오래 머물면, 경보보다 먼저 "퇴각 건의" 무전이 나온다.
3. 오래 걸린 판에서 디브리핑의 구조대상자 상태를 보면, 낮은 농도에서는 전보다 오래 버틴다. 짙은 연기(고농도)에서는 더 빨리 위험해진다.
