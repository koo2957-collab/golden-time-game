# 화면 점검 — 시점(약 50° 부감)·대원 비율·차량 세부 — 테스트 방법

참고 이미지(게임 스타일 1·2, 아이소매트릭 3/4 시점)와 비교해 고친 내용이다.

## 바뀐 것
- 입체 화면 시점: 바닥 비율(HALF_H 14 → 21)과 높이 비율(1m = 51px)을 같은 카메라(약 50° 내려다보기)로 맞춤. 전에는 바닥은 30°, 높이는 50°로 어긋나 모든 것이 위로 길쭉했다.
- 대원·지휘관·관계인: 키 약 1.75m, 어깨 약 0.45m의 사람 모양(몸통·안전모·얼굴·반사띠·장화).
- 차량: 실제 높이(3m)로 그리고, 옆면 띠·바퀴·앞유리·빨강/파랑 경광등을 더함.
- 입체 화면 시작 확대 0.9 → 0.75 (집과 도로가 한 화면에).

## 자동 테스트
```
GODOT --headless --path . -s res://tests/run_tests.gd
GODOT --path . -s res://tests/ui_smoke.gd
```
조작 점검(클릭 선택·우클릭 이동·소화전 점령 등 입체 화면 좌표)이 모두 통과해야 한다.

## 직접 해 보기
1. 주택화재 ①을 시작하고 출동 지령을 닫는다.
2. 입체 화면에서 집 전체와 앞 도로가 함께 보이고, 방 안(가구·바닥)이 전보다 넓게 보인다.
3. 휠로 확대해 대원을 보면 흰/색 안전모, 반사띠가 있는 사람 모양이다. 대원 키는 펌프차 높이의 절반 남짓이다.
4. 펌프차·물탱크차에 바퀴와 옆 띠가 보이고, 지붕 경광등이 깜빡인다.
5. 대원 클릭 선택, 우클릭 이동, 펌프차 선택 후 소화전 우클릭이 전처럼 정확히 된다.
6. Tab(상황판)은 바뀌지 않았다.

## 아직 다른 점
- 참고 이미지의 질감(벽돌·조경·정교한 차량 모델)은 그림 파일(스프라이트)이 필요해 이번 범위에 넣지 않았다.
