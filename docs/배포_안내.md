# 소방 지휘관 훈련게임 — 배포·설치 안내

교육 담당자와 PC 관리자를 위한 문서다. 게임 조작법은 게임 안 "? 조작" 버튼과 [튜토리얼]에서 익힌다.

## 1. 필요한 것

| 항목 | 기준 |
|---|---|
| 운영체제 | Windows 10/11 64비트 |
| CPU | 4코어 이상 권장. 시뮬레이션은 CPU를 쓴다. 15층 아파트 1틱(0.1초)이 이 개발 PC에서 약 19ms였다 |
| 그래픽 | OpenGL 3.3 이상 내장 그래픽이면 충분하다. Compatibility 렌더러로 2D 도형만 그린다 |
| 메모리 | 4GB 이상 |
| 화면 | 1280×720 이상. 1920×1080을 권장한다 |

## 2. 배포 방법 (둘 중 하나)

### A. 실행 파일 하나로 (권장)
1. 개발 PC에서 Godot 4.7.2 편집기로 프로젝트를 연다.
2. **편집기 > 내보내기 템플릿 관리 > 다운로드 및 설치**를 한 번만 한다. 약 1GB이고, 이 단계는 아직 하지 않았다.
3. 프로젝트 폴더의 `실행파일_만들기.bat`를 실행하면 `build/FireCommander.exe`가 생긴다. 이 파일 하나에 데이터(JSON)까지 들어 있다.
4. 교육용 PC에 `FireCommander.exe`만 복사해 실행한다.

### B. 프로젝트 폴더 그대로
1. 프로젝트 폴더를 교육용 PC에 복사한다.
2. 폴더 안 `godot` 폴더에 `Godot_v4.7.2-stable_win64.exe`(편집기와 같은 파일)를 넣는다.
3. `게임_실행.bat`를 실행한다.

이 방식에서는 교관이 `data/*.json`을 바로 고칠 수 있다. 고칠 수 있는 것은 카드 문구·등급, 수치, 시나리오다.

## 3. 처음 설치 후 확인
1. `성능_측정.bat`를 실행한다. 아래 두 가지를 확인한다.
   - 시나리오별 계산 시간: 평균 30ms 미만이면 "여유", 100ms 미만이면 실시간으로 돈다.
   - 15층 아파트 입체 화면의 평균 fps: 30 이상이면 통과다.
2. 30fps가 안 나오면 시작 화면 **화면 설정**에서 다음 두 가지를 바꾼다.
   - "화면 갱신 30"(저사양 모드)
   - "HD 1280×720"
3. 결과 파일은 `%APPDATA%\Godot\app_userdata\<프로젝트 이름>\benchmark.txt`에 생긴다.

## 4. 게임 안에서 성능 보기
- **F12**: 성능 표시(fps·시뮬레이션 계산 ms·그리기 호출 수·메모리)를 켜고 끈다.

## 5. 기록이 저장되는 곳
`%APPDATA%\Godot\app_userdata\<프로젝트 이름>\` 아래에 저장된다.

| 파일 | 내용 |
|---|---|
| `reports/*.json` | 판마다 결과(디브리핑). 내 기록·익명 집계에 쓰인다 |
| `export/*.html`, `export/results.csv` | 디브리핑의 "보고서 저장"으로 만든 인쇄용 보고서와 결과표(교관 취합용) |
| `crew_growth.json` | 대원 성장 기록(신임 → 고참) |
| `display.json` | 화면 설정 |
| `instructor.json` | 교관 설정(수치 조정) |

## 6. 교관이 바꿀 수 있는 데이터 (방식 B)

| 파일 | 내용 |
|---|---|
| `data/cards/cards.json` | 질문 카드 문구·선택지·등급·해설·SOP 근거 |
| `data/sop/rules.json` | 판정 항목·기준·해설 |
| `data/scenarios/*.json` | 시나리오(발화 위치·요구조자·후착대 시간·지령문) |
| `data/units/*.json` | 대원 수치·차량 제원·편성(crews.json)·적재 장비·성장 단계 |
| `data/fire/*.json`, `data/materials/materials.json` | 화재·위험 수치 |

모든 수치에는 `source`(교재·SOP·추정)가 붙어 있다. "추정"은 현장 검수가 필요한 값이다.

## 7. 자동 점검 (개발자용)

```
GODOT --headless --path . -s res://tests/run_tests.gd     (단위 테스트, 약 15분)
GODOT --path . -s res://tests/ui_smoke.gd                 (조작 점검, 창이 잠깐 뜬다)
GODOT --path . -s res://tests/benchmark.gd                (성능 측정)
```
