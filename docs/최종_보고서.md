# 소방 지휘관 RTS 훈련게임 — 최종 보고서

**기획서와 비교한 구현 방식, 개선점, 기획서보다 나은 방법**

작성일: 2026-11-09 · 대상 기획서: 「소방 지휘관 RTS 훈련게임 개발 기획안」(docs/references)
기준: 2025 재난현장표준작전절차(SOP), 소방전술 Ⅰ·Ⅱ·Ⅲ

## 1. 한눈에 보기

기획서의 로드맵(R0~R15)은 모두 만들었다. 그래픽 교체(G1)만 처음 결정대로 보류했다.

| 기획서 내용 | 상태 | 한 줄 설명 |
|---|---|---|
| 2장 SOP·교재 → 게임 규칙 | ✅ | 판정 42개 항목이 SOP 조항 번호를 달고, 해설에는 교재를 인용한다 |
| 3장 핵심 루프 (실시간·질문 카드·임무형 지휘) | ✅ | 실전 난이도는 멈추지 않는다. 질문 카드 35장, 선제지시 13종, 임무 조건 |
| 4장 스테이지 9개 | ✅ (스테이지마다 시나리오 1~4개) | 0 훈련탑부터 4-1 초고층까지. 정식 시나리오 18개, 캠페인 14장 |
| 5장 화재·연기·생존 모델 | ✅ | 구획 2층 모델과 칸 단위 연소, 특수현상, CO 교재 표, 산소, 호흡량 4단계 |
| 6장 유닛·차량·장비 | ✅ (굴절차 없음) | 2인 1조, 공기호흡기, 펌프·물탱크·구조·구급차, 방수포, 송풍기, 승강기 |
| 7장 질문 카드 | ✅ | 카드 1장 = SOP 조항 1개, JSON이라 교관이 고칠 수 있음, 4등급(화면에 안 보임) |
| 8장 평가·디브리핑 | ✅ | 5축(30/30/10/10/20), 판단 해설, 리플레이 보기, 인쇄용 보고서·CSV, 대원 성장 |
| 9장 화면·조작 | ✅ | 상황판·하단 콘솔·미니맵·원형 메뉴·끌어다 놓기·무전 자막 |
| 10장 기술·저사양 | ✅ | 노트북(i5, 내장 그래픽)에서 55fps, 가장 무거운 25층도 1틱 30ms |
| G1 그래픽 교체 | ⏸ 보류 | 처음 결정대로 지금은 도형으로 그린다 |

숫자로 보면:

## 2. 게임은 이렇게 돌아간다 (쉽게)

### 2-1. 불과 연기: "방마다 위층 연기층과 아래 맑은 층"
- 건물을 **방(구획)** 단위로 나눈다. 방마다 천장 아래 **뜨거운 연기층**과 바닥 쪽 **맑은 층**이 있고, 두 층의 온도·두께·산소·그을음을 계산한다(교재의 "중성대"와 같은 생각).
- 바닥은 **0.5m 칸**으로 나눈다. 칸마다 소파·침대 같은 가연물이 있고, 불은 칸에서 칸으로 번진다.
- 문·창이 열리고 닫히는 데 따라 공기가 드나든다. 그래서 아래 현상이 계산 결과로 일어난다.
  - 플래시오버(약 500℃)
  - 롤오버
  - 백드래프트(산소가 모자란 닫힌 방을 갑자기 열 때)
  - 화재가스발화 350℃
  - 가스 폭발, 붕괴, 샤프트를 통한 위층 확대
- **중요한 원칙**: 오답을 고른다고 사고가 "벌칙"으로 나지 않는다. 사고는 그 방의 실제 상태(온도·산소·가스)가 만든다. 운 좋게 넘어가도 디브리핑에서는 오답으로 짚어 준다.

### 2-2. 대원: "2인 1조, 공기, 열"
- 대원은 늘 **2인 1조**로 움직인다.
- **공기호흡기**는 교재 공식(6.8ℓ × 300bar, 경보 55bar)으로 줄어든다.
  - 호흡량은 활동에 따라 40·55·65·80ℓ/분이다.
  - 고열 구역에서는 ×1.3, 경보가 울린 뒤 호흡조절을 하면 ×0.8이다.
- 출구까지 가는 데 필요한 공기를 계산해, 모자라기 전에 **"퇴각 건의"** 무전을 보낸다.
- 복사열이 쌓이면 열 스트레스로 쓰러진다. 쓰러지면 긴급탈출 상황이 되고 RIT가 출동한다.
- 대원은 이름이 있다. 판을 마칠 때마다 경험치가 쌓여 **신임 → 일반 → 숙련 → 고참**으로 자라고, 단계가 오르면 공기·열에 강해진다.

### 2-3. 지휘: "보이는 곳은 직접, 안 보이는 곳은 임무와 무전"
- **밖**(지휘관 눈에 보이는 곳): 우클릭으로 차량·대원을 바로 움직인다.
- **건물 안**: 대원을 칸칸이 조종하지 않는다.
  - "2층 검색", "1층 거실 진압" 같은 **임무**를 준다.
  - 철수 잔압, 화점 발견 시, 요구조자 발견 시 행동을 **임무 조건**으로 미리 정한다.
- 건물 안 지시는 **무전**으로 간다. "진압1 1조, 1층 거실로 이동하라" → (2~3초) → "이동하겠음".
  - 다른 무전이 나가고 있으면 기다린다. 여러 조에 동시에 지시하면 늦어진다.
- **구조는 직접 밝힌다**: 처음에는 건물 안 벽이 보이지 않는다. 대원이 본 곳만 지도에 남는다.
  - 방재실에 조를 보내면 도면을 얻는다. 지휘대가 도착하면 상황실에서도 도면이 온다.
  - 도면을 얻으면 미니맵이 열리고 방 단위 임무가 가능해진다.
  - 도면과 실제가 다른 곳(발코니 확장 등)은 대원이 보면 알게 된다.

### 2-4. 질문 카드: "대원이 묻고, 지휘관이 답한다"
- 잠긴 문, 백드래프트 징후, 요구조자 발견, 공기 경보 같은 순간에 **질문 카드**가 뜬다.
  - 긴급 8초, 중요 12초, 일반 20초 안에 답한다.
  - 답하지 않으면 대원은 지시를 기다리며 멈춘다.
- 정답·오답은 게임 중에는 보이지 않고, 디브리핑에서만 공개한다.
- **질문을 줄이는 것도 실력**이다. 질문을 줄이는 방법은 세 가지다.
  - 선제지시
  - 임무 조건
  - 지휘권 이양 뒤 단위지휘관 대리 처리

### 2-5. 평가: "누가가 아니라 무엇이"
- 5축 배점: 대원 안전 30, 인명구조 30, 재산 보호 10, 화재 안정화 10, SOP 준수 20.
- 판정 42개 항목이 판 기록을 보고 점수를 매긴다. 항목마다 SOP 조항과 교재 해설이 붙어 있다.
- 치명적인 선택을 하면 등급이 B를 넘지 못한다.
- 디브리핑은 4단계다: ① 무엇을 계획했나 ② 실제로 무슨 일이 ③ 왜 일어났나 ④ 다음에는.
  - 어느 시점부터든 **다시 하기**나 **리플레이 보기**를 할 수 있다.
  - **보고서 저장**으로 인쇄용 HTML(PDF로 저장 가능)과 CSV(교관 취합용)를 만든다.

## 4. 기획서와 다르게(또는 덜) 만든 것

정직하게 적는다.

1. **소리가 없다.** 무전 교신음, 잔압 경보음, 휘파람·균열음 같은 징후 소리가 아직 없다. 기획서 8장의 "실시간 긴장감" 요소다.
2. **굴절차·고가사다리차가 없다.** 외부 구조와 고소 방수는 공기안전매트·방수포로만 한다.
3. **스테이지당 시나리오가 1개뿐인 곳이 있다.** 필로티·시장·지하·창고·초고층·고층 2-2가 그렇다. 지도는 있으니 발화 위치·시간대·요구조자만 바꿔 쉽게 늘릴 수 있다.
4. **신임 대원 오보고가 없다.** 기획서의 "신임 대원은 일정 확률로 위치를 틀리게 보고"는 아직 넣지 않았다. 관계인 진술이 틀리는 것은 있다.
5. **굴뚝효과·스프링클러·임시응급의료소가 없다.** 고층 계단실 연기는 기존 연기 모델만으로 오른다.
6. **혼자 배정하는 대원이 없다.** 남는 1명을 관창보조·방재실 연락으로 쓰는 기능이 없어 선착대 분대원을 4명으로 두었다.
7. **START 분류를 플레이어가 하지 않는다.** 구조된 사람은 자동으로 분류하고, 긴급 환자가 나오면 카드가 뜬다.
8. **exe 파일은 아직 만들지 않았다.** 내보내기 설정과 배치 파일은 준비했다. 이 PC에 내보내기 템플릿(약 1GB)이 없어 한 번 설치가 필요하다.
9. **그래픽은 도형이다(G1 보류).** 기획서도 "초기에는 단색 도형"이라 했고, 사용자 결정으로 보류했다.
10. **"추정" 수치가 많다.** 호흡량 55·65·80, 카드 제한시간, 옥내소화전 수조, 방수포 방수량 등이다. 모두 `source: 추정`으로 표시했고 현장 검수가 필요하다.

## 5. 개선이 필요한 점 (우선순위)

| 순위 | 할 일 | 왜 |
|---|---|---|
| 1 | **현장 검수**: "추정" 수치 목록을 뽑아 경력자가 확인 | 교육 효과는 수치의 신뢰도에서 나온다. JSON에 `source`가 있어 자동으로 목록을 뽑을 수 있다 |
| 2 | **소리 넣기**(무전음·경보음·징후음) | 긴장감과 징후 인지 훈련에 크다. 그래픽보다 비용 대비 효과가 크다 |
| 3 | **시나리오 늘리기**(스테이지당 3개) | 지도는 있으므로 시나리오 JSON만 쓰면 된다. 교관이 직접 만들 수 있는 시나리오 편집기도 이미 있다 |
| 4 | **시범교육 → 피드백** | 기획서 4-1의 권장대로 2-1 아파트로 직원 시범교육을 해서 조작 난이도·카드 문구를 다듬는다 |
| 5 | 굴절차·사다리차 | 고층·필로티에서 외부 구조 선택지가 생긴다 |
| 6 | 신임 대원 오보고, 혼자 배정 대원 | 정보의 불확실성과 인력 배분 판단을 가르친다 |
| 7 | exe 배포 | 템플릿 설치 후 `실행파일_만들기.bat` 한 번이면 된다 |
| 8 | 그래픽 교체(G1) | 마지막에 한 번에 한다. 그리기 코드가 한 곳에 모여 있어 교체가 쉽다 |

## 6. 기획서보다 더 좋은 방법 (제안)

1. **"임무 조건" = 선제지시의 진화형으로 정리하기**
   - 지금은 선제지시(전체)와 임무 조건(조별)이 함께 있다.
   - 교육적으로는 "조별로, 임무를 줄 때 조건을 같이 정한다"가 실제 지휘(SOP 107 지시 요령)에 더 가깝다.
   - 선제지시를 "모든 조 기본 조건"으로 합치면 화면이 단순해지고 개념도 하나가 된다.
2. **"지휘관이 안 것 vs 실제" 나란히 보기**
   - 기획서 9-1이 말한 비교를 리플레이에 겹쳐 보여 준다(왼쪽: 그때 지휘관 화면, 오른쪽: 실제 불·사람).
   - 구조와 정보 안개 데이터는 이미 따로 저장하고 있어 추가 비용이 작다.
   - "왜 몰랐나"를 가르치는 가장 강한 장면이 된다.
3. **교관 실시간 개입 모드**
   - 교관이 교육 중 사건을 넣는다: "지금 대원 1명 무전 두절", "2층에서 요구조자 목소리".
   - 같은 시나리오도 매번 달라지고, 교관이 약점을 집중 훈련시킬 수 있다.
4. **무전을 음성으로(TTS)**
   - 자동으로 만든 무전 문장을 음성으로 읽어 준다.
   - "듣고 판단하기"는 실제 현장 능력과 직결된다. 자막은 그대로 둔다.
5. **2인 협동(지휘관 + 단위지휘관)**
   - 지휘권 이양·단위지휘관 구조가 이미 있다. 두 사람이 망을 나눠 쓰는 협동 훈련으로 확장할 수 있다.
6. **약점 맞춤 시나리오 자동 추천**
   - 결과 CSV에 틀린 SOP 조항이 쌓인다.
   - 자주 틀리는 조항이 나오는 시나리오·카드를 다음 훈련으로 추천한다.
7. **수치 검수표 자동 생성**
   - 모든 수치가 JSON에 `source`를 달고 있다.
   - "추정" 항목만 뽑아 검수용 엑셀을 만들어 주는 도구를 붙이면, 1번(현장 검수)이 쉬워진다.

## 7. 직접 확인하는 순서 (추천)

1. **튜토리얼 → 훈련탑(0)**: 조작에 익숙해지기.
2. **주택화재 ①**: 지휘권 선언, 진입 명령, 임무(W·Q), 질문 카드, 완진·종료, 디브리핑.
3. **고층 아파트 ①(15층)**: 출동 준비 장비, 옥내소화전 → 송수구, 방재실 도면·미니맵.
4. **고층 아파트 ④(25층)**: 승강기, 지휘권 이양, 단위지휘관 대리.
5. **지하층(3-2)·창고(3-3)·초고층(4-1)**: 라이트라인, 진입 판단, 피난안전구역.
6. 디브리핑에서 **리플레이 보기**·**보고서 저장**을 해 본다.

단계별 자세한 확인 방법은 `docs/test_guides/`(R1~R15)에 있다. 설치·배포는 `docs/배포_안내.md`를 본다.
